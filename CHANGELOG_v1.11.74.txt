ПРОЧиталка v1.11.74-beta CLEAN — изменения относительно v1.11.73-beta

1. Приоритетное скачивание произвольного предложения Edge TTS
   Файлы: EdgeDownloadService.java, EdgePlaybackService.java (без изменения API).
   - Устранена зависимость выбора предложения от ранее подготовленного
     непрерывного диапазона MP3. Точная позиция в книге — источник истины.
   - Весь текст индексируется по SentenceChunks, максимальная длина 600 символов.
   - При нажатии на слово выбирается содержащее его предложение, без воспроизведения
     до Play (если автозапуск выключен).
   - Запущенная генерация другого предложения отменяется, запрос возвращается
     в список pending. Выбранное предложение синтезируется первым.
   - По завершении следующими идут текущее/следующее предложения, затем pending.
   - Если MP3 уже сохранён на диске, он используется без новой загрузки.
   - Запрос, выбранный до окончания чтения текста книги, запоминается.
   - При ожидании выбранного предложения плеер не запускает посторонние MP3.

2. Постоянный индекс EdgeTTS/sentences.json
   - Создаётся запись для КАЖДОГО предложения с start/end, хешем аудиофайла,
     полями ready, status (saved/downloading/pending/missing), played, queued.
   - Запись атомарная (android.util.AtomicFile), при перезапуске восстанавливаются
     незавершённые задания. Хранятся сами MP3 и .words.json отдельно.
   - Сохраняется совместимость с ранее скачанными файлами и старыми индексами.
   - При смене голоса создаётся соответствующий индекс по ключам нового голоса,
     но MP3 других голосов не удаляются.

3. Системные панели без отдельной светлой подложки
   - В SafeSystemBars добавлен matchBackground(activity,color).
   - В EdgeOnlineActivity область статус-бара, системной навигации и фон книги
     получают один цвет. Системные значки меняют контраст под фон.
   - Сохраняется существующая обработка безопасных WindowInsets на Android 15+.

4. Остаток времени таймера сна в TTS
   - Вместо одной иконки таймера — компактный блок 44dp (иконка сверху,
     обратный отсчёт внизу).
   - Используется общая audio_sleep_deadline: корректно для локального TTS и Edge.
   - Остаток обновляется вместе с плеером, исчезает при выключенном таймере.
   - Не меняется сам механизм остановки озвучки и переключения движка.

5. Тестирование и чистота архива
   - qa/check_sentence_chunks.sh: максимальная длина 600, сохранение смещений.
   - qa/check_java_syntax.sh: проверка синтаксиса всех Java-файлов через JavacTask.
   - Проверка XML, сравнение 18 спрайтов с v1.11.73 и ZIP integrity.
   - В CLEAN-архиве только документация v1.11.74.

ВАЖНО: полноценная сборка assembleRelease и поведение TTS на реальном телефоне
не проверены локально (Android SDK и Gradle отсутствуют).
