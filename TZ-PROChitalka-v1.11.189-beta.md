# ТЗ — ПРОЧиталка v1.11.189-beta CLEAN

## 1. Плавная прокрутка при TTS

Основа `v1.11.188-beta CLEAN`. Переработать автопрокрутку через независимый `ReaderTtsScrollController`. Управляющий параметр — текущая координата **произносимого слова** по WordBoundary, не видимость части предложения. Пока слово в зоне чтения, не двигать viewport; у нижней границы примерно 65–70% полезной высоты обеспечить плавное сопровождение без регулярного повторного центрирования. Поддерживать единственную отменяемую анимацию с изменяемой целью и без конкурирующих `smoothScrollBy`; постепенное прохождение соседних блоков RecyclerView. Мгновенное перемещение разрешено только по явному переходу на далёкую позицию.

Ручной скролл, выделение, перемещение маркеров, пауза и закрытие/смена экрана отменяют автосопровождение. Оно не возобновляется после ручного скролла без явного действия пользователя; при возврате к текущему слову проверять поколение навигации (`viewportNavigationEpoch`). Не менять позицию TTS, не пересоздавать MP3 и не портить аннотации. В журнал `TTS_SCROLL` добавить начало, цель, завершение, пропуск, отмену, ручную прокрутку, явный возврат. Проверить длинные предложения, скорость речи, ручной скролл, маркеры, паузу и переходы между MP3/главами.

## 2. Речевое облачко питомца

Запрещено увеличивать внешний контейнер, карточку и окно питомца ради цитат. Исходный `petSpeechFrame` оставить высотой `260 dp` и не менять расположение питомца. Подбирать только размер **самого облачка** по длине цитаты, в пределах свободной области. Короткая цитата — компактный пузырь; средняя — расширение без изменения карточки; длинная — обрезание видимого текста многоточием `…` в конце (`TextUtils.TruncateAt.END`), без вертикальной прокрутки пузыря. Полный текст остаётся в SQLite, без изменений. Сохранять внешний вид и анимацию питомца, хвостик облачка, обычные реплики и вероятность категорий `50% обычные / 50% цитаты` при наличии разрешённых цитат.

## 3. Выпуск и контроль качества

Полный исходный архив ZIP, `versionCode=18900`, `versionName=1.11.189-beta`, четыре MD документа только текущей версии. Автономные тесты контроллера и размеров облачка; регрессионные тесты Edge TTS, WordBoundary, выделения, цитат и питомца. Команды встроить в GitHub Actions до сборки APK. Результат проверять также на Android-устройстве, записью диагностического TXT.
