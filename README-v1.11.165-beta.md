# ПРОЧиталка v1.11.165-beta — установка, SAF, проверка

## Комплект

Полный исходный Android Java проект, Gradle-конфигурация, XML-ресурсы, класс `ReaderMarginMarksTextView` для отображения левых маркеров, `CategorySafRecovery` для ручной SAF-публикации, локальные QA-тесты. APK не включён.

Версия: `1.11.165-beta`, `versionCode 16500`, JDK 17. Изменения подробно описаны в `CHANGELOG-v1.11.165-beta.md`. README и CHANGELOG прошлых версий в архиве отсутствуют.

## Как выбрать папки на Android 16

1. Откройте **Настройки → Загрузки / Онлайн**.
2. Нажмите **Book** и через системный Android SAF выберите существующую папку `Book`. Подтвердите доступ.
3. Аналогично отдельно выберите **Manga** → `Manga` и **Audiobook** → `Audiobook`.
4. Убедитесь, что статус каждой папки — **доступна**. Выбор каждой папки выполняется отдельно, они могут находиться на разных накопителях.
5. В универсальном менеджере загрузки откройте «Мета»: там указан путь/состояние папки соответствующей категории и кнопка её изменения.

Для Android 11+ корень всего внутреннего накопителя или защищённые системные папки могут быть недоступны. Выбирайте именно сами папки `Book`, `Manga`, `Audiobook`, а не корень внутренней памяти.

## После изменения пути

Новые загрузки автоматически сохраняются в выбранную папку соответствующей категории. Для ранее скачанных файлов нажмите **«Повторить сохранение готовых файлов в SAF»** в настройках. Действие работает в фоне, использует локальные данные и не удаляет старые файлы, выводит сводку сохранённых и недоступных файлов.

## Что проверить на устройстве

1. Создайте заметку с текстом и закладку на разных строках книги: в левом отступе должны появиться мини-иконки.
2. Создайте несколько заметок на одной строке, убедитесь в счётчике и открытии горизонтального списка.
3. Нажмите на существующую заметку и вернитесь к чтению: ручки выделения не должны появляться.
4. Долгий тап, расширение выделения и прокрутка должны продолжать работать как в v1.11.164.
5. Импортируйте EPUB/FB2/HTML: книга должна появиться внутри Book и открываться из нового SAF-адреса.
6. Скачайте главу RanobeLIB и Ranobes.net: HTML/обложка должны появиться внутри Book.
7. Скачайте главу MangaLib: CBZ должен появиться внутри Manga и открываться в комикс-ридере.
8. Скачайте трек «Книга в ухе»: MP3 должен появиться внутри Audiobook и открываться через Аудиотеку по SAF-адресу.
9. Создайте озвучку Edge TTS: результат должен сохраняться в категории Book.
10. Измените путь одной категории и воспользуйтесь ручным восстановлением; остальные две категории должны остаться прежними.
11. Перезапустите приложение и телефон; проверьте, что папки и ранее открываемые файлы доступны.

## Сборка APK

На машине с Android SDK 35+, Gradle 8.7+, JDK 17 выполните:

```bash
gradle --no-daemon :app:assembleRelease --stacktrace
```

Ранее пользователь использовал GitHub Actions для сборки. Если сборка выдаёт новые ошибки, приложите полный лог `compileReleaseJavaWithJavac` или `mergeReleaseResources` для точечного исправления. В среде подготовки пакета выполнялась синтаксическая проверка Java (не полноценная типовая проверка Android) и структурные локальные тесты.
