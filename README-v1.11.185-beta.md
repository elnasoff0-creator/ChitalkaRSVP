# ПРОЧиталка v1.11.185-beta CLEAN

Полные исходники приложения. Исправлена регрессия выделения текста и переходов
чтения после внедрения системного TextView selection в v1.11.184.

## Основное

- Штатное выделение Android в пределах одного текстового блока сохранено.
- Долгое нажатие/перетаскивание маркеров больше не вызывает случайный переход к слову.
- Внутри одного TextView диапазон управляется Android; между строками RecyclerView —
  единым диапазоном UTF-16 всего текста книги с собственными маркерами.
- Новые и старые заметки, цитаты, закладки и контекстное меню остаются доступными.
- Позиция чтения синхронизируется только с подтверждённым активным MP3 или TTS.
- Старые callback/метаданные Edge, потеря временной WordBoundary-разметки и поздние
  команды старого плейлиста не должны возвращать подсветку назад.
- Во время выделения автоматическая прокрутка приостанавливается.

## Версия

`versionName = 1.11.185-beta`, `versionCode = 18500`, Java 17, Android compileSdk 35.

## Проверка и сборка

Запустить `bash qa/test_reader_selection_navigation_185.sh`,
`python3 qa/check_v185_contracts.py` и `bash qa/check_java_syntax.sh`.
Готовый `app` + `qa` + `.github` + файлы Gradle разместить в репозитории.
GitHub Actions выполняет `:app:assembleRelease` и подписывание при наличии секретов.

Полная Android-компиляция и жестовые тесты на реальном устройстве здесь не проводились.
