# CHANGELOG — ПРОЧиталка 1.11.188-beta CLEAN

## 1. Принудительное переключение TTS

**Дефект в v1.11.187:** в `ReaderActivity.chooseTtsEngine()` при совпадении выбора пользователя с `ttsLocal` происходил досрочный `return`, несмотря на работающий резервный `AudioPlaybackService`. Таким образом, повторный выбор Microsoft Edge не останавливал Google/RuVoice, а бейдж продолжал показывать резервный движок.

**Исправление:**
- Добавлен `TtsSwitchPolicy.shouldSwitch()`: одинаковый выбранный Edge **не** является no-op, если активна fallback-сессия.
- `ReaderActivity` запоминает состояние воспроизведения и текущий индекс; при переключении в Edge отправляет команду `STOP` в `AudioPlaybackService` и повторно готовит Edge с сохранением Play/Pause.
- `ReaderTtsController.begin(...)` передаёт новое поле `EXTRA_FORCE_EDGE` и разрешает автопродолжение только при прежнем активном Play. Для обычного локального TTS также передаётся режим автопродолжения.
- `EdgeStreamingService` обнуляет старую ошибку и retry-флаги запрошенного клипа, отменяет устаревшие live-задачи, очищает старую очередь Media3 через `setAnchor(selected,true)`. Новый сетевой запрос не должен наследовать отменённый буфер старого Edge.
- В `AudioPlaybackService` при `STOP` отменяется ожидающее автозапускание и повышается поколение асинхронной загрузки книги: старый callback не может запустить резервный движок повторно после Stop.
- При любом событии `ACTION_STATE` в TTS-режиме ReaderActivity обновляет состояние; бейдж строится по фактическому активному движку, а не только по предпочтению пользователя.

## 2. Ускоренный первый звук Edge TTS

- `ReaderActivity.toggleTtsPlayback`: заменена медленная проверка `EdgeFolderPicker.available` с синхронным SAF `DocumentFile.exists()` на лёгкую проверку **сохранённых разрешений** `DownloadFolderPicker.granted`. Достоверная проверка физической папки остаётся на стороне фонового сохранения и выдаёт ошибку при реальной недоступности.
- `EdgeFirstAudioPolicy`: для foreground аудио введено окно восстановления SAF **160 мс**, для фонового восстановления сохранено **9000 мс**. При превышении окна — сеть синтезирует недостающий файл; пользователь не ждёт полного тайм-аута SAF.
- Если при нажатии Play уже выполняется фоновое восстановление, оно не блокирует новый запрос; его `AtomicBoolean` разрешения публикации отменяется.
- В `EdgeChapterArchive.restoreClip` перед публикацией `MP3` и `.words.json` проверяется отмена и наличие уже готового файла. Поздний SAF-восстановитель не должен перезаписывать готовый файл нового синтеза. Старое восстановление целой главы (legacy v1), которое не допускает безопасной отмены, не запускается в рамках гонки foreground с WebSocket и может потребовать отдельного восстановления через менеджер загрузок.
- Полная сборка групп по предложениям всё ещё происходит в фоновом потоке перед `bookReady`. Она теперь измеряется в логе, но **не считается полностью оптимизированной** в этой версии. Группировка сохранена для совместимости кеша.

## 3. Расширенная диагностика

- Новый `EdgeStartupTrace.java`: сквозной монотонный идентификатор одного запуска Play, прошедшее время и дедупликация этапов. События `EDGE_STARTUP`: `PLAY`, `SAF_PERMISSION`, `BOOK_OPENED`, `BOOK_REUSED`, `GROUP_INDEXED`, `BOOK_READY`, `CLIP_PREPARED`, `SAF_RESTORE_CHECK`, `SAF_RESTORE_BYPASS`, `TRACK_READY`, `NETWORK_REQUEST`, `WS_CONNECTED`, `FIRST_MP3_PACKET`, `FIRST_AUDIO` или `CANCEL`.
- События `TTS_SWITCH`: ручной выбор, запрос остановки локального сервиса, фактическая остановка, повторная активация Edge, обновление бейджа, запуск и продолжительность инициализации fallback.
- `ReaderDiagnosticLog` скрывает сетевые URL, `content://`, `file://` и распространённые абсолютные локальные пути; полный текст книги и SSML не записываются.
- `ReaderLogActivity` показывает назначение новых событий; экспорт остался через системное меню «Поделиться» после включения режима разработчика.
- Новые unit tests для двух политик и проверки корреляции журнала; подключены к GitHub Actions.

## 4. Что сохранено

Принцип **не разрезать предложения** в Edge TTS; существующие MP3 и WordBoundary; переключение TTS только после подтверждения ошибки, если включён резервный TTS; оформление бейджа без фоновой подложки; цитаты и питомец 50/50; собственные маркеры выделения; анимация загрузок.

## Ограничения

Не проводилась полноценная Android Gradle-компиляция и ручные измерения фактического звука на смартфоне. Отдельно проверить взаимодействие с устаревшими архивами SAF (legacy v1) и действительно медленным провайдером документов.
