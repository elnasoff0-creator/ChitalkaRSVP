# ПРОЧиталка v1.11.167-beta CLEAN — сборка и проверка

Полный Android Java-проект. Базовая версия — v1.11.166-beta.

## Конфигурация

- Android Gradle Plugin и Gradle использовать совместимые с существующим `build.gradle` и вашим CI.
- Java 17.
- `compileSdk` 35, `targetSdk` 35, `minSdk` 24.
- `versionCode 16700`, `versionName 1.11.167-beta`.
- Команда CI: `gradle --no-daemon :app:assembleRelease --stacktrace` (при наличии Android SDK и зависимостей).

## Что проверить на Android 16

1. Открыть менеджер загрузки Edge TTS и обычной аудиокниги. **Обе вкладки «Файлы» и «Инфо» должны быть видны**, одинакового размера; не прокручивать горизонтально ради второй.
2. На вкладке «Инфо» проверить путь именно к папке `Book`, `Manga` либо `Audiobook` в зависимости от типа задания, без имени отдельного файла. Проверить иконку папки справа и выбор SAF.
3. В «Настройках» проверить пять вкладок **только с иконками**, переключить все разделы и убедиться, что заголовок обновляется как «Настройки · ...». Прокрутить вниз, переключить вкладку и вернуться — позиция должна сохраниться.
4. Сверить вертикальную позицию toolbar между менеджером и настройками. Кнопка бокового меню и заголовок должны использовать одну геометрию.
5. Проверить вкладки «Замены / Игнорировать» словаря Edge TTS и «Книги / Циклы» поиска аудиокниг: браузерный стиль без залитой акцентом вкладки; действия работают.
6. Смахнуть карточку загрузки влево. **«В архив» акцентного цвета темы, «Отмена» обычного цвета кнопок.** После смены темы проверить оба цвета и читаемость. Архивация только по нажатию.
7. Проверить меню «три точки» в общем списке загрузок, архиве, менеджере файлов и читалке: видна только иконка, но вся область остаётся удобной для нажатия.
8. Проверить подтверждения удаления и переименования, редактор шрифта, меню выбора источника: углы скруглены, текст не обрезан, действия выполняются.
9. Проверить, что после новых UI-изменений продолжают работать Play/Pause загрузки, «Скачать всё», управление главами, Edge TTS и сохранение через SAF.
10. Проверить в дневной, ночной, сепии и пользовательской теме, в портретной/альбомной ориентациях.

## Локальные проверки без Android SDK

```sh
sh qa/check_java_syntax.sh
python qa/test_v167.py
```

Эти проверки не собирают APK и не проверяют выполнение Activity. Для подтверждения сборки запустить CI на Android SDK и проверить `:app:assembleRelease`.
