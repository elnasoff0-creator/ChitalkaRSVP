# QA — ПРОЧиталка v1.11.198-beta

База: v1.11.197-beta CLEAN. VersionCode 19800.

## Фактически выполнено
- 41 из 41 групп итогового локального прогона завершились с кодом 0. Журнал: `qa/qa-results-v198.txt`. В него входят команды текущего GitHub Actions, дополнительные JVM-проверки ReaderActivity, BookLoader и миграции.
- Java: синтаксический разбор 240 файлов. Это не проверка типов всего Android-проекта.
- Реальные JVM-классы EdgeSpeechSegments, EdgeSpeechSize, EdgeSpeechLayout: обычные целые предложения, аварийное деление слишком длинного предложения, непрерывные исходные индексы, фактические байты экранированного SSML, сохранение прежних схем кэша, соответствие стабильного префикса полному каталогу — PASS.
- На синтетическом тексте из 100 длинных абзацев историческая схема дала 100 блоков, новая — 44. На другом примере из 100 коротких абзацев новая схема дала 7 блоков, начальный префикс — 2. Это количество блоков, а не измерение скорости сети или речи.
- `test_edge_fits_198.sh`: проверка эквивалентности быстрого подсчёта и реального преобразования текста для пустого, старого, игнорирующего и SQLite-словаря — PASS. Добавлена в GitHub Actions.
- Очередь и транспорт на заглушках: Retry-After в секундах и HTTP-дате, резервные 500 мс, приоритет Play, отсутствие лишнего транспортного ретрая, повторное использование WebSocket и отмена — PASS. Проверка 47 секунд вместо старого ошибочного ожидания 500 мс обновлена в тесте reuse pool.
- Предыдущие тесты TTS, синхронизации, Web Transfer, жизненного цикла, статистики и миграции — PASS.
- Дополнительная проверка оригинального текста EPUB/HTML компилировалась с API-заглушками; реальный XML-парсер FB2 прошёл. Реальный jsoup отсутствует локально, поэтому проверка EPUB/HTML ожидает GitHub Actions.

## Известные ограничения и незавершённые проверки
- Полная Android-компиляция и APK не выполнялись: в окружении нет Gradle и Android SDK. Новый двухфазный запуск и повторные запросы проверены статическими контрактами и тестами отдельных Java-компонентов, но не полноценным Android/Media3-интеграционным тестом.
- Реальный сетевой синтез Microsoft не выполнялся. Ускорение первого звука на телефоне и устойчивость воспроизведения новых книг ещё не подтверждены. Поздние позиции в крупных книгах и первичный разбор/миграция RBI5 могут ждать полный расчёт.
- Для ранее сохранённых маркеров EdgeTTS оставлена прежняя схема группировки ради совместимости; сокращение числа запросов за счёт объединения абзацев применяется к новым схемам. Аварийное деление слишком длинных предложений применяется и к старым схемам. Патологически длинное единственное слово не дробится. Изменение словаря после построения каталога и целые ранее подготовленные аудиоглавы требуют дополнительной проверки.
- Исторический необязательный `qa/test_edge_text_transform.sh` отдельно запускался и остановился на устаревшем утверждении `V1 regular punctuation`: автоматические замены пунктуации были отменены ранее, а этот тест не входит в действующий workflow. Новый тест `test_edge_fits_198.sh` использует актуальное поведение. Не выдавать исторический тест за пройденный.
- Ранее известные ограничения Web Transfer и визуальной проверки Android из v196/v197 сохраняются.
