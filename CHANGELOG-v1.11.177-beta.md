# ПРОЧиталка v1.11.177-beta CLEAN — изменения исходников

- Сохранён пункт «Загрузка озвучки» в ReaderActivity. Теперь он открывает UnifiedDownloadManagerActivity для текущего URI книги, включая случай до первой загрузки MP3.
- Добавлена отправка события изменения словаря после успешного изменения SQLite, с исключением повторного сохранения полностью идентичного правила.
- EdgeStreamingService сразу сопоставляет текущий фрагмент с новым произносимым текстом. При изменении ключа остановливает старый аудиоисточник, сохраняет Play/Pause и возобновляет синтез выбранного предложения онлайн.
- Обновление ожидаемых фрагментов: текущий, пять следующих, вся текущая глава, следующие главы и предыдущие главы в простое. Проверка выполняется порциями вне UI-потока. Старые задачи игнорируются по поколению.
- Аудиофайл повторно используется при совпадении нового ключа. Запоздавшие завершения сетевых задач не могут привязать старый MP3 к новому ключу.
- Фоновый загрузчик глав переходит на новое поколение словаря вместо публикации устаревшей очереди.
- В индекс сохранённой главы добавлена ревизия словаря. Менеджер помечает главы, ожидающие проверки, и подготовка всей книги повторно проверяет такие главы. Неизменившиеся ключи не требуют нового синтеза.
- Версия приложения: versionCode 17700, versionName 1.11.177-beta.
- Сохранён предыдущий release.yml с поддержкой тегов с суффиксом beta и без него.

## Ограничения проверки

Сделаны структурные проверки и отдельные Java-тесты TTS. Полная Android Gradle-сборка, работа Media3, SAF, фоновое воспроизведение и UI на устройстве в этой среде не проверены: Android SDK/Gradle wrapper отсутствуют. До релиза обязателен прогон CI и ручные тесты смены правил во время воспроизведения.
