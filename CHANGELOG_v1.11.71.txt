ПРОЧиталка v1.11.71-beta — CLEAN / единый TTS-плеер

Основа: v1.11.70-beta.

1. Единый экран для системного TTS и Microsoft Edge.
   - Из ReaderActivity убран предварительный диалог «Способ озвучивания».
   - Кнопка TTS сразу открывает EdgeOnlineActivity, использующую выбранный ранее движок.
   - При переключении метода используется тот же тип Activity и сохраняется позиция книги.

2. Верхняя панель TTS компактна: шесть одинаковых по внешним габаритам кнопок.
   - Назад: существующая контурная стрелка.
   - Метод озвучивания: существующие ic_android_tts и ic_edge_tts, без подписи и диалога.
   - Выбор голоса: ic_tts_engine. Edge: Дмитрий/Светлана; системный: диалог установленных локальных русских голосов с переходом к полной настройке движков.
   - Таймер сна: существующий ic_sleep_timer с фоновой подложкой.
   - Настройки: ic_settings открывает SettingsActivity на вкладке Аудио.
   - Скорость: существующий спидометр + WPM, общий диалог с пресетами и шагом ±10.
   - Название книги удалено из визуальной панели (сохраняется во внутренних метаданных).

3. Нижняя панель:
   - Только время прослушивания / расчётное время всей книги, Play/Pause, процент сохранения Edge MP3 (для локального режима 0%), кнопка «Загрузки».
   - Убраны многословная статистика и кнопка папки MP3.
   - Файлы Edge сохранены и доступны в экранах загрузок / управления аудиоданными.

4. SettingsActivity -> Аудио:
   - Создан единый минималистичный список карточек с контурными иконками в стиле утверждённого референса.
   - Вся настройка Edge TTS перемещена из вкладки «Онлайн» в раздел TTS.
   - Разделы TTS и «Аудиокниги MP3 / M4A» разделены линией.
   - Новые векторные ресурсы: ic_tts_waveform, ic_tts_autoplay, ic_tts_document, ic_tts_pause_trim, ic_tts_storage, ic_tts_background.
   - Предыдущие настройки не утеряны: автовоспроизведение по касанию, конечные паузы Edge, WPM, выбор локальных голосов, эквалайзер, интервал перемоток, таймер.

5. Не изменены: правило 600 символов на фрагмент, Edge WordBoundary, постоянные Edge MP3 и временный кэш системного TTS, 18 VectorDrawable спрайтов Чтейца, MP3/M4A плеер.

Проверки: синтаксический разбор Java (69 файлов); разбор XML; тест SentenceChunks (лимит 600); проверка связей с drawable-ресурсами и ZIP.
Ограничение: полная сборка Gradle и тесты на телефоне не выполнялись (в окружении отсутствует Android SDK/Gradle). Наличие исходников не гарантирует успешный assembleRelease без проверки в GitHub Actions.
