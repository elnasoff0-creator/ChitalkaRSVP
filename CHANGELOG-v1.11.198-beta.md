# ПРОЧиталка v1.11.198-beta — Edge TTS HOTFIX

База: v1.11.197-beta CLEAN. VersionCode: 19800.

## Запуск и производительность
- Для начала длинной книги (до 512-го предложения) сначала строится стабильный префикс каталога аудиоблоков: до выбранного предложения и 64 следующих. Незавершённый последний блок не публикуется. Полный каталог формируется после публикации префикса, а уже созданные Clip, ключи MP3 и активные буферы сохраняются. Переход за ещё не готовую область откладывается до публикации каталога. Для коротких книг и поздних позиций остаётся полный расчёт.
- Используется один общий индекс предложений и исходных слов вместо повторного разбиения. Поиск главы переведён с линейного обхода на двоичный поиск. Чтение готовой книжной сессии не блокируется монитором, который нужен для сериализации новой загрузки и миграции.
- Подсчёт UTF-8/SSML теперь выполняется без выделения экранированной строки и regex для каждого кандидата. Словарь без совпадающих правил не создаёт лишнее сопоставление символов. Сложные правила по-прежнему проверяются через реальное преобразование.
- В новых папках Edge TTS соседние предложения из разных абзацев могут объединяться в пределах целевого размера и границ группировки глав. Существующие маркеры и папки старых MP3 сохраняют историческую схему для совместимости, включая потенциальный внешний SAF-кэш. Новые маркеры сохраняют режим группировки. Не удаляются пользовательские MP3.
- В случае превышения жёсткого бюджета 3840 байт текста (4096 с резервом SSML) длинное предложение делится по исходным границам слов с предпочтением естественной паузы. Не изменяется исходный текст, сохраняются индексы слов и символов. Обычные предложения не режутся по мягкому лимиту. Одно патологически длинное слово остаётся на прежнем пути обработки ошибки/резервного TTS, чтобы не потерять позиции.

## Ошибки и повторный запуск
- Учитывается Retry-After (секунды или HTTP-дата), 500 мс используется только как минимальная/резервная задержка. Верхняя защитная граница — 7 суток. Сохранённая задержка не обрезается до 500 мс при перезапуске.
- Для активного фрагмента возможен один повтор после временной ошибки, в том числе 429 с задержкой до 30 секунд. При более долгой блокировке или окончательной ошибке включается ранее настроенный резервный TTS, если условия выполнены, либо прекращается состояние бесконечной загрузки. Явный Play может повторить запрос, не обходя cooldown.
- Исправлена гонка между ошибкой сети и Media3: сетевой callback отвечает за собственную ошибку, а не дублирует повтор через декодер. Ошибка предварительной загрузки не должна навсегда блокировать первый запрос при переходе к этому фрагменту. Автоматическая спекулятивная повторная загрузка таких фрагментов запрещена.
- Ошибка загрузки книги позволяет повторно открыть ту же книгу через Play. Добавлена защита от устаревших callback смены книги.
- В существующей строке прогресса отображается подготовка книги/аудио, ожидание Edge TTS и предложение повторить. Для HTTP 429 всплывающие Toast по-прежнему не показываются.

## Совместимость
- Голоса, темп речи и настройки скорости воспроизведения не изменены. RBI5, оригинальный текст, оглавление, навигация, миграция и пользовательские данные v197 сохраняются. Web Transfer, питомец, рыбалка, общая статистика и награды не изменены.
- Полная Android-компиляция, сетевой запуск Microsoft Edge TTS, реальные времена до первого звука и совместимость всех старых целых аудиоглав остаются предметом тестирования на устройстве. Не гарантируется устранение сетевых ограничений Microsoft. При чтении далеко от начала большой книги ещё возможна полная группировка перед стартом.
