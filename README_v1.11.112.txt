ПРОЧиталка v1.11.112-beta CLEAN
================================
Основа: v1.11.111-beta CLEAN, без изменения принципов Edge WebSocket pool.

НОВОЕ
Настройки -> Аудио -> Диагностика -> Показать лог-файл.

Журнал хранится внутри приложения в files/diagnostics/, без READ_LOGS и
разрешения на хранение. Две части журнала по 512 КиБ. Запись асинхронная;
MP3 и сетевой поток не ждут дисковую запись. На экране журнала можно обновить,
поделиться текстовым файлом через Android Sharesheet и очистить журнал.

Записываются: очередь Edge TTS, WebSocket (открытие и повторное использование),
время до первого MP3-пакета и первого звука, завершение синтеза, HTTP-статусы,
кэш MP3, предварительная генерация, ошибки декодирования Media3.

Не записываются: содержимое книги, SSML, ключи, cookies, полный адрес запросов.
Это журнал СОБСТВЕННЫХ событий приложения, а не системный Android Logcat.

Особенно важно: в скриншотах Quickify ошибка HTTP 429 возникает в модуле
MS_TIME_SYNC, т.е. в отдельной операции синхронизации времени. Она не
доказывает ошибку текущей генерации MP3, поэтому может не тормозить чтение.
В ПРОЧиталке диагностика отдельно обозначает HTTP 429 TTS handshake.

СОХРАНЕНО
- Пул WebSocket из четырёх ресурсов (до двух фоновых запросов)
- Повторное использование сокетов между SSML-turn
- Потоковое MP3 в Media3
- Подсветка WordBoundary и MP3-кэш
- Фиксированный локальный предел ожидания 500 мс, без адаптивного backoff
- Никакого автоматического повтора после HTTP 429

ПРОВЕРКИ
24 QA shell-скрипта успешно выполнены, включая тест реального локального
журнала в Java-окружении, ротацию, редактирование секретных URL, экспорт и
очистку. Проверена синтаксическая корректность 105 Java файлов и XML.

ОГРАНИЧЕНИЯ
Android SDK и Gradle не были доступны для полноценной сборки. Реальное
открытие экрана на телефоне и работа с сетью Microsoft не проверены.

СБОРКА НА ANDROID SDK
./gradlew :app:assembleDebug (при наличии Gradle wrapper) либо
Gradle 8.x с Android Gradle Plugin, JDK 17, Android SDK Platform 35.

ИСПРАВЛЕНИЕ СИНХРОНИЗАЦИИ ВРЕМЕНИ MICROSOFT (та же v1.11.112-beta CLEAN)
- Асинхронно читается HTTP Date от уже существующего Edge WebSocket-handshake
  со статусом 101 и от отдельных ответов ошибок, в том числе 429.
- Смещение сервера сохраняется между запусками и учитывается в Sec-MS-GEC.
- Коррекция HTTP 403 / одна повторная попытка оставлена без изменений.
- Дополнительного MS_TIME_SYNC подключения нет: новый запрос синхронизации
  сам мог бы столкнуться с HTTP 429.
- Play не ждёт синхронизации. Если Date недоступен, TTS продолжает работать.
- Версия, версии Android и состав экранов не менялись.
- Добавлен QA test_edge_clock_sync.sh. Полный повторный прогон: 25/25 PASS.
- Подробности: TIME_SYNC_FIX_v11112.md.
