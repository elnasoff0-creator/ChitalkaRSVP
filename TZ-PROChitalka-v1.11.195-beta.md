# Техническое задание v1.11.195-beta

База: v1.11.194-beta CLEAN JAVA HOTFIX. Новая версия 1.11.195-beta, versionCode 19500.

1. Web Transfer: постоянный порт 8787, ручной ввод 1024–65535, переключатель «Динамический порт», сохранение настроек. При занятом порте показать ошибку и предложить ручную смену; не выбирать случайный порт без согласия. Локальное имя prochitalka.local через mDNS; IP как запасной вариант; QR должен соответствовать действующему адресу. При смене IP — обновление адреса либо явный перезапуск, без автоматического запуска. Не изменять порт во время передачи.
2. Постоянный пароль вместо PIN: генерация 12 символов, пользовательский пароль 8–64 символа, защищённое хранение, показать/скрыть/копировать, защита от перебора, сброс авторизаций. Запоминание браузера через случайный токен, не пароль. Пароль не помещается в URL/QR/лог. Только доверенная Wi-Fi сеть: HTTP не зашифрован.
3. Передача папок: выбор, Drag & Drop, вложенные пути, Unicode, несколько папок. Аудиокнига/манга — одно произведение и одна карточка, название корневой папки, естественная сортировка глав. Обложки из именованных картинок или встроенных тегов, не считать обложку страницей. Для смешанных типов — осмысленный выбор или отказ с пояснением. Не перезаписывать без согласия; при совпадении предложить пропуск/новое имя, в дальнейшем объединение/замену. Потоковая запись, 64-битные счётчики, 8 ГиБ на файл, без прежнего 1 ГиБ ограничения на группу, проверка свободного места, отмена и очистка временных файлов.
4. Акцентная кнопка Play/Stop, плавная анимация 1800 мс, состояние в общем разделе загрузок; переходы между экранами не останавливают сервер. Остановка активной передачи с подтверждением. При сворачивании прекращается анимация, не сервер.
5. Боковое меню: заменить старую иконку на актуальный ресурс приложения.
6. Вкладки: единый контур активной вкладки и контейнера, без горизонтальной линии под активной вкладкой. Верхние углы вкладок скруглены, нижние прямые, все углы основного контейнера прямые. Внутренние карточки не менять. Общий компонент, проверить все экраны, темы, ориентации и прокрутку.
7. Перенос незавершённых задач 194: обложки папок, передача >1 ГиБ, проверка кормления при перемотке, отсутствие двойного начисления. Сохранить стадии, имя, ресурсы, статистику, подпись и библиотеки.
8. Документация: постоянный README.md; версионные CHANGELOG, QA-REPORT и ТЗ. QA и GitHub Actions должны использовать новые контракты, без устаревших требований PIN и номера 194.

## Известные отклонения текущей реализации
mDNS — минимальная IPv4 A-запись, разрешение конфликтов и совместимость не подтверждены. IP/QR являются основным путём; смена IP требует ручного перезапуска. Доступность места до записи проверяется только на primary external storage. Слияние/замена папок, произвольные смешанные папки, полная проверка HTML-пакетов и визуальная проверка не закрыты. Обложки в истории после импорта. Подробности в CHANGELOG.
