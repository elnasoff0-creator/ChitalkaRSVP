ПРОЧиталка v1.11.85-beta CLEAN — Edge TTS HTTP 429 / request-rate fix

Исправлено
- Общий EdgeRequestGate для всех способов генерации Edge: живое прослушивание, предзагрузка следующего предложения и подготовка книги через «Загрузки».
- Одновременно разрешён только один WebSocket-запрос синтеза; между новыми запросами выдерживается минимальный интервал 2200 мс. Самый первый запрос запускается без искусственной задержки, если сервер не ограничил доступ.
- Приоритет запросов: выбранное пользователем предложение → одно следующее предложение → массовая подготовка книги. При переходах отменённые ожидающие запросы не начинают синтез.
- HTTP 429 больше не приводит к мгновенным повторным попыткам и смене endpoint. Учитывается Retry-After, если сервер его возвращает; иначе используется экспоненциальный cooldown (начиная с 60 секунд, максимум 30 минут).
- Во время cooldown обычное прослушивание не создаёт бесполезные сетевые задачи. При сохранённом запросе Play повтор возможен после окончания ограничения. В интерфейсе отображается сообщение о временном ограничении.
- Фоновый загрузчик всей книги приостанавливает задание на HTTP 429, не усиливает ограничение повторными запросами. Задание можно возобновить позже из «Загрузок».
- Исправлено отслеживание времени ожидания подключения: тайм-аут первого MP3 отсчитывается от фактической попытки соединения, а не от нахождения в локальной очереди.
- Переподключение на другой endpoint допускается лишь один раз при реальной ошибке соединения/403/5xx, но не при HTTP 429.
- В QA добавлен тест Java с имитацией HTTP 429: проверяет cooldown, отсутствие повторного подключения и приоритет Play перед массовой загрузкой.

Сохранено без изменений
- MediaCodec/AudioTrack live PCM для первого воспроизведения.
- WordBoundary и подсветка предложения/слова.
- Сохранение только полностью принятых MP3, кэш и офлайн-индексы.
- Единая книга, оглавление и UI, 18 одобренных спрайтов «Чтейца».

Ограничения
- 429 — ограничение внешней службы. Исправление снижает частоту запросов, но не гарантирует снятие ограничения или немедленное воспроизведение.
- Полная Android-сборка и воспроизведение на Samsung не проверялись. Java-синтаксис, XML и локальные QA-тесты пройдены.
