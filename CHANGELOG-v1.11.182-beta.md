# CHANGELOG — ПРОЧиталка v1.11.182-beta CLEAN

Уточнение: невозможный по размеру запрос Edge TTS не повторяется автоматически; при включённом резервном TTS целое предложение передаётся ему без разрезания.

## 1. Длинные URL Ranobes.net

Сохранён внедрённый ранее (как промежуточный хотфикс) маршрут `RanobesSearchActivity` → `RanobesApi.resolveBookLink()`. Ссылки на книги, копированные главы, `www`, параметры URL и длинные пути не отправляются в поиск по названию, где сохраняется отдельное ограничение в 70 символов. Неподдерживаемые адреса завершаются объяснимой ошибкой вместо «Слишком длинный запрос». Для ссылок на главы поиск родительской книги выполняется только в пределах ranobes.net. Нельзя обещать, что любой неканонический адрес успешно разрешится при изменениях сайта.

## 2. Встроенный Microsoft Edge

Добавлен `app/src/main/res/drawable-nodpi/ic_edge_official.webp` (512×512, прозрачный фон). `TtsEngineIcons.edge()` использует `R.drawable.ic_edge_official` с запасным `ic_edge_tts`. Браузер Microsoft Edge устанавливать не нужно, `PackageManager` не используется для значка онлайн Edge. `ReaderActivity` отображает встроенное изображение в нижнем правом бейдже поверх исходной XML-иконки и в правой части диалога «Способ озвучивания». Переключение на резервный Android TTS не затрагивает основную XML-иконку.

## 3. Папки в «Общие», не «Онлайн» и не «Аудио»

В `SettingsActivity.draw()` нижним блоком вкладки «Общие» вызывается `drawDownloadFoldersSection()`. Добавлен горизонтальный разделитель и заголовок «Папки загрузок». Пункты: «Книги», «Комиксы», «Аудиокниги», «Повторить сохранение готовых файлов», «Проверить и очистить дубликаты». Удалено многословное пояснение о выборе папок через Android 16. Из аудио полностью исключён пункт «Папка Book · Edge TTS». `DownloadFolderPicker` продолжает использовать прежние ключи, URI, обработчики выбора и сохранённые разрешения SAF. Реальные имена файлов и каталогов не переименовываются. Ошибки доступа отображаются с русскими названиями категорий.

## 4. Справка «Редактирование меню»

Вместо отдельного `addHelpIcon()` под переключателем использован `headerWithHelp()`: заголовок и кликабельная иконка помощи находятся в одной горизонтальной строке. Справа зарезервирована область 44dp. Больше нет пустого пространства, созданного прежним самостоятельным блоком помощи.

## 5. Сегментация Edge TTS без разрезания предложений

- `SentenceChunks.split()` и `SentenceIndex.fromText()` используют один источник естественных границ `EdgeSentenceBoundary.split()`; прежний цикл разрезания длинной строки по 800 символов удалён.
- `EdgeSpeechSegments.split()` группирует только **полные** предложения; при превышении мягкого целевого размера или лимита после словаря текущее объединение завершается без следующего предложения.
- Разделение между главами и абзацами сохраняется. Отдельное длинное предложение сохраняется целиком даже при превышении 800 символов.
- `EdgeSpeechSegments.priorityPieces()` теперь принимает индекс предложений, а не пытается нарезать последовательность по словам. Ручной переход в середину предложения синтезирует его целиком. При наличии WordBoundary сохранённая озвучка может начинаться с выбранного слова; иначе допустимо начало выбранного предложения.
- `EdgeStreamingService.restoreStartPosition()` теперь также не отправляет обрезанный остаток предложения после восстановления чтения.
- `EdgeSpeechSize` учитывает UTF-8 после XML-экранирования; `EdgeSpeechEngine` выполняет предварительную проверку и проверку финального SSML перед отправкой. Слишком длинное неделимое предложение — явная ошибка без обрезки текста. Резервный TTS применяется только если его отдельно включил пользователь.

## 6. Адаптивность и кеш

`EdgeAdaptiveBlocks` учитывает латентность первого MP3, длительность готового результата и сбои активных запросов. Мягкие целевые размеры: приоритетный блок 300–500, обычный 600–800 символов (для первых запусков 480/760). Адаптация влияет на только что подготавливаемую книгу, а не на уже воспроизводимые MP3.

`EdgeSpeechLayout` сохраняет размеры блоков для каждой книги в её приватной рабочей папке. Для книг с локальными MP3 старой версии выбирается традиционное 800/800 как наилучшая попытка переиспользования кеша. Уже имеющиеся файлы не удаляются автоматически, но аудио с изменившимися фактическими границами или словарём может потребовать адресного синтеза. `UnifiedBookSession.edgeGroups(options, layout)` разделяется между Reader и EdgeFullBookService для одной книги.
