# Читалка RSVP v1.11.13-beta: вход в MRT

Для Android: соберите APK именно из этого архива и установите поверх существующей Читалки RSVP.

- На главном экране под разделом «Продолжить чтение» — большая кнопка «♫ Слушать онлайн · MRT (beta)».
- Настройки → Аудио → «♫ Слушать онлайн · MRT (beta)».
- В режиме чтения → «♫» → «Слушать онлайн (MRT)».
- Вверху экрана настроек должно быть указано «RSVP v1.11.13-beta · Онлайн MRT». Если этого текста нет, на телефоне запущен APK другой версии.

Версия: versionCode 11020, versionName 1.11.13-beta. Пакет: ru.reader.rsvp. Используется та же подпись GitHub Actions, что у ранее установленной Читалки RSVP.

При запуске GitHub Actions вручную: перед сборкой загрузите новые исходники в основную ветку репозитория и в Actions выберите эту ветку. APK скачивайте из Artifacts именно нового запуска, а не из старого Release.

Это экспериментальный онлайн-режим: реальное аудиовоспроизведение в Android WebView и автопереход между фрагментами ещё требуют проверки на устройстве.
