# ПРОЧиталка v1.11.162-beta — руководство

## Подготовка и сборка

Распакуйте исходный ZIP. Понадобятся JDK 17, Android SDK 35 и Gradle 8.x. Собирайте через Android Studio или командой `gradle --no-daemon :app:assembleRelease` из корня проекта. Данные пользователя при штатной установке поверх предыдущей версии должны оставаться на устройстве, но перед тестированием экспериментальной беты рекомендуем сохранить резервную копию.

## Раздел «Загрузки»

Нажимайте на любую карточку, включая Edge TTS, RanobeLIB и MangaLib. Экран подробностей должен открываться по ID из кэша, даже если общий список файлов ещё обновляется. Отдельные действия с физическими файлами проверяются в фоне.

Смахивание карточки **влево** раскрывает **«В архив»** и **«Отмена»**. Для незавершённой активной загрузки приложение попросит подтвердить паузу. Архив — логический: сами файлы не удаляются.

## Раздел «Озвучка Edge TTS»

Алгоритм сборки блоков возвращён к поведению v1.11.158: около 800 символов для стандартного блока и до 500 для приоритетного продолжения после ручного перехода. Длительные предложения могут вновь разделяться на отрезки, поэтому эта версия ориентирована прежде всего на восстановление стабильного поведения v158. Серверный HTTP 429 может потребовать ручного ожидания; дополнительные длительные автоматические задержки из v161 отменены.

Отдельное действие сохранения готовых MP3 при наличии всех частей и диагностика записи в SAF остались доступными, но не должны менять обычную очередь загрузок.

## RanobeLIB: очистка служебного HTML

Для **новых** глав удаляются технические элементы страницы (включая «Офлайн-копия», время, ссылки навигации, повторные заголовки), текст сохраняется в нормальных абзацах и одним заголовком главы в общей книге.

Для **уже скачанной** книги: откройте карточку произведения в загрузчике и нажмите **«Пересобрать HTML без служебного текста»**. Это операция по запросу, а не фоновое сканирование. До обработки сохраняется `book.html.before_cleanup` внутри папки книги RanobeLIB, включая ситуацию, когда основная книга находится на SD-карте. Не удаляйте резервную копию до проверки результата. Если перевод отличается по длине, после ручной пересборки позиция чтения может сместиться; новая автосинхронизация не запускается.

## «Все закладки»

В меню чтения нажмите **⋮ → Все закладки**. На каждой карточке главное — фрагмент книги; ниже реальное название главы из оглавления, ещё ниже номер слова. Старые закладки без сохранённой цитаты получают подпись из книги, уже находящейся в памяти. Левый верхний угол — кнопка бокового меню.

Смахните карточку влево, чтобы увидеть **«Удалить»** и **«Отмена»**. Простое смахивание запись не удаляет. После удаления короткое время доступен возврат.

## Добавление закладки

Выделите слово или фразу долгим касанием текста. Плавающее меню содержит пять действий:

**Цвет · Копировать · Заметка · Словарь · Закладка**

Первоначальные четыре XML-иконки сохранены без замены. Выберите «Закладка», чтобы сохранить именно отмеченный текст. В меню трёх точек прежней команды добавления больше нет.

## «Все заметки»

**⋮ → Все заметки** — новый список с одинаковыми карточками и меню. Здесь основным текстом является запись заметки, далее цитата, название главы и номер слова. При нажатии открывается соответствующее место книги и редактор заметки. Смахивание влево предлагает «Удалить / Отмена».

Если у текста есть заметка, справа виден небольшой тематический значок. Для нескольких заметок на одной строке показывается общий индикатор с числом. Нажмите его, прокрутите горизонтальные мини-карточки и выберите нужную заметку. Это не изменяет позицию текущей озвучки.

## Ограничения и проверка

На крупном тексте угол/ширина иконки, поведение перетягивания выделения и конфликты жестов требуют проверки на реальном Android-устройстве. Отдельно проверьте открытие SAF-книги после переноса, архивирование незавершённых Edge TTS задач и восстановление сохранённых MP3. Разработчик исходников не проводил Android Gradle-сборку в данной среде: архив **не содержит APK**.
