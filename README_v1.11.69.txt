ПРОЧиталка v1.11.69-beta — полный исходный Android проект

Откройте папку проекта в Android Studio и соберите :app:assembleRelease, либо скопируйте app/ в свой GitHub-репозиторий, сохранив собственные .git и .github.

Новые настройки:
- Настройки -> Аудио -> Автовоспроизведение при касании (выключено по умолчанию)
- Настройки -> Онлайн -> Сокращение пауз между предложениями MS Edge (включено по умолчанию)

Сокращение применяется только к подтверждённой тишине в конце законченного предложения, при генерации новых Edge MP3. MP3 и *.words.json остаются без изменений. Конец клипа хранится в *.mp3.tail.json, при выключении переключателя воспроизводится полный оригинал. Старые MP3 без *.tail.json воспроизводятся как прежде.

Исходники не проходили полноценную Android сборку: необходимо прогнать GitHub Actions и проверку воспроизведения на Samsung/Google/Edge на устройстве.
