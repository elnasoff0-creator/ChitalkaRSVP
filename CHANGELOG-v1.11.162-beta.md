# ПРОЧиталка v1.11.162-beta CLEAN — полный перечень изменений

**Основа:** v1.11.161-beta CLEAN Full Source.
**Проверенная основа механизмов:** сегментация и основная очередь Edge TTS из v1.11.158-beta.
**Версия:** `1.11.162-beta`, `versionCode=16200`, Android Java 17, minSdk 24, compileSdk 35.

## 1. Исправление недоступных карточек загрузок

- Нажатие на карточку загрузки больше не блокируется предварительным статусом `previewOnly` и сообщением «Проверяем состояние загрузки…».
- RanobeLIB и MangaLib открываются непосредственно в своих экранах выбора томов/глав по сохранённому идентификатору.
- Edge TTS открывает экран глав через сохранённый URI книги; он не ожидает обхода всех папок Android SAF.
- Для загрузок по ссылкам используется стабильный ID задания, даже если предварительный снимок ещё не содержит полного объекта.
- Операции, требующие полного подтверждения файлов (меню, архивирование, перенос), проверяют только выбранную задачу в отдельном исполнителе, не блокируя UI; при ошибке сообщают причину и позволяют повторить.
- Существующие фильтры, переименование, перенос файлов, поиск, архив и расположение кнопок toolbar сохранены.

## 2. Возврат сегментации Edge TTS из v1.11.158

- `EdgeSpeechSegments.java` и `EdgeTextSegments.java` возвращены к реализации версии 158.
- Обычная целевая длина блока — **800 символов**; приоритетная последовательность после ручного выбора слова — **до 500 символов**.
- `EdgeSpeechQueue.java` возвращена к политике очереди и локальной реакции на HTTP 429 версии 158 (`MAX_LOCAL_DELAY_MS=500L`). Новая политика автоматического ожидания 60–900 секунд из v161 снята согласно требованию пользователя.
- Сохранены быстрый индекс предложений, открытая сессия чтения, пословная подсветка и WordBoundary из новых версий.
- Основной путь подготовки завершённой книги в `EdgeFullBookService` согласован с v158. Отдельный пользовательский механизм повторной публикации MP3 и диагностический код v161 оставлены изолированными от обычного механизма очереди.
- **Компромисс:** старое деление приоритетных блоков до 500 символов может снова дать паузу внутри длинного предложения; локальная задержка 500 мс не гарантирует снятия серверного HTTP 429. Это сознательный откат ради воспроизведения поведения v158.

## 3. RanobeLIB: очистка HTML

- Добавлен `RanobeLibHtmlCleaner.java` на основе Jsoup: при сохранении и сборке удаляются служебные контейнеры навигации, «ОглавлениеГлава», отметки «Офлайн-копия», технические даты, блоки комментариев, скрипты и дублирующиеся заголовки глав.
- В объединённый `book.html` добавляется ровно один структурный заголовок на главу (разметка `section` и `h2`). Индекс глав остаётся доступным для оглавления.
- Содержательные абзацы, диалоги, сноски, иллюстрации и допустимое HTML-форматирование сохраняются.
- В карточке RanobeLIB добавлена команда **«Пересобрать HTML без служебного текста»** для уже скачанных глав. Повторная загрузка с сайта не требуется.
- Перед **ручной** пересборкой сохраняется отдельная копия `book.html.before_cleanup` в приватной папке произведения; копия создаётся и для книг, размещённых через SAF.
- Добавлена корректная работа кнопки открытия книги из внешней SAF-папки и после перемещения на SD-карту (`content://` вместо отсутствующего локального файла).
- Автоматическая очистка ранее сохранённых книг при каждом возвращении к чтению **не включена**.

## 4. «Все закладки» — компактный обновлённый интерфейс

- Верхняя строка с кнопкой универсального бокового меню и заголовком «Все закладки».
- Основная часть каждой карточки — **текст выбранной закладки** (не название главы).
- Под текстом — компактный разделитель, настоящее название главы из индекса оглавления, затем отдельная нижняя строка «Слово № ...».
- Добавлены компактные отступы и сортировка по порядку чтения или по времени.
- Для старых закладок без текста карточка заполняется фрагментом непосредственно из текущего **загруженного в память** текста, без повторного чтения HTML.
- Нажатие на карточку открывает нужное слово в ReaderActivity с сохранением быстрой сессии.

## 5. «Все заметки» — новый общий менеджер

- В меню трёх точек ReaderActivity первым пунктом теперь идёт **«Все заметки»**, с оригинальной иконкой заметок; «Все закладки» — рядом.
- «Добавить закладку» из меню трёх точек удалено. Для добавления закладки применяется долгий тап по тексту.
- Экран «Все заметки» использует ту же компактную структуру и кнопку бокового меню: заметка, цитата, разделитель, название главы, номер слова.
- Тап по заметке переводит к выбранному фрагменту книги и вызывает её редактор по стабильному ID.
- Данные остаются в исходной SQLite-базе `ReaderAnnotationsStore`, без копирования и миграции.

## 6. Долгое нажатие: пять действий

- Сохранены четыре отрисованные по предоставленному образцу XML VectorDrawable из v161: **Цвет**, **Копировать**, **Заметка**, **Словарь**.
- Добавлен пятый пункт **«Закладка»** с отдельной контурной иконкой. При нехватке ширины меню прокручивается горизонтально.
- Закладка сохраняет выделенный текст, позицию, главу и дату, избегая повторного сохранения одной и той же позиции.
- Выделения, заметки, словарь Edge TTS и новая справка Regex версии 161 сохранены.

## 7. Жесты смахивания

- В «Все закладки» и «Все заметки» смахивание влево открывает **«Удалить / Отмена»**, ничего не удаляя до нажатия «Удалить»; предусмотрено короткое восстановление через «Отменить».
- В «Загрузках» смахивание влево показывает **«В архив / Отмена»**. Архивирование не удаляет MP3, изображения, главы и метаданные.
- Для активной задачи перед архивированием предлагается сначала приостановить её; операция инициирует штатное действие паузы соответствующего источника.
- В архиве можно восстановить записи завершённых и приостановленных заданий.

## 8. Заметки непосредственно в строке текста

- У строки с заметкой справа от текста отображается тематический значок заметки.
- Если несколько заметок заканчиваются на одной визуальной строке, вместо накладывающихся значков рисуется одна иконка со счётчиком.
- Нажатие на иконку открывает горизонтальный ряд компактных заметок с именем и цветом; выбор открывает конкретную заметку.
- При одной заметке она открывается напрямую.
- После возврата из менеджера пересчитываются только аннотации отображаемых текстовых блоков, **не пересобирается книга и не загружается новый текст**.

## 9. Быстрая работа с оглавлением

- Новый `ReaderChapterLabels.java` сохраняет лёгкий индекс «начальный номер слова — название главы» из уже разобранного оглавления.
- Списки закладок/заметок не открывают HTML и не создают новый `BookLoader`.
- Дешёвая проверка ревизии главы обновляет названия после явной пересборки книги, без полного сканирования файлов.
- Прежний ускоренный ReaderBookCache и UnifiedBookSession не изменены.

## 10. Тесты, возможности и ограничения

**Проверены локально:**
- Синтаксический разбор всех 171 исходных Java-файлов.
- Корректность 169 Android XML-файлов.
- JVM-тест сегментации Edge TTS 800/500 символов и непрерывности индексов слов.
- Структурная проверка контекстного меню, заметок, архива, RanobeLIB и быстрого кэша.
- Несколько совместимых проверок более старых функций (см. `qa/README-v162-TESTS.md`).

**Не проверено:** полноценная Android Gradle-сборка и фактическая работа UI, чтения из SAF, жестов и WebSocket на Android-устройстве, так как в рабочей среде нет Android SDK. Из-за этого корректность релиза на устройстве пока не подтверждена. Архив содержит исходный проект, **не APK**.
