# ТЗ v1.11.193-beta CLEAN — Web Transfer UI и объединённые загрузки

**Статус:** реализовано на уровне исходников, автономные тесты предусмотрены. Основа — 1.11.192 Javac Hotfix. APK должен собираться GitHub Actions и проверяться на устройстве.

## А. Экран «Передача по Wi-Fi»

1. Единый стиль UI: тематические фоны, размеры кнопок 44 dp, скругления, цвета от текущей темы, корректная работа на небольших экранах и со светлой/тёмной темой.
2. Кнопка запуска/остановки сервера — **контурная XML-иконка в правой части Toolbar**, с переключением иконки, защитой от двойного нажатия и подтверждением остановки при активных передачах. Из содержимого экрана большую кнопку удалить.
3. Выбор папок — стандартная кнопка в блоке папок. Меню «Книги / Комиксы / Аудиокниги», затем системный `ACTION_OPEN_DOCUMENT_TREE`, проверка разрешения на запись и сохранение текущих SAF-URI для каждой категории.
4. Адрес: отдельная контурная кнопка копирования **полного** `http://IP:PORT`; недоступна при выключенном сервере. Тост об успехе.
5. Убрать с экрана кнопку «Настройки Web Transfer» (оставить сами настройки во вкладке «Онлайн»).
6. Перенести инструкцию в пользовательскую «Справку», добавить `?` с переходом непосредственно к разделу «Передача книг по Wi-Fi».
7. Оставить на экране статус, локальный адрес, PIN, QR, число подключений, число активных передач и текущий краткий статус.

## Б. Единый список «Загрузки» для Wi-Fi

1. В **существующем** списке загрузок показывать **каждый файл**, переданный через Web Transfer; не вводить второй менеджер. Пользоваться существующим `DownloadsRepository`, `DownloadChangeBus`, RecyclerView.
2. Устойчивый ID операции и запись на каждую попытку, без дублирования при повторной загрузке списка или возвращении в Activity. Сохранять состояние и историю после закрытия приложения.
3. Отображать: имя, источник «Wi-Fi», расширение, размер, текущий полученный объём, прогресс (байты/%), статус и ошибку. Фильтр «Wi-Fi».
4. Последовательность статусов: ожидание → передача → импорт → готово; альтернативно отменено, ошибка, дубликат. **100% передачи ≠ готово** до успешной индексации библиотеки.
5. Отмена из общей карточки должна прерывать соответствующую операцию сокета; при отмене браузером — тот же ID. Поздний ответ не должен отменять статус «Отменено». Во время финального импорта SAF нельзя отменять запись, чтобы не получить полусохранённый файл.
6. Историю хранить ограниченно (до 300 записей); удалять записи истории отдельно от библиотечных файлов. При неожиданной гибели сервиса/процесса не оставлять «вечных» активных операций.
7. Не изменять существующие менеджеры Edge TTS, MP3, аудио, MangaLib, RanobeLib, Ranobes, загрузок по ссылке, функции архива и библиотек.

## В. Web Transfer backend

- Сохранить локальную Wi-Fi-привязку, QR, PIN, временную cookie после авторизации, строгие Host/Origin, запрет внешнего доступа и ограничение двух одновременных файлов до 1 ГиБ.
- Каждая операция получает уникальный ID; прогресс фиксируется по реальным байтам, а успешный результат — только после SAF-импорта.
- `POST /api/cancel` только для авторизованного браузера с корректным ID, без возможности получить список или прочесть содержимое библиотеки.
- При потере соединения или остановке очищать временные `.part`, обновлять статус в общей истории, не стирать готовые файлы.

## Г. Приёмочные сценарии

- Новый вид сервера в светлой и тёмной темах; Toolbar-кнопки, отключение копирования при остановленном сервере, папки, прямая справка.
- Загружать 1 EPUB, 2 параллельных файла и CBZ; наблюдать каждую карточку в общем списке и фильтре Wi-Fi, проверять байты и финальный импорт.
- Закрыть/снова открыть «Загрузки», сверить устойчивость записей и сохранение истории.
- Отменить из Android и браузера, проверить прерывание сокета, удаление временного файла и запрет позднего «Готово».
- Проверить дубликаты, отсутствие папки, потерю сети, остановку сервера и аварийный перезапуск процесса.
- Проверить существующие Edge TTS, WordBoundary и ранее исправленные механизмы чтения, манги и CSV-словаря.

**Безопасность:** HTTP в локальной сети не шифрует содержимое, использовать только в доверенном Wi-Fi.
