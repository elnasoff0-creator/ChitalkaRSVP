ПРОЧиталка v1.11.92-beta CLEAN — 26.10.2026

НОВАЯ АРХИТЕКТУРА EDGE TTS
- Media3 получает MP3 напрямую из WebSocket по мере поступления первых аудиопакетов.
- EdgeLiveBuffer + EdgeLiveDataSource: отдельный потокобезопасный буфер, блокирующие чтения на фоновых потоках Media3, отмена при переключении.
- Завершённые MP3 по-прежнему проходят проверку формата, атомарно сохраняются в кэш вместе с WordBoundary.
- Во время живого воспроизведения поступающие метки WordBoundary доступны для подсветки слов.
- Старый путь «сначала скачать полностью, затем запустить Media3» больше не используется при текущем воспроизведении; сохранён только для фоновой генерации и кэша.

ОЧЕРЕДЬ И РУЧНАЯ НАВИГАЦИЯ
- EdgeSpeechQueue переписана: при тапе и Play нет фиксированного ожидания 4,5 секунды.
- Приоритет нового выбранного предложения выше предварительной и полной генерации книги.
- Запущенный фоновый запрос можно прервать без зависания фоновой очереди.
- Старый аудиопоток разблокируется при отмене, новая позиция начинает новый запрос.
- Для уже сохранённого MP3 остаётся точная перемотка по WordBoundary; при их отсутствии синтез начинается с выбранного предложения.

ОГРАНИЧЕНИЯ MICROSOFT
- Убрана 15-минутная блокировка предварительной загрузки и прежнее экспоненциальное ожидание.
- При отсутствии серверного Retry-After — короткий антиштормовый интервал 3 секунды, без автоматического повторения 429.
- Реальный заголовок Retry-After при наличии соблюдается; гарантированно устранить серверный HTTP 429 нельзя.
- После отказа текущий фрагмент ожидает нового явного Play/тапа, не запускает бесконечный цикл запросов.
- Старый ключ сохранённой блокировки v1.11.91 не переносится в новую очередь.

СОХРАНЕНО
- Все девять пользовательских Android VectorDrawable из v1.11.90.
- Выбор голоса, скорость/WPM, плейлист Media3, локальный MP3-кэш и озвучивание всей книги.

ПРОВЕРКА
- Тесты исходников, WebSocket, первого аудиопакета, приоритетов, отмены, MP3-кэша, навигации.
- На реальном Android и на серверах Microsoft скорость не измерялась: APK не собирался в среде без Android SDK.
