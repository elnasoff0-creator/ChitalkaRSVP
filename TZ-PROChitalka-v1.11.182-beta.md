# Утверждённое ТЗ — ПРОЧиталка v1.11.182-beta CLEAN

**Основа:** v1.11.181-beta CLEAN Ranobes URL Hotfix. На выходе: полный ZIP исходников, версия `1.11.182-beta` / `18200`, CLEAN-документация только текущего релиза.

## Требования

1. **Ranobes.net:** URL может превышать 70 символов. Распознавать ссылки на книги/главы отдельно от текстового поиска, не обрезать параметры для целей определения формата; корректно объяснять неподдерживаемый тип ссылки. Лимит текстового запроса в 70 символов сохраняется.
2. **Edge TTS иконка:** добавить в проект иконку `ic_edge_official.webp`. Ни установка браузера, ни поиск его Android-пакета не нужны. Основная XML-иконка ReaderActivity остаётся; на неё справа внизу накладывается мини-бейдж встроенного Edge. Та же иконка появляется в диалоге выбора способа озвучивания. Для системного/резервного Android TTS — системная иконка реально активного движка.
3. **SAF:** перенести три селектора папок и два действия в самый низ вкладки «Общие» под разделитель. Папки: «Книги», «Комиксы», «Аудиокниги». Полностью убрать объяснение про Android 16 и старые английские категории. Не изменять фактические папки и URI/разрешения SAF. Удалить дублирующую настройку «Папка Book — Edge TTS» из «Аудио». Во вкладке «Онлайн» этой секции не должно быть.
4. **Справка:** убрать отдельно стоящий под переключателем значок `?` для «Редактирование меню»; поместить его справа от заголовка в горизонтальную строку с корректной кликабельной областью и отступами.
5. **Неделимость предложений:** во всех путях Edge TTS отправлять только целые предложения. При превышении целевого блока не добавлять очередное предложение, даже если блок окажется меньше цели. Не разрезать предложение ни по символам, ни по словам, включая первую порцию, ручной переход к слову, фоновые фрагменты и всю книгу.
6. **Адаптивный размер:** при первом старте/ручном переходе целевой блок 300–500 символов, далее 600–800, приоритет Play выше фоновых загрузок. Учесть длительность очереди, первого MP3 и полного синтеза. Не пересоздавать существующие готовые MP3 только по причине изменения сетевого состояния.
7. **Проверка после словаря:** проверять фактические UTF-8 байты текста с заменами и игнорированием, включая XML-экранирование и SSML. Если добавление следующего целого предложения превышает лимит, переносить всё предложение в следующий запрос. Если один неделимый текст превышает предельный размер — не обрезать, сообщить об ошибке или использовать только явно включённый резервный TTS.
8. **Совместимость:** структура фрагментов чтения и массового скачивания согласована. Индекс слов и подсветка не изменяют исходный текст. Готовые аудиофайлы повторно использовать при совпадении ключей, без принудительного удаления. Все проверки, подготовка книги и файловая работа выполняются вне главного UI-потока.

## Критерии готовности

- Полная сборка Android release в GitHub Actions; на устройстве работающая иконка Edge и overlay, переход на локальный TTS.
- В «Общие» внизу виден новый раздел SAF, в «Аудио» и «Онлайн» старого блока нет.
- Нет отдельной строки `?` после «Редактирование меню».
- Ни одно предложение не отрезано из-за лимита 500/800; переход в его середину не делает усечённый WebSocket-запрос.
- Превышение лимита после словарных замен не создаёт незаметно неполный MP3.
- При повторном открытии книги сохранённые группировки и готовые MP3 не пересчитываются из-за адаптивного бюджета.
- Содержание файла ZIP и действительные результаты QA отражены в отчёте, без скрытого обещания полной проверки на устройстве.
