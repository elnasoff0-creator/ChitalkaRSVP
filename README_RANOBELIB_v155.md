# ПРОЧиталка 1.11.155-beta — инструкция

## Сборка проекта

Распакуйте ZIP и откройте корневую папку проекта (с `settings.gradle` и `app/build.gradle`) в Android Studio с установленным Android SDK 35 и JDK 17. Выполните **Build → Make Project** или `gradle assembleDebug` с установленными Gradle и Android SDK. Это полный исходный проект, а не готовый APK. Версия приложения: `1.11.155-beta`, `versionCode: 15500`.

## Поиск и скачивание книг

1. Откройте **Загрузки** и нажмите иконку **книги с лупой** («Поиск ранобэ · RanobeLIB»). На узком экране пролистайте панель иконок горизонтально.
2. Введите название книги или ссылку на RanobeLIB и нажмите «Найти книги».
3. Откройте карточку найденной книги. Там должны отображаться обложка, краткое описание и тома с главами.
4. Нажмите **«Скачать том»** рядом с нужным томом, **«Скачать всю книгу»** либо **«Выбрать главы»**. Для книги с несколькими переводами при массовом скачивании используется первая ветка; при выборе глав можно отметить другую ветку.
5. Прогресс наблюдайте во вкладке загрузок, фильтр **«Ранобэ»**. Контекстное меню карточки позволяет приостановить, продолжить, повторить ошибки, открыть книгу.
6. После первой загруженной главы книга появляется в обычной **Библиотеке** с локальной обложкой. Книга открывается через ReaderActivity; оглавление формируется из скачанных глав.
7. Для внешней копии HTML нажмите иконку папки на экране RanobeLIB и выберите доступный каталог Android (SAF). Без этого HTML сохраняется в локальные файлы приложения.

Внутри хранилища приложения файлы располагаются в `Books/RanobeLIB/<id--slug>/book.html`, `book.json`, `cover.jpg`, `images/` и `volumes/` с файлами отдельных глав. Очередь сохраняется в служебном JSON хранилища приложения и обслуживается WorkManager.

## Исправление рыбалки

В разделе Чтейца, если питомец отключён, компактная кнопка рыбалки находится у заголовка «Статистика и награды». Если питомец включён, кнопка остаётся у имени Чтейца. Повторное нажатие не создаёт дублирующее игровое окно. Отдельная кнопка «Игры» в статистике улова удалена.

## Диагностика

Если поиск возвращает HTTP 403/429 или пустой список, причина может быть в доступности или изменениях внешнего RanobeLIB; это не означает, что следует очищать библиотеку. На публичных примерах сеть из этой среды не тестировалась. При проблеме с отдельной главой другие главы не должны удаляться; можно выбрать «Продолжить / повторить ошибки».

## О проверках

В комплект входит `qa/test_v11155_ranobelib_and_games.py` для статической проверки ключевых связок и регрессии игры. Выполнены синтаксический разбор Java (154 файла), локальные проверки XML и частичный Java typecheck существующего модуля EPUB/FB2. **Сборка APK и тесты на устройстве не подтверждены**.
