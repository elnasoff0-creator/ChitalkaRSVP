## Что нельзя считать подтверждённым

- Отсутствует локальный Android SDK/Gradle; задача `:app:assembleRelease` **не запускалась**. Android Java typecheck и aapt2 остаются задачей GitHub Actions.
- Не выполнены реальные сетевые запросы к Edge TTS и переключения между онлайн/резервным режимами.
- Не проведён ручной визуальный тест настроек, меню, SAF и overlay на Android 16 и других версиях.
- Без реальной книги и её предыдущих MP3 нельзя гарантировать побитовое повторное использование каждого старого файла: новое правило целостности предложений может намеренно менять старые группировки с разрезанными фразами.
- Старые исторические QA-скрипты, которые жёстко ожидают нарезку по словам и 800-символьные предложения, отражают прежние версии и не являются тестами спецификации v1.11.182.

## Рекомендуемые ручные проверки после GitHub Actions

1. Новая книга: Edge TTS включается, первый фрагмент целый, MP3 воспроизводится; встроенная Edge-иконка появляется без установки Microsoft Edge.
2. Книга с сохранёнными MP3: файлы повторно используются там, где совпадают настоящие ключи и границы предложений.
3. Выбор слова внутри длинного предложения: WebSocket отправляет **всё предложение**, читает с нужного слова при доступном WordBoundary, иначе с начала этого предложения.
4. Словарь замен увеличивает UTF-8 размер: блок уменьшается за счёт переноса следующего целого предложения; единичная недопустимо длинная фраза обрабатывается явной ошибкой или только разрешённым резервным TTS.
5. Массовая загрузка той же книги: совпадают границы глав, фрагментов, кеш-ключи и прогресс; нет лишних перегенераций.
6. Вкладка «Общие»: пять пунктов SAF в самом низу под разделителем, корректные названия, пути/разрешения сохранены. Вкладка «Онлайн»: секция SAF удалена. «Аудио»: нет «Папка Book — Edge TTS».
7. Значок `?` виден непосредственно справа от «Редактирование меню», не занимает новую строку.
8. Длинная ссылка Ranobes (книга и глава) обрабатывается отдельно от текстового поиска.
