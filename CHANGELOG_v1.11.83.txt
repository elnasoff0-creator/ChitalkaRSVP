ПРОЧиталка v1.11.83-beta — CHANGELOG

1. ReaderActivity: обложка книги + название/автор встроены в первую виртуализированную строку RecyclerView. Обложка скроллится вместе с текстом, без GONE-манипуляций, вызывавших прыжки.
2. ReaderActivity: чтение занимает всё доступное место до системных insets, Toolbar и нижние органы управления располагаются поверх текста в FrameLayout.
3. Toolbar: режим — вторая кнопка после Назад, настройки последняя; режим акцентный; метод TTS акцентный. Скрытие/показ через translationY+alpha, без повторной разметки содержимого.
4. Footer: плавающий акцентный объединённый элемент «оглавление + прогресс» без текста названия; центральная акцентная Play/Pause только в режимах с воспроизведением; акцентный WPM перенесён вправо вниз.
5. Fullscreen: старый переключатель «Во весь экран» удалён из настроек и убраны его условия из ReaderActivity. Системные панели остаются доступны.
6. Режим Скорочтение: новая отличимая иконка ic_mode_speedreading.xml, в меню режимов и настройках.
7. MediaSession: добавлен PlaybackArtwork с асинхронной ограниченной по памяти загрузкой EPUB/FB2 и аудиокниг, обложка в системных MediaMetadata/MediaStyle notifications. Название, автор, положение по книге, WPM-оценка общей длительности для TTS.
8. EdgePlaybackService: живой PCM правильно отображается в MediaSession как Playing вместо состояния неактивного ExoPlayer.
9. Режимы не разделяют текст на новые экраны: общая UnifiedBookSession и структуры глав/фрагментов прежней версии сохраняются.

Ограничения: динамика Android/One UI уведомления управляется ОС. Реальное Edge WebSocket и AudioTrack требуют проверки на устройстве; данное обновление не меняет сетевой протокол Edge.
