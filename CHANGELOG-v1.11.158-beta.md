# ПРОЧиталка v1.11.158-beta CLEAN — перенос библиотеки

База: v1.11.157-beta CLEAN Full Source. Версия приложения: `1.11.158-beta`, `versionCode 15800`.

## Перенос в выбранную папку Android (SAF)

- В меню `⋮` текстовых книг, аудиокниг и комиксов добавлена команда **«Перенести в папку»**.
- В меню загрузок RanobeLIB, MangaLib, «Книга в ухе», по ссылке и Edge TTS — **«Перенести файлы»**; в архиве загрузок также можно переносить записи с доступными файлами.
- В выпадающем меню фильтра раздела **«Загрузки»** добавлена команда **«Перенести всё из внутреннего хранилища»** для неактивных загрузок и файлов приложения.
- Android Storage Access Framework поддерживает выбранные пользователем папки накопителя и SD-карты с постоянным разрешением на чтение и запись.
- Копии файлов и совпадающие файлы проверяются по SHA-256. В случае конфликта содержимого файл не перезаписывается, старые данные сохраняются.
- Для добавленных приложением файлов после подтверждённой записи обновляются постоянные пути и удаляются только безопасно идентифицированные исходники приложения. Пользовательские оригиналы в чужих SAF-папках не удаляются.

## MangaLib

- Меняются пути завершённых CBZ в очереди MangaLib; сохранённые главы продолжают отображаться в Комиксотеке.
- Поддержано открытие архивов через `content://` (временный кэш создаётся только при чтении).
- Исправлены счётчики готовых глав, обложки/превью и удаление отдельных CBZ из SAF.
- После переноса новые скачанные главы автоматически публикуются в выбранную папку с проверкой сохранения.
- Сохранены номера томов/глав, переводческие ветки и позиция чтения.

## RanobeLIB

- Перемещается вся локальная папка произведения: `book.html`, `book.json`, `cover.jpg`, файлы глав и иллюстрации.
- Путь объединённой HTML-книги в Библиотеке меняется без потери имени книги и связанного состояния чтения.
- Список загрузок, восстановление обложек и счётчики глав распознают `content://`.
- Публикация новых глав, обложки, метаданных и пересобранного HTML происходит непосредственно в уже выбранную папку.
- Удаление произведения удаляет его собственную папку, а не корень пользовательского каталога.

## Остальные книги и аудиозагрузки

- Отдельные FB2/EPUB/HTML/TXT и другие импортированные документы можно перенести в выбранную папку. Для приложения-владельца оригинал удаляется только после успешного переноса; пользовательские исходные файлы остаются.
- Для локальных HTML с `images/`, `assets/` и `cover.jpg` перемещаются также известные приложению ресурсы.
- Аудиокниги сохраняют свой ID, список треков, прогресс и пользовательские названия.
- Для завершённых заданий «Книга в ухе» и загрузок по ссылке обновляются URI в данных загрузчика и в Аудиотеке/Библиотеке.
- Незавершённые аудиозагрузки и загрузки по ссылке не переносятся, чтобы последующая докачка не разбросала части по разным местам.

## Edge TTS, безопасное ограничение

- Сохраняется связь старого и нового адресов текстовой книги с ранее созданными заданиями Edge TTS и WordBoundary.
- Рабочая озвучка и служебный кэш Edge TTS **не удаляются** автоматически: удаление могло бы сломать фоновую подготовку и пословную подсветку.
- Экспорт полностью завершённых глав Edge TTS как MP3-аудиокниги остаётся доступен. Перенос Edge из загрузок создаёт проверенную копию данных и оставляет рабочие файлы.

## Системная надёжность

- SAF хранит корневой URI разрешения и имя конкретной вложенной папки отдельно; это предотвращает попадание новых глав в неправильный каталог после перезапуска.
- Перенос комикса внутрь его же папки запрещён.
- Восстанавливается ID ожидающей передачи после повторного создания экрана системным окном выбора папки.
- Сохранён прежний функционал поиска RanobeLIB, MangaLib и «Книга в ухе», переименования и встроенной рыбалки.
