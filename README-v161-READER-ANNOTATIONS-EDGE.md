# ПРОЧиталка v1.11.161-beta — руководство по новой версии

## Установка и сборка

Используйте полный исходный Android-проект вместо предыдущей версии. Для сборки нужен Android SDK 35 и JDK 17. Из корня проекта выполните `gradle --no-daemon :app:assembleRelease` (или сборку через Android Studio). APK в архив не включён.

Версия приложения: `1.11.161-beta`, код `16100`. Обновление не должно удалять существующие данные приложения.

## Долгое нажатие на текст

Откройте книгу в обычном режиме чтения, курсоре или озвучке. Удерживайте слово, пока оно не выделится, и перетягивайте маркеры диапазона. Над текстом появятся четыре маленькие кнопки с иконками из предоставленного примера: **Цвет · Копировать · Заметка · Словарь**.

**Цвет** сохраняет окрашенную подложку выбранного текста. Палитра открывается из меню, её четыре цвета и прозрачность регулируются в Настройки → Чтение. Если удаляется окраска заметки, сама заметка сохраняется.

**Копировать** отправляет выделение в буфер обмена Android.

**Заметка** открывает поле ввода с цитатой. Сохранённый отрывок подчёркнут, рядом отображается индикатор, а касание отмеченного фрагмента в обычном чтении позволяет открыть заметку.

**Словарь** открывает быстрый диалог настройки произношения без перехода в Activity. Измените произношение, отметьте ударную гласную и нажмите прослушивание. Если нужно только для текущего контекста, включите переключатель ограничения контекста. Для пропуска слова включите «Игнорировать». Используется та же база, что и у большого словаря.

### Важные ограничения выделения

При изменении текста самого файла внешним редактором позиции, привязанные к индексам слов, могут сместиться. В этой версии **нет автоматического пересчёта HTML**: это сознательно оставлено ради скорости загрузки книги.

Для очень длинного выделения маркеры ориентируются на видимые строки RecyclerView; при перетягивании вне видимой области список нужно сначала прокрутить вручную.

## Edge TTS: если глава на 99%

В разделе «Загрузка озвучки» у незавершённой главы с MP3 в кэше нажмите **«Сохранить»**. Программа проверит фрагменты и повторит только публикацию в папку Edge TTS, не заново озвучивая текст. Если фрагмента нет, она прямо сообщит количество отсутствующих MP3.

При HTTP 429 новые запросы выдерживают возрастающую паузу, вместо прежних 500 мс. Сервер может сохранять ограничение дольше паузы. Не удаляйте готовые части, если книга не прошла финальное сохранение.

Если появится ошибка Android SAF, она теперь должна показывать точный этап: нет доступа к папке, ошибка записи, ошибка разметки WordBoundary, переименование `.pending`, повреждённые MP3 или несоответствие SHA-256. По этой информации можно уточнить последующее исправление конкретного провайдера Android.

## Справка Regex

Откройте Словарь Edge TTS → «Регулярные выражения… — справка». Прежний краткий текст заменён подробным справочником Java Pattern, групп, Unicode, границ, вариантов квантификаторов и подстановок.

Для обычного слова **не нужно** включать Regex: это снижает вероятность ошибочной глобальной замены.

## О производительности

Не добавлен прежний функционал постоянной проверки или пересборки HTML при возврате к книге. Файлы книги не меняются при добавлении заметок. SQLite читает список отметок один раз для открываемой книги, и отрисовка использует только видимые блоки текста.

## Проверка на устройстве

После установки рекомендуются следующие сценарии: долгий тап на слове, перенос маркера между строками, копирование, создание заметки, изменение цвета, добавление словарной замены с прослушиванием, сохранение уже закэшированной MP3-главы на 99%, смена папки SAF и проверка книги после выхода в Библиотеку.

**Известное ограничение проверки этого архива:** исходники прошли синтаксические, JVM и структурные тесты, но Android Gradle сборка и реальное устройство не были доступны в рабочей среде.
