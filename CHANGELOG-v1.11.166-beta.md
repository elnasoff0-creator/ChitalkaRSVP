# ПРОЧиталка 1.11.166-beta CLEAN — полная расшифровка изменений

## Менеджер загрузок

- `UnifiedDownloadManagerActivity.java`: заголовок **«Менеджер»**, без верхней кнопки «Назад»; сохранено боковое меню.
- Карточка произведения с обложкой, названием и кратким набором доступных метаданных; нажатие открывает произведение. Отдельные «Подробнее», «Слушать», «Читать» и «Обложка» из главного экрана убраны.
- Под карточкой оставлена одна строка **Play/Pause — Общий прогресс — процент — Скачать всё** и одна шкала. Кнопки акцентно-контурные, не полностью залитые.
- Существующая `R.drawable.ic_autoload` запускает подготовку/добавление всех недостающих элементов; Play/Pause отдельно управляет очередью.
- Убраны повторные служебные статусы, количество готовых глав и размер под карточкой; подробности перенесены во вкладки.
- «Файлы» открываются по умолчанию: список глав/файлов, индивидуальный прогресс, меню повторной постановки, удаления, открытия, выбор нескольких; специальные действия Edge TTS по переозвучке, публикации готовых фрагментов и объединению. Для прямых ссылок встроены открытие конкретного сохранённого файла, добавление MP3 всей загрузки в Аудиотеку, отмена оставшихся файлов и открытие папки.
- В Edge TTS список глав берётся из оглавления исходной книги и кэшируется, не пересчитывается в каждом цикле обновления. Отмечаются опубликованные MP3, ожидающие задачи и ошибки.
- «Инфо» содержит техническую сводку, статус, размеры, количество элементов и адрес каталога назначения. Не повторяет автора/название, если они уже указаны в карточке.

## Папки и файловая система

- `DownloadFolderPicker.directoryPath`: извлечение отображаемого пути **папки**, а не адреса файла, из реального SAF tree URI выбранной категории. Для стандартной внутренней памяти используется понятная подпись; при невозможности определить полный путь — название папки.
- Путь отображается одной строкой с `TextUtils.TruncateAt.START`, что сохраняет видимость последнего участка. Справа — контурная иконка папки, открывающая Android SAF-диалог для текущей категории.
- Три независимых каталога **Book**, **Manga**, **Audiobook**: правильная привязка типов Edge TTS/ранобэ, манги и скачиваемых аудиокниг. Сохраняются существующие раздельные tree URI/постоянные разрешения SAF.
- Убран абсолютный путь временного кэша со вкладки «Инфо».
- `AudioSafDuplicates.java`, `DownloadWorker.java`: после успешного экспорта MP3 во внешнюю пользовательскую папку выполнена проверка SHA-256 и подтверждение ссылки в Аудиотеке. Только подтверждённые локальные копии удаляются, если аудиоплеер не воспроизводит их в данный момент.
- `SettingsActivity.java`: отдельный пункт безопасной проверки и очистки старых полных дублей MP3 по явному подтверждению; без автоматического удаления других типов файлов, незавершённых загрузок и единственных копий.
- Размеры MP3, удалённых из внутреннего кэша, в менеджере берутся из итогового SAF-файла.
- `MangaLibDownloadWorker.java`: локальный полный CBZ после публикации в SAF удаляется лишь при совпадении SHA-256, подтверждённом статусе задания и записанном SAF URI; промежуточные страницы и неудачные публикации не удаляются преждевременно.

## Браузерные вкладки и единый UI

- `BrowserTabs.java`: общий компонент вкладок с закруглёнными верхними углами, небольшим акцентным индикатором и объединённой панелью содержимого.
- Применён к двум вкладкам менеджера и к разделам Настроек «Общие», «Чтение», «Аудио», «Онлайн», «Чтейцо». Принят как стандарт для последующих экранов.
- Вкладки и содержимое не используют сплошную акцентную заливку.

## Загрузки и смахивание

- `DownloadActivity.java`: перемещается только передняя карточка; действия «В архив» / «Отмена» остаются на задней неподвижной панели. Ширина раскрытия вычисляется по измеренной области действий, а не по фиксированной координате.
- Состояние раскрытия привязано к ID загрузки; завершение свайпа не обновляет весь список, что уменьшает вероятность исчезновения кнопок при обновлении прогресса.
- Архивирование по-прежнему происходит только по кнопке, не по самому жесту.
- `DownloadSourcePicker.java`: если доступен один источник, поисковик открывается сразу; при двух и более сохраняется верхний диалог выбора с карточками.

## ReaderActivity и заметки

- Плавающее контекстное меню выделения содержит **пять XML-иконок без текстовых подписей**: цвет, копировать, заметка, словарь, закладка. Доступность — через `contentDescription` и подсказки.
- `ReaderMarginMarksTextView.java`: левый маркер заметки 18 dp вертикально ориентирован по видимым символам первой строки отмеченного фрагмента, а не по высоте всего межстрочного интервала; акцентный цвет темы сохранён.
- Переход к заметкам/закладкам из менеджера выполняется как просмотр `browseToWord`, не вызывает перенаправление позиции Edge TTS. Сохраняется логика ручек выделения, автопрокрутки и меню.
