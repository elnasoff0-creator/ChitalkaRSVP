# ПРОЧиталка v1.11.154-beta CLEAN — полная расшифровка

База: v1.11.153-beta CLEAN BUILD HOTFIX.
Версия: `versionName=1.11.154-beta`, `versionCode=15400`.
Исходный проект: Android Java + XML; функции предыдущей версии сохранены.

## 1. Справочник
Содержимое `ActivityInfo` переработано в понятное руководство. Удалены формулы,
техническое устройство Edge TTS и описания для разработчиков. Описаны основные
сценарии чтения, аудиокниг, загрузок, архива, Edge TTS, манги, Чтейца и рыбалки.
Справочные пояснения вынесены из перегруженных пользовательских экранов.

## 2. Иконка «Скачать по ссылке»
Новый `ic_import_link.xml`: контурный VectorDrawable 24x24dp, прозрачная заливка,
единая толщина линий 1.5dp. Иконка работает с цветовыми темами.

## 3. Загрузки без блокирующего экрана
`DownloadActivity` отображает сохранённый список сразу после открытия. Проверка
файлов, актуальных статусов и обложек выполняется в фоне. Карточки обновляются
пакетно через DiffUtil, без потери прокрутки. Кэш ограничен 150 записями.
Кэшированная запись не используется для опасных действий, пока фактические данные
не подтверждены повторной проверкой загрузок.

## 4. Завершение озвучки Edge TTS
При подтверждённой готовности всех глав в выбранной папке показываются 100%
и «Завершено». Состояние сохраняется для объединённых MP3 и полных наборов
фрагментов. В проверке последних учтено наличие ожидаемых MP3 и JSON
метаданных каждой части; только временный кэш не считается основанием для 100%.

## 5. Названия загрузок по ссылке
В карточках показывается фактическое имя скачанного файла. EPUB/FB2 получают
заголовок из метаданных, если он доступен. При отсутствии корректного названия
используется файловое имя. Извлечение метаданных выполняется после загрузки,
вне UI-потока, и не меняет физическое имя документа.

## 6. Настройки: выделение и отступы
Толщина обводки «Цвет выделения» увеличена вдвое. Стандартизированы вертикальные
отступы карточек, добавлен интервал перед «Добавить шрифт». Маленькие кнопки
справки выравниваются справа в соответствии с вкладкой «Аудио».

## 7. Рыбалка: окно награды и эргономика
Кнопка «Продолжить» в окне награды уменьшена, чтобы избежать случайного
нажатия. Панель вываживания находится по центру игровой области, удобно
дотянуться любой рукой.

## 8. Рыбалка: масса и баланс
Максимальные массы по редкостям: обычная 1 кг, необычная 2 кг, редкая 5 кг,
легендарная 10 кг, мифическая 20 кг. Рост сопротивления по массе ограничен
12% дополнительного времени заполнения шкалы. Система удочек по-прежнему
регулирует доступные редкости: лучшая удочка позволяет поймать мифическую
рыбу массой до 20 кг.

## 9. Рыбалка: мерцающие рыбы
Базовый шанс мерцания по редкости: 1%, 2.5%, 5%, 10%, 15%.
Сохранён бонус лучшей удочки (+5 процентных пунктов), а также
режим 100% для разблокированного разработчика. Мерцающая рыба по-прежнему
даёт тройную награду золотом.

## 10. Рыбалка: ускорение после разворота
После смены направления рыба временно ускоряется (до +22%, около 0.30 с),
плавно возвращаясь к базовой скорости. Ускорение не накапливается бесконечно.

## 11. Награда «Мифический улов»
Достижение выдаётся при первом успешном мифическом улове, показывается
уведомление и сохраняется в статистике. Добавлена новая XML VectorDrawable
иконка награды, включая отображение в общем разделе наград.

## 12. Чтейцо и независимая рыбалка
Убраны длинные подсказки об отключённом питомце с информационной панели;
объяснения перенесены в справочник. Статистика рыбалки и кнопка «Игры» работают
при отключённом Чтейце. Игровая карточка автоматически открывается и
прокручивается в видимую область.
