# ТЗ — ПРОЧиталка v1.11.191-beta CLEAN

## 1. Быстрый возврат к текущему предложению

Не менять скорость обычного плавного TTS-сопровождения WordBoundary. Близкий возврат — короткая плавная анимация; дальний — прямое позиционирование к **нужной строке внутри RecyclerView-блока**, затем минимальная коррекция. Не прокручивать всю книгу по 22 dp за кадр. Старые callbacks не должны изменять экран после ручной навигации. Текущая аудиопозиция от визуального перехода не меняется.

## 2. Восстановление текстовой книги при запуске

При повторном открытии сразу показывать сохранённую позицию чтения/TTS из `UnifiedReadingProgress`, даже если временный `viewportWord` остался на обложке. Восстановление не требует Play и не зависит от сети или MP3. При неготовности TextView.Layout повторить попытку после измерения, без долгой видимой прокрутки. Сохранить возможность отдельного ручного просмотра в активной книге и перехода из заметок, закладок и оглавления.

## 3. Восстановление позиции манги

Сохранять устойчивый ID главы (в MangaLib — ID задания), страницу и относительное смещение внутри изображения в режиме ленты; не путать прочитанную главу после новой загрузки/пересортировки. WebView должен подтверждать восстановление после разметки. Запретить слепые поздние переходы по таймеру после пользовательского жеста. Сохранять последнее подтверждённое положение при быстром закрытии; отклонять ответы старых поколений главы. Проверить CBZ, CBR, HTML, MangaLib, поворот устройства и переключение «Лента/Страницы».

## 4. Перестановка и межстрочный интервал

Перенести из «Общие» в самый верх «Чтение»: предпросмотр текста, шрифт, добавление шрифта, размер шрифта. После них новый слайдер межстрочного интервала 0,8×–2,0×, шаг 0,05×, значение по умолчанию 1,0× без изменения прежнего внешнего интервала. Ниже разделитель и «Режимы чтения», все последующие настройки — как раньше. Настройка должна сохраняться, сразу отображаться в предпросмотре и применяться к книге после возвращения без сброса TTS, WordBoundary, выделений или текущей позиции.

## 5. Диагностика и выпуск

Добавить в логи этапы восстановления книги, быстрого возврата и позиций манги. В CI запустить автономные тесты + полную Android-сборку. Архив — полные исходники, только четыре MD-документа текущей версии. `versionName=1.11.191-beta`, `versionCode=19100`. После установки APK обязательна проверка реального UX.
