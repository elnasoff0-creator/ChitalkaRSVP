# ПРОЧиталка v1.11.157-beta — RanobeLIB cover hotfix

База: **v1.11.156-beta CLEAN Full Source**. Данная версия содержит полный Android-исходник.

## Исправления

1. **Новый CDN:** `cover.lib.social` включён в разрешённые источники обложек и изображения теперь запрашиваются с `Referer: https://ranobelib.me/`.
2. **Нормализация URL:** относительные пути `/uploads/cover/...` теперь направляются на `https://cover.lib.social`, а не на старый `cover.cdnlibs.org`. При неудаче сохраняется возможность попробовать старый CDN.
3. **Разные формы ответа API:** обработка `cover.default`, `cover.md`, `covers.default`, `coverImage`, `cover_image`, сырого идентификатора обложки и других встречающихся полей. При наличии UUID обложки путь восстанавливается через идентификатор произведения.
4. **Резервный источник:** если API не предоставляет рабочую ссылку, приложение пытается найти обложку в HTML страницы произведения — `img.cover__img[src]`, `data-src`, `og:image`, `twitter:image`.
5. **Надёжное сохранение:** поток скачивания ограничен 6 МБ, проверяются Content-Type и декодируемость, файл сохраняется как локальный `cover.jpg`.
6. **Восстановление ранее скачанных книг:** при отображении HTML-книг в обычной библиотеке фоновый загрузчик обложек повторяет попытку при отсутствии/повреждении локального файла. Старая HTML-книга пересобирается с найденной обложкой без повторного скачивания глав.
7. **Кнопка восстановления:** на странице RanobeLIB-книги, если обложка отсутствует, доступна «Загрузить обложку повторно» (обходит 15-минутный интервал между автоматическими попытками).
8. **Независимость от оглавления:** найденная обложка отображается даже при ошибке получения списка глав.
9. **Без изменений данных:** прогресс чтения, сохранённые главы, переименования книг, MangaLib, аудиозагрузки и рыбалка сохранены.

## Проверки и ограничения

- `qa/TestRanobeLibCoverUrls.java` компилируется и запускается обычным JDK, проверяет полный URL пользователя, относительные адреса, ID, оба CDN и отказ от сторонних доменов.
- `qa/test_v11157_cover_recovery.py` проверяет интеграционные контракты в исходниках и корректность XML.
- Предыдущие регрессионные тесты v155/v156 включены.
- **Сборка Android Gradle и проверка сетевой загрузки в Android не выполнялись**: в среде отсутствуют Android SDK и доступ к RanobeLIB из контейнера. При изменении HTML/API или антибот-защите сайт может не выдать обложку; код сохраняет книгу даже при этой ошибке.

Версия приложения: `versionCode 15700`, `versionName 1.11.157-beta`.
