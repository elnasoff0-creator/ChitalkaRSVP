# ПРОЧиталка v1.11.167-beta CLEAN — полная расшифровка

**База:** v1.11.166-beta CLEAN Full Source  
**VersionCode:** `16700`  
**VersionName:** `1.11.167-beta`  
**Среда:** Android 7.0+ (minSdk 24), targetSdk/compileSdk 35; целевая проверка пользователя — Android 16.

## 1. Исправлена видимость «Инфо» в универсальном менеджере

- Исправлен `BrowserTabs`: при двух–пяти вкладках полосе теперь задаётся фактическая ширина экрана, а вкладкам — равные доли доступного пространства (`MATCH_PARENT` + вес). В прежней реализации `HorizontalScrollView` мог располагать вкладки вне видимой части.
- В `UnifiedDownloadManagerActivity` ширина полосы и высота заданы явно, вместо неявного `addView()`.
- В менеджере по-прежнему ровно две вкладки — **«Файлы» и «Инфо»**; «Файлы» открывается первой, «Инфо» переключает содержимое, не создавая отдельный экран.
- Сохранены действия глав, MP3, CBZ, HTML, повторных загрузок, массовое «Скачать всё», Play/Pause, а также одна строка общего прогресса.
- Сохранено отображение однострочного пути SAF категории Book/Manga/Audiobook с видимым концом и кнопкой папки справа. Путь временного кэша не возвращён.

## 2. Общая браузерная система вкладок

`BrowserTabs.java` теперь служит единым компонентом оформления: закруглённые верхние углы, визуально связанная нижняя поверхность, тонкий акцентный индикатор, отсутствие сплошной акцентной заливки.

- `strip()` — текстовые вкладки.
- `iconStrip()` — вкладки только с XML VectorDrawable, с сохранением названия в `contentDescription`.
- Две–пять вкладок делят доступную ширину поровну. Для большего количества предусмотрена горизонтальная прокрутка.
- Общий стиль применяется **в четырёх существующих экранах с функциональными вкладками**: менеджер загрузок, настройки, словарь Edge TTS, поиск аудиокниг («Книги/Циклы»).
- `BrowserTabs` следует использовать и для всех новых вкладок будущих выпусков.

## 3. Настройки: иконки и динамический заголовок

`SettingsActivity`:

- Вкладки «Общие», «Чтение», «Аудио», «Онлайн», «Чтейцо» показывают **только иконки**. Текстовых подписей под ними нет.
- Заголовок верхней панели обновляется по выбранному разделу: **«Настройки · Общие»**, **«Настройки · Чтение»**, **«Настройки · Аудио»**, **«Настройки · Онлайн»**, **«Настройки · Чтейцо»**.
- Настройки и универсальный менеджер используют `AppToolbar`: одинаковая высота 52 dp, кнопка бокового меню 44 dp, одинаковые отступы и расположение заголовка.
- Полоса вкладок остаётся на месте при прокрутке содержимого раздела.
- Положение прокрутки сохраняется отдельно для каждого раздела при переключениях и пересоздании Activity.
- Кнопки изменения размера шрифта приведены к обычной поверхности и акцентному цвету темы.

## 4. Смахивание загрузок оформлено цветами текущей темы

`DownloadActivity.java`:

- **«В архив»**: фон `UiColorScheme.accent(...)`, контрастный текст.
- **«Отмена»**: фон `UiColorScheme.neutral(...)`, то есть обычная поверхность кнопок, контрастный текст.
- Удалены ранее жёстко заданные фиолетовый и коричневый цвета свайпа.
- Добавлен небольшой промежуток между действиями, смещение карточки по-прежнему рассчитывается от измеренной ширины задней панели, а не от жёстко заданного числа.
- Смахивание не архивирует файл само по себе: требуется нажатие «В архив».

## 5. «Три точки» больше не имеют видимой подложки

- Кнопки дополнительных действий с `ic_more_vertical` отображаются как **одна иконка без рамки/карточки**.
- Изменены менеджер загрузок, общий список загрузок, архив загрузок и верхнее меню чтения. В карточках Библиотеки троеточие уже было без подложки и сохранено.
- Сенсорная область остаётся прежней (порядка 43–46 dp), подписи доступны через `contentDescription`/tooltip.
- Индикатор перехода из карточки произведения менеджера заменён на стрелку `ic_next_chapter`, чтобы не путать переход с меню дополнительных действий.

## 6. Скруглённые собственные диалоговые окна

- Большинство диалогов приложения уже использовало `SwipeDialogs` со скруглёнными углами; этот механизм сохранён.
- Для оставшихся стандартных `AlertDialog.Builder` добавлен `RoundedDialogs.Builder`, который сохраняет нативные кнопки, выбор, ввод и обработчики, но задаёт скруглённый фон из `UiColorScheme.neutral`.
- Добавлена общая тема `ChitalkaAppTheme` и стиль `ChitalkaPopupMenu` со скруглённым фоном для нативных меню дополнительных действий.
- Собственные плавающие меню чтения и окно выбора источника уже имели скруглённые фоны; не заменялись.
- **Системные окна SAF/разрешений Android не изменялись.** Их форму определяет система.
