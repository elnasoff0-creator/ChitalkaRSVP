# ПРОЧиталка v1.11.134-beta CLEAN — FINAL HOTFIX

**Основа:** v1.11.134-beta CLEAN AUDIO UI HOTFIX. **Версия без повышения:** `versionName = 1.11.134-beta`, `versionCode = 13400`.

## 1. MangaLib: исправлен адрес первой страницы

В API MangaLib обнаружен реальный путь вида `//manga/shijou_saikyou_no_deshi_kenichi/chapters/1-6/01.png`. Прежний `MangaLibApi.imageUrls()` трактовал любой путь с `//` как потенциальный удалённый адрес и отвергал его до HTTP-загрузки. Теперь допускаются только **известные относительные пути каталога изображений** `//manga/...` и `//uploads/...`: начальный слеш нормализуется, затем путь объединяется с разрешёнными CDN. Записи вида `//evil.com/...`, непроверенные HTTP-адреса, `..` и посторонние хосты остаются заблокированными. Сохраняется обработка API-структур `url`/`path` и допустимых резервных серверов. HTTP 401/403 не обходятся; HTTP 429 обрабатывается ограниченными отложенными попытками.

## 2. MangaLib: продолжение загрузки после паузы

`MangaLibDownloadWorker` сохраняет каждую полученную и проверенную страницу во временной папке главы (`.pages_...`). Для повторного запуска уже имеющиеся изображения проверяются декодером и повторно не скачиваются. Кэш страниц **не удаляется** при паузе, системной остановке и ошибке сети. После скачивания всех страниц Worker формирует CBZ, проверяет ZIP и содержимое, затем удаляет временные изображения. Завершённый CBZ также проверяется перед повторным использованием.

Состояние задания дополнено `bytes` (количество байт проверенных страниц) наряду с `done`, `total` и `status`. Записи хранятся в существующем `MangaLibStorage`, с обратной совместимостью для старых заданий без поля `bytes`.

Кооперативная пауза происходит после завершения текущего сетевого запроса/страницы. Если Android останавливает Worker по системным причинам, это не помечается как пользовательская пауза: задание остаётся доступным для повторной обработки. Сохранённые страницы используются из кэша.

## 3. Новый экран «Загрузка манги»

Добавлена `MangaLibChapterDownloadsActivity`, открываемая из карточки MangaLib в общих «Загрузках» и через меню этой карточки. Экран оформлен по образцу менеджера загрузки озвучки:

- Название манги; число глав, общее количество проверенных/ожидаемых страниц, процент и общий объём в МБ.
- Группировка по томам с отдельной статистикой страниц, глав и МБ.
- Каждая глава: название, процент, прогресс-бар, скачанные/все страницы, объём, локализованное состояние и текст ошибки при наличии.
- Кнопки «Скачать все» (повторить имеющиеся приостановленные/ошибочные задания) и «Пауза»/«Продолжить», управляющие заданиями данного произведения.
- Нажатие на ошибочную/приостановленную главу запускает повторную обработку. Нажатие на готовую открывает чтение манги.

Новый экран предназначен для **уже добавленных в очередь глав**, а не для получения полного каталога всех ещё не выбранных глав. Дополнительные главы выбираются через поиск MangaLib.

## 4. Общие загрузки: действия `⋮`

Иконка системного overflow-контрола в карточках загрузок заменена на три вертикальные точки `⋮`, без круглого треугольника. По нажатию открывается прежний список действий. В меню MangaLib добавлены «Главы и загрузка», «Найти другие главы» и «Пауза загрузки манги»/«Продолжить загрузку манги»; экспорт готового CBZ и отмена очереди сохранены.

В общей карточке MangaLib показываются число проверенных страниц, объём и статус «Приостановлено» после паузы.

## 5. Загрузка Edge-озвучки: кнопка паузы

В `EdgeChapterDownloadsActivity` длинная подпись «Пауза / Продолжить» заменена динамической кнопкой: при активной подготовке — «Пауза», при приостановленной — «Продолжить». В сводке статусы `running`, `queued`, `paused`, `failed` отображаются по-русски. Действия сервиса EdgeFullBookService сохранены.

## 6. MS Edge TTS: удалена устаревшая обработка пауз и точек

В `SettingsActivity` удалены переключатель «Сокращение пауз между предложениями MS Edge» и элементы «Замена точки · Edge TTS». Текстовый преобразователь не выполняет автоматическую глобальную замену точки: пунктуацию меняют только правила SQLite-словаря Edge TTS.

Из `EdgePlaybackService` удалена обрезка MP3 по вычисленной длине тишины. Из `EdgeStreamingService` и `EdgeCacheCommitter` удалён вызов анализа конечной тишины, сам класс `EdgeTrailingSilence.java` удалён. Обработка MP3 и WordBoundary, навигация по предложениям и кэш Edge сохраняются. Старые значения настроек могут оставаться в пользовательских `SharedPreferences`, но больше не применяются.

## 7. Настройки: подписи, отступы, иконка словаря

Исправлен зазор между кнопкой бокового меню и крупным заголовком «Настройки»: 14 dp. Сохранено ранее выполненное AUDIO UI HOTFIX — длинные подписи настроек Audio размещаются под заголовком, вместо вертикального сжатия букв.

Пункт словаря теперь называется **«Словарь MS Edge»** и использует существующий актуальный XML `ic_edge_dictionary.xml`. Старое описание «Каждая строка: исходное слово=произношение. Только...» полностью удалено, как и лишнее текстовое действие «Редактировать» у перехода.
