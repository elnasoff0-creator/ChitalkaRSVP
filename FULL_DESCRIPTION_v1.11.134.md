## 1. MangaLib: исправление «Не удалось определить адрес страницы 1»

**Файл:** `app/src/main/java/ru/reader/rsvp/MangaLibApi.java`.

В предыдущей версии метод `pages()` читал только строковое `url`, а затем безусловно подставлял `image` при отсутствии URL. По структуре публичного API MangaLib поле `image` часто содержит **имя файла**, а `url` — относительный путь. Имя файла без каталога не является адресом. Кроме того, если API не отдавал список серверов, даже корректный относительный путь не имел допустимой базы.

Сделано:

1. Добавлен `pagePath(JSONObject)`: поиск по `url`, `path`, `image_url`, `imageUrl`, `src`, поддержка вложенных объектов и относительных путей `/uploads/...` в `image`. Одиночное имя файла не интерпретируется как путь к изображению.
2. Если `data.pages` отсутствует, проверяется вложенная структура `data.chapter.pages`.
3. Серверы из `imageServers` фильтруются по `site_ids` для MangaLib (site ID 1), по HTTPS и по разрешённым доменам. Проверяются `imglib.info`, `mixlib.me`, `cdnlibs.org`, `mangalib.me` и соответствующие поддомены.
4. Если `imageServers` временно недоступен, для **уже известного корректного относительного пути** используются два публично документированных адреса: `https://img2.imglib.info` и `https://img3.mixlib.me`. Из одного имени файла путь не изобретается.
5. При отсутствии кандидатов выводятся номер страницы, очищенный от URL-параметров путь и число допустимых CDN. Токены в параметрах запроса не выводятся.
6. Сохранены ограничения предыдущего выпуска: HTTPS и allowlist, не более четырёх CDN-кандидатов при загрузке, отсутствие обхода HTTP 401/403/429, проверка сигнатуры/декодирования, проверка готового CBZ, лимит размера.

**Ограничение:** реальный HTTP-ответ для конкретной манги на устройстве в этой среде не получен. Исправление покрывает обнаруженные ошибки парсинга и резервных CDN, но не подтверждает успешность скачивания каждого конкретного тайтла. Если API возвращает только `image: "001.jpg"` без пути, приложение теперь сообщает о недостаточных данных, а не строит потенциально ложную ссылку.

## 2. Словарь Edge TTS: переработка интерфейса

**Файлы:** `EdgeDictionaryActivity.java`, `SwipeDialogs.java`, `UiColorScheme.java`.

- Удалена кнопка **«Символы +»**. Символьные правила можно по-прежнему создавать через обычное «Добавить замену».
- Оставлена **одна кнопка «+»**, с акцентной подложкой и контрастной иконкой. Во вкладке «Замены» она добавляет замену, во вкладке «Игнорировать» — правило игнорирования.
- Удалены отдельные кнопки **«+ Добавить исключение»** и **«Убрать пустые строки · Regex»**. Сохранённые Regex-правила не удаляются из SQLite.
- Активная вкладка «Замены / Игнорировать» подсвечивается выбранным акцентным цветом. Неактивная имеет нейтральную подложку.
- Прослушивание в списке и в диалоге теперь отображается **иконкой микрофона** (`ic_microphone`).
- В диалоге «Добавить замену» кнопка микрофона синтезирует **ровно содержимое поля «Заменить на»**. Убраны поле «Текст для предварительной проверки», кнопка «Проверить Regex / замену» и длинная подсказка о символьной замене.
- При сохранении Regex по-прежнему проверяются синтаксис и корректность групп замены с помощью Android-совместимого компилятора `EdgeSpeechTextTransform.compileUserRegex`. Вкладка игнорирования не теряет эту проверку.
- Добавлены нейтральные подложки кнопок редактирования/прослушивания/бокового меню и стандартный Ripple при касании; диалоги словаря используют `SwipeDialogs` со стандартным свайпом и анимацией.
- Сохранены редактирование слова из текущего предложения, контекст обычных замен, выбор ударения по гласной, поиск и SQLite-пагинация.

## 4. Единая настраиваемая цветовая схема

**Новый файл:** `UiColorScheme.java`.  
**Изменены:** `SettingsActivity.java`, `ReaderButtonColors.java`, `ReaderActivity.java`, `MainActivity` (использует общий ReaderButtonColors), `UiNavigationSheet.java`, `TtsTextBlockManager.java`, `AudioPlayerActivity.java`, `ComicReaderActivity.java`, `EdgeDictionaryActivity.java`, `MangaLibSearchActivity.java`, `SwipeDialogs.java` и некоторые общие элементы через `ReaderButtonColors`.

**Настройки → Оформление → Цветовая схема интерфейса**:

- **Из текущей темы** (по умолчанию) — использует настройку `button_accent_color`, если выбрана, иначе стандартный акцент;
- **Тёплая** — `#A26949`;
- **Зелёная** — `#39845B`;
- **Сиреневая** — `#7551A6`;
- **Свой цвет (HEX)** — выбор `#RRGGBB` с валидацией.

Сохранение в `SharedPreferences`: `ui_color_scheme` и `ui_custom_accent`. Существующие цвета `button_accent_color`, `button_color`, `bg`, `fg` сохраняются и учитываются. Оттенок подложки выделения рассчитывается как смешивание акцента с фоном (отдельные интенсивности для светлой и тёмной темы). Для кнопок используется контрастная иконка.

Унифицированы выделения и галочки в режиме чтения, ComicReader, выборе ориентации, оглавлении манги/аудиокниги/текстовых блоков, списках словаря. `SwipeDialogs` централизованно окрашивает кнопки диалогов, чекбоксы и радио-элементы; для длинных списков покрываются переиспользуемые пункты ListView. MangaLib использует стандартную анимацию и лист выбора глав. Основные кнопки приложения получают цвет через общий `ReaderButtonColors.accent`. Выбор палитры обновляет отображение в настройках сразу, при возврате в MainActivity/ReaderActivity/AudioPlayerActivity актуализируется оформление; в ComicReader обновление акцента не пересоздаёт WebView, чтобы не терять позицию.

**Граница реализации:** некоторые узкоспециализированные экраны, рисующие системные диалоги напрямую, всё ещё могут использовать цвета Android-темы. Для подтверждения полного визуального единообразия нужны скриншоты и тестирование на Android разных версий.

## 6. Рекомендуемые проверки в GitHub Actions и на устройстве

1. Запустить `gradle --no-daemon :app:assembleRelease --stacktrace` и убедиться, что отсутствуют ошибки компиляции.
2. Скачать с MangaLib первую главу и главу другого тайтла, проверить количество страниц в CBZ. Если возникает ошибка, записать новый подробный текст.
3. Проверить словарь: обе вкладки, одну кнопку «+», текст для прослушивания, сохранение/удаление Regex, фон микрофона и бокового меню.
4. Переключить три палитры и свой HEX. Проверить ReaderActivity, MangaLib, книгу, аудиокнигу, словарь, стандартные диалоги, светлую и тёмную тему.
5. Открыть мангу, перейти в настройки и обратно: убедиться, что изменение палитры не сбросило текущую страницу/прокрутку.
