# ПРОЧиталка v1.11.132-beta — Comic OCR

## Реализовано
- В существующем ComicReaderActivity добавлена кнопка OCR (сканирует текущую видимую страницу).
- Русский + английский офлайн Tesseract4Android; данные `rus.traineddata` и `eng.traineddata` находятся в assets и автоматически копируются в приватное хранилище при первом запуске OCR.
- Текстовые OCR-абзацы обводятся overlay-рамками поверх изображения. Координаты нормализованы по исходной картинке, учитывают режимы «Страницы» и «Лента», изменение размеров и масштабирование WebView.
- По нажатию на блок: через общий EdgeTtsClient синтезируется текст только выбранной рамки. Новое нажатие отменяет предыдущий запрос и воспроизведение. Автоматического следующего блока нет.
- Отдельный foreground-аудиосервис позволяет продолжать озвучивание при сворачивании ComicReaderActivity. В самой активности нет кнопок Play/Pause, управление — только тапом по области.
- Сохраняются JSON-кеши OCR для страниц комиксов в приватном filesDir/comic_ocr/<hash>. При повторном открытии overlay восстанавливается без OCR.
- Сохранены существующие методы восстановления скролла, перелистывания, масштабирования и ориентации.
- Версия в Gradle: 1.11.132-beta, versionCode 13200.

## Ограничения и статус проверки
- Разметка OCR основана на hOCR-абзацах; в сложных комиксах облачка могут распознаваться неточно.
- Один тап озвучивает один найденный абзац, не всю страницу.
- EdgeSpeechEngine ограничен 4096 байт входного UTF-8 текста; ComicOcrSpeechService ограничивает отдельный фрагмент до 1800 символов. Обычно текст облачка значительно короче.
- Зависимость Tesseract4Android 4.9.0 загружается через JitPack при сборке; требуется доступ к Gradle-репозиториям.
- Android SDK/Gradle отсутствуют в этом окружении, поэтому компиляция APK и проверка на устройстве НЕ выполнялись.
- Выполнены синтаксическая проверка Java и статические OCR-проверки. Старый QA_RUN_v1.11.131.py показывает 10/12 в текущем окружении; тесты feature-contract (ждут предыдущую версию) и Edge clock sync не проходят. Это НЕ является доказательством работоспособности на устройстве.

## Проверки в Android Studio
1. Открыть проект, дождаться загрузки зависимости Tesseract4Android, выполнить `:app:assembleDebug`.
2. Открыть CBZ, изображение из папки и HTML-комикс; вызвать OCR на каждой странице.
3. Проверить рамки, тап, новый тап во время загрузки звука, скролл/масштаб/поворот.
4. Свернуть приложение во время аудио, вернуть его, проверить восстановление позиции и OCR-кеша.
5. Проверить разрешение на уведомления (Android 13+) и работу foreground mediaPlayback на Android 14/15.
