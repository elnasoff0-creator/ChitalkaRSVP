# ПРОЧиталка v1.11.163-beta CLEAN — журнал изменений

**База:** v1.11.162-beta CLEAN Full Source.  
**Версия:** `1.11.163-beta`, `versionCode 16300`.  
**Формат поставки:** полный исходный Android-проект, без APK.

## 1. Расширяемый выбор источников

В разделе «Загрузки» сохранены ровно три существующие кнопки категорий: поиск ранобэ, манги, аудиокниг. Теперь каждая сначала открывает общий диалог выбора поставщика.

| Категория | Поставщики v163 | Ключ выбранной папки |
|---|---|---|
| Ранобэ | RanobeLIB, Ranobes.net | `ranobelib_search_tree` |
| Манга | MangaLib | `mangalib_search_tree` |
| Аудиокниги | Книга в ухе | `audiobook_search_tree` |

При подключении будущего сайта добавляется запись в `DownloadSourcePicker`, а не отдельная кнопка. Хранилища скачанных материалов разных сайтов остаются разделёнными по идентификаторам и подпапкам.

## 2. Новый HTML-источник Ranobes.net

Добавлены:

- `RanobesApi.java`: HTML-поиск названий, открытие книги по адресу `/novels/...html`, получение публичной карточки, извлечение ссылок на главы, чтение HTML. Запросы ограничены HTTPS и Ranobes.net; при HTTP 403/429/503 либо странице подтверждения — явная ошибка без обхода защиты.
- `RanobesSearchActivity.java`: поиск по названию/прямой ссылке, сохранение запроса, перелистывание результатов, обложки.
- `RanobesBookActivity.java`: автор/описание/обложка; разбиение доступных глав по томам; выбор глав, тома и всех доступных глав. При объёмных списках предусмотрен выбор диапазона.
- `RanobesQueue.java` и `RanobesDownloadWorker.java`: отдельная последовательная очередь WorkManager с независимым состоянием каждой главы, паузой и возобновлением. Повторно скачивать успешно сохранённые главы не нужно.
- `RanobesStorage.java`: локальные файлы глав, объединённый `book.html`, метаданные `book.json`, обложка `cover.jpg`, запись книги в стандартную Библиотеку. У книги на русском и английском отдельные каталог, HTML и прогресс чтения. При настроенной общей папке «Ранобэ» экспортируются и главы, и итоговая книга, и метаданные.
- `RanobesTranslate.java`: *не GTranslate*. Необязательный машинный перевод с английского на русский **на устройстве** через Google ML Kit. Требует загрузить модель Google при первом использовании. Для выбранного русского перевода можно дополнительно сохранять оригинал.

**Ограничение:** публичный HTML Ranobes и структура оглавления могут меняться; на сайте встречаются HTTP 503. Реальную полноту поиска и оглавлений, машинный перевод и массовое скачивание на живом сайте подтвердить не удалось. При закрытых главах загрузка не выполняется. Ни API GTranslate, ни обход антибота не реализованы.

## 3. Единый менеджер загрузок

Новый `UnifiedDownloadManagerActivity.java` открывается при нажатии на карточку любого типа в общем списке. В нём одинаковые секции **«Мета»**, **«Файлы»**, **«Обложка»**, общий прогресс, файлы/главы/треки, статусы, кнопки управления и доступные метаданные.

- Аудиокниги «Книга в ухе»: новый менеджер вместо автоматического запуска `AudioPlayerActivity`. Плеер доступен по отдельной явной кнопке «Слушать».
- Для Edge TTS, MangaLib, RanobeLIB, Ranobes.net и загрузок по ссылке используются те же вкладки, но данные берутся из *существующих* очередей. В «Подробнее» сохранены специализированные экраны для расширенных действий.
- Сохранённые карточки открываются по идентификатору немедленно, а обновление состояния идёт асинхронно. Нет обязательной глобальной проверки диска перед открытием.
- Добавлены размеры/прогресс отдельных MP3 или HTML-глав по данным соответствующего загрузчика.
- Локальная/доступная по сети обложка загружается асинхронно, при отсутствии показывается нейтральная иконка.
- В общие карточки добавлены компактные метаданные (автор, исполнитель, формат) только при наличии сведений.
- Уведомление обычной аудиокниги теперь ведёт в менеджер, а не в плеер.

**Техническая оговорка:** унифицирован UI и его адаптеры данных, **не** переписаны низкоуровневые сетевые движки других источников. Специализированные экраны остаются через кнопку «Подробнее».

## 4. Совместимость

- Сохранены предыдущие изменения v1.11.162: компактные менеджеры закладок/заметок, контекстное меню, словарь Edge, очистка RanobeLIB HTML, быстрое открытие книг.
- Сохранена сегментация Edge TTS v1.11.158 (обычные части около 800, приоритетные до 500 символов), без возвращения тяжёлой автоматической пересборки HTML.
- Идентификаторы существующих загрузок и прежние настройки выбранных папок не меняются.
- Пользовательские файлы не удаляются, скрытые записи архива не восстанавливаются автоматически.

## 5. Проверка и ограничения

- Синтаксически разобраны **180 Java-файлов** стандартным `JavacTask.parse()` Java 17: ошибок синтаксиса 0.
- Проверены **169 XML-файлов**: ошибок разметки 0.
- **11 структурных тестов** `qa/test_v163.py` прошли, включая выбор источников, единые папки, интеграцию меню, карточки загрузок и новые компоненты.
- Оригинальные папки v162 не удалялись; сборка основана на полном проекте v162.
- **Android SDK и Gradle здесь недоступны: не выполнялись `assembleRelease`, установка APK и тестирование на смартфоне.** Проверка синтаксиса и структурные тесты не заменяют Android-компиляцию.
- При первом запуске on-device ML Kit перевода может понадобиться сеть для загрузки языковой модели. Сайт Ranobes.net может ограничивать автоматический доступ; реализована корректная фиксация ошибок, но не гарантирована загрузка всех глав.
