# ПРОЧиталка v1.11.184-beta CLEAN

Полные исходники Android-приложения «ПРОЧиталка».

## Главное

- Штатное выделение Android по долгому нажатию внутри блока текста и собственные действия контекстного меню.
- Расширение через несколько блоков через отдельную команду и существующий контроллер маркеров.
- Цитатник для каждой книги со списком «Все цитаты», редактированием, удалением и исключением из реплик питомца.
- Питомец «Чтейцо» показывает случайные цитаты в облачке (50/50 с обычными фразами на тап при наличии цитат).
- Неизменённая модель просмотра книг и синтеза Edge TTS.

## Версия

`versionName = 1.11.184-beta`, `versionCode = 18400`, Android Java 17, `compileSdk = 35`.

## Сборка в GitHub Actions

Содержимое архива нужно поместить в корень репозитория вместе с каталогами `app`, `qa`, `.github` и файлом `build.gradle`. CI выполняет проверки Java, тест вероятности цитат, проверку XML, `gradle :app:assembleRelease` и подписывание при настроенных секретах.

## Проверки

См. `QA-REPORT-v1.11.184-beta.md`. Android SDK и Gradle не были доступны в локальной среде подготовки, поэтому успешная сборка APK и корректная работа системного ActionMode на устройстве ещё должны быть подтверждены через CI/Android-тесты.
