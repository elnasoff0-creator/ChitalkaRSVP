# CHANGELOG v1.11.186-beta CLEAN

## A. Собственная система выделения текста вместо платформенной

**Причина:** с момента подключения штатного `setTextIsSelectable(true)` / `ActionMode` в v1.11.184 обнаруживались конфликты с жестами, WordBoundary, прокруткой и собственным меню действий; штатный TextView не поддерживает межблочное выделение в RecyclerView.

**Изменено:**

- `ReaderActivity.java`: отключено системное TextView-выделение; удалены системное контекстное меню, callback и его поля состояния. Сохраняется только собственная панель с векторными иконками «Цвет», «Копировать», «Заметка», «Словарь», «Закладка», «Цитата».
- `ReaderTextTouchPolicy.java`: независимый от Android pure-Java шлюз жестов. Короткий тап, долгое нажатие, скролл, мультитач и переиспользование строки RecyclerView не смешиваются. Проверяется номер связанного элемента; движение больше `touchSlop` отменяет запуск выделения.
- Долгое нажатие создаёт выделение слова, не переводит TTS на новое предложение при отпускании пальца; щадящий haptic-feedback. Прокрутка остаётся у RecyclerView.
- Абсолютные диапазоны выделения — UTF-16 координаты полной книги с исключённым концом, корректировкой суррогатных пар; слова служат только совместимостью со старыми заметками/закладками.
- `ReaderSelectionController.java`: зеркальные каплевидные маркеры с верхней точкой привязки к каретке, в акцентном цвете действующей темы, геометрия и зона касания согласованы. Сохранены изменение краёв выделения, переход через другой край, переход между текстовыми блоками, автопрокрутка при приближении к границе экрана.
- `ic_reader_selection_dictionary.xml`, `ic_edge_dictionary.xml`: новые XML VectorDrawable — `strokeWidth=1.5`, `strokeLineCap=round`, прозрачная заливка; цвета перекрашиваются через тему.

## B. Плавность WordBoundary без откатов позиции

- `ReaderActivity.java`: прежний постоянный опрос каждые 180 мс заменён на `wordBoundaryRefreshDelay()`; интервал 20–95 мс определяется близостью следующего настоящего WordBoundary и скоростью Media3. При отсутствии метаданных используется ограниченный опрос (90 мс).
- `WordBoundaryRefresh.java`: отдельная чистая функция для расчёта интервала; не изменяет позицию аудио или текущий выбранный фрагмент.
- `ReaderActivity.ChunkAdapter.Holder`: статические стили аннотаций и выделения вынесены в `annotationSpans`, а движущаяся подсветка — в `playbackSpans`. Только смена аннотации/диапазона пересоздаёт аннотационный слой; изменение слова затрагивает лишь динамический слой.
- `ReaderWordHighlightSpan.java`: 70-мс плавное изменение непрозрачности слова, без пересоздания текста, изменения ширины символов или прокрутки. На высокой скорости озвучки анимация пропускается; на устройствах с выключенными системными анимациями не запускается.
- Сохранены `ReaderSpeechPositionGuard`, фильтрация устаревших событий Edge TTS и запрет автоматического скролла во время пользовательского выделения. WordBoundary остаётся ведомым относительно времени воспроизведения Media3; никаких выдуманных временных меток или повторного синтеза MP3.

## C. Анимация загрузок и состояние кнопок

- `AnimatedDownloadProgressBar.java`: поверх реальной полосы заполнения движется полупрозрачный блик; значение процента остаётся фактическим из загрузчика. При неопределённом размере используется штатное indeterminate-отображение без фиктивного процента. Анимация останавливается при паузе/завершении, уничтожении/отсоединении View и учитывает системные ограничения анимаций.
- `DownloadButtonFeedback.java`: для нажатого и активного состояния кнопки используется акцентная обводка 2 dp; `StateListDrawable` без изменения внешних размеров. Ненажатые кнопки остаются нейтральными; цвет берётся из темы.
- `UnifiedDownloadManagerActivity.java`: главный прогресс-бар анимируется только в процессе работы; кнопки Play/Pause и «Скачать всё» показывают акцентную обводку с учётом оптимистичной реакции и подтверждения команд. Существующее кольцо ожидания вокруг иконки сохранено.
- `DownloadActivity.java`: прогресс в карточках задач показывает индикатор движения только для реально запущенных загрузок.
- `EdgeChapterDownloadsActivity.java`: анимация общего прогресса книги и отдельных глав; обводка «Подготовить все» / «Пауза» / «Продолжить» при нажатии и подтверждённом активном состоянии.

## D. Совместимость / ограничения

- Сохранены функции цитат, цветов выделения, заметок, закладок, словаря, Edge TTS и пет-памяти 50/50.
- Сохранены SAF-пути/разрешения, существующий кеш MP3, WordBoundary-sidecar, схема загрузки главы, миграция цитат/заметок.
- Удалены только устаревшие MD-файлы прошлых версий; в корне находятся README, CHANGELOG, QA и ТЗ текущего выпуска.
- Подтверждены статическая синтаксическая проверка и pure-Java/SQLite регрессионные тесты; полная Android-компиляция, UI-жесты и плавность на телефоне требуют отдельного испытания.
