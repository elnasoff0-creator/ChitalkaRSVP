# Изменения 1.11.181-beta

- В ReaderActivity сохранены штатные XML-иконки, системная иконка фактически активного движка показана небольшим бейджем справа внизу. Для Edge используется установленная иконка Microsoft Edge, если доступна, иначе встроенная XML-иконка Edge.
- В выборе способа озвучивания штатные XML-иконки слева, значки движков справа, выбор отмечается общей галочкой в кружке. Системный вариант назван «Системный оффлайн движок».
- Настройка «Резервный TTS» отображает системный значок вместо длинного названия. Диалог переведён на общий скруглённый лист со списком движков, пакетов и галочками справа. Системный вариант отделён от установленных.
- Техническая версия 1.11.181-beta / 18100.
