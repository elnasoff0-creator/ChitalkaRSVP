# ПРОЧиталка v1.11.128-beta CLEAN — полная расшифровка выпуска

**Дата выпуска:** 3 ноября 2026 года.  
**Основа:** `v1.11.127-beta CLEAN FEED TAP HOTFIX` (самая поздняя согласованная версия).  
**Новый `versionName`:** `1.11.128-beta`  
**Новый `versionCode`:** `12800`

## 1. Что обновлено в v1.11.128

1. В `app/build.gradle` повышен номер выпуска с `1.11.127-beta` / `12700` до `1.11.128-beta` / `12800`.
2. Добавлена отдельная автоматическая проверка метаданных версии `qa/test_v11128_release_metadata.py`.
3. Актуализированы проверки версии в двух действующих тестах функциональности `v1.11.127`, чтобы они проверяли текущий выпуск `12800`.
4. Общий запуск регрессии переименован в `QA_RUN_v1.11.128.py` и дополнен проверкой номера версии.
5. Пакет очищен от документов и протоколов выпуска `v1.11.127` и содержит только документацию текущего выпуска. Архив содержит весь код проекта, ресурсы и историю функциональных тестов.

**В этом выпуске нет новых изменений логики или интерфейса.** Это перенос утверждённого состояния приложения на следующий номер версии; версии Android `minSdk=24`, `targetSdk=35`, `compileSdk=35` не меняются.

## 2. Сохранённый ComicReaderActivity

- Верхний Toolbar без градиента. Слева кнопка бокового меню и активная иконка «Страницы / Лента», справа — название произведения и текущего файла внутри общей скруглённой подложки.
- Нижнее плавающее оглавление в стиле ReaderActivity со статистикой файла и текущей страницы.
- В режиме **«Страницы»** короткий тап одновременно скрывает или показывает обе панели, а горизонтальные свайпы перелистывают страницы.
- В режиме **«Лента»** короткий тап переключает обе панели; **прокрутка вверх/вниз только перемещает изображения и не изменяет видимость панелей** — последнее исправление v1.11.127.
- Масштабирование щипком и сохранение позиции остаются активны.

## 3. Сохранённый MainActivity

- Семь независимых блоков: продолжить текстовую книгу, Библиотека, продолжить комикс, Комиксотека, продолжить аудиокнигу, Аудиотека, Мини-Чтейцо.
- Отдельные заголовки «Продолжить чтение / аудиокнигу / комикс» над карточками убраны; сами карточки продолжения и управление ими сохранены.
- Квадратная скруглённая обложка продолжения комикса — `88 × 88 dp`.
- Изменение порядка секций, скрытие, переименование и восстановление названия через режим редактирования.
- Во всех трёх библиотеках меню `⋮`: «Открыть / Продолжить», «Сделать текущей», «Убрать из библиотеки». Удаляется только запись приложения, без удаления файлов. В Аудиотеке нет отдельной кнопки ▶ в строках списка.

## 4. Сохранённая Комиксотека

- Добавление комиксов папками; каждый CBZ/CBR в папке — отдельная глава; сохранилась поддержка одиночных архивов, папок изображений и HTML.
- Обложки, сохранение текущей главы, изображения, количество страниц и вычисление общего процента произведения; вид `3/18 · Стр 12/47 · 13%` — пример, реальная величина вычисляется из известного количества изображений во всех главах.
- При отсутствии полного индекса страниц приложение не подставляет выдуманный процент и не показывает `/0`.
- Для MangaLib сохранены поиск, обработка ссылок, выбор глав и создание локальных CBZ; также сохранены HTTP-заголовки и диагностика ошибок, добавленные в v1.11.127. Сетевая доступность MangaLib не подтверждена тестами в рабочем окружении.

## 5. Сохранённые TTS и Аудиотека

- Работа чтения, курсора, RSVP, системного и Edge TTS, аудиокниг, словаря произношения, закладок и сохранения позиции не изменена.
- При воспроизведении после паузы по настройке «Повторять предыдущее предложение» сервисы используют общую логику для Play в приложении, MediaSession, уведомления и гарнитуры.
- Сохранено исправление ссылки на внешний класс `EdgeStreamingService.this::rewindOnResume`.
- Сохранено центрирование иконок таймера сна, когда цифровой индикатор отсутствует.

## 6. Проверка и ограничения

Набор офлайн-тестов запускается командой:

```bash
python3 QA_RUN_v1.11.128.py
```

Он включает отдельную проверку `versionName/versionCode`, анализ Java-синтаксиса (без разрешения Android-типов), тестовые JVM-компиляции для MangaLib/обработчика Edge TTS и проверки жестов, регрессию проигрывания и комиксов. **Это не Android Gradle-сборка.** В среде без Android SDK/Gradle полноценная сборка `:app:assembleRelease` не подтверждена.

Для сборки в Android Studio или GitHub Actions:

```bash
gradle --no-daemon :app:assembleRelease --stacktrace
```

После компиляции требуется проверить на устройстве жесты «Страницы / Лента», MediaSession/гарнитуру и фактическую работу API MangaLib.
