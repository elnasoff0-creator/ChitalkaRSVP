ПРОЧиталка v1.11.83-beta CLEAN
Android исходный проект: Gradle 8.7 / AGP согласно build.gradle, JDK 17, compileSdk 35.

Основные изменения:
- Единая прокручиваемая книга. Обложка в элементе 0 RecyclerView, метаданные следом за обложкой.
- Контент до нижнего системного отступа, верхние и нижние кнопки в overlay-слоях; не меняют геометрию прокрутки.
- Toolbar по жесту вверх/вниз плавно сдвигается, не скрывает системный status bar.
- Нижняя единая акцентная кнопка оглавления + статистика; Play/Pause только в Курсоре/Скорочтении/Озвучке, по центру; WPM справа.
- Удалена опция полноэкранного режима и соответствующие ветви поведения.
- Отдельный вектор режима Скорочтение, не совпадающий со спидометром WPM.
- MediaSession в обоих аудиосервисах показывает реальную обложку, название, автора, прогресс и Play/Pause, плюс навигацию по аудиофрагментам/главам, если поддерживается.
- Существующие 18 спрайтов Чтейца неизменны.

Проверка: gradle --no-daemon :app:assembleRelease --stacktrace
