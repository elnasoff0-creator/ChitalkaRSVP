# ПРОЧиталка v1.11.118-beta — описание релиза

Базовая версия: v1.11.117-beta CLEAN FIX4. Новая версия: versionName `1.11.118-beta`, versionCode `11800`.

## Новые функции

1. В `EdgeDictionaryActivity` добавлена отдельная кнопка «Игнорировать» и список редактируемых правил (добавить, изменить, удалить, поиск). Правило является буквальной последовательностью символов, слов или строк, без регулярных выражений. Одно правило — до 400 символов. Лимиты: до 100 строк и 8192 символов хранения.
2. Игнорирование выполняется перед словарными заменами и перед передачей текста в Edge TTS. Если после исключения заданных символов/текста в фрагменте нет произносимого содержимого (букв/цифр), фрагмент полностью пропускается; ни MP3, ни WebSocket-запрос для него не создаются. Если правило встречается внутри нормального предложения, удаляется только совпавший текст, а остальная часть произносится. Позиции остальных слов сопоставляются с исходным текстом по UTF-16 для WordBoundary.
3. В потоковом `EdgeStreamingService` пропущенные клипы исключены из предварительной загрузки и кэшированного плейлиста. При выборе/переходе на отдельный пропущенный фрагмент сервис переходит к следующему валидному, включая последовательные пропуски и конец книги.
4. В `EdgeFullBookService` игнорируемые фрагменты исключаются из списка задач для синтеза. Проверка завершения подготовленной книги не требует MP3 для пропущенных фрагментов.
5. При наличии старого точного правила `***=.` из версии v1.11.117 его смысл меняется на «Игнорировать ***». После открытия словаря это правило переносится в новый список и удаляется из списка замен.
6. Пример кнопки «Добавить знаки» теперь `! → -`, прежний пример со звёздочками и его пояснение удалены. Обычные символьные и фонетические замены, ударения, контекстные правила и прослушивание сохраняются.

## Пример поведения

- Игнорирование `***`, текст клипа `***`: перейти к следующему клипу без обращения к WebSocket.
- Игнорирование `***`, текст клипа `Привет *** мир.`: отправить `Привет  мир.` на озвучку, но не отправлять звёздочки.
- Игнорирование `Пустая строка.`, полный текст клипа `Пустая строка.`: пропустить целиком.
- Если правило не совпало, текст передаётся без изменений.

## Примечания

- Это именно список исключений для Edge TTS. Исходный EPUB/FB2/HTML, оглавление, закладки и видимый текст остаются прежними.
- Новые правила вступают в силу для создаваемых запросов и могут требовать обновления текущего плейлиста при возврате из редактора словаря.
- Пользовательский ввод используется как буквальное совпадение, не как регулярное выражение.
- Сохранены все функции предыдущей версии CLEAN FIX4.
