ПРОЧиталка v1.11.72-beta CLEAN — полная расшифровка
=====================================================

1. ЕДИНЫЙ TTS / ПЕРЕКЛЮЧЕНИЕ
- EdgeOnlineActivity.switchTo больше не запускает новую Activity через startActivity/finish.
- Текущий движок останавливается, наблюдатели и привязки сервисов снимаются.
- Новый движок подключается в том же экране, без повторной загрузки UI и книги.
- Сохраняются выбранное предложение, позиция, подсветка, прокрутка и таймер сна.
- Состояние Play/Pause переносится на новый движок; при паузе автозапуска нет.
- Обработчики соединений проверяют активный метод TTS; переключение назад на
  Edge переустанавливает текущий якорь книги.

2. ВЫБОР СПОСОБА ОЗВУЧИВАНИЯ
- Кнопка движка открывает диалог: Системный TTS или Microsoft Edge TTS.
- Используются существующие ic_android_tts и ic_edge_tts.
- Одно нажатие на пункт выбирает метод и закрывает диалог.
- Кнопки Выбрать и Отмена отсутствуют.

3. ГОЛОСА SAMSUNG И GOOGLE
- Новый LocalVoiceCatalog перебирает установленные Android TTS engines,
  отдельно запрашивая русские локальные голоса каждого.
- Отображается поставщик Samsung / Google / прочий и идентификатор голоса.
- Выбор сохраняет точные engine package и voice ID; локальный сервис
  переинициализируется, не заменяя Activity.
- Аналогичный общий список добавлен в TtsVoiceActivity. Возможная блокировка
  Samsung TTS системой One UI отображается как недоступность, без подмены имени.

4. КОМПАКТНЫЙ TOOLBAR И ЦВЕТА
- TTS: Назад, Способ TTS, Голос, Таймер, WPM, Настройки (последняя справа).
- Курсор / Скорочтение: вертикальная кнопка WPM — спидометр сверху, число снизу.
- Во всех затронутых режимах Настройки — последняя кнопка справа.
- Верхние TTS-кнопки читают button_color и подбирают контраст.
- Play/Pause использует button_accent_color; цвета перечитываются после
  возвращения из настроек без повторного чтения книги.

5. НИЖНЯЯ ПАНЕЛЬ TTS
- Play/Pause закреплена геометрически по центру FrameLayout.
- Время прослушивания слева, процент Edge MP3 и переход в Загрузки справа.
- Для системного TTS процент Edge и кнопка Загрузки полностью скрыты.

6. СИСТЕМНЫЕ ОТСТУПЫ
- Новый SafeSystemBars применяется через ReaderApp ко всем Activity.
- Android WindowInsets учитывают статус-бар, нижнюю панель навигации и вырез.
- Иммерсивный режим чтения остаётся отдельным состоянием системных панелей.

7. SWIPE ДЛЯ ДИАЛОГОВ И МЕНЮ
- Все стандартные AlertDialog.Builder заменены на SwipeDialogs.Builder.
- Поддерживается закрытие смахиванием вниз от заголовка, а в списках —
  смахиванием вниз при достижении верхней позиции.
- Боковое меню MainActivity открывается свайпом вправо от левого края и
  закрывается свайпом влево, Back и нажатием вне меню.
- Прокрутка текстовых списков при обычных жестах сохраняется.

8. РЕЖИМЫ ЧТЕНИЯ
- Убрана широкая фоновая подложка вокруг Play/Pause в Курсоре/Скорочтении.
- Саму цветную кнопку Play/Pause, логику режимов и положение в книге сохранили.

9. НЕИЗМЕННЫЕ ВОЗМОЖНОСТИ
- Нарезка по предложениям не длиннее 600 символов.
- Edge MP3/WordBoundary постоянные, локальный TTS использует временный кэш.
- Нет пользовательской очереди Edge, сохранены фрагменты и офлайн-режим.
- Подсветка предложения плюс меток слов, выбор старта по предложению.
- Таймер сна, переключатели автозапуска касанием и хвостовой тишины Edge.
- Все 18 утверждённых XML-спрайтов Чтейца без изменений.

ПРОВЕРКА: Java синтаксис, XML и qa/check_sentence_chunks.sh пройдены.
Сборка Android SDK/Gradle не выполнена: требуются GitHub Actions и тест на устройстве.
