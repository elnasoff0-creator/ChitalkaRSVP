ПРОЧиталка — v1.11.99-beta CLEAN

Исходный Android-проект. Прежнее applicationId: ru.reader.rsvp.
Android Studio: открыть корень проекта и синхронизировать Gradle.
Требования проекта: compileSdk 35, Java 17, AndroidX Media3.

Архитектура
- MainActivity.java: домашний экран, библиотека, мини-Чтейцо.
- ReaderActivity.java: все четыре режима чтения, без отдельной Edge Activity.
- ReaderTtsController.java: безэкранный маршрутизатор TTS-команд.
- AudioPlaybackService.java: локальная озвучка и аудиокниги.
- EdgeStreamingService.java: получение Edge аудио, warmup и очередь.
- EdgePlaybackService.java: воспроизведение через Media3.
- EdgeFullBookService.java: фоновая подготовка озвучки книги.
- EdgeAudioManager.java: единый индекс и совместимые ключи MP3 для всех Edge
  производителей и DownloadActivity. Не меняет формат сохранённых данных.
- DownloadActivity.java: интерактивный экран, асинхронные снимки загрузок.
- DownloadsRepository.java: чтение источников загрузок на фоновом потоке.
- EdgeChapterDownloadsActivity.java: статус и подготовка по главам.
- ReaderToolbarController.java: общая геометрия и анимация верхней панели.
- ReaderSheets.java / UiNavigationSheet.java / SheetDragLayout.java: общие
  выдвижные диалоговые окна чтения.
- ChteicoActivity.java: большой питомец; миниатюра в MainActivity.

Проверить на Android после сборки:
1. Большая библиотека: прокрутка загрузок, меню ⋮, смена фильтров при
   нескольких активных загрузках, открытие статуса отдельной главы.
2. Перезапуск с сохранёнными MP3 старых версий: доступность кэша, продолжение
   полной подготовки, соответствие процента скачанного текста.
3. Все четыре режима ReaderActivity, выбор локального и Edge голосов и запуск
   TTS без открытия другого Activity. Проверить переключение предложений.
4. Скрытие/появление toolbar, выдвижные диалоги и жесты закрытия.
5. Мини-Чтейцо: реплика не сдвигает питомца, закрывается автоматически,
   длинное нажатие открывает большой экран.
6. Выход из приложения во время загрузки и повторное открытие, чтобы исключить
   регрессию и проверить отсутствие ошибочного удаления файлов.

Это исходный beta-проект. APK и испытания на телефоне не выполнены.
