# ПРОЧиталка v1.11.195-beta — изменения

Основа: v1.11.194-beta CLEAN JAVA HOTFIX. versionCode 19500. Сохранены package name, настройки подписи, существующие ключи сохранений и предыдущие исправления сборки.

## Web Transfer
- Постоянный порт 8787; пользовательский порт 1024–65535; отдельный переключатель динамического режима (выключен по умолчанию). Динамический режим передаёт 0 в ServerSocket, статический порт запоминается. При занятом порте выводится сообщение о смене порта. Изменение порта и пароля только после остановки сервера.
- Локальное IPv4-имя prochitalka.local: добавлен минимальный mDNS-ответчик A-записи с multicast lock. IP остаётся основным адресом QR и копирования; локальное имя отображается при запуске ответчика. Реальное разрешение имени зависит от клиента и сети; полноценное разрешение конфликтов имён не реализовано. При смене сети/IP сервер останавливается по прежней политике, затем запускается вручную.
- Постоянный пароль: случайные 12 символов при первом запуске, пользовательский пароль 8–64 символа, шифрование AES/GCM через AndroidKeyStore, показ/скрытие и копирование. Вместо PIN браузер отправляет URL-encoded пароль в заголовке POST. HttpOnly SameSite=Strict cookie с случайным токеном; опциональное запоминание на 30 дней, в хранилище — хеш токена; сброс авторизаций и смена пароля. Пять неудачных попыток приводят к блокировке на минуту. HTTP не шифруется; только доверенная сеть.
- Выбор папки и перетаскивание с рекурсивным обходом. Протокол /api/folder: 4-байтовая длина JSON-манифеста + манифест + последовательные байты файлов, без ZIP и без чтения всей папки в массив. 8 ГиБ на файл; общий размер в long. Манифест до 4 МиБ, до 10 000 файлов, до 16 уровней пути. SAF-запись буфером 64 КиБ, временная папка, проверка размеров, переименование после завершения. Проверяется свободное место для primary external storage; на иных SAF-провайдерах ошибки записи обрабатываются, но предварительная оценка места не гарантирована. При отмене/обрыве незавершённая временная папка удаляется по возможности. После успешного переименования готовые файлы сохраняются даже при ошибке индексации.
- Одна папка аудиокниги — одна запись AudioLibrary с названием папки и естественной сортировкой глав (включая вложенные каталоги). Манга — одна запись ComicLibrary; вложенные каталоги, исключение именованных обложек из страниц. EPUB/FB2 и другие поддерживаемые текстовые файлы регистрируются отдельно. Смешанные несовместимые типы необходимо разделить; HTML допускает выбор типа, полное восстановление HTML-пакетов не подтверждено.
- Одна запись в истории на папку: суммарные байты, число файлов, отмена. Обложки cover/folder/front/poster, встроенные аудиообложки и первая страница комикса через существующие загрузчики; кэширование. Обложка сохраняется после импорта, не в ходе передачи. Дубликаты: пропуск или новое имя; объединение и замена папок намеренно не реализованы, чтобы не удалять имеющиеся данные.
- Акцентная Play/Stop в верхней панели, пульсирующий контур 1800 мс, индикация в общем разделе загрузок. В текущем интерфейсе фильтр — выпадающий список, поэтому состояние показано в заголовке рядом с «Загрузки» и на существующей кнопке Wi-Fi. Анимация отключается при уходе с экрана; сервис сохраняется.

## Интерфейс
- Боковое меню использует R.mipmap.ic_launcher вместо старого ic_launcher_foreground.
- BrowserTabs: нижние и верхние углы основного контейнера прямые; разрыв верхней линии под активной вкладкой; рамка рисуется Path на foreground, стык рассчитан по фактическим координатам вкладки. Настройки: граница закреплена на ScrollView, содержимое прокручивается внутри. Это изменение общего компонента, визуальная проверка на реальных устройствах необходима.

## Чтейцо
- Сохранено кормление, накопления, баланс 194 и преобразование опыта рыбалки. Убрано начисление по произвольной разнице index: RSVP/Курсор начисляют реально пройденные слова в ticker; обычный режим использует ограниченный положительный сдвиг видимой позиции после жеста и минимальную задержку. TOC сбрасывает временную точку отсчёта. TTS/аудио используют существующие тики фактического воспроизведения. Повторные страницы комиксов по-прежнему не начисляются. Сохранение полученных слов при паузе. Для уже достигнутой взрослой стадии начальный XP не ниже 1050. Точные пограничные сценарии чтения, перемотки и изменения ориентации требуют устройства.

## Ограничения
Это исходная beta-сборка. Полная Android-компиляция, подпись, UI на устройстве, mDNS в реальной сети, передача 1–8+ ГиБ и поведение SAF-провайдеров не проверены. См. QA-REPORT и ТЗ.
