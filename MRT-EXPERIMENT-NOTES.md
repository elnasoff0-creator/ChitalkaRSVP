# Эксперимент: онлайн-озвучивание через MRT (v1.11.11-beta)

Добавлена опция в ReaderActivity: ♫ -> Онлайн MRT (экспериментально).

Это не Yandex Cloud API: открывается опубликованная автором оригинальная HTML-страница
https://alkohole.github.io/machine-reading-text/index.html
в Android WebView и передаётся фрагмент текста текущей EPUB/FB2. Страница сама загружает
веб-скрипты, включая WebSpeechKit, и управляет воспроизведением. Сторонний исходный
JavaScript в APK не копируется; у репозитория не обнаружена явная LICENSE.

Ограничения / тесты:
- В приложении необходимо соединение с Интернетом.
- Нажатие Play внутри WebView должно быть настоящим пользовательским жестом;
  Android может блокировать автозапуск WebAudio.
- Проверка работоспособности голоса/сервиса на Android ещё НЕ выполнена.
- На текущем этапе нет гарантированной фоновой работы, MediaSession/управления
  через шторку для данного режима и бесшовного автоперехода между фрагментами.
- Текст ограничен 8000 символами на фрагмент, пользователь выбирает следующий
  вручную; сохранение позиции осуществляется при переходе между фрагментами.
- Это приблизительная позиция, точных временных отметок отдельных слов нет.
- На страницы Яндекса могут действовать ограничения, и они могут изменить
  способ авторизации или WebSocket-протокол без предупреждения.
- Системный TTS, MP3-аудиокниги и их прогресс не переписаны.
- Новая версия пробная; не публиковать как стабильную без проверки на смартфоне.
