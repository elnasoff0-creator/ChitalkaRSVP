# CHANGELOG — ПРОЧиталка v1.11.189-beta CLEAN

Базовый проект: v1.11.188-beta CLEAN. Основная цель: устранить рывки TTS-автопрокрутки, правильно подстраивать цитатное облачко питомца без изменения размеров его окна.

## 1. ReaderTtsScrollController.java — единый контроллер

- **Word-level геометрия.** Контроллер получает `word` и координату центра его строки (по `ReadingWordMap` + `BookChunkIndex` + `TextView.getLayout()`) в системе координат RecyclerView.
- **Условие запуска.** Пока слово остаётся в рабочей зоне, страница не смещается. Нижняя граница — 69% полезной области (исключены 88 dp сверху и 96 dp снизу для наложенных элементов интерфейса); исходная цель — около 61% при прокрутке, около 50% при явном возврате.
- **Одна анимация.** Через один `postOnAnimation`-цикл выполняется плавная последовательность коротких `scrollBy(0, step)` с ограниченным шагом; если WordBoundary сообщает следующее слово, цель меняется без запуска конкурирующей анимации.
- **Соседние элементы RecyclerView.** Если нужный блок пока вне экрана, контроллер доводит viewport до него постепенными шагами. Мгновенный переход `scrollToPositionWithOffset()` разрешён только для далёкой явно запрошенной позиции.
- **Без гонок.** При ручной прокрутке, выделении, перетаскивании маркеров, паузе/остановке озвучки, смене экрана и Activity-состояния движение отменяется. Перед каждым кадром сверяются актуальная эпоха навигации и разрешение автосопровождения.
- **Разделение обязанностей.** Контроллер не управляет Media3, не меняет текущий индекс TTS, WordBoundary, MP3, заметки или стили текста.

## 2. ReaderTtsScrollPolicy.java — проверяемая геометрия

Независимые от Android расчёты рабочей зоны, направления движения к ещё не разложенному элементу, ограниченного шага анимации. Добавлены Java-тесты `TestReaderTtsScrollPolicy189.java`.

## 3. ReaderActivity.java — подключение

- В `ensureWordVisible()` для TTS используется только новый контроллер; старое центрирование остаётся в другом режиме (CURSOR).
- Удалена мёртвая логика определения видимости *любой части предложения*; плавающая подпись теперь ориентируется на реально видимое слово.
- Геометрия слова учитывает фактическое смещение вложенного TextView относительно RecyclerView.
- Перехватывается начало ручного жеста; контроллер отменяется и в журнал пишется `MANUAL_SCROLL`.
- Перетаскивание маркеров, выбор текста и просмотр оглавления отменяют старое сопровождение.
- Отложенный явный возврат к речи защищён проверкой `viewportNavigationEpoch`.
- Смена режима, повторная отрисовка, приостановка/уничтожение Activity закрывают активные анимации. Возврат в Activity в режиме TTS больше не вызывает автоматическое центрирование только из-за жизненного цикла.

## 4. ChteicoActivity.java — облачко питомца

- Убрано увеличение `petSpeechFrame` с `260 dp` до `425 dp` для цитат; исходный контейнер питомца теперь всегда остаётся `260 dp`.
- Удалены `SpeechQuoteScroll` и внутренний прокручиваемый текст.
- `SpeechBubbleLayout` и `TextView` используют `WRAP_CONTENT` в доступной области с ограничением ширины и высоты.
- Для цитат число строк рассчитывается с учётом доступного пространства и текущих метрик шрифта, а длинный текст заканчивается системным `…` (`ellipsize END`).
- При переходах между короткими и длинными фразами габариты пузыря пересчитываются заново, внешний контейнер и изображение питомца не двигаются.
- Обычное поведение фраз, 50/50 при наличии цитат, режим сна, сохранение полного текста цитат и таймер показа сохранены.

## 5. PetSpeechBubbleSizing.java — ограничения пузыря

Чистые функции, не привязанные к Android View: максимальная ширина/высота внутри рамки питомца и безопасное число строк. Добавлены `TestPetSpeechBubble189.java`.

## 6. Логи

Категория `TTS_SCROLL`: `FOLLOW_TARGET`, `FOLLOW_START`, `FOLLOW_FINISHED`, `FOLLOW_SKIPPED`, `FOLLOW_CANCELLED`, `MANUAL_SCROLL`, `RETURN_TO_SPEECH`, `FOLLOW_JUMP_EXPLICIT`. События включают технические значения word/epoch/delta_px/elapsed_ms, без текста книги.
