# ПРОЧиталка v1.11.187-beta CLEAN — Full Source

**Исходная база:** v1.11.186-beta CLEAN. В версии v1.11.187 исправлен повторный запуск предложения Edge TTS, при котором могли пропускаться начало аудио и подсветка первого слова.

## Ключевые изменения

1. `EdgeSentenceSeek` не выбирает второе слово, если первая временная метка отсутствует. При невозможности точной перемотки в группе заново готовится **целое выбранное предложение**.
2. Для сохранённого MP3 при точном позиционировании используется небольшая предварительная перемотка (до 105 мс) с учётом окончания предыдущего слова.
3. `EdgeStreamingService` удерживает выбранное начало предложения при асинхронном переключении Media3-треков. Полный текст и кеш остаются прежними.
4. `ReaderActivity` отображает подсветку первого слова сразу при тапе, ещё до первой временной метки.
5. Сопоставление WordBoundary допускает русскую орфографическую нормализацию `ё`/`е`, без создания несуществующих таймингов.

В `.github/workflows/release.yml` проверки запускаются перед Gradle-сборкой. Для получения подписанного APK требуются Android SDK и секреты подписи в GitHub Actions.

Проверить на телефоне повторный тап по прослушанному предложению в начале, середине и конце сохранённого MP3, паузу и Play, смену голосового движка, отсутствие обрезания аудио, плавность WordBoundary и отсутствие откатов подсветки.

**Важно:** приведённые тесты выполняются без Android SDK и не заменяют сборку APK или реальные аудиопроверки на устройстве.
