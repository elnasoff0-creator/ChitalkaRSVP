ПРОЧиталка v1.11.67-beta CLEAN

Это исходный проект Android Studio, не APK.
Сборка CI: gradle --no-daemon :app:assembleRelease --stacktrace
Компиляция Android SDK в текущем окружении не проверена.

Проверка разделителя предложений на компьютере с JDK 17:
  sh qa/check_sentence_chunks.sh

Принцип работы:
- Откройте EPUB/FB2, выберите голос TTS, начните чтение в режиме «Курсор».
- При касании слова TTS откроет нужную позицию. При отсутствии точных меток воспроизведение начинается с предложения.
- Системный голос сохраняет временный WAV в кэше; Edge сохраняет MP3 и его метки постоянно.
- «Файлы аудиокниги» открывает встроенный просмотрщик файлов/экспорт.
- Для проверки локальных голосов откройте «Голос и озвучивание» и нажмите «Проверить» рядом с голосом.
- Полная подготовка Edge-книги доступна через «Загрузки».
