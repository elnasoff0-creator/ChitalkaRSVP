ПРОЧиталка v1.11.103-beta CLEAN — исходный Android-проект
Основа: v1.11.102-beta

Единственное функциональное изменение: восстановление WebSocket-подключения
MS Edge TTS после HTTP 403, если отказ вызван рассинхронизацией часов.
По заголовку HTTP Date вычисляется смещение, пересчитывается Sec-MS-GEC v2,
и отправляется максимум одна повторная попытка подключения с новым токеном.
Системное время телефона не меняется. Когда заголовок некорректен или токен
остаётся прежним, повторная попытка не выполняется.

Сохранены без изменений: размеры блоков Edge 900/600, потоковый Media3,
WordBoundary, предзагрузка, аудиокэш, HTTP 429, UI, главы и функции питомца.

Проверки: 15 shell-наборов в qa и qa/check_ui_core.py, включая
четыре сценария HTTP 403. Протокол моделировался локально, без подключения
к реальному серверу. Синтаксис Java проверен (Android SDK здесь отсутствует).

Сборка в окружении с Android SDK:
    gradle --no-daemon :app:assembleRelease --stacktrace
