## 1. Свайпы Чтейца: горизонтальные эмоции, вертикальная прокрутка

Изменён `ChteicoEmotions.attach()`:

- Горизонтальное движение пальца влево/вправо вызывает эмоцию питомца.
- Вертикальный жест передаётся родительскому `ScrollView` и прокручивает интерфейс.
- Направление фиксируется после достижения системного touch-slop; горизонтальный жест определяется по отношению |dx| > 1.25 × |dy|.
- Блокировка перехвата жеста родительским ScrollView включается только после определения горизонтального направления.
- Обычный короткий тап по питомцу продолжает вызывать прежнюю реакцию.
- Долгое нажатие на мини-питомца MainActivity теперь включает режим редактирования главного экрана вместо немедленного перемещения.

## 2. Новый пункт «Комикс» в левом боковом меню

В `UniversalDrawer` добавлен маршрут `comic` с иконкой `ic_comic_library.xml`.

- При наличии последнего доступного комикса открывает его непосредственно в `ComicReaderActivity`, с сохранёнными главой, позицией и режимом «Постраничный/Вертикальный».
- Если есть несколько комиксов, выбирает последний открытый по полю `opened`.
- Если ранее ни один не открывали, использует первый доступный элемент списка.
- Если комиксов нет или все записи недоступны, переходит к диалогу добавления через MainActivity.

Названия: пункт навигации — **Комикс**, секция главного экрана — **Комиксотека**.

## 3. Умная навигация «Чтение» и «Аудиокнига»

Аналогичная логика продолжения:

- «Чтение»: открывает последнюю книгу в ReaderActivity; если сохранённая последняя книга отсутствует, выбирает доступную книгу из сохранённой библиотеки. При пустой библиотеке открывает системный выбор файла книги.
- «Аудиокнига»: открывает последний сохранённый аудиотом через AudioPlayerActivity; при отсутствии последнего выбирает первый элемент аудиотеки. При пустой аудиотеке открывает диалог импорта аудиокниги.
- Если пользователь пришёл из другой Activity, MainActivity получает одноразовый параметр `drawer_action` (`book`, `audio`, `comic`) и запускает нужный импорт.

## 4. Редактор бокового меню

Созданы `DrawerEditorActivity.java` и `DrawerMenuStore.java`.

- Внизу левого меню есть постоянная кнопка **«Редактировать»**.
- Все маршруты имеют неизменяемые ID (`home`, `reading`, `audio`, `comic`, `downloads`, `pet`, `settings`, `update`, `help`).
- Пользователь может переименовать пункт, не меняя его действия.
- Можно изменить порядок пунктов перетаскиванием за ручку.
- Можно скрыть пункт и восстановить его через «Добавить пункт».
- Можно сбросить пользовательскую конфигурацию к стандартной.
- «Главный экран» и «Настройки» остаются обязательными, кнопка редактирования закреплена вне редактируемых маршрутов.
- Название и иконка «Чтейцо/Статистика» по умолчанию зависят от включения питомца.
- Изменения сохраняются в SharedPreferences. Скрытие пунктов не удаляет пользовательские данные.

## 5. Добавление комиксов из единой кнопки «+»

- Удалена отдельная кнопка **«Добавить комикс»** из карточки Комиксотеки.
- Диалог `showAddMenu()` на главном экране теперь предлагает три пункта: **Книгу**, **Аудиокнигу**, **Комикс**.
- Выбор «Комикс» открывает прежнее меню форматов импорта: папка с HTML, папка с изображениями, архив CBZ/CBR.
- Поддержка HTML/JPG/PNG/WebP/CBZ/CBR из v1.11.122 сохраняется.

## 6. Режим редактирования MainActivity

Переработан `HomeSectionOrder.java`.

- Вход: долгое нажатие на свободную область главного экрана, область блока или на мини-питомца.
- В обычном режиме прямой Drag & Drop отключён.
- В режиме редактирования появляются подписи элементов, ручки для Drag & Drop, кнопки скрытия, «Добавить элемент», «Сброс» и «Готово».
- Для упорядочивания используются шесть независимых секций:
  1. Продолжить чтение
  2. Библиотека
  3. Комиксотека
  4. Продолжить аудиокнигу
  5. Аудиотека
  6. Мини-Чтейцо
- Удаление секции означает скрытие; книги, комиксы, аудио и статистика остаются нетронутыми.
- «Добавить элемент» восстанавливает скрытые секции.
- После перезапуска сохраняются видимость и порядок элементов.
- При первом запуске после обновления старый порядок трёх групп `reading,audio,pet` отображается на новые шесть секций без принудительного сброса.
- Редактор главного экрана независим от редактора бокового меню.

## 8. Статистика игры под наградами

В `ChteicoActivity` после секции наград появляется «Статистика игры», отображающая:

- личный рекорд (м);
- суммарную игровую дистанцию (м);
- количество забегов;
- накопленный игровой опыт XP.

Используются прежние ключи `runner_best`, `runner_distance`, `runner_games` и `runner_xp` в `ChteicoStore`. Данные не сбрасываются.

## 9. Переработка игрового поля

- Экран игры построен на светлой карточке `#FFF9F2`, аналогичной контейнеру питомца.
- Размер игрового контейнера — вся доступная ширина с горизонтальными отступами, высота **260 dp**, скругление 18 dp.
- Тёмный контур `#30221E` на светлом фоне, без серой заливки внутри игровых спрайтов.
- Игровые эволюции получили увеличенные размеры: Чтенчик — **72 dp**, Чтенец — **88 dp**, Чтун — **108 dp**.
- Контурные книги-препятствия увеличены: высота примерно **32–80 dp**.
- Сохраняется 2 кадра бега + 1 статичный прыжок на каждую из трёх стадий.
- На игровом экране есть компактная верхняя панель с кнопкой назад и паузой, индикаторы дистанции и рекорда.
- Подробный инструктаж удалён из игры.

## 10. Переменная высота прыжка и гравитация +30%

- Исходная гравитация 1050 dp/с² → новая **1365 dp/с²** (+30%).
- Короткий тап запускает прыжок немедленно, с целевой высотой около **30 dp**.
- Пока палец удерживается, действует дополнительное подъёмное ускорение **1254 dp/с²** (не дольше 240 мс).
- После отпускания подъёмная сила отключается, продолжает действовать гравитация.
- Максимальная высота программно ограничена **90 dp**.
- Нет двойного прыжка в воздухе; новый прыжок возможен только после приземления.
- Целевые ориентиры: 80 мс ≈50 dp; 160 мс ≈70 dp; 240 мс ≈90 dp.
- Расчётный интервал полного прыжка ~0.79 с при интеграции с переменной подъёмной силой, вместо прежнего баллистического 0.83 с; реальная длительность зависит от частоты кадров.
