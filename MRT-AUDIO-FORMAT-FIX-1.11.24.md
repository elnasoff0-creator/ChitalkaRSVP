# ChitalkaRSVP v1.11.24-beta — исправление перехвата аудиоформата

## Причина

`AudioContext.decodeAudioData()` принимает **закодированные аудиоданные разных форматов**, а не только MP3. В v1.11.23 `MrtAudioCache.finish()` отвергал всё, что не имело сигнатуры MP3, хотя WebView мог получать большой самостоятельный WAV/AAC/OGG/MP4/WebM/FLAC буфер. У пользователя первый фрагмент (19 чанков) успешно создаётся, а второй (1 чанк, ~242 КБ) отклоняется. По скриншоту нельзя достоверно определить формат второго буфера без первых байтов.

## Изменения

- `MrtAudioFormat.java`: определение исходного формата по сигнатуре файла.
- `MrtAudioCache.java`: хранение оригинальных байтов с корректным расширением; отсутствие повторного кодирования; диагностика первых 16 байтов при неизвестном формате. Не удаляем старые MP3 и восстанавливаем файлы всех распознаваемых форматов.
- `MrtPlaybackService.java`: передаёт Media3 ExoPlayer `mimeType` в соответствии с форматом; отображает фактическую ошибку декодирования.
- `MrtDownloadActivity.java`, `MrtOnlineActivity.java`: показывают сообщение об ошибке генерации/плеера.
- `MrtFileExplorerActivity.java`: позволяет открывать и экспортировать WAV/AAC/OGG/M4A/WebM/FLAC наряду с MP3.
- Добавлен тест `tests/test_mrt_audio_formats.sh`, включён в GitHub Actions.

## Как проверить на Android

1. Обновить приложение без удаления старой установки (сохранить библиотеку и кэш).
2. Открыть книгу и включить автоподгрузку с тремя фрагментами.
3. Проверить первый и второй аудиофайлы. Если второй распознан, расширение будет соответствовать кодеку и будет добавлено в плеер без повторного кодирования.
4. Если приложение снова покажет ошибку, прислать **только текст ошибки** (особенно первые байты в HEX). Это позволит определить фактический формат источника. Не нужно публиковать саму книгу или аудиофайлы.

## Ограничения

- Распознавание по заголовку не гарантирует декодирование Android конкретного кодека. Реальную поддержку определит ExoPlayer.
- Неизвестные/raw данные без заголовков (например, PCM без параметров) нельзя корректно интерпретировать как MP3 и воспроизвести без дополнительной информации о частоте, числе каналов и типе выборок.
- Полная сборка APK и реальный Android/WebView тест не выполнялись в окружении без Android SDK; проверка будет в GitHub Actions.
