# Импорт папки с HTML в ПРОЧиталку v1.11.159-beta

## Добавление книги

1. Откройте **Главная → + → Книгу → Импортировать папку с HTML**.
2. Выберите исходную папку книги в системном окне Android (желательно `Documents/Книга/` или на SD-карте).
3. Разрешите приложению чтение этой папки.
4. ПРОЧиталка отсортирует HTML по томам и номерам глав, создаст одну `book.html`, обнаружит локальную обложку и добавит книгу в обычную Библиотеку.
5. Нажмите «Продолжить» в Библиотеке — откроется существующий ReaderActivity с оглавлением.

Пример расположения исходников:

```text
All The Skills/
  cover.jpg
  v1/
    chapter_1.html
    chapter_2.html
  v2/
    chapter_1.html
    chapter_1.5.html
    chapter_2.html
```

Можно использовать и простую папку без томов; имена глав могут содержать кириллицу. Допускается одна готовая HTML-книга с встроенными `section.ranobe-chapter`.

## Безопасная замена текста

1. В обычном файловом менеджере замените содержимое `chapter_XX.html` **в той же исходной папке**. Не меняйте путь папки, если она уже импортирована.
2. Откройте книгу повторно либо выберите **Библиотека → ⋮ → Проверить изменения HTML**.
3. Программа проверит SHA-256 файлов и при обнаружении изменений соберёт новую книгу, сохранив предыдущую версию `book.html.bak`.
4. Позиция чтения будет найдена по фрагменту текста; если он исчез, приложение ориентируется на примерное место в той же главе. Проверьте текущий абзац при крупных изменениях перевода.

Не редактируйте сгенерированный `book.html` — он собирается автоматически и при следующем обновлении будет пересоздан. Правьте исходные файлы глав.

## Ранобэ, загруженные из RanobeLIB

Книги RanobeLIB используют собственные папки томов и глав (`volumes/vX/chapter_Y_bZ.html`). Изменения этих файлов выявляются перед следующим открытием книги; `book.html` собирается заново. Для ручной проверки используйте пункт в меню книги. Отдельные главы должны оставаться корректными HTML с непустым `<article>`.

## Где хранятся созданные файлы

Подготовленные HTML-книги размещаются в папке приложения `Documents/Books/ImportedHTML/<идентификатор>/`. Там есть `book.html`, `manifest.json`, `cover.img` (если найден локальный файл), `assets/` (иллюстрации) и резервные версии `.bak`. Исходная папка остаётся отдельно, на выбранном пользователем накопителе. Если книга переносилась через «Перенести в папку», связь с исходной HTML-папкой сохраняется.

## Если папка стала недоступна

Если **сама собранная книга** находится в доступной памяти устройства, она остаётся читаемой; проверка исходной папки откладывается до восстановления доступа. Если собранная книга тоже перенесена на извлечённую SD-карту, она будет недоступна до возврата карты. Для нового расположения файлов выберите «Импортировать папку с HTML» ещё раз.

## Проверки и установка

Это полный исходный Android-проект, а не APK. Откройте его в Android Studio и соберите с JDK 17/Android SDK 35. Перед обновлением на устройстве рекомендуется сделать резервную копию библиотек и пользовательских файлов. В этой среде проверены синтаксис и структурные тесты, не запуск Android-приложения и не полноценная сборка.
