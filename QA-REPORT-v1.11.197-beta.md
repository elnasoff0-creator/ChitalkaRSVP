# QA — ПРОЧиталка v1.11.197-beta

База: v1.11.196-beta CLEAN WEB DASHBOARD. VersionCode 19700.

## Выполнено локально
- 39 групп проверок (38 команд + ReaderActivityMethodCheck), все завершились успешно. Тест BookLoader в локальном режиме проверял только FB2 и сигнатуры API-заглушек.
- ReaderTextMigration и ReaderAnnotationsStore: дополнительная проверка типов Java с Android/JSON-заглушками — PASS.
- Java syntax: 240 исходных файлов, без Android typecheck.
- ReaderTextReanchor: JVM-тест сопоставления слов, символьных смещений, повторяющегося текста, позиции в удалённом оглавлении — PASS.
- BookLoader: компиляция против API-заглушок Android и jsoup. Настоящий XML-парсер FB2: заголовки, вложенные разделы, примечания — PASS. HTML/EPUB-часть теста не запускалась локально: jsoup отсутствует.
- Основной журнал: qa/qa-results-v197.txt. Реальная проверка EPUB2/3 и HTML добавлена в release.yml после сборки Gradle с обязательным jsoup 1.18.3.

## Не подтверждено
- Полная Android-компиляция, подписанный APK, визуальная проверка и запуск на устройстве.
- Миграция реальной SQLite базы и Android SharedPreferences на пользовательском устройстве, все варианты ранее импортированных книг и SAF.
- Точное восстановление позиций при отсутствии RBI4 или изменении источника. Никакие пользовательские записи не удаляются, но возможна неточная привязка. Старые заголовки, уже удалённые прежним загрузчиком из исходного файла, невозможно восстановить без оригинала.
- Полная совместимость всех ранее подготовленных целых Edge-аудиоглав: ключи фрагментов уже зависят от текста; переподготовка изменившихся фрагментов может быть необходима. Индексы и статусы опубликованных глав требуют проверки на устройстве. Пользовательские MP3 не удалены.
- Оставшиеся ограничения Web Transfer, mDNS, многогигабайтных передач и рамок из v1.11.196 не изменялись.
