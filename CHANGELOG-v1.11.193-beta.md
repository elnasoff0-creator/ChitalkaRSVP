# Изменения ПРОЧиталка v1.11.193-beta CLEAN

База: v1.11.192-beta CLEAN Javac Hotfix. `versionCode 19300` / `versionName 1.11.193-beta`.

## Web Transfer — внешний вид и навигация

- Большая кнопка «Запустить сервер» убрана из содержимого; запуск/остановка через новую контурную кнопку в правой части общего Toolbar. Состояние иконки автоматически меняется при работе сервера; повторный тап во время запуска блокируется. При активной передаче остановка требует подтверждения.
- Новая XML VectorDrawable для запуска, остановки и копирования адреса (`ic_web_server_start`, `ic_web_server_stop`, `ic_web_copy_address`). Используются размеры, цвета, фоны, скругления и отступы общего интерфейса.
- Компактная стандартная кнопка папок с меню выбора категории и системным SAF-пикером; прежние разрешения не сбрасываются.
- Удалена кнопка «Настройки Web Transfer» из экрана сервера; настройки по-прежнему находятся в «Настройки → Онлайн».
- Убраны две длинные инструкции с экрана. Новый раздел «Справка → Передача книг по Wi-Fi» содержит пошаговое руководство, объяснение PIN, защиты, форматов, просмотра прогресса и ошибок. Иконка `?` в Toolbar открывает сразу этот раздел.

## Все Wi-Fi-передачи — в общем списке «Загрузки»

- Новый `WebTransferDownloadStore` хранит последние 300 операций: ID, имя/формат, полученные и ожидаемые байты, статус, ошибку, время и URI успешно импортированного файла (без содержимого книги или PIN).
- Стабильный ID `wifi:...` используется одновременно сервером, браузером и `DownloadsRepository`, чтобы не создавать дублей при обновлении экрана.
- Фильтр «Wi-Fi» добавлен в «Загрузки», источник «Wi-Fi» показан на карточках, прогресс основан на фактическом объёме полученных байтов.
- Статусы: «Ожидает», «Передача», «Импорт в библиотеку», «Готово», «Ошибка», «Отменено», «Дубликат». Завершение 100% HTTP-тела ещё не означает успешный импорт.
- Передача отменяется непосредственно из общего менеджера. Остановка разрывает сокет, удаляет `.part` и сохраняет статус; запоздалые callbacks не могут превратить отменённое задание в завершённое.
- История сохраняется после закрытия экрана/приложения; прерванные при сбое процесса активные операции корректно помечаются ошибкой. Завершённую запись можно удалить из истории, **не удаляя импортированный файл**.
- В браузере уникальный `X-WT-Transfer-ID` и авторизованное `POST /api/cancel`; повторная отправка с другим именем получает новый ID.
- Все обновления передаются через существующий `DownloadChangeBus`, прежние загрузчики Edge TTS/MP3, аудио, Ranobes/MangaLib и загрузки по ссылке не заменены.

## QA и CI

- Вновь добавлены `qa/typecheck_web_transfer_history_193.sh` (настоящий javac и изолированные тесты переходов истории/отмены) и `qa/typecheck_web_transfer_activity_193.sh` (javac экранного UI с Android-заглушками), `qa/check_web_transfer_ui_193.py` (структурные контракты и, если есть Node.js, синтаксис браузерного JS).
- Обновлены заглушки `qa/typecheck_web_transfer_server_192.sh` для нового журнала; оба теста включены в GitHub Actions перед Gradle.
- Исторические контракты адаптированы к номеру 1.11.193 без отмены проверок функций.
- Полноценная компиляция Android и работа на устройстве требуют CI / тестирования; SDK отсутствует в рабочем окружении.
