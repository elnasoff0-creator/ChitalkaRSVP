## Что обновлено в этой пересобранной v1.11.122-beta

Эта сборка не повышает номер версии, а расширяет уже подготовленную ветку **v1.11.122-beta**.

### 1. Комиксотека: новые поддерживаемые источники
Комиксотека теперь рассчитана не только на HTML-главы, но и на дополнительные варианты хранения комиксов:

- **CBZ / ZIP**-архивы с изображениями;
- **CBR / RAR**-архивы с изображениями;
- **обычные папки с изображениями** (`jpg`, `jpeg`, `png`, `webp`, `gif`, `bmp`, `avif`);
- прежние **папки с HTML-главами** также сохранены.

### 2. Импорт Комиксотеки
В `MainActivity` добавлено меню **«Добавить в Комиксотеку»** с тремя вариантами:

1. **Папка с HTML-главами**
2. **Папка с изображениями**
3. **Архив CBZ / CBR**

Для папок используется `ACTION_OPEN_DOCUMENT_TREE`, для архивов — `ACTION_OPEN_DOCUMENT`.

### 3. Логика определения формата
`ComicLibrary` теперь определяет и обслуживает несколько типов источников:

- `html` — главы в HTML;
- `images` — изображения из папки или подпапок;
- `cbz` — zip/cbz-архив;
- `cbr` — rar/cbr-архив;
- `auto` — автоматическое определение при первом открытии.

### 4. Папки с изображениями
Добавлена поддержка двух сценариев:

- **одна папка = один комикс / один том**;
- **подпапки = отдельные главы / тома**.

Изображения сортируются естественным способом, чтобы страницы `2`, `10`, `11` не шли раньше страницы `3`.

### 5. Открытие архивов CBZ/CBR
Архивы распаковываются во внутренний кэш приложения:

- **CBZ/ZIP** — через `ZipInputStream`;
- **CBR/RAR** — через библиотеку **Junrar**.

После распаковки страницы также сортируются естественно и показываются в обычном ридере Комиксотеки.

### 6. Единый экран чтения Комиксотеки
`ComicReaderActivity` теперь умеет открывать:

- HTML-главы;
- страницы из папок с изображениями;
- страницы из распакованных архивов CBZ/CBR.

Сохраняются ранее согласованные режимы просмотра:

- **Постраничный**
- **Вертикальный**

Сохраняется текущая глава/том, режим просмотра, позиция прокрутки и последнее открытие.

### 7. Новая XML-иконка Комиксотеки
Добавлен новый ресурс:

- `app/src/main/res/drawable/ic_comic_library.xml`

Иконка выполнена как `VectorDrawable` в общем минималистичном контурном стиле проекта и подключена в секцию **Комиксотека** на главном экране.

### 8. Gradle dependency
Для поддержки `CBR` в `app/build.gradle` добавлена зависимость:

- `com.github.junrar:junrar:7.5.5`
