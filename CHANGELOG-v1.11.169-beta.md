# ПОЛНАЯ РАСШИФРОВКА — ПРОЧиталка v1.11.169-beta CLEAN

**Основа:** v1.11.168-beta CLEAN (Gradle Compile Hotfix). **Новая версия:** `versionCode 16900`, `versionName 1.11.169-beta`. Сохраняются исправления Java-компиляции из предыдущего Hotfix.

## 1. Верхние панели и меню «⋮»

**Проблема:** кнопка «⋮» в Toolbar чтения была без фоновой подложки и не совпадала с остальными неакцентными кнопками.

**Исправлено:**
- `ReaderActivity`: убрано принудительное `setBackground(null)` и переопределение tint цветом текста. «⋮» наследует готовый стиль `icon(...)`: фон кнопки из темы настроек, контрастный значок и общий радиус.
- Для overflow «⋮» экрана загрузок применяется `ReaderButtonColors.neutral(...)` и контрастный цвет значка; выпадающее меню использует тематический `PalettePopupMenu`.
- Кнопки «⋮» **внутри карточек и строк** не менялись: по ТЗ остаются без подложки.
- Никаких новых статичных цветов или отдельных акцентных контуров.

## 2. «Проверить загрузки» перемещено в раскрывающийся список

**Было:** отдельная кнопка полного сканирования в Toolbar забирала место у основных действий.

**Стало:**
- `DownloadActivity`: кнопка `ic_refresh_download` удалена из Toolbar.
- В раскрывающемся списке фильтра **«Все загрузки»** добавлен пункт **«Проверить загрузки»** в секцию служебных действий.
- Пункт открывает существующее подтверждение полной сверки, после подтверждения запускает имеющийся `refresh()`. Никаких скрытых фоновых циклов сканирования не возвращено.
- Существующие пункты категорий, «Перенести всё из внутреннего хранилища», «Удалить скачанные файлы» сохранены.

## 3. Адаптивная ширина Toolbar «Загрузки»

**Было:** горизонтально прокручиваемый набор действий мог скрывать кнопки за видимой областью.

**Стало:**
- Боковое меню остаётся слева, правая панель размещается в оставшейся ширине.
- По результату компоновки вычисляется число доступных слотов по 49dp с учётом отступов.
- Влезшие действия остаются отдельными кнопками, остальные автоматически уходят в тематическое меню по **«⋮»**.
- На широком экране действия снова показываются напрямую; на узком экране и при изменении размера окна не требуется прокрутка Toolbar.
- Подписанные действия сохранены: поиск аудиокниг, поиск манги, поиск ранобэ, импорт по ссылке, подготовка книги Edge.
- Смена числа видимых кнопок не меняет обработчики их действий.

## 4. Кнопки универсального «Менеджера» по стандарту приложения

**Было:** Play/Pause, «Скачать всё» и «Папка» рисовались на фоне `panel` с зелёным контуром и зелёными иконками независимо от принятого стиля.

**Стало:**
- `UnifiedDownloadManagerActivity.actionIcon(...)` использует `ReaderButtonColors.neutral(this,panel)` для **сплошной подложки без контура**.
- Цвет иконки автоматически подбирается `ReaderButtonColors.contrastingText(...)`, чтобы оставаться различимым на обычном фоне кнопки.
- Радиус 12dp и область касания 44dp; нейтральная кнопка — для Play/Pause, «Скачать всё», «Папка».
- Состояния «недоступно», Play/Pause, прогресс, постановка всех отсутствующих глав и выбор папки функционально сохранены.
- «⋮» внутри списка файлов остаются бесконтурными, как предусмотрено общим правилом.

## 5. Ускорение повторного открытия «Инфо» Edge TTS

**Проблема:** при каждом новом `UnifiedDownloadManagerActivity` сбрасывались поля `lastInfoKey` и `edgeTocCache`, поэтому экран вновь собирал сведения из хранилищ и читал оглавление книги.

**Исправлено:**
- Добавлен `DownloadInfoSnapshot.java`: небольшая сериализованная запись по ID произведения (`status`, `done`, `total`, `bytes`, `description`, категория, фактическое отображаемое расположение, ошибка сохранения).
- При запуске Activity кэш «Инфо» читается **до первого обращения к реестру или SAF**. Для ранее открытого произведения вкладка сразу показывает прошлые сведения, не очищая их.
- `buildInfo(...)` вычисляет фактический путь/статусы в фоновом `disk` executor; `showInfo(...)` только выводит уже готовую модель и **не обращается к SAF**.
- После фоновой проверки сохранённые данные автоматически уточняются и сохраняются; неизменившийся «Инфо» не перестраивается.
- При выборе другой папки соответствующий кэш сбрасывается; выводится актуальное расположение после проверки.
- Добавлен `EdgeTocSnapshot.java`: постоянный кэш имён глав по URI книги в приватном хранилище приложения с SHA-256-именем файла; он позволяет избежать повторного `BookLoader.load(...)` при обычном возвращении в тот же менеджер.
- Если оглавление ещё не кэшировано, чтение выполняется как и прежде в фоне. Ошибки разрешений не сохраняются как успешный результат, чтобы после исправления доступа была повторная попытка.
- Снимки предназначены только для **отображения**. Операции над файлами продолжают использовать проверенное текущее задание и не доверяют отображаемым полям.

**Ограничение:** после внешнего изменения исходной книги по прежнему URI сохранённое оглавление может устареть; перед будущей полной реализацией инвалидации следует проверить импорт/переимпорт книги на устройстве. Полноценная перепроверка файлов при каждом открытии специально не добавляется.

## 6. Функции предыдущей версии сохранены

- Событийные изменения загрузок `DownloadChangeBus` без циклов полного сканирования.
- Кэш карточек загрузок и строк файлов, адресная загрузка через `DownloadsRepository.loadOne`.
- Быстрое открытие контекстного меню карточки и проверка выбранного задания при опасных действиях.
- Отдельная ручная полная проверка состояния файлов.
- Поддержка Edge TTS, аудиокниг, MangaLib, RanobeLIB, Ranobes и загрузки по ссылке.
- Отдельные функции Play/Pause и «Скачать всё» / «Подготовить всё» без подмены одного другим.
- Двухстрочный путь в «Инфо» с приоритетом последних сегментов, серой подписью «Файлы» и цветом текста из темы.
- Исправления Java-компиляции `illegal forward reference` и нестатических цветов из Gradle Compile Hotfix.

## 8. Проверка и ограничения поставки

Java-синтаксис проверен через `JavacTask.parse` (без разрешения Android-зависимостей). Дополнительные тесты исходников проверяют размещение кнопок, кэши, стили, номера версии. **Android SDK/Gradle здесь недоступны**, поэтому `assembleRelease` и проверка на устройстве остаются обязательными этапами. Архив **содержит исходный проект, не APK**.
