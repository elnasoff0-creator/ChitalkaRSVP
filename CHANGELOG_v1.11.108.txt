ПРОЧиталка v1.11.108-beta CLEAN
Изменения относительно v1.11.107-beta

1. ПОСЛЕДОВАТЕЛЬНЫЙ EDGE TTS С ОДНИМ СЛЕДУЮЩИМ БЛОКОМ
- Получение текущего блока до 800 символов остаётся потоковым: Media3 может начинать играть по первым MP3-пакетам.
- После события turn.end, валидации и атомарного сохранения полного MP3 (включая WordBoundary) сервис может начать синтез ТОЛЬКО одного следующего блока.
- Очередь EdgeSpeechQueue удерживает единственный сетевой слот, пока старый WebSocket не завершится; следующий запрос ожидает подтверждения закрытия.
- Media3 продолжает воспроизводить предыдущий MP3 независимо от сетевого соединения.
- Если следующий MP3 готов к моменту перехода, он добавляется в очередь Media3. Если ещё получается, плеер может подключиться к его растущему EdgeLiveBuffer.
- После готовности следующего блока сервис НЕ запрашивает ещё один следующий, пока плеер не перейдёт на следующий блок.
- Пауза/отсутствие Play не запускают новых сетевых синтезов. Отмена и ручные переходы по-прежнему имеют приоритет.
- Параметры разбиения сохранены: MAX/FIRST_TARGET/LIMIT=800, FIRST_TARGET_PRIORITY=500.

2. НОВЫЕ НАСТРОЙКИ EDGE TTS
Настройки > Аудио > TTS:
- Настоящий выпадающий список: «Не заменять точки», «Заменять точки на ,», «;», «:», «-» и «три переноса строки».
- Второй компактный список с режимами V1, V2 и V3.
- V1: заменять все обычные точки, за исключением защищённых последовательностей.
- V2: заменять обычные точки, кроме точек в конце строки или непосредственно перед переносом.
- V3: заменять точки только непосредственно перед пробелом либо табуляцией.
- Автоматическая защита десятичных чисел, URL, доменных имён и распространённых сокращений.
- Пользовательский словарь произношения: исходное слово=произношение, одна пара на строку. До 100 буквальных правил, до 8192 символов. Готовый набор RU.lexx не включён; его правила не переносятся целиком.
- Редакторы и настройки используют собственные стандартные Android-контролы, без переноса темы сайта.

3. СОХРАНЕНИЕ ИСХОДНОГО ТЕКСТА / ПОДСВЕТКИ
- Оригинальный текст книги, индексы слов, отображение, выделение и закладки НЕ изменяются.
- Словарная коррекция и пунктуация применяются только к строке, отправляемой по WebSocket.
- Для каждого символа синтезированного текста сохраняется соответствие диапазону исходного UTF-16 текста. Сопоставленные WordBoundary переводятся обратно в исходные диапазоны; sidecar .words.json по-прежнему привязан к оригинальному тексту.
- При изменении озвучиваемой строки меняется MP3-хеш. Без изменений трансформации исторический ключ MP3 сохраняется.
- Фоновая подготовка всей книги использует единый снимок опций на время задания, чтобы ключ и синтезированный звук не расходились при изменении настроек.
- При возвращении из настроек Reader обновляет индексы Edge TTS; при смене правил текущая очередь может быть сброшена для предотвращения проигрывания устаревшей версии.

4. БЕЗ ИЗМЕНЕНИЙ
- Потоковый MP3 + Media3, серверные WordBoundary, MP3-кэш, восстановление после HTTP 403.
- Тихая обработка HTTP 429: локальная задержка 1 секунда, соблюдение более длинного Retry-After сервера, запись в Logcat без всплывающего сообщения.
- Движок системной TTS, интерфейс Чтейца, аудиокниги, библиотека и остальные режимы.

5. ПРОВЕРКИ
- Shell QA, отдельные тесты V1/V2/V3, словаря, URL/чисел, обратных диапазонов WordBoundary и разделения MP3-кэша.
- Проверка Java-синтаксиса (101 файл), XML-ресурсов (90), UI и мини-питомца.
- Регрессии HTTP 403/429, WebSocket close-ack, MP3, навигации и потокового воспроизведения.
- Проверка архива и Git-патча относительно v1.11.107.

ОГРАНИЧЕНИЯ
- Android SDK отсутствует в среде проверки: полноценная компиляция APK не выполнялась.
- Реальные серверные задержки и фактическое отсутствие HTTP 429 должны быть проверены на Android-устройстве.
- Даже один WebSocket не гарантирует отсутствие HTTP 429 при частых последовательных запросах.
- Уменьшение пауз между блоками возможно, но не гарантируется: зависит от длительности синтеза и завершения WebSocket.
