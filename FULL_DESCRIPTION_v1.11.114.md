# ПРОЧиталка v1.11.114-beta CLEAN — полная расшифровка

## Основа и границы изменений

Исходный проект v1.11.113-beta CLEAN ColorFill Icons FIX, новые параметры:
`versionName = 1.11.114-beta`, `versionCode = 11400`. Вся остальная
логика чтения, EPUB/FB2, локального и Edge TTS, словарей, настроек тем,
плеера, закладок, кэша и WordBoundary оставлена на исходной базе.

## 1. Сон мини-питомца

**MainActivity.java**: удалена конструкция, которая отрезала `( ◡‿◡ )`
из строки `ChteicoEmotions.sleep(phase)`. В облачке снова выводится полный
текст, например `( ◡‿◡ ) Zzz...`. Количество точек меняется по существующему
трёхфазному циклу. При пробуждении возвращается обычный режим эмоций.

## 2. Ночная тема только для мини-питомца

**MainActivity.java**: пока мини-питомец спит, его квадратная карточка
получает фон `#1D2531`, текст эмоции — белый цвет, а облачко — локальный
ночной стиль. При пробуждении восстанавливаются цвета текущей темы.

**ChteicoPetView.java**: добавлен флаг `forceNightWhenSleeping`, который
установлен исключительно на главном мини-питомце. Когда флаг включён
и питомец спит, контуры его векторного изображения становятся белыми.
Для питомца в полном UI этот флаг не установлен: весь остальной интерфейс
не меняет тему из-за состояния сна.

**ChteicoSpeechBubble.java**: добавлен `setNightAppearance(boolean)`;
при сне обводка белая, заливка тёмная. Рисуется без пересоздания виджета.

## 3. Размер и ширина облачков

В `MainActivity.java` обычные эмоции увеличены с 23 до **30 sp**
(приблизительно +30,4%). Длинная строка сна отображается с размером 20 sp,
чтобы лицо и `Zzz` оставались видимыми в квадрате 140 dp.
В `ChteicoActivity.java` прежние **27 sp** для коротких эмоций
не изменены. Короткие эмоции в обоих экранах имеют `wrap_content` и
боковые отступы **5 dp**. Длинные обычные реплики полного UI по-прежнему
могут ограничиваться шириной 235 dp, чтобы текст переносился.

## 4. Виброотклик

**ChteicoActivity.java**: короткий тап по питомцу и свайп вызывают
`performHapticFeedback(HapticFeedbackConstants.VIRTUAL_KEY)`.
Это системная обратная связь, уважающая настройки вибрации Android.
В мини-питомце `ChteicoEmotions.attach()` не изменялся: виброотклик
происходит лишь при длительном удержании, непосредственно перед
`HomeSectionOrder.startPetDrag()`. Короткое касание мини-питомца
открывает полный UI; свайп вызывает эмоцию и не перетаскивает карточку.

## 5. Ограничение фоновых WebSocket

**EdgeSpeechQueue.java**: когда `interactivePlayback=true`, фоновой
задаче `PREFETCH` разрешается запуск только при наличии уже свободного
WebSocket в `EdgeWebSocketPool`. Нет свободного соединения — задача остаётся
в очереди до освобождения ресурса или изменения режима чтения.
**EdgeWebSocketPool.java**: добавлен синхронизированный метод
`hasIdleTransport()` для проверки состояния пула.

**Приоритетный Play не блокируется этим ограничением**: по запросу
пользователя он может создать новый WebSocket. Не добавлены авто-повторы 429
и адаптивные задержки. Общий пул из 4, до 2 фоновых задач, существующие
MP3 cache / WordBoundary / TimeSync и локальная пауза 500 мс сохранены.
Ограничение может отсрочить фоновую генерацию на свежем запуске без
готовых соединений — это осознанный компромисс для снижения риска 429.
Нулевая вероятность HTTP 429 не гарантируется.

## 6. Диагностика переходов и Media3

**EdgePlaybackService.java**: при автоматическом переходе, когда
`player.isPlaying()` остаётся истинным, регистрируется
`auto_transition_continuous_state=true sample_gap_ms=unavailable`,
без ожидания нового callback `onIsPlayingChanged(true)`.
Если плеер действительно переходит из неиграющего состояния в играющее
на том же треке, регистрируется `auto_transition_resume_callback_ms`.
Время буферизации дополнительно отмечается
`auto_transition_buffering_callback_ms`.
Устаревшие callback после ручного переключения не засчитываются.

**EdgeTtsDiagnostics.java**: имя `inter_track_gap_ms` заменено
на `track_callback_gap_ms`, а `first_sound_after_play_ms` в журнале
переименовано в `play_to_is_playing_callback_ms`.
Это устраняет неверное впечатление, будто callback, появившийся через
27043 мс, точно означает 27 секунд тишины. Реальный разрыв между
последним и первым PCM-сэмплами здесь **не измеряется**.

## 7. Цветные иконки и ночной контраст

Все десять утверждённых `VectorDrawable XML` остались неизменными:
дневная, ночная, мягкая, сепия, пользовательская; два контрастных
варианта каждого. Цвет заполнения сохранён, фон прозрачный, тонкий
контур чёрный/белый в зависимости от темы.

## 8. Проверки и ограничения

В каталоге `qa/` лежат тесты исходного проекта и новый сценарий
`test_v11114_completion.py`. Всего проверено 32/32 сценария.
Проверены Java-синтаксис (107 файлов), жесты, UI-структура, XML,
очередь, возврат WebSocket, поток MP3, 403/429, TimeSync,
WordBoundary и сохранение логов.

**Не проводилось:** полноценная сборка Android APK, инструментальные
UI-тесты на телефоне, реальное сетевое взаимодействие с Microsoft
после изменений. Поэтому итоговую производительность и анимацию
следует проверить на реальном устройстве.
