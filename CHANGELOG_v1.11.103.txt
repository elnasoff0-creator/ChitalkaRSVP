ПРОЧиталка v1.11.103-beta CLEAN
Основа: v1.11.102-beta

ИЗМЕНЕНИЕ ТОЛЬКО ОДНО: восстановление Edge TTS после HTTP 403.

1. Новый EdgeServerClock.java
   - Строго разбирает стандартный HTTP-заголовок Date (RFC 1123, GMT).
   - Вычисляет смещение времени сервера относительно времени устройства.
   - Хранит смещение в памяти процесса (без изменения часов Android).
   - Использует скорректированное время только при расчёте Sec-MS-GEC.
   - Не принимает пустую, недействительную или неполную дату.
   - Не инициирует повторную попытку, если токен остался прежним.

2. Обновлён EdgeSpeechEngine.java
   - При HTTP 403 пытается получить Date из ответа WebSocket handshake.
   - Если дата корректна и новый токен отличается от предыдущего,
     пересчитывает Sec-MS-GEC v2 и выполняет ровно ОДНО подключение заново.
   - После повторного 403 возвращает ошибку, новых запросов не создаёт.
   - Сохраняет исходный приоритет EdgeSpeechQueue и единый callback.
   - Сбрасывает отсчёт тайм-аута первого аудиопакета для повторного handshake,
     не сбрасывая общий показатель задержки воспроизведения.
   - Отсеивает запоздалые события старого WebSocket по номеру подключения,
     чтобы старый ответ не заменил успешное новое соединение.
   - HTTP 429 обрабатывается прежним путём через Retry-After без нового retry.

3. Расширены тесты qa/test_edge_speech_engine.sh:
   - 403 с корректным Date -> обновлённый GEC, второй handshake, готовый MP3;
   - 403 повторился -> ровно два запроса, затем ошибка;
   - отсутствующая / некорректная дата -> только один запрос;
   - дата в том же 5-минутном окне -> токен не меняется, повтор не нужен;
   - сохранены тесты потоковой выдачи MP3 и HTTP 429 без повтора.

4. Сохранены без изменений:
   - EdgeSpeechSegments.MAX=900, FIRST_TARGET=900, FIRST_TARGET_PRIORITY=600;
   - SentenceChunks.LIMIT=900;
   - режимы чтения, плееры, Media3, настройки, UI, мини-Чтейцо;
   - существующий кэш MP3, WordBoundary, фоновая подготовка и загрузки.

ПРОВЕРКИ:
- 15 shell-наборов и qa/check_ui_core.py прошли в тестовой среде.
- Синтаксически разобраны 99 Java-файлов, XML-ресурсы проверены.
- ZIP проверен на целостность.
- Фактическая Release-сборка и работа с сервером Microsoft не проверены,
  потому что в среде нет Android SDK и не проводилась сетевая TTS-сессия.

ОГРАНИЧЕНИЯ:
- HTTP 403 по другим причинам, кроме неправильного времени, может остаться.
- HTTP 429 и лимиты Microsoft этим изменением не устраняются.
- Если HTTP Date отсутствует или не меняет GEC, лишняя попытка не делается.
