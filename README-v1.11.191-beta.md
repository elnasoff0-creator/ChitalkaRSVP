# ПРОЧиталка v1.11.191-beta CLEAN — полные исходники

**Основа:** `v1.11.190-beta CLEAN`. **Android-версия:** `versionName=1.11.191-beta`, `versionCode=19100`.

Полный Android Java-проект: `app/`, `qa/`, `.github/workflows/release.yml`, Gradle-конфигурация и пример редактируемого TTS-словаря `samples/PROChitalka_TTS_Dictionary_example.csv`. APK не включён: в рабочей среде нет Android SDK/Gradle; настоящую Android-сборку должен выполнить GitHub Actions, после чего обязателен тест на телефоне.

## Новое в v1.11.191

### Быстрый возврат к произносимому предложению

Переход через «Вернуться к текущему предложению» больше не должен прокручивать много экранов ограниченными шагами по 22 dp. Для далёкого слова выполняется быстрый переход к соответствующему RecyclerView-блоку **с учётом вертикального смещения конкретной строки внутри блока**, а близкая цель остаётся под управлением плавной анимации. Обычное непрерывное сопровождение WordBoundary **не ускорено**, его правила 69%/61% сохранены. Явный возврат сохраняет защиту от устаревших событий и ручной прокрутки.

### Восстановление места чтения при открытии книги

Новый запуск `ReaderActivity` берёт каноническую сохранённую позицию чтения/TTS из `UnifiedReadingProgress`. Устаревшая запомненная позиция **просмотра** (`viewport:<uri>`) больше не может показать обложку вместо прочитанного предложения при новом запуске. RecyclerView сначала быстро позиционируется по нужному блоку, затем уточняет положение строки после готовности `TextView.Layout`. На время начального позиционирования список не показывает неверную обложку. Для восстановления не требуется нажимать Play или подключаться к Edge TTS. Внутри уже открытой книги ручной просмотр других страниц остаётся независимым от позиции озвучивания.

### Манга: сохранение главы, страницы и смещения

`ComicLibrary.Comic` сохраняет устойчивый `chapterId` и относительную долю смещения `pageFraction`. Для MangaLib ID формируется из устойчивого `Job.id()`, поэтому после загрузки более ранней главы прежний индекс в списке не подменяет прочитанную главу. Для старых сохранений без ID действует совместимый переход по прежнему индексу. Режим «Лента» восстанавливает страницу и её относительное вертикальное положение; горизонтальный режим «Страницы» — номер страницы. Прогресс обновляется из WebView при прокрутке и фиксируется при паузе/закрытии Activity.

`restoreWhenReady(...)` выполняет восстановление после подготовки HTML-разметки и подтверждает его через JS-мост. Вместо прежнего безусловного `restore(...)` через 1800 мс добавлена ограниченная повторная отправка при отсутствии подтверждения. Пользовательское касание отменяет ожидающее восстановление и предотвращает поздний скачок; события старой главы отклоняются по номеру поколения. Сохранена поддержка CBZ/CBR, HTML, папок изображений, MangaLib, режимов «Страницы» и «Лента».

### Настройки → Чтение: типографика

Из вкладки «Общие» **без дублирования** перенесены «Предпросмотр текста», «Шрифт», «Добавить шрифт» и «Размер шрифта». Добавлен пункт **«Межстрочный интервал»**: от **0,80× до 2,00×**, шаг **0,05×**, значение по умолчанию **1,00×**. Значение 1,00× сохраняет прежнюю визуальную величину интервала (множитель TextView 1,12 и существующий дополнительный отступ), а новые значения масштабируют этот множитель. Изменение немедленно обновляет предпросмотр и сохраняется между запусками.

Под типографикой расположен разделитель и заголовок **«Режимы чтения»**. Все прежние параметры режимов чтения идут ниже, без переименований и перестановки. В `ReaderActivity` при возвращении из настроек учитывается изменение межстрочного интервала: текст пересоздаёт только необходимые View, TTS, цитаты и сохранённый словесный индекс не сбрасываются.

## Проверка на устройстве

После сборки откройте ранее прочитанную книгу, не нажимая Play: должен показываться сохранённый текст, а не обложка. Перейдите на несколько глав в сторону и нажмите «Вернуться к текущему предложению»: переход должен быть быстрым, а обычный TTS-автоскролл — по-прежнему плавным. В манге проверьте быстрое закрытие, повторное открытие, смену режима/ориентации и загрузку более ранней главы MangaLib. В настройках проверьте изменение интервала с последующим возвратом в книгу и сохранение шрифтов.

Доступен журнал `READER_STARTUP`, `TTS_SCROLL` и `COMIC_RESTORE` без текста книги; по нему можно проверить восстановление и время переходов.

## Совместимость

Сохранены SQLite словаря TTS и CSV импорта/экспорта, Edge MP3/WordBoundary, SAF-папки, системный и резервный TTS, собственное выделение, заметки, цитаты и питомец «Чтейцо» (50/50). JSON-схема библиотеки манги расширена необязательными полями, старые записи открываются без миграции с удалением данных.
