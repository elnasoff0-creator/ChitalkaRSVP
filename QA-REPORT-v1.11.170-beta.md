# QA REPORT — ПРОЧиталка v1.11.170-beta CLEAN

Результат офлайновых проверок исходников приведён после завершения тестов. **Отчёт не заменяет сборку Gradle и тестирование на Android.**

## Scope

1. Поля `source=null` в строках кэша и Edge-главах без Task не должны блокировать показ `PalettePopupMenu`.
2. Изменяющие действия используют свежий `DownloadsRepository.loadOne(id)` и адресные задания из соответствующих хранилищ.
3. Тест HTML-выдачи Ranobes: только две карточки (IDs 1205570 / 1205975), с CSS-обложками, описаниями, без боковой рекомендации.
4. Смена пользовательской палитры поиска; действительная ссылка на следующую страницу.
5. Номер версии и удаление документации старых релизов.

## Known limits

- Точный сетевой AJAX-запрос Ranobes DLE Filter неизвестен; полный HTML сохранённого результата не является сетевым HAR.
- В этой среде отсутствуют Android SDK и Gradle, поэтому нет сборки APK или инструментального UI-теста на устройстве.
- Требуется GitHub Actions release-компиляция и ручная проверка всех типов загрузок/SAF перед установкой на основной телефон.

### Проверка тестового HTML
В `qa/fixtures/ranobes_filter_all_the_skills.html` сохранены только блоки результатов и применённого фильтра из предоставленного HTML. Тест нашёл ровно два произведения (ID `1205570`, `1205975`), оба с CSS-обложками и описаниями. Добавленная в фикстуру боковая ссылка на другое произведение не должна попасть в разбор результатов.

### Обязательная проверка после сборки
- Edge TTS: `source=null` при восстановлении кэша, глава без задачи, готовая глава, ошибочная глава.
- Все типы источников: аудиокниги, MangaLib, RanobeLIB, Ranobes, загрузки по ссылке; открыть меню, повторить, удалить, проверить обновление состояния.
- Edge-планировщик `PLAN=-2`: повторная постановка всей недостающей очереди.
- Ranobes: поисковое поле `l.title`, реальный HTTP-ответ, два результата, CSS-обложки и описание, реальная пагинация.
- Все темы оформления и изменение пользовательской темы на открытом экране.
