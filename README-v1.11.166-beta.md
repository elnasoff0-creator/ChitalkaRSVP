# ПРОЧиталка v1.11.166-beta CLEAN — руководство по обновлению

## Назначение

Выпуск основан на 1.11.165-beta CLEAN Full Source. Он объединяет подробные менеджеры загрузок под общим экраном, приводит вкладки к браузерному стилю, исправляет смахивание и адреса хранения в SAF, улучшает интерфейс заметок и сохраняет файловые настройки Android 16.

## Сборка

Открыть полный проект в Android Studio с JDK 17 и Android SDK Platform 35. Сохранена конфигурация Gradle и зависимости базовой версии. Запустить `:app:assembleRelease` в имеющемся GitHub Actions либо в Android Studio. Этот архив содержит **полные исходники, не APK**. В рабочей среде создания архива отсутствует Android SDK, поэтому успешная Android-сборка, работа интерфейса на Android 16 и сетевое скачивание на живых сайтах **не подтверждены**.

## Экран «Менеджер»

При открытии загрузки показываются карточка произведения (нажатие открывает произведение), единая строка `[Pause/Play] Общий прогресс [XX%] [Скачать всё]` и вкладки браузерного стиля «Файлы»/«Инфо». «Файлы» — первая активная вкладка. В ней встроены действия с отдельными главами, включая повтор, удаление, выбор нескольких, действия подготовки/сохранения Edge TTS; для всех категорий используются существующие очереди. «Инфо» содержит статус, объём, счётчики и путь папки. Не показываются отдельные «Подробнее», «Слушать», «Читать», «Обложка» или повторяющиеся строки состояния под обложкой.

**Важно:** иконка Play/Pause управляет *загрузкой*, не аудиоплеером. Иконка `ic_autoload` добавляет в очередь все недостающие элементы.

## SAF-папки и строка пути

На Android 16 отдельно выбрать действующие папки в настройках загрузок:

- **Book** — книги EPUB/FB2/HTML, RanobeLIB, Ranobes.net, готовые главы Edge TTS;
- **Manga** — MangaLib и CBZ;
- **Audiobook** — «Книга в ухе», готовые MP3.

Вкладка «Инфо» показывает путь к выбранной папке, **не к файлу**. Длинные пути сокращаются в начале, чтобы название конечной папки было видно. Справа кнопка с иконкой папки открывает системный выбор SAF именно той категории, к которой относится открытая загрузка. Путь временного кэша из «Инфо» исключён. SAF URI и разрешения каждой категории остаются отдельными.

## Временные MP3 и очистка

Загрузчик «Книга в ухе» допускает локальный временный MP3 для докачки. После сохранения в Audiobook проверяется размер, SHA-256, ссылка в Аудиотеке и отсутствие активного воспроизведения; **только потом** локальная полная копия удаляется. Если проверка, запись в SAF или обновление Аудиотеки не удались, локальную копию необходимо сохранить.

В настройках добавлен пункт «Проверить и очистить дубликаты загрузок». Он сначала показывает число проверенных копий и объём потенциальной очистки, затем отдельно запрашивает подтверждение удаления. Не удаляются незавершённые `.part`, файлы без действительной и идентичной SAF-копии или главы во время воспроизведения. Ручная проверка дубликатов ограничена управляемыми загрузками «Книга в ухе»; личные файлы пользователя не сканируются. Для MangaLib новый полный локальный CBZ удаляется автоматически только после подтверждённого сохранения идентичного SAF-файла и обновления записи главы.

## Проверка на устройстве

1. Открыть загрузки аудиокниги, ранобэ, MangaLib и Edge TTS. Убедиться, что кнопки и вкладки одинаковы и первая — «Файлы».
2. Выбрать три независимые папки Book/Manga/Audiobook. На вкладке «Инфо» проверить однострочный путь с концом и правильную системную папку по значку справа.
3. Приостановить и возобновить загрузку через Play/Pause, затем нажать «Скачать всё» и проверить, что готовые файлы не скачиваются заново.
4. В общем списке загрузок открыть свайп «В архив / Отмена» при обновлении прогресса.
5. Долгим нажатием на текст вызвать компактное меню из пяти иконок без подписей; создать заметку и проверить положение левого маркера.
6. Во время Edge TTS открыть заметку/закладку из списка и убедиться, что текст прокручивается к ним, а озвучивание не перескакивает.
7. Скачать MP3 «Книга в ухе» и проверить, что после подтверждённой публикации в Audiobook в `Android/data/.../Music/Audiobooks` нет второй полной копии; затем проверить воспроизведение MP3 из SAF.
8. В разделе «Настройки» проверить браузерные вкладки и возможность переключения всех пяти разделов.
9. При ошибке SAF убедиться, что файл можно восстановить без повторной загрузки.

## Примечание

Старые подробные Activity сохранены в исходниках для совместимости существующих переходов. Основной путь через «Менеджер» использует встроенную вкладку «Файлы» без открытия этих Activity. Для разных источников сохраняются их собственные сервисы и очереди.
