# ПРОЧиталка v1.11.117-beta CLEAN FIX2 — словарь знаков и Android TTS overlay

Это исправленная редакция исходников **v1.11.117-beta** на базе ранее выданной **v1.11.117-beta CLEAN FIX**, без повышения версии: `versionName '1.11.117-beta'`, `versionCode 11700`.

## 1. Символы в словаре Microsoft Edge TTS

- В `EdgeDictionaryActivity` рядом с обычным добавлением записи есть отдельная кнопка **«Знаки +»**. Она открывает редактор для символьных последовательностей с отключёнными текстовыми подсказками клавиатуры.
- Добавлено правило для любого буквального сочетания пунктуации, не содержащего специальных разделителей словаря `=` и `|`, например `***=.` (три звёздочки превращаются в одну точку при отправке текста на Edge TTS). Другие примеры: `---=,`, `!!!=.`.
- Символьные последовательности сопоставляются даже рядом с буквами. Внутри движка словаря они экранированы `Pattern.quote`: `*` не воспринимается как регулярное выражение.
- Более длинные последовательности имеют приоритет над короткими (`***` перед `*`), при равных условиях контекстные правила первее общих.
- Пользовательские замены обрабатываются только один раз, чтобы новое значение не изменялось вторым правилом. Точка, внесённая словарём, не меняется глобальной настройкой «Замена точки».
- Книга, исходная позиция символов и подсветка Edge WordBoundary остаются привязанными к оригинальному тексту. Изменённый текст синтеза входит в идентификатор MP3-кэша.
- Оставлены прежние ограничения хранения словаря: до 100 правил и 8192 символов. В старом формате `=` разделяет ключ и замену, а `|` разделяет ключ и контекст — эти знаки нельзя использовать как сам ключ без смены формата хранения.

## 2. Полный текст предложения в overlay Android TTS

- Исправлен случай, когда Android TTS (системный голос) не предоставляет `onRangeStart` или метки WordBoundary и индекс чтения удерживается на первом слове фрагмента.
- Для **системного TTS** `ReaderActivity.updateFloatingCaption` теперь сразу показывает **всё текущее предложение**, а не только первое слово. Этот способ не зависит от точности WPM или покадровых меток конкретного движка.
- Для **Edge TTS** сохранён прежний режим постепенного добавления произносимых слов на основе WordBoundary.
- Все согласованные правила показа overlay сохранены: он появляется после ручного скролла только когда текущее подсвеченное предложение полностью покинуло видимую область, а тап возвращает к текущей позиции.
