## Исправления после первых проверок

- Добавлены заглушки `WebTransferDownloadStore` и `Outcome.uri` в тест компиляции сервера, чтобы проверялся новый интерфейс, а не устаревшая сигнатура.
- При HTTP-запросе с повторно использованным ID сервер не перезаписывает существующую карточку и не удаляет привязку другого Socket.
- Отмена во время финального SAF-импорта запрещена: меню показывает, что файл уже сохраняется, а запоздавшие callbacks не отменяют статус завершённой операции.
- При отмене в браузере сообщение корректно показывает «Отменено» вместо сетевой ошибки; авторизованный запрос отмены отправляется до прерывания XHR.
- Wi-Fi-карточки обновляют прогресс и описание без полного перестроения содержимого строки на каждом обновлении байтов.

## Ограничения и что проверить в GitHub Actions

В этой среде **нет Android SDK и Gradle**. Полная сборка `gradle --no-daemon :app:assembleRelease --stacktrace` и Android API type-check всего проекта здесь **не выполнялись**. Выполненные `javac`-проверки с заглушками и JavaParser не гарантируют успешный Android APK.

После сборки на устройстве необходимо проверить: связь двух устройств в одной Wi-Fi-сети; запуск/остановку сервера, PIN и QR; фактическую передачу EPUB/CBZ/MP3; появление в «Загрузках» новой записи каждого файла, обновление прогресса, импорт через SAF, защиту от дублей; отмену из браузера и списка; повторное открытие/историю после завершения приложения; светлую/тёмную темы и работу иконок.

**Важно:** транспорт локальный HTTP без TLS; для тестов и работы следует использовать только доверенный Wi-Fi.
