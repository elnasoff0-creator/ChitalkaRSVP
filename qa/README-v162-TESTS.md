# Проверки релиза v1.11.162-beta

Текущий тестовый маршрут:

```bash
python3 qa/test_v11162_release.py
```

Проверяет синтаксис всех Android Java-файлов через JDK Compiler API, XML, структуру меню/хранилищ и сегментацию Edge TTS из v1.11.158.

Старые тесты в этой папке оставлены для исторических версий. Тесты с явными константами `versionCode 16100`, автоматической паузой HTTP 429 от 60 секунд или приоритетными блоками без прежнего ограничения 500 символов предсказуемо расходятся с **намеренным** откатом v162. Это не подтверждает исправность исполнения на Android.

Ограничения проверки: нет Android SDK и среды для полноценных instrumented-тестов. После сборки проверить реальные вызовы Android SAF, обработку long tap, RecyclerView swipe, переходы заметок, WebSocket Edge и сохранение прогресса на устройстве.
