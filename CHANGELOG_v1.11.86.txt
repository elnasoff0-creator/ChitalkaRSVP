ПРОЧиталка v1.11.86-beta CLEAN — Edge Realtime Transport

1. Полная замена сетевого EdgeTtsClient на совместимый фасад к новому EdgeRealtimeTransport.
2. Новый потоковый цикл WebSocket: audio -> PCM playback / cache независимо; WordBoundary передаётся без ожидания turn.end. Сохранены MediaCodec / AudioTrack и постоянные файлы Edge.
3. Новая схема EdgeRequestGate: приоритет Play, одна активная сетевая сессия; убрана принудительная пауза 2200 мс после каждого запроса. При настоящем HTTP 429 продолжает действовать Retry-After / backoff без немедленного повтора.
4. Транспорт использует единый OkHttpClient и ConnectionPool, короткое ожидание подключения и контроль первого аудиопакета; уменьшено количество обновлений прогресса на пакеты.
5. Исправлена критическая ошибка: реальное значение параметра rate отправляется в SSML (раньше всегда использовалось +0%).
6. Обновлён первичный endpoint под протокол Edge v2; при сетевом reset ДО поступления аудио допускается один резервный протокол; не происходит обхода HTTP 429 через другой адрес.
7. Уточнена обработка ошибки 403 с учётом времени сервера и ограниченным повторным запросом, без бесконечных циклов.
8. Сохранена семантика одного выбранного предложения и одного следующего, переходов, отмены прерванных стримов, фонового офлайн-кэша, WordBoundary и подсветки. Ранее скачанные MP3 и 18 утверждённых спрайтов не изменены.
9. Добавлены регрессионные тесты: ответ WebSocket 429, приоритет Play, приход первого аудио раньше turn.end и корректная передача скорости в SSML.

Техническое ограничение:
Microsoft Edge Read Aloud — неофициальная сторонняя служба. Ошибку HTTP 429, возвращаемую самим сервером, нельзя устранить декодером или гарантированно обойти изменением клиента. Релиз сокращает искусственные задержки приложения, но фактическая скорость/доступность сервера требует тестирования на устройстве.

Проверено: синтаксический разбор всех Java-исходников, XML, JVM-тесты основных индексов и транспорта; полная Android Gradle сборка / реальный сетевой тест не выполнялись в этой среде.
