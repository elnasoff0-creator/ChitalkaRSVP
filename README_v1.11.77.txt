ПРОЧиталка v1.11.77-beta CLEAN

Содержимое: полный Android-проект с app/, корневыми Gradle файлами, ресурсами и QA.

Как собрать:
1. Загрузить содержимое ZIP в свой Android/Gradle репозиторий.
2. Убедиться, что доступен Android SDK 35, JDK 17 и Gradle с Android Gradle Plugin из окружения сборки.
3. Выполнить gradle --no-daemon :app:assembleRelease --stacktrace.
4. На устройстве проверить первые Edge MP3, быстрые переходы и выбор локального голоса.

Тесты на устройстве:
- Тапнуть по предложению без MP3, Play: воспроизведение должно начинаться из WebSocket, а не из сохранённого файла.
- Во время чтения перейти из 100-го предложения к 800-му: прежние неполные запросы отменяются.
- Дослушать предложение: оно переносится в офлайн-хранилище с WordBoundary; повторное прослушивание берёт MP3 локально.
- Сохранение целого MP3 происходит лишь после успешного окончания синтеза.
- Во время обычного Edge TTS не должно быть уведомления загрузчика; уведомление медиаплеера может отображаться.
- Нажать менеджер блоков: у каждого ряда фактический диапазон SentenceChunks и одна строка текста.
- При ручной прокрутке слежение выключается на 3 секунды бездействия, затем центрирует текущее предложение.
- Отдельно проверить «Подготовить всю книгу» в «Загрузках».

Содержит README, CHANGELOG и COMMIT_MESSAGE только текущей версии.
Официальный Edge TTS API для этой интеграции не используется; протокол может измениться.
Полная Gradle-сборка в среде создания релиза не выполнялась.
