# CHANGELOG — ПРОЧиталка v1.11.191-beta CLEAN

Основа `v1.11.190-beta CLEAN`; полный исходный Android-проект, без APK.

## 1. `ReaderActivity` — быстрое возвращение и корректное открытие

- Убрана ситуация, когда при новом открытии книги сохранённый `viewportWord=0` (позиция ручного просмотра) имел приоритет над `UnifiedReadingProgress` и показывал обложку; этот временный viewport теперь действует лишь внутри активного экземпляра читалки.
- Добавлена функция `positionReaderAtWord()`: быстрый прыжок к RecyclerView-блоку, затем точная коррекция по `TextView.Layout` к строке текущего слова. Запоздавшие callbacks отвергаются по `viewportNavigationEpoch`; отсутствие готовой разметки приводит к ограниченной повторной попытке, а не к молчаливому пропуску.
- Во время первого позиционирования не показывается ошибочная обложка; после успешного применения фиксируется событие `RESTORE_APPLIED`.
- В `ReaderTtsScrollPolicy` добавлена функция `needsFastReturn()`: дальний **явный** возврат отделён от мягкого обычного сопровождения WordBoundary. В `ReaderTtsScrollController.Host` добавлен метод `jumpToWordLine` (с default fallback для совместимости существующих тестов).
- Сохранены пауза, режим просмотра оглавления, текущий индекс TTS, словесная подсветка и ручное выделение.

## 2. `ComicReaderActivity`/`ComicLibrary`/`MangaLibStorage` — восстановление манги

- В модель комикса добавлены необязательные поля `chapterId` и `pageFraction`. Старый `chapter` и `scroll` продолжают читаться для обратной совместимости.
- Для MangaLib устойчивый `chapterId` строится из `Job.id()`, а новый `ComicRestorePolicy.resolveChapter` находит нужную главу после загрузки/пересортировки списка.
- В JS разметке главы `positionInfo()` возвращает номер страницы, пиксельное смещение и долю смещения в пределах изображения. При восстановлении ленты применяется относительное смещение, зависящее от актуальной геометрии; режим страниц остаётся постраничным.
- JS-мост `ComicRestore.onPositionChanged` обновляет прогресс на событиях прокрутки с ограничением частоты, без ожидания следующего 600-мс опроса. Последняя подтверждённая позиция сохраняется при `onPause` до уничтожения WebView.
- Удалён слепой возврат `restore(...)` спустя 1800 мс; `onPageFinished` вызывает `restoreWhenReady()` с ограниченными повторными запросами при отсутствии подтверждения.
- `WebView` не показывает ошибочную первую страницу перед восстановлением сохранённой. Взаимодействие пользователя отменяет отложенное восстановление на стороне Java и JS; события старой главы отвергаются по `generation`.
- Добавлены события `COMIC_RESTORE` (`POSITION_LOADED`, `CHAPTER_RESOLVED`, `LAYOUT_READY`, `RESTORE_APPLIED`, `RESTORE_CANCELLED`, `POSITION_SAVED`).

## 3. `SettingsActivity` — типографика в разделе «Чтение»

- Перенесены в начало «Чтение»: предпросмотр, выбор шрифта, добавление TTF/OTF, размер шрифта.
- Добавлен регулятор «Межстрочный интервал» 0,80×–2,00× с шагом 0,05×, настройка хранится в `reading_line_spacing_percent` (100 по умолчанию).
- Предпросмотр меняется сразу. `ReaderActivity` применяет значение к `TextView.setLineSpacing` и учитывает его в проверке обновлённых предпочтений по возвращении из настроек.
- Ниже идут разделитель и «Режимы чтения», после них сохранён прежний порядок остальных параметров.
- Предыдущие темы, пользовательские шрифты, настройки выделения и кнопок сохранены.

## 4. QA/CI и ограничения

- `ComicRestorePolicy.java` — чистая тестируемая логика определения главы по ID и нормализации относительной координаты.
- `qa/TestComicRestore191.java`, `qa/test_reader_and_comic_restore_191.sh`, `qa/check_restore_settings_191.py` — проверки стабильности главы, порогов быстрого возврата, связей UI и безопасного восстановления.
- Workflow запускает новый QA перед Gradle-сборкой. Актуализирован контракт предыдущей версии для нового `versionName` и CLEAN-документов.
- Автономный Java-синтаксис и pure-Java тесты **не заменяют** полную компиляцию Android и испытание поведения WebView/RecyclerView на устройстве. APK здесь не собирался.
