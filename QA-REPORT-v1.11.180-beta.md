# QA 1.11.180-beta

## Требует проверки на Android

1. Edge выбран, резерв отключён: при сетевой ошибке Android TTS не должен запускаться.
2. Edge выбран, резерв включён: после повторной неудачи запустить резерв с текущего фрагмента.
3. После восстановления Edge overlay должен вернуть значок и вывести одно короткое сообщение.
4. Проверить системные иконки Google / Samsung / сторонних TTS и поведение при удалении пакета.
5. Проверить игнорирование целого предложения и частичного текста во всех движках.
6. Проверить соответствие WordBoundary исходным позициям после замен текста.
7. Проверить открытие лога через боковое меню и запрет Activity при выключенном developer mode.
8. Повторить ранее наблюдавшийся сбой запуска новой книги и собрать новый диагностический лог.

Предварительные проверки выполняются в среде контейнера; Android SDK / Gradle wrapper в исходном архиве отсутствуют.

## Статическая проверка в рабочей среде

- Проверка XML-парсинга всех 175 разметок.
- Проверка наличия русских пользовательских названий словаря.
- Проверка очистки архивной MD-документации.
- `javac` без Android SDK: ошибок Java-синтаксиса не выявлено, полная типизация невозможна из-за отсутствия Android API.

Важно: успешная компиляция APK, исправность Edge WebSocket и работа TTS/WordBoundary на устройстве не подтверждены. Проверка повторного запуска Edge после первого сбоя требуется в GitHub Actions и на устройстве.
