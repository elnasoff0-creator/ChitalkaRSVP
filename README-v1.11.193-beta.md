# ПРОЧиталка v1.11.193-beta CLEAN — полные исходники

**Основа:** `v1.11.192-beta CLEAN Javac Hotfix`. Java/Android, приложение `ru.reader.rsvp`. `versionCode 19300`, `versionName 1.11.193-beta`. Включены исходники, ресурсы, веб-интерфейс Web Transfer, QA и GitHub Actions. APK в этом ZIP нет.

## Ключевые изменения версии

### 1. Управление Wi-Fi-передачей в стиле приложения

В «Загрузки» → «Передача по Wi-Fi» большой кнопки запуска сервера больше нет. В правой части общего Toolbar размещены компактные контурные иконки запуска/остановки (`ic_web_server_start.xml` и `ic_web_server_stop.xml`) и `?` с прямой ссылкой на раздел справки. При активных передачах остановка запрашивает подтверждение. Кнопка копирования адреса имеет собственную XML VectorDrawable-иконку `ic_web_copy_address.xml`, доступна только при запущенном сервере, копирует **полный адрес** `http://IP:PORT` и подтверждает копирование. Цвета/подложки/скругления кнопок наследуют текущую тему (`UiColorScheme`).

Кнопка выбора папки использует штатную иконку `ic_folder_audio.xml` и позволяет выбрать одну из трёх категорий: «Книги», «Комиксы», «Аудиокниги». Выбор выполняется через `DownloadFolderPicker.choose/receive` и Android SAF, с проверкой реальной записи и сохранением разрешения, без перезаписи остальных путей. Кнопка перехода в «Настройки Web Transfer» и подробная инструкция удалены с экрана. Сам модуль по-прежнему настраивается в **Настройки → Онлайн**. Все шаги использования и типичные ошибки теперь объясняются в **Справка → Передача книг по Wi-Fi**.

### 2. Каждая передача из браузера появляется в общем списке «Загрузки»

Реализован `WebTransferDownloadStore.java` — отдельное долговременное хранилище метаданных операций Wi-Fi (без текста файлов, PIN или содержимого книг). Каждому файлу выделяется устойчивый ID вида `wifi:<уникальное-значение>`; одна операция = одна карточка. Источник отображается как **Wi-Fi**, доступен фильтр «Wi-Fi» наряду с прежними типами загрузок.

Статусы: **Передача**, **Импорт в библиотеку**, **Готово**, **Ошибка**, **Отменено**, **Дубликат**. Прогресс отображается на основании реальных полученных байтов; получение 100% тела HTTP ещё не означает «Готово» до успешного импорта. Ошибки SAF и конфликты имени видны в записи. Все операции сохраняются после закрытия экрана/приложения, последние 300 хранятся в истории; завершённые записи удаляются **только из истории**, не затрагивая уже импортированные книги. При аварийной остановке процесса незавершённая передача после повторного открытия отмечается как прерванная.

В общем меню записи можно посмотреть подробности, **отменить активную передачу** или удалить законченную запись истории. Для отмены и отображения прогресса используется единый `WebTransferDownloadStore` и `DownloadChangeBus`; WebTransferServer хранит временную привязку ID → Socket. При отмене сокет закрывается, файл `.part` удаляется, статус становится «Отменено» и не может быть перезаписан поздним успешным callback. Отмена во время уже начавшегося SAF-импорта недоступна, чтобы не оставить частично импортированный файл.

### 3. Веб-страница согласована с Android-историей

Браузер присылает уникальный `X-WT-Transfer-ID` для каждого файла, в том числе повторной попытки с новым именем. Отмена через веб-страницу обращается к авторизованному `POST /api/cancel`; отмена из Android использует тот же ID. HTTP-эндпоинт защищён прежним сеансовым cookie после PIN, Origin/Host и `X-WT-Request`; внешние сайты не получают доступа. Сервер не открывает чтение файлов пользователя и продолжает слушать только активный адрес Wi-Fi.

## Использование

1. В «Загрузки» нажмите **«Передача по Wi-Fi»**.
2. При необходимости нажмите значок папки и выберите через Android папку соответствующего формата (книги/комиксы/аудиокниги).
3. Нажмите верхнюю иконку запуска сервера. Получите IP-адрес, QR-код и шестизначный PIN.
4. На компьютере или другом телефоне в **той же доверенной сети Wi-Fi** откройте адрес (либо QR) и введите PIN.
5. Перетащите файлы или выберите их в браузере. Каждая текущая передача появится в общем списке «Загрузки»; в фильтре «Wi-Fi» видны все Wi-Fi-файлы и история.
6. При необходимости отмените передачу в браузере или из меню записи в Android. По окончании остановите сервер иконкой в Toolbar.

Инструкция также открывается через `?` на экране сервера. Дополнительные настройки находятся в «Настройки → Онлайн».

## Форматы и ограничения

Поддерживаются файлы: `.epub`, `.fb2`, `.txt`, `.html`, `.htm`, `.cbz`, `.cbr`, `.mp3`, `.m4a`, `.m4b`, `.ogg`, `.flac`. Максимум 1 ГиБ на файл; не более двух параллельных загрузок. Файлы сохраняются через существующие SAF-папки, затем индексируются в соответствующих библиотеках. Web Transfer не публикует библиотеку в браузере и не делает обратной передачи. Отдельная кнопка «Подготовить аудиокнигу» ранее упразднена: связанные возможности остаются в Менеджере загрузок и Edge TTS. Менеджеры Edge TTS и других источников не меняются.

**Безопасность:** транспорт — локальный HTTP **без шифрования**; PIN не заменяет TLS. Используйте только защищённую домашнюю/доверенную сеть Wi-Fi, не общедоступный или изолированный гостевой Wi-Fi. Сервер запускается только вручную и работает через foreground-service с уведомлением.

## Основные изменённые файлы

- `WebTransferActivity.java` — новый компактный экран, toolbar actions, SAF picker, справка.
- `WebTransferDownloadStore.java` — постоянная история файлов Wi-Fi, статусы, отмена, прогресс, защита от поздних ответов.
- `WebTransferServer.java` — связь Socket ↔ ID, запись прогресса, `/api/cancel`, завершение после SAF-импорта.
- `WebTransferService.java` — отмена операции из общего менеджера и жизненный цикл сервера.
- `DownloadsRepository.java` — тип `WIFI`, проекция Wi-Fi-операций в существующую модель списка.
- `DownloadActivity.java` — фильтр, карточки, байтовый прогресс, меню отмены и истории.
- `ActivityInfo.java` — новый пользовательский раздел справки.
- `assets/webtransfer/index.html` — уникальные ID и авторизованная отмена.
- `res/drawable/ic_web_server_start.xml`, `ic_web_server_stop.xml`, `ic_web_copy_address.xml` — новые векторные иконки.
- `.github/workflows/release.yml`, `qa/typecheck_web_transfer_history_193.sh`, `qa/typecheck_web_transfer_activity_193.sh`, `qa/check_web_transfer_ui_193.py` — новые проверки.
