ПРОЧиталка v1.11.106-beta CLEAN
Дата выпуска: 27.10.2026. Основа: v1.11.105-beta.

Исходный проект Android (без APK).

ГЛАВНЫЕ ИЗМЕНЕНИЯ
- Обычные Edge TTS и общие SentenceChunks: максимум 800 символов.
- Первое приоритетное озвучивание после ручного перехода: максимум 500 символов
  для каждого куска остатка обычного блока (сохранён порядок и индексы слов).
- Точность WordBoundary: слово с нулевой продолжительностью больше не
  подсвечивается бесконечно во время длинной тишины; сохранены исходные
  временные метки Edge без добавления искусственных 875 мс.
- Media3: стартовый порог буферизации 250->160 мс; после ребуферизации
  500->350 мс; минимальный буфер 500->450 мс. Это экспериментальная настройка,
  требующая прослушивания на реальном устройстве и с разными сетями.
- Диагностика Logcat, тег EdgeTtsLatency: начало запроса, открытие WS,
  первый MP3, первое чтение декодером, старт воспроизведения Media3,
  завершение синтеза, WordBoundary и паузы между блоками.
  Текст книги и токены в логи не записываются. Событие player-start означает
  начало воспроизведения с точки зрения Media3, а не доказанный момент
  слышимого звука на динамике.

СОХРАНЕНО
- Одна активная сетевая Edge TTS задача, без фонового запроса следующего блока.
- Первый блок может прогреваться при входе в режим TTS, до Play.
- Следующий отсутствующий блок запускается после завершения воспроизведения
  текущего и закрытия предшествующего WebSocket.
- Повтор после HTTP 403 по корректировке времени Date (один раз);
  прежний контроль HTTP 429 и Retry-After.
- Потоковый MP3, локальный кэш, ручной выбор предложения,
  встроенная подсветка слов, плеер и мини-питомец.

ПРОВЕРКА
- 18 shell-наборов (в том числе отдельный тест меток/диагностики),
  2 UI Python-проверки, синтаксис 100 Java и 90 XML-файлов пройдены.
- Полная компиляция Gradle и реальная работа на телефоне НЕ проверены:
  Android SDK не установлен в окружении сборки.
- При последовательном синтезе всё ещё возможна пауза между несохранёнными
  MP3; HTTP 429 может приходить и на одиночные запросы.

Для сборки на Android CI с SDK:
  gradle --no-daemon :app:assembleRelease --stacktrace

Документы в корне CLEAN-проекта: README, CHANGELOG, COMMIT_MESSAGE этой версии.
