# ПРОЧиталка v1.11.177-beta CLEAN — отчёт о проверках

## Пройдено в рабочем окружении
- `python qa/test_v11177_dictionary_refresh.py` — PASS (структурные проверки внесённых изменений).
- `python qa/test_v176_android_types.py` — PASS (Java 17, типы подсистемы прогресса со stub API).
- `bash qa/test_v11132_dictionary_regex.sh` — PASS (словари, Regex, WordBoundary, аудиоключи).
- `bash qa/test_edge_save_contract.sh` — PASS (безопасная привязка завершённого MP3 к запросу).
- `bash qa/test_edge_offline_chapters.sh` — PASS (манифесты и офлайн-главы в тестовой модели).

## Не проверено / требует CI и устройства
- Полная Gradle/Android-сборка: в исходном ZIP нет `gradlew`, в окружении нет Android SDK.
- Media3: бесшовный переход при активном проигрывании и возврат к предложению.
- Работа с SAF на реальном устройстве и переиндексация ранее опубликованных глав.
- Гонка нескольких быстрых изменений словаря, Android lifecycle и фонового режима.

Некоторые более старые версии тестов фиксируют устаревшие числовые политики 429 либо точное текстовое выражение сохранения MP3; они не использованы как доказательство готовности новой версии.
