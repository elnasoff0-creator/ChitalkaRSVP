# Техническое задание v1.11.196-beta

Утверждённое обновление Чтейца на базе v1.11.195-beta.

1. Переместить накопленные ресурсы и кнопку «Покормить» непосредственно под изображение питомца, не добавляя отдельный экран.
2. Добавить статус настроения: до 3 часов после кормления отличное, 3–8 хорошее, 8–24 нормальное, от 24 грустное. Успешное кормление восстанавливает отличное настроение, обычные тапы нет. Яйцо не голодает. Время сохраняется, для выключенной функции приостанавливается.
3. Распределить существующие смайлы и новые смайлы на четыре категории (18 всего). Использовать только текущую категорию; сон нейтрален. Сохранить пользовательские цитаты. Добавить голодные фразы.
4. Независимый переключатель уведомлений о голоде. По умолчанию выключен. От суток без еды — до одного напоминания в сутки, после трёх суток — до двух. Использовать имя или стандартную стадию, дневное окно, подавление дублей. После кормления пересчитать расписание. Погибшему питомцу уведомления не отправлять.
5. При одновременном отсутствии посещений приложения и кормлений 30 суток добавить необратимое состояние «Погиб». Проверять до обновления даты посещения. Яйцо не погибает. После обновления отсчёт для прежнего питомца начинается с текущего времени, без сброса существующего прогресса.
6. Надгробие RIP с символом книги, без анимации и реакции на тап. Отключить кормление, развитие и переименование погибшего питомца. Кнопка «Попрощаться» с подтверждением сбрасывает только данные питомца, затем появляется яйцо. Библиотека, общая статистика и остальные данные приложения остаются.
7. **Уточнение пользователя — рыбалка автономна и не блокируется даже при гибели и отключённом Чтейце.** При первом входе в рыбалку после каждой гибели появляется overlay-диалог «Начать заново или продолжить». Продолжение сохраняет всё. Новый старт очищает всё о рыбалке, возвращая стандартную экономику. Прощание с питомцем не сбрасывает рыбалку; решение сохраняется до выбора пользователя. Рыбалка без живого питомца не начисляет ему пищу.
8. Обновить справочник, README, CHANGELOG, QA-REPORT и версию 19600 / 1.11.196-beta. Не менять package name, подпись, данные пользователей и другие подсистемы. Добавить регрессионные проверки состояния и независимого сброса рыбалки. Проверить Android-сборку и реальный UI при наличии SDK и устройства.

Критерии: интервалы на границах, миграция, пауза, неубиваемое яйцо, смерть до обновления посещения, отсутствие пищи после гибели, рыбалка при отключённой функции, оба выбора, сохранение статистики, сброс без потери библиотеки, уведомления Android, отображение RIP и интерфейс на телефоне. Результаты автоматизированной и непроведённой ручной проверки разделены в QA-REPORT.


## Согласованное дополнение без повышения номера версии

9. Не удалять общую статистику чтения, аудио, манги и общие награды при гибели или прощании с Чтейцом. Сохранять доступ к общей статистике и наградам при погибшем питомце. Независимый сброс рыбалки удаляет только игровые данные; перенести исторические счётчики уникальных страниц манги и их идентификаторы в независимую статистику без потери значений.
10. Исправить неподвижную акцентную рамку вкладок: в настройках рисовать её на родительской области, а не на ScrollView. Все углы основного контейнера прямые, верхние углы вкладок скруглены. Нет линии под активной вкладкой, есть линия под неактивными; контур сохраняется при прокрутке, изменении размера и переключении.
11. Расширить Web Transfer по согласованному макету: белый фон, компактная навигация «Передача / Библиотека / Статистика / Награды», общий обзор, поиск, фильтры, список всех зарегистрированных произведений с локальными обложками и прогрессом, история Wi-Fi. Краткая статистика чтения и аудио, манги/комиксов, график за 7 дней, общие награды. Старые суммарные данные сохранять, отсутствующую дневную историю не выдумывать. Просмотр только после авторизации, без внешнего облака и изменения библиотеки через браузер. Сохранить существующую передачу файлов и папок.
12. Проверить регрессии независимого сброса, новую проекцию данных Web Transfer, доступ только через существующие проверки авторизации/origin, UI браузера (включая узкую ширину), совместимость прежних QA. Полная Android-компиляция и визуальный тест на устройстве обязательны для окончательной приёмки.
