# ПРОЧиталка v1.11.190-beta CLEAN — полные исходники

**Основа:** v1.11.189-beta CLEAN. **Версия:** `versionName=1.11.190-beta`, `versionCode=19000`.

В архиве находится Android-проект на Java, исходники и ресурсы, workflow GitHub Actions, автономные QA-тесты и четыре MD-файла документации только версии 1.11.190. APK не включён. Для компиляции необходимы Gradle 8.7, Android SDK 35 и JDK 17; подписанный релиз создаётся GitHub Actions при наличии настроенных секретов подписи.

## Что изменилось

**Плавная автопрокрутка WordBoundary.** Исправлен дефект предыдущей версии: после первого шага активное слово возвращалось в допустимую зону, и контроллер ошибочно останавливал движение, не доведя слово до позиции 61% высоты рабочей области. Теперь **порог начала движения** (69%) не используется как **условие завершения**: если сопровождение началось, оно продолжается до зафиксированной цели. Для явного возврата используется целевая позиция 50%; поступившее при возвращении новое событие WordBoundary больше не отменяет режим возврата. Сохраняются единая кадровая анимация, приоритет ручного управления, защита от старых callback и отсутствие вмешательства в аудио.

**Импорт и экспорт словаря TTS.** Только `.csv` (никакого JSON). Меню `⋮` экрана «Словарь TTS» содержит «Импорт словаря (.csv)», «Экспорт словаря (.csv)» и при наличии копии — «Восстановить последнюю копию». Используется системный выбор/сохранение документов Android (SAF), без разрешения на доступ ко всему хранилищу. Файл создан для удобного редактирования на ПК и телефоне.

## Формат CSV

- UTF-8 с BOM и разделителем **точка с запятой `;`**; текстовые поля в двойных кавычках с удвоением внутренних кавычек. Строки можно переставлять: их порядок сохраняется при импорте.
- Заголовок первой строки, строго семь колонок: `Тип;Шаблон;Произношение;Контекст;Regex;Включено;Комментарий`.
- `Тип`: **Замена** или **Игнорировать**. `Regex` и `Включено`: **Да** или **Нет**. Для игнорирования замена и контекст пустые; для Regex контекст пустой.
- В поле «Произношение» сохраняются буква `ё`, комбинированные ударения (например, `замо́к`), ссылки на группы `$1`, кавычки и знаки препинания.
- «Включено: Нет» оставляет запись в редакторе, но исключает её из синтеза. «Комментарий» позволяет хранить заметку до 500 символов, не попадающую в Edge.
- Чтобы формулы из CSV не выполнялись при открытии в табличном редакторе, опасные начальные символы `= + - @` экранируются обратимым текстовым префиксом. Для сохранения шаблонов/номеров **в Excel обязательно импортируйте CSV с типом столбцов «Текст»**, а не автоматически определённым форматом.

Пример также вложен в проект как `samples/PROChitalka_TTS_Dictionary_example.csv` (UTF-8 BOM). Можно открыть и изменить его в обычном текстовом редакторе.

Пример (можно сохранить как `.csv` в UTF-8):

```csv
Тип;Шаблон;Произношение;Контекст;Regex;Включено;Комментарий
"Замена";"замок";"замо́к";"дверь";"Нет";"Да";"Смысл определяется контекстом"
"Игнорировать";"***";"";"";"Нет";"Да";"Служебный разделитель"
"Замена";"№ ([0-9]+)";"номер $1";"";"Да";"Да";"Номер по шаблону"
```

## Как импортировать

1. Откройте «Словарь TTS» → `⋮` → «Импорт словаря (.csv)», выберите CSV через Android SAF.
2. Приложение **не изменяет SQLite до завершения проверки**: валидирует заголовок, число столбцов, Regex, номера групп, длину значений, повторяющиеся строки и лимиты словаря; ошибки выводит с номером строки CSV.
3. На экране предпросмотра видны новые записи, совпадения, конфликты, обновления и удаления; выберите режим:
   - **Объединить, сохранить мои правила** — по умолчанию, конфликты оставляет нетронутыми.
   - **Объединить, обновить совпадающие из CSV** — изменяет их на месте, сохраняет идентификаторы и порядок старых строк.
   - **Заменить весь словарь** — создаёт приватную резервную копию CSV и заменяет всё содержимое после повторного подтверждения.
4. Импорт осуществляется **одной транзакцией SQLite**. При ошибке транзакция откатывается. Единственное уведомление `DICTIONARY_CHANGED` инициирует проверку затронутых фрагментов Edge TTS; неизменившиеся MP3 не перезаписываются просто из-за импорта.
5. Чтобы откатить замену, выберите `⋮` → «Восстановить последнюю копию». Сохраняются пять последних копий в приватном хранилище приложения.

## Экспорт

«Словарь TTS» → `⋮` → **«Экспорт словаря (.csv)»**. Выберите расположение файла через системный диалог. Экспортируются все правила, включая выключенные, комментарии, контексты, Regex, порядок и игнорирование. Системные разрешения папки `Book` для этого не нужны.

## Проверка

```bash
bash qa/check_java_syntax.sh
bash qa/test_tts_dictionary_csv_190.sh
bash qa/typecheck_dictionary_store_190.sh
bash qa/test_tts_scroll_controller_190.sh
bash qa/test_reader_tts_scroll_189.sh
```

В CI эти проверки запускаются до Android-сборки. **Автономные проверки не заменяют Gradle-компиляцию и тест на телефоне.** Обязательно проверить сохранение файлов через Android SAF, миграцию словаря в реальной SQLite, визуальную плавность скролла и неизменность сохранённых MP3.

## Совместимость

Сохранены существующие MP3/WordBoundary, SAF, целые предложения Edge TTS, собственные маркеры выделения, заметки, цитаты, словарь резервного TTS и питомец «Чтейцо» с вероятностью фраз/цитат 50/50. SQLite словаря обновляется с v1 до v2 **без удаления правил**; новые поля `enabled=1`, `note=''` присваиваются существующим записям автоматически.
