# Использование ПРОЧиталки v1.11.163-beta

## Сборка

Открыть проект в Android Studio с Android SDK, синхронизировать Gradle; требуется Java 17. Собрать `:app:assembleDebug` или `:app:assembleRelease`. В `app/build.gradle` добавлена Google ML Kit Translate `17.0.3`. Онлайн-модель для перевода скачивается при первом запросе на русском языке.

Исходный архив не является готовым APK. Перед установкой поверх рабочей версии рекомендуется сделать резервную копию данных.

## Поиск ранобэ

1. Открыть «Загрузки» → значок «Поиск ранобэ».
2. Выбрать **RanobeLIB** или **Ranobes.net** в одном диалоге.
3. При выборе Ranobes.net ввести название или URL, например `https://ranobes.net/novels/1205570-all-the-skills-v741610.html`.
4. В карточке произведения выбрать главы, том или все доступные главы.
5. При необходимости сменить язык: английский оригинал или русский машинный перевод на устройстве. Это не перевод сайта GTranslate.
6. Подтвердить скачивание; откроется единый файловый менеджер.

Кнопка выбора папки общая для обоих сайтов ранобэ. Для каждого произведения Ranobes создаётся отдельная подпапка `Ranobes_<идентификатор>_<язык>`. Английская и русская версии не перезаписывают друг друга.

Если Ranobes.net возвращает HTTP 403, 429, 503 или не публикует полный список глав, программа покажет ошибку. Повторите позже либо откройте доступную книгу через браузер; обход ограничений не выполняется.

## Единый менеджер

Нажатие на любую запись в разделе «Загрузки» показывает менеджер с секциями:

- **Мета:** название, известные метаданные, формат, числа файлов/глав, состояние.
- **Файлы:** прогресс отдельных MP3, HTML, CBZ и других файлов/глав.
- **Обложка:** сохранённая или доступная по сети миниатюра; если нет — нейтральная иконка.

Кнопка **«Подробнее»** открывает прежний расширенный менеджер конкретного источника. Существующие очереди скачивания сохранены, они не запускаются заново от простого открытия менеджера. 

### Обычные аудиокниги

После запуска скачивания открывается менеджер файлов, а **не аудиоплеер**. Готовые MP3 отображаются отдельными строками; для прослушивания нужно явно нажать «Слушать».

## Сохранённые книги

Ranobes HTML объединяется в `book.html` с оглавлением. Рядом хранится `book.json`, `cover.jpg` и файлы отдельных глав. После сохранения первых глав собранная книга добавляется в стандартную Библиотеку, откуда открывается через `ReaderActivity`.

Если SAF-папка временно недоступна, локальная HTML-книга сохраняется и регистрируется в Библиотеке, а экспорт во внешнюю папку может потребовать повторной операции после восстановления доступа.

## Известные ограничения версии

Реальную работу с Ranobes.net на Android не удалось проверить из-за ограниченного доступа к сайту и отсутствия Android SDK в среде сборки. HTML-разметка сайта может измениться. Для русской версии используется **Google ML Kit**, а не прямое получение GTranslate-страниц. В первую очередь рекомендуется протестировать поиск, скачивание одной главы, чтение в Библиотеке и затем массовое скачивание.

Полная расшифровка изменений — `CHANGELOG-v1.11.163-beta.md`.
