# ChitalkaRSVP v1.11.22-beta — независимый MP3-плеер MRT

## Архитектура

* `MrtOnlineActivity`: показывает текст, статистику, две шкалы прогресса и управляет **только очередью загрузки**. Синтез движком MRT остался в WebView и записывает MP3 на диск через `MrtAudioCache`.
* `MrtPlaybackService`: отдельный Android Service с Media3 ExoPlayer и системной MediaSession. **Не импортирует WebView и не вызывает JS**. Получает только готовые локальные файлы через `appendReady()`.
* Во время MP3 воспроизведения синтез продолжает готовить текущий + N−1 будущих фрагментов, где N задаётся настройкой «Онлайн» (3–10).
* По завершении последнего **готового** MP3 ExoPlayer ждёт новый файл. При появлении нового файла и сохранённом намерении Play очередь продолжается, не повторяя предыдущий трек.
* Кнопка «Автоподгрузка» управляет **только генератором** и не включает звук. Play/Pause/Stop, предыдущий/следующий, ±10 секунд управляют **только Media3-плеером**, а не WebUI.
* Перемотка первого бегунка — по положению в тексте книги (по словам), поскольку для ещё не сгенерированных MP3 нельзя знать длительность в секундах. Второй бегунок показывает реальную позицию текущего MP3 в миллисекундах.
* Очередь MP3, файловый просмотрщик, очистка с подтверждением и сохранение на диск по книге оставлены. Выбор фрагмента сбрасывает плейлист к выбранной позиции и запускает генерацию отсутствующих MP3.
* Сервис получает аудиофокус, останавливается/ставится на паузу при внешнем аудио, поддерживает аппаратные медиакнопки. Сигнал TTS/обычного аудиоплеера прекращает MRT-сервис даже когда экран MRT закрыт.

## Проверка на устройстве

1. Откройте книгу, выберите MRT и нажмите «Автоподгрузка». Убедитесь, что MP3 появляются в списке **без звука**.
2. Нажмите Play — должен играть только текущий готовый файл. Проверяйте Pause, ±10, Stop, предыдущий/следующий.
3. Настройка N=3: при переходе на второй фрагмент должен появиться четвёртый; при переходе на третий — пятый, пока генерация работает.
4. Перейдите к фрагменту через список очереди и проверьте положение обоих бегунков.
5. Проверьте звонок, гарнитуру, уведомление, запуск TTS и возврат к MRT.

### Ограничения проверки

В контейнере нет Android SDK/Gradle, поэтому здесь не выполнялась настоящая компиляция Android APK и нет подтверждения поведения WebView на телефоне. JavaScript и изолированные JVM-тесты тестируются локально; реальная сборка остаётся за GitHub Actions. Синтез WebView возможен, пока экран MRT работает; отдельный сервис обеспечивает автономность **воспроизведения** уже готовых файлов, но не синтеза в фоне при уничтоженной Activity.
