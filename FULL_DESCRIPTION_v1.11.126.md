## 1. Новый ComicReaderActivity: единый интерфейс в стиле ReaderActivity

### Верхняя панель
- СЛЕВА добавлена кнопка бокового меню, открывающая существующий `UniversalDrawer`.
- Следом размещена компактная **активная кнопка режима просмотра, только с иконкой**.
- В зависимости от выбранного режима отображается `ic_comic_mode_pages.xml` (Страницы) либо `ic_comic_mode_feed.xml` (Лента).
- Вместо старого `Spinner` при нажатии открывается **нижняя выдвижная панель** с двумя режимами и текстовыми пояснениями; выбранный пункт выделен.
- Название текущего комикса и файла/главы показываются в двух строках с ограничением длинных названий.
- Режим сохраняется отдельно для каждого произведения.

### Режимы
**«Страницы»** — перелистывание изображений горизонтальным свайпом; короткий тап переключает видимость верхней и нижней панелей одновременно (нажатие по краям более не листает).
**«Лента»** — непрерывная вертикальная прокрутка; движение вниз скрывает панели, движение вверх показывает их.
После смены режима приложение старается оставаться на текущем изображении, не перепрыгивая к первой странице.

### Нижняя активная кнопка глав
- Внизу комикс-ридера расположена выделенная фоном кнопка оглавления: `Файл 3/18 · Изображение 12/47` (цифры пример).
- Позиция отслеживается внутри WebView и обновляется по мере перелистывания/прокрутки.
- Нажатие открывает Bottom Sheet в стиле ReaderActivity. Он показывает список файлов и глав, выделяет текущий файл и позволяет перейти к другому.
- Для уже открытых глав показывается известное количество изображений, для ещё не обработанных архивов — сообщение о том, что количество будет подсчитано при открытии (ленивая обработка вместо предварительной распаковки всей библиотеки).
- Прогресс хранится как номер текущего файла, индекс картинки, смещение и выбранный режим; восстанавливается после повторного открытия.

Изменены `ComicReaderActivity.java` и `UiNavigationSheet.java`.
Добавлены `ic_comic_mode_pages.xml`, `ic_comic_mode_feed.xml`.

## 1.1. Дополнение: скрытие панелей и масштабирование изображений (эта пересборка)

- **Экран просмотра теперь полноэкранный внутри ComicReaderActivity**: `WebView` занимает всю область контента, а верхний Toolbar и нижняя кнопка глав размещены как два плавающих overlay на `FrameLayout`. Их исчезновение не меняет размер страницы и не сбивает горизонтальную/вертикальную позицию.
- **«Страницы»**: короткий одиночный тап по странице показывает/скрывает одновременно Toolbar и нижнюю панель. Горизонтальное перелистывание осуществляется свайпом вправо/влево, а не нажатием на края картинки. При открытии главы элементы управления видны; при смене режима показываются снова.
- **«Лента»**: прокрутка вниз скрывает оба элемента, прокрутка вверх показывает. Используется фактическое изменение вертикальной прокрутки с порогом, без автопоказа по таймеру. Программная прокрутка при восстановлении позиции не должна случайно скрывать панели.
- **Pinch-to-zoom**: в обоих режимах включено стандартное масштабирование двумя пальцами средствами Android WebView (`setSupportZoom`, `setBuiltInZoomControls`, без системных экранных контролов). Диапазон, разрешённый веб-страницей, 1–5×. Повороты и изменения масштаба не должны интерпретироваться как одиночный тап. Зум выполняется внутри ридера, без дополнительного экрана.
- Сохранены `UniversalDrawer`, активная кнопка «Страницы/Лента», нижнее оглавление и сохранение позиции. Масштабирование страницы не записывается как постоянный параметр для произведения.
- Практическая проверка на Android обязательна: WebView и обработка pinch/scroll зависят от движка WebView и плотности экрана.

## 2. Импорт комиксов: CBZ/CBR только через выбор папки
- В общем диалоге добавления комиксов третий вариант называется **«Папка с архивами CBZ / CBR»**.
- Вместо `ACTION_OPEN_DOCUMENT` для отдельного архива теперь используется выбор папки через `ACTION_OPEN_DOCUMENT_TREE`.
- **Одна выбранная папка = одно произведение.** Имя папки становится названием произведения.
- Каждый архив CBZ/CBR/ZIP/RAR в папке интерпретируется как отдельный файл/глава.
- Оглавление формируется в естественном числовом порядке (`1`, `2`, `10`, а не `1`, `10`, `2`), заголовок главы берётся из имени архива без расширения.
- Если папка содержит HTML-файлы или изображения вместо архивов, существующие варианты импорта сохраняются.
- Ранее сохранённые как отдельные CBZ/CBR остаются совместимыми для просмотра, но новые такие одиночные файлы через кнопку добавления не импортируются.
- Архив выбранной главы распаковывается только при открытии этой главы; содержимое других глав не распаковывается заранее.
- Используется кэш распаковки и безопасные автоматически формируемые имена страниц, без использования внутренних путей архива при записи на диск.
- Добавлены пределы количества и размера изображений при распаковке CBZ; для CBR также ограничено количество изображений и размер отдельной страницы.

Изменены `ComicLibrary.java`, `MainActivity.java`.

## 3. Обложка и «Продолжить просмотр» в Комиксотеке
- Под заголовком Комиксотеки появляется полноценная карточка **«Продолжить просмотр»**, если произведение ранее открывалось.
- В карточке показываются обложка, название папки, номер файла/главы, номер изображения и кнопка продолжения.
- Обложка строится по первому изображению первого CBZ/CBR в естественно отсортированной папке.
- Для обычных папок изображений и HTML-книг также используется первая доступная локальная картинка; для загруженных MangaLib — первая страница первого доступного CBZ.
- Создание уменьшенной обложки происходит в фоновом потоке, результат кэшируется; главный экран не блокируется длительной распаковкой.
- Старые сохранённые позиции и произведения продолжают использоваться; новые поля общего количества файлов и изображений имеют безопасные значения по умолчанию.
- В списке Комиксотеки также показывается положение внутри каждого произведения.

Добавлен `ComicCovers.java`, расширены данные `ComicLibrary.Comic`, обновлён `MainActivity.java`.

## 4. Центрирование иконки «Таймер сна» во всех режимах
- В ReaderActivity (системный TTS и Edge TTS) и в AudioPlayerActivity (аудиокниги / режимы TTS) кнопки таймера переведены на контейнер `FrameLayout`.
- Когда таймер выключен и число минут/глав не отображается, сама иконка **строго центрируется по горизонтали и вертикали**.
- Когда таймер активен, иконка остаётся в верхней части кнопки, а числовой счётчик показывается снизу.
- Для скрытия пустого счётчика применяется `View.GONE`, а не `View.INVISIBLE`, который раньше оставлял пустую область и смещал иконку.
- Меняется только расположение элементов: механика сна, время, режим «Конец главы» и сохранение таймеров не изменены.

Добавлен `SleepTimerBadge.java`, изменены `ReaderActivity.java` и `AudioPlayerActivity.java`.

1. Импорт папки с `001.cbz`, `002.cbr`, `010.cbz` — одна серия, верный порядок глав и обложка из первой страницы `001.cbz`.

4. Проверить все нижние панели и кнопки при длинных именах файлов и большом количестве глав.
5. Проверить таймер без отсчёта и с отсчётом в системном TTS, Edge TTS и аудиокниге.
6. Проверить прежние MangaLib CBZ и одиночные архивы, импортированные до обновления.
7. В «Страницах» проверить короткий тап, обе скрывающиеся панели и перелистывание свайпами вправо/влево.
8. В «Ленте» проверить скрытие при прокрутке вниз и показ при прокрутке вверх, без дерганий при инерционном скролле.
9. В обоих режимах проверить щипок для увеличения и уменьшения, панорамирование увеличенного изображения и восстановление после переключения главы.
10. Убедиться, что открытие/скрытие панелей не сбивает страницу и сохраняемую позицию.


## HOTFIX: исправление компиляции GitHub Actions (та же v1.11.126-beta)

Причина: `ComicLibrary.pagesForChapter(...)` объявлен с `throws Exception`, а
`ComicReaderActivity.prepareImageAssets(...)` был объявлен только с `throws IOException`.
Gradle-задача `:app:compileReleaseJavaWithJavac` останавливалась на этом вызове.

Изменён **только контракт исключения** метода `prepareImageAssets`: теперь он объявлен
с `throws Exception`. Исключение передаётся через `buildChapterHtml(...)` в уже
существующий обработчик ошибок `loadChapter()`, который выводит сообщение.
Никакие жесты, главы, изображения или стили оформления не менялись.

Добавлен `qa/test_v11126_compile_exception_fix.py` и включён в набор QA.
Проверки исходников не заменяют Gradle/Android SDK сборку. Исправление ожидает
повторного запуска `gradle --no-daemon :app:assembleRelease --stacktrace` в CI.
