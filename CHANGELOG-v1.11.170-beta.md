# ПРОЧиталка v1.11.170-beta CLEAN — полная расшифровка изменений

**Основа:** v1.11.169-beta CLEAN Full Source  
**Версия:** `versionCode 17000`, `versionName 1.11.170-beta`  
**Дата подготовки исходников:** 16 ноября 2026 года

## 1. Исправлен отказ меню «⋮» у глав в универсальном менеджере

### Причина
В `UnifiedDownloadManagerActivity.fileMenu()` проверялось `row.source==null`; при этом выполнялись `reload()`, уведомление «Проверяем выбранную главу» и досрочный `return` **без открытия PopupMenu**. `DownloadRowsSnapshot` преднамеренно не сериализует поля типа `Object`: восстановленные строки получают `source=null`. Для Edge TTS `source` мог оставаться `null` и у настоящих строк — если у главы нет активной `EdgeFullBookStore.Task` (глава готова, ожидает или не запускалась). Перезагрузка сама по себе не гарантировала появления `source`; меню не открывалось повторно автоматически.

### Что изменено
- `fileMenu()` больше не зависит от `row.source` и не вызывает `reload()` при обычном нажатии. Палитровое `PalettePopupMenu` строится сразу из отображаемой строки.
- Удалено уведомление «Проверяем выбранную главу» из сценария открытия меню.
- «В очередь / повторить», «Удалить файл» и пакетные действия проверяют **актуальное** произведение через `DownloadsRepository.loadOne(id)` **после** выбора действия, в фоновом исполнителе.
- По идентификатору `row.key` заново находятся актуальные задания: `MangaLibStorage.find`, `RanobeLibStorage.find`, `RanobesStorage.find`. Старый `row.source`, который мог быть из кэша или уже изменившегося состояния, больше не используется для модификации файлов.
- Для аудиоглав, Edge TTS и файлов загрузки по ссылке проверяется соответствие ключа и индекса текущему произведению.
- У Edge TTS кнопки «Переозвучить главу», «Сохранить готовые MP3», «Объединить MP3 главы» могут отображаться без активного Task: актуальное произведение разрешается при выполнении операции.
- `openFinishedFile()` не блокируется на `source=null`: для загрузок по ссылке текущий файл берётся из `LinkDownloadStore`; если снимок произведения ещё не готов, получение происходит в фоне.
- Пакетное действие по выбранным главам допускает строки из кэша; перед исполнением однажды получает актуальное произведение и адресно проверяет каждую строку.

**Сохраняется:** подтверждение перед удалением, штатная работа загрузчиков и очередей, права SAF, актуальная проверка операций с файлами, настраиваемая тема меню.

## 2. Исправлен разбор результатов поиска Ranobes.net

### Основание
Полученный HTML от пользователя — результат поиска **All The Skills** через форму каталога `form[data-dlefilter=dle-filter]`, поле `name=l.title`, с двумя результатами в `#dle-content`:
- `All The Skills I Have Are Boss Skills`, ID `1205975`;
- `All The Skills`, ID `1205570`.

### Изменения `RanobesApi.java`
- Парсер результатов ограничен настоящими карточками `#dle-content article.shortstory`/`article.short-story`; ссылки из правой колонки, рекомендаций и футера больше не считаются результатами.
- Заголовок и URL извлекаются из `h2.title a`/`h3.title a`; URL и ID проверяются, дубликаты удаляются.
- Обложки извлекаются как из `img`, так и из CSS `background-image: url(...)` в `figure.cover`.
- Краткое описание извлекается из `.short-desc` и альтернативных поддерживаемых контейнеров.
- Добавлен `SearchPage` со списком, доступным количеством результатов и фактической ссылкой на следующую страницу.
- Реализована попытка запроса каталожного DLE Filter по `l.title` через публичный путь `/novels/f/.../`; результат принимается **только** при подтверждении применённого фильтра в HTML.
- При неподтверждённой работе каталожного маршрута остаётся резервный публичный POST-поиск (`story`, `do=search`, `subaction=search`). Он тоже использует строгий парсер; в резервном режиме исключаются карточки, название которых не содержит поисковый текст.
- Не принимаются внешние перенаправления, антибот-страницы и другие неподтверждённые ответы как «пустая выдача». Ошибки показываются пользователю явно.

### Пагинация
- Больше нет искусственного воспроизведения первой страницы при клике «Далее».
- Для перехода используется только фактическая ссылка на следующую страницу, извлечённая из HTML Ranobes.
- Если ссылки нет, кнопка «Далее» не показывается; «Назад» возвращает к предыдущей странице.

**Ограничение:** приложенный HTML подтверждает формат страницы, поле фильтра и два результата, но **не содержит сетевого HAR** и не подтверждает точный адрес/метод AJAX-запроса. Стандартный DLE Filter-адрес в коде — гипотеза совместимости. Из доступной среды прямой запрос к ranobes.net выполнить не удалось, поэтому работоспособность HTTP-поиска и пагинации на реальном сайте требует проверки на устройстве. Приложение не пытается обходить защиту сайта.

- Фон, текст, вспомогательные надписи и нейтральные кнопки получают цвета из `UiColorScheme`.
- При возвращении на экран учитывается изменение палитры настроек.
- В карточках поиска отображается краткое описание найденного произведения, если оно есть.
- Работа поиска, кнопки папки, меню и перехода к произведению сохранена.

## 5. Что проверено, а что ещё требуется проверить

**Проверено в этой среде:** синтаксический разбор Java 17 (без Android type checking), XML-разметка ресурсов, офлайновые тесты контрактов и извлечения двух карточек из пользовательского HTML, отсутствие устаревших документов.

**Не проверено здесь:** полноценная Gradle release-сборка, запуск на Android, клики по пунктам меню на телефоне, реальный ответ Ranobes для `l.title`, взаимодействие с SAF и переходы по следующим страницам на сайте.

### Минимальная ручная приёмка
1. Меню «⋮» у готовой/неготовой/ошибочной Edge TTS главы открывается **с первого нажатия**.
2. После возвращения в Менеджер меню работает у строки из `DownloadRowsSnapshot` до фоновой сверки.
3. «Повторить», «Удалить», «Сохранить MP3» и «Объединить» корректно работают; повторная проверка не блокирует само меню.
4. Пакетные действия по выделенным главам выполняются без ссылок на устаревшие задания.
5. Поиск `All The Skills` на Ranobes должен показать настоящие совпадения (ожидаемый образец — две карточки); обложки и описания доступны, справа не подмешиваются рекомендации.
6. Пагинация отображается только при наличии реальной следующей страницы и не повторяет первую страницу.
7. Проверить дневную, ночную, мягкую, сепию и пользовательскую тему, включая смену темы на лету.
