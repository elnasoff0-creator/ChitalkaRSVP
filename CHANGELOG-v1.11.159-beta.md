# ПРОЧиталка v1.11.159-beta — импорт HTML-папок и безопасная синхронизация

База: v1.11.158-beta CLEAN Full Source. Изменён `versionCode` на 15900.

## Новые функции

- Кнопка **+ → Книгу → Импортировать папку с HTML**. Системный выбор папки через Android SAF; сохраняется разрешение на её чтение.
- Поиск файлов `.html`/`.htm` во вложенных каталогах, естественная сортировка томов и глав, включая 1.5, 2, 10 и 01.
- Сборка одной книги `book.html` со структурными главами (`section.ranobe-chapter`), автоматическим оглавлением, названием по имени папки и локальной обложкой (`cover.jpg`, `cover.png`, `cover.webp` и варианты).
- Поддержка относительных иллюстраций: изображения копируются в контентно-адресованную папку `assets/`, чтобы старая резервная книга не теряла изображения при обновлении.
- Папка-источник остаётся нетронутой. При следующем открытии сравнивается **SHA-256 содержимого**, а не только имя, дата или размер; изменённые главы пересобирают `book.html`.
- Меню трёх точек у импортированных HTML-книг и RanobeLIB: **Проверить изменения HTML**.
- При синхронизации запоминаются позиция чтения и закладки, ищется соответствующая текстовая фраза в той же главе; при невозможности точного совпадения берётся относительная позиция внутри главы. Это приближение, не гарантия точного слова.
- На время обновления создаётся `.bak`; если глава не читается, не содержит текста или сборка не удалась, старая собранная книга не перезаписывается.
- После переноса импортированной книги через приложение сохраняется связь с папкой-источником и поддерживается обновление копии по её внешнему URI с контрольной проверкой и резервным файлом восстановления. Новые локальные иллюстрации публикуются до обновления HTML.
- Для глав RanobeLIB добавлена сверка содержимого перед открытием книги, повторная сборка изменённых глав, резервная HTML-копия и отказ от пересборки по пустой главе. Поддерживается извлечение содержимого из целых HTML-страниц перевода (не только из `<article>`).
- Дисковый кэш чтения RBI4 проверяет SHA-256 для HTML, в том числе при замене на файл такого же размера; загруженная в память сессия также сверяет ревизию.
- Оглавление отображается и для произведений с одной или двумя главами.

## Ограничения и рекомендации

- Синхронизация с исходными HTML-файлами происходит **при следующем открытии книги** или вручную через меню, не в процессе текущего озвучивания.
- Точное восстановление слова невозможно гарантировать, если текст главы полностью переписан и прежний фрагмент исчез.
- Если исходная папка недоступна (например, извлечена SD-карта), ранее собранная книга должна оставаться читаемой из сохранённого `book.html`. Пункт ручной проверки сообщает ошибку.
- Для RanobeLIB заменяйте **отдельные файлы глав** в `volumes/`, а не генерируемый `book.html`.
- На внешних SAF-провайдерах замена собранного файла выполняется с предварительным сохранением резервной копии и побайтовой проверкой; сама операция записи не является гарантированно атомарной на уровне провайдера.
- За пределами приложения нельзя автоматически заменить/переместить произвольную `content://`-ссылку без повторного предоставления разрешений.
- Обложки, не имеющие подходящего локального файла, продолжают показывать обычную заглушку.

## Проверки

Синтаксис Java (`JavacTask.parse`), XML (`ElementTree`), JVM-проверка естественной сортировки, новая структурная QA-проверка и совместимые регрессионные проверки переноса, переименования, RanobeLIB и игр. Полноценная сборка Gradle и испытание на Android-устройстве не выполнялись: в среде отсутствуют Android SDK/Gradle.
