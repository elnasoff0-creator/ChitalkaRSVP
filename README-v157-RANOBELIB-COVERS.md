# ПРОЧиталка v1.11.157-beta — как восстановить обложки RanobeLIB

## Новая загрузка

Откройте **Загрузки → Поиск ранобэ**, найдите книгу и откройте карточку. Обложка теперь извлекается из метаданных RanobeLIB, а при необходимости — со страницы книги из `img.cover__img` (или мета-тегов). При скачивании первой главы файл обложки сохраняется рядом с `book.html` под именем `cover.jpg` и используется Библиотекой офлайн.

## Книга была скачана в v1.11.156 и осталась без обложки

Не нужно удалять книгу или заново скачивать главы. После установки v1.11.157 откройте обычную **Библиотеку**: фоновая подгрузка обложек попытается восстановить `cover.jpg`. Если из-за сети обложка не появилась, откройте **Загрузки → Поиск ранобэ → карточка нужной книги** и нажмите **«Загрузить обложку повторно»**.

## Когда не получится

Если RanobeLIB временно возвращает HTML-ошибку, блокирует запросы или не отдаёт ни API-метаданные, ни страницу обложки, изображение скачать нельзя. Сам текст книги, главы, пользовательское название и прогресс чтения при этом не удаляются.

## Структура файла

```
Books/RanobeLIB/<id--slug>/
  book.html
  book.json
  cover.jpg
  volumes/
```

## Сборка

Полный Android-проект, JDK 17, Android SDK 35. В Android Studio: `Build → Make Project`. Эта поставка — **исходники**, а не готовый APK. Новая версия `1.11.157-beta` (`15700`).

Тесты (требуются Python 3 и JDK): `python qa/test_v11157_cover_recovery.py`, `python qa/test_v11155_ranobelib_and_games.py`, `python qa/test_v11156_book_rename.py`.
