# ПРОЧиталка v1.11.155-beta — RanobeLIB и исправление рыбалки

База: v1.11.154-beta CLEAN Full Source. Android / Java 17 / XML.

## Новый источник: RanobeLIB

- На экране «Загрузки» добавлена иконка раскрытой книги с лупой (VectorDrawable, 24dp). Панель иконок прокручивается горизонтально.
- Поиск книг по названию или прямой ссылке ranobelib.me; перелистывание результатов.
- Экран книги: автор, обложка, описание, жанры, статус, список глав по томам.
- Можно скачать главу, выделенные главы, целый том или всю книгу; поддерживаются дробные номера и несколько переводческих веток. При массовом скачивании выбирается первая ветка, ручной выбор позволяет переключиться на другие.
- Изображения и текст публичных глав сохраняются локально, без повторного скачивания готовых глав.
- Для ответа API `content` поддерживаются обе формы: HTML и ProseMirror JSON с разрешением приложенных изображений.
- Фоновая последовательная очередь WorkManager, экспоненциальная задержка при HTTP 429 и временных сетевых ошибках, остановка/продолжение/повтор ошибок; закрытые главы помечаются как недоступные.
- Для каждой книги строится `book.html`, главы располагаются в отдельных HTML-файлах по томам, обложка сохраняется в `cover.jpg`; книга регистрируется в обычной Библиотеке.
- Доработано извлечение названия, автора и оглавления из HTML RanobeLIB в BookLoader; ReaderBookCache инвалидируется при изменении локальной книги.
- В общей ленте загрузок появился фильтр «Ранобэ»; статус сгруппирован по произведениям, доступны управление очередью и удаление после подтверждения.
- Опционально поддерживается выбор отдельной папки загрузок Android SAF. При наличии выбранного дерева HTML, обложка и изображения экспортируются туда; собственные файлы приложения хранятся независимо.

## Исправление игры «Рыбалка»

- Удалена кнопка «Игры» из блока статистики улова и отдельная игровая карточка, создававшаяся при каждом нажатии.
- Когда Чтейцо выключен, у заголовка «Статистика и награды» находится компактная кнопка игры в стиле кнопки у Чтейца. Игра открывается **внутри той же карточки**.
- Когда Чтейцо включён, его мини-кнопка игры остаётся у имени питомца и использует существующий контейнер питомца.
- Повторное нажатие не создаёт новую игру: одновременно разрешена только одна встроенная `ChteicoFishingView`.
- При закрытии игры освобождаются предыдущие игровые представления и таймеры.

## Проверки

- Проверены разметка и XML-ресурсы нового модуля, синтаксис Java для исходников проекта (154 файла), регрессионные структурные проверки и локальная проверка реального кода извлечения EPUB/FB2 метаданных.
- Компиляция через Android Gradle Plugin, запуск на Android-устройстве и живой запрос к RanobeLIB в данной среде **не выполнялись**. Перед установкой требуется сборка Android Studio и проверка на устройстве.

## Ограничения

- API RanobeLIB не имеет стабильного публичного контракта: в будущем могут понадобиться правки адаптера.
- Работа с закрытыми/платными главами и обход ограничений доступа не реализованы.
- Огромные произведения собираются в один `book.html` для совместимости с текущим ReaderActivity; производительность чтения многомегабайтных книг на слабых устройствах следует отдельно проверять.
- Скачанные книги хранятся в каталоге данных приложения, удаление приложения может удалить их. Для сохранения копии отдельно выберите папку через кнопку каталога (SAF).
