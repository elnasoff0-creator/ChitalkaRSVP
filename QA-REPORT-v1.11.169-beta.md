## Известные ограничения

- Частичное получение данных из файлов при первом открытии или после потери кэша всё ещё происходит в фоне.
- Кэш оглавления идентифицируется URI и не отслеживает изменения содержимого внешнего файла при неизменном URI; требуется ручная проверка переимпорта.
- Снимок «Инфо» используется только для отображения, не для выполнения действий над файлами.
- Без SDK нет подтверждённого APK или успешно собранной release-версии; дополнительные ошибки `javac` / Android ресурсов не исключены.
