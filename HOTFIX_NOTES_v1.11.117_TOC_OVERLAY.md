# ПРОЧиталка v1.11.117-beta CLEAN FIX3 — оглавление при активном TTS

**Версия неизменна:** `versionName 1.11.117-beta`, `versionCode 11700`.
**База:** `PROChitalka-v1.11.117-beta-CLEAN-FIX2-Full-Source.zip`.

## Исправление

Ранее обработчик `ReaderActivity.showToc()` при любом выборе главы вызывал `stop()`, записывал выбранное слово в основной индекс озвучивания `index` и принудительно вызывал `ensureWordVisible(true)`. Поэтому во время активного Edge TTS / системного TTS выбор другой главы либо приводил к возврату к произносимому предложению, либо нарушал связь с реальной позицией аудио.

Теперь при `mode == TTS && ttsCurrentlyPlaying()` применяется **навигация только по экрану**:

1. Выбранная глава или текстовый блок позиционируется в `RecyclerView` по реальному слову, включая смещение слова внутри блока.
2. Озвучивание продолжает работать; не вызываются `stop()`, `setAnchor()`, `localSelect()`, `pause()` или перезапуск речи.
3. Индекс произносимого слова `index`, текущая подсветка, позиция аудио и история/кэш не изменяются из-за выбора главы.
4. `followSuspended=true`: автоматическая прокрутка к озвучиваемому предложению запрещена до явного возврата.
5. После размещения выбранной главы проверяется видимость **активного произносимого предложения**. Если оно полностью вне читаемой области, показывается TTS-overlay с текущей озвучкой. Если предложение хотя бы частично видно, overlay остаётся скрытым.
6. Нажатие на overlay по-прежнему возвращает к текущей озвучке и возобновляет автосопровождение без рестарта TTS.
7. Поколение `tocPreviewGeneration` отменяет устаревшие отложенные позиции при повторном выборе, ручном скролле или явном возврате через overlay.

Когда TTS не воспроизводится, ранее существовавшая логика выбора главы сохранена.

### Код

- `app/src/main/java/ru/reader/rsvp/ReaderActivity.java`: `previewTocDuringPlayback()`, ветка обработчика `showToc()`, защита поколением `tocPreviewGeneration`.
- `qa/test_v11117_toc_browsing.py`: регрессионные проверки сохранения TTS-позиции, отсутствия принудительного `ensureWordVisible()` и обновления overlay после навигации.

### Проверить на устройстве

1. Запустить Edge TTS, открыть оглавление, выбрать далёкую главу: экран остаётся на выбранной главе, речь не прерывается, overlay показывает озвучиваемое предложение.
2. Во время озвучивания выбрать близкую страницу, на которой текущее предложение всё ещё видно: overlay не появляется.
3. Повторить для системного TTS.
4. Нажать overlay: плавно вернуться к произносимому предложению без перезапуска голоса.
5. Во время подготовки прокрутки сразу начать листать вручную или повторно выбрать главу: устаревшая прокрутка не должна срабатывать.
6. При паузе TTS выбрать главу: сохраняется прежняя логика перехода.
