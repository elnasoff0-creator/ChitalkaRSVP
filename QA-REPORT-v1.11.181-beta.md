# QA report — v1.11.181-beta CLEAN

## Выполнено
- В ReaderActivity штатная XML-иконка остаётся базовой; иконка фактически работающего TTS выводится отдельным бейджем справа снизу, не заменяя основную иконку.
- Для Edge предпринимается попытка получить значок установленного пакета com.microsoft.emmx. Если недоступен — встроенный XML-значок Edge.
- В окне «Способ озвучивания» текст системного режима изменён на «Системный оффлайн движок», длинное старое пояснение удалено; справа показаны значок движка и индикатор выбора.
- В настройках «Резервный TTS» справа выводится системная иконка движка либо XML-иконка системного варианта.
- Список резервных движков использует общее скруглённое диалоговое окно, ограниченную прокрутку, иконки и короткие имена; выбранный пункт отмечен в правой колонке.
- Обновлены versionName/versionCode. Удалены устаревшие корневые Markdown документы предыдущих версий.

## Проверки
- AST-парсер javac: 204 Java-исходника, ошибок синтаксиса 0.
- XML: 173 файла, ошибок разбора 0.
- ZIP: целостность проверена архиватором.

## Ограничения
- Android SDK/Gradle отсутствуют в локальной среде: полноценный assembleRelease не запускался.
- Визуальный тест системных иконок Edge/Google/RuVoice, проверки тем и поведения Overlay на устройстве остаются обязательными перед релизом.
- Подписи и APK внутри архива нет.
