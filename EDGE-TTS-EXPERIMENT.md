# ChitalkaRSVP v1.11.26-beta — experimental Edge TTS

## Что нового

Откройте EPUB/FB2/HTML → кнопка ♫ → «Edge TTS · онлайн». MRT и Android TTS остались в выборе.

- `EdgeOnlineActivity`: отдельный экран, выбор голоса (ru-RU-SvetlanaNeural, ru-RU-DmitryNeural), скорость, Play/Pause и перемотка.
- `EdgeQueueActivity`: список аудиофрагментов, повторная загрузка, очистка, переход на выбранный готовый MP3.
- `EdgeDownloadService`: независимый фоновый планировщик «текущий + ещё 2–9» с записью MP3, индексом очереди и повторными попытками при ошибках. Автоподгрузка **не запускает аудио**.
- `EdgePlaybackService`: отдельный ExoPlayer/MediaSession с кнопками гарнитуры, аудиофокусом и собственной очередью. Не вызывает сетевой API.
- `EdgeTtsClient`: прямое неофициальное соединение с Edge Read Aloud по WebSocket, без серверной части и API-ключа.
- `EdgeToken`: генерация временного токена подключения v2. Проверена фиксированным тест-вектором; протокол может измениться.

## Хранение

Для каждой книги: `.../Books/<название>--<id>/EdgeTTS/` с `*.mp3` и `queue.json`. MRT продолжает использовать `Аудио/`, поэтому кэши не смешиваются. Параметры количества и размера сегментов пока общие с MRT (3–10, изменение в Настройки → Онлайн). Голос и скорость Edge независимые.

## Ограничения

Microsoft не предлагает этот интерфейс как гарантированно безлимитный публичный API. Возможны HTTP 403, ограничения частоты, изменение протокола и голосов. На устройстве пока не проверялись WebSocket, получение аудио и сборка APK. Код рассчитан на одну последовательную генерацию и экспоненциальный интервал повторов; он не обходит ограничения сервиса.

Протокол/token адаптированы по открытому проекту `rany2/edge-tts` (GPL-3.0), источники: https://github.com/rany2/edge-tts. При распространении учитывайте применимые требования лицензии GPL-3.0 и условия внешнего сервиса.

## Тест

1. Соберите APK через GitHub Actions из **нового коммита**.
2. В открытой книге нажмите ♫ → Edge TTS · онлайн.
3. Выберите голос Светлана, скорость +0%, 300 символов, предзагрузку 3.
4. Нажмите «Автоподгрузка» — в очереди должен появиться готовый MP3 без звука.
5. Нажмите Play и проверьте, что пока играет №1, скачивается №2; после перехода — №3.
6. Если не работает, пришлите точный текст ошибки Edge / HTTP в нижнем статусе или в списке очереди.
