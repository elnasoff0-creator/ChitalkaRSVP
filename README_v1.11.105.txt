ПРОЧиталка v1.11.105-beta CLEAN

Исходный проект Android (без APK). Основа: v1.11.104-beta.

Обновление: строго последовательная Edge TTS озвучка без фонового
синтеза следующего блока. Обычные блоки по 900 символов;
приоритетные блоки при ручном переходе по 600 символов.

При входе в Edge TTS текущий блок ещё может прогреваться заранее.
Последующий блок запускается только после окончания текущего аудио,
после закрытия предшествующего WebSocket. При активной озвучке
подготовка всей книги ждёт окончания/паузы чтения.

Возможны паузы между не сохранёнными блоками. HTTP 429 зависит также
от сервера Microsoft. Код протестирован доступными тестами, но APK
здесь не собран: требуется Android SDK.

Для сборки на подготовленном Android CI:
  gradle --no-daemon :app:assembleRelease --stacktrace

Документы: README, CHANGELOG и COMMIT_MESSAGE только этой версии.
