ПРОЧиталка / Чтейцо v1.11.67-beta — TTS Cursor & Sentence Audio
Дата: 24.10.2026

1. Общий алгоритм разбиения текста (SentenceChunks.java)
- И системный Android TTS, и Edge TTS теперь используют одинаковую разбивку по предложениям.
- Жёсткий максимум — 600 символов на аудиоотрезок, вместе с пробелами и пунктуацией.
- Если предложение длинное, оно делится по пробелам, сохраняя соответствие исходному тексту, словам и позициям. Крайне длинное слово без пробелов делится по лимиту.
- Для Edge удалён пользовательский выбор размера фрагментов.
- Включён независимый консольный регрессионный тест qa/check_sentence_chunks.sh.

2. Новый общий TTS-экран (EdgeOnlineActivity.java)
- Системный TTS и онлайн Edge отображаются как чтение в стиле «Курсор».
- Нет обложки, аудиодорожки, бегунка, кнопок +/- секунд, +/- фрагментов и списка очереди.
- Прокручиваемый текст книги; касание по слову выбирает новую стартовую позицию.
- Центральная кнопка Play/Pause, переключение способа озвучки, выбор голоса.
- Иконка спидометра + числовой WPM; пресеты 100/200/300/400/500, шаг +/-10.
- Загрузка текста Edge выполняется через EdgeDownloadService без дублирования загрузки книги на экране.
- Отображаются позиция в процентах, фактическое время прослушивания и расчётное общее время по WPM.
- Для Edge отображается доля сохранённого офлайн-аудио, рассчитываемая по физически готовым MP3.
- При отсутствии соединения после окончания сохранённых Edge-файлов предлагается переход на локальный TTS.

3. Microsoft Edge TTS
- Удалены экран EdgeQueueActivity и EdgeQueuePlanner, настройки ручной очереди/числа подгружаемых фрагментов.
- Внутренне подготавливаются только текущее и следующее предложение для плавного воспроизведения.
- Каждая новая запись Edge — постоянный MP3 с WordBoundary-файлом *.words.json; остаётся доступной офлайн.
- Индекс новых отрезков хранится в sentences.json; старый queue.json распознаётся при переходе.
- Старые MP3 физически сохраняются без удаления; для полного соответствия новым предложениям могут быть нужны новые записи.
- Сохраняется кнопка «Файлы аудиокниги» (встроенный проводник и экспорт в системную папку).
- Для Edge подсветка произносимого слова привязывается к аудиовремени ExoPlayer, а не к проценту длительности.
- Без точной метки подсвечивается целое предложение. При выборе слова и наличии метки выполняется переход к его временной позиции.
- Экран полной подготовки книги в DownloadActivity остаётся доступен. Убраны кнопки «Очередь/Фрагменты».

4. Android TTS: Google, Samsung и другие установленные локальные голоса
- synthesizeToFile продолжает сохранять WAV только во временном cacheDir.
- Собираются onBeginSynthesis (sampleRate) и onRangeStart (начало/конец слова, audio frame).
- При наличии достоверных callback-меток сохраняется временный *.words.json рядом с WAV и включается подсветка отдельных слов.
- Иначе подсвечивается целое предложение, и касание слова начинает выбранное предложение.
- В TtsVoiceActivity появилась кнопка «Проверить» у каждого локального голоса: пробный синтез показывает, доступны ли метки для конкретного голоса/движка на устройстве.
- Результат сохраняется индивидуально по движку и имени голоса, без утверждения, что все Samsung/Google голоса поддерживают onRangeStart.

5. WPM
- В ReaderActivity скорочтение/«Курсор» теперь открывают тот же тип диалога через компактную кнопку со спидометром и числом.
- Диалог в TTS-плеере остаётся единым для Edge и системного TTS.
- Скорость обычных MP3/M4A аудиокниг по-прежнему измеряется в × и хранится отдельно.

6. Совместимость
- Все 18 утверждённых VectorDrawable-спрайтов «Чтейца» сохранены без изменений.
- Сохранены библиотека, награды, обновления, обычный аудиоплеер, темы и прочие функции.
- Исходники обновлены до versionCode 11167, versionName 1.11.67-beta.

ОГРАНИЧЕНИЯ И ПРОВЕРКИ
- Компиляция через Gradle :app:assembleRelease НЕ выполнялась: Android SDK/Gradle здесь недоступны.
- Все исходные Java-файлы проверены синтаксическим парсером JDK (без Android classpath).
- Все Android XML разобраны XML-парсером.
- Тест разбиения до 600 символов пройден.
- Реальные события WordBoundary у Samsung/Google надо проверить на телефоне: Android API поддерживает callback, но конкретный установленный голос может не возвращать метки.
- Из-за ограничений доступа к /Android/data прямой переход в системный проводник может требовать экспорта через Storage Access Framework.
