ПРОЧиталка / Чтейцо v1.11.63-beta CLEAN
Основа: v1.11.62-beta. Полный исходный Android-проект.

1. Главное меню
- Нижняя навигация библиотеки заменена выдвижной боковой панелью с кнопкой из трёх линий.
- В меню присутствуют Библиотека, Чтение, Аудиокнига, Загрузки, Чтейцо/Статистика, Настройки, Обновление и Справка.
- Равномерные векторные иконки, миниатюра приложения, закрытие при касании затемнённой области и при Back.
- Добавлена ActivityInfo с краткой справкой по функциям приложения в разворачиваемых секциях.

2. Аудиокниги
- Цвета AudioPlayerActivity читаются из настроек bg/fg. При возвращении из оформления экран обновляет палитру.
- Нажатие на обложку открывает диалог сохранённых вариантов, есть Закрыть и Добавить из файла.
- Выбранное пользователем изображение копируется в постоянный личный каталог этой аудиокниги.
- Пункт Аудиокнига из меню использует последний доступный источник (аудио или текстовый TTS).
- Если подходящей книги нет, предлагается выбрать папку; пустой AudioPlayerActivity не открывается.

3. Выбор TTS и WPM
- Новый TtsVoiceActivity перечисляет русские голоса установленных системных движков, в первую очередь локальные.
- Движок и голос сохраняются. Предусмотрены прослушивание тестовой фразы и переход к системной загрузке голосов.
- В AudioPlayerActivity и EdgeOnlineActivity добавлен переход между системным и онлайн-способом озвучивания.
- Общий TtsWpm с компактным показом числа и иконкой спидометра. Диалог выбора: 100, 200, 300, 400, 500 WPM, изменение на -10/+10.
- Скорость обычных MP3/M4A сохраняется отдельно и по-прежнему отображается в x.

4. Фрагменты TTS и хранение
- Системный Android TTS синтезирует WAV-файлы во временный каталог cacheDir/system-tts-audio.
- Локальные фрагменты используются повторно, пока существует временный кэш, и подготавливаются вперёд.
- Система не гарантирует сохранность этого кэша. Android может удалить его без предупреждения.
- Edge TTS сохраняет MP3 в постоянной папке книги, как в предыдущих версиях; не удаляет автоматически.
- Предзагрузка Edge запускается автоматически; кнопка ручной автоподгрузки удалена.
- Настраивается количество фрагментов впереди (1–8; фактически включая текущий в очереди 2–9).
- Удалён пользовательский выбор количества символов. Сохранены прежние размеры фрагментов в настройках данных для совместимости с уже загруженными Edge MP3.
- При отсутствии сети и недоступности следующих Edge-файлов предлагается продолжить через системный TTS.
- Сохранены существующие очередь Edge, экран файлов и подготовка всей книги через Загрузки.

5. Подсветка
- Для обоих способов озвучивания добавлена приближённая подсветка слова в рамках текущего фрагмента.
- Важно: пока это оценка по позиции аудио, не гарантированная точная синхронизация по временным меткам сервиса.

6. Совместимость
- 18 ранее утверждённых векторных XML спрайтов питомцев не менялись.
- Иконки и функции Чтейца, награды, настройки и механика MP3 сохранены.
- Версия: versionCode=11163, versionName=1.11.63-beta.

ОГРАНИЧЕНИЯ И ПРОВЕРКИ
- Архив содержит ИСХОДНЫЙ проект, не APK. В среде отсутствуют Android SDK и Gradle;
  компиляция и запуск на устройстве не проверены.
- Реальные голоса Samsung/Google, генерацию WAV на различных движках, foreground-работу Edge
  и сценарии отсутствия сети необходимо проверить на телефоне.
- Экран системного TTS и экран Edge сохранили отдельные Activity с переходом через общий выбор;
  полностью единая Activity для обоих движков пока не создана.
- WPM является целевой оценкой, рассчитываемой по скорости воспроизведения; точная скорость
  зависит от длительности синтеза, пауз и возможностей Android MediaPlayer/Media3.
- Точные границы произнесённых слов по данным движков пока не синхронизированы.
