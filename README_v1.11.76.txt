ПРОЧиталка v1.11.76-beta CLEAN — исходный Android-проект

Ключевая функция: Streaming-first Microsoft Edge TTS.
ExoPlayer читает MP3-пакеты сразу по мере их получения через собственный
EdgeLiveAudio DataSource. WordBoundary выравнивается в памяти относительно
оригинального текста без ожидания сохранённого sidecar JSON. Воспроизведение
не ждёт завершения синтеза, записи MP3 или анализа конечной тишины.

После завершения запроса MP3 и *.mp3.words.json сохраняются фоново;
предложения индексируются в EdgeTTS/sentences.json. Ручной переход открывает
новый поток, уже начатые запросы продолжаются; не более 3 одновременных
стримов, вытесненные записи возвращаются в постоянную очередь. Остальные
пропуски книги докачиваются последовательно, пока служба может работать.
Повторно готовые MP3 воспроизводятся с устройства без сетевого запроса.

Android может останавливать фоновую службу по системным ограничениям,
а Microsoft Edge может ограничивать число запросов. При последующем
открытии книги очередь восстанавливается по sentences.json и сохранённым MP3.

Это исходный проект, НЕ собранный и НЕ проверенный на телефоне APK.
Для проверки: gradle --no-daemon :app:assembleRelease --stacktrace
Без Android SDK: bash qa/check_java_syntax.sh && bash qa/check_sentence_chunks.sh
