# ПРОЧиталка v1.11.164-beta CLEAN — исходный Android-проект

Это полный проект на Java, обновлённый с **v1.11.163-beta BUILD HOTFIX**. Код старых релизов сохранён, но файлы README/CHANGELOG старых версий намеренно удалены из архива.

## Состав обновления

1. **Ranobes.net:** исправлены POST-поиск и обработка перенаправлений; сканируется полное оглавление `/chapters/{bookId}/`, включая `/page/{n}/`. Учитывается `window.__DATA__` и резервный HTML-парсинг. Неполный список глав явно обозначается.
2. **«Больше глав»:** отдельная область просмотра оглавления с переключением страниц, выбором глав страницы, выбором томов или всей доступной книги. Записи сохраняются в правильном порядке чтения и без повторов по идентификаторам.
3. **Выбор источника:** существующие кнопки ранобэ/манги/аудиокниг открывают верхний диалог с отдельными закруглёнными карточками сайтов; дополнительные кнопки toolbar не добавляются.
4. **Закладки:** закладка по одному слову захватывает всё предложение. При вручную растянутом выделении сохраняется выбранный диапазон. Полный фрагмент записывается в хранилище. Старые закладки не удаляются.
5. **Маркеры на странице:** маленькая иконка заметки 18 dp перенесена слева, окрашена в акцентный цвет темы. Слева добавлен горизонтальный акцентный маркер закладки, «язычком» в сторону текста. При совпадении отметок доступны обе записи. Постоянный левый отступ компенсируется правым, чтобы сохранить ширину текста.
6. **Ручки выделения:** перерисовка при прокрутке, временное скрытие не видимых маркеров, автопрокрутка при удержании возле края, смена ролей ручек при пересечении, отслеживание указателя касания и репозиционирование контекстного меню.

## Принципы совместимости

- Общие пути загрузки ранобэ для RanobeLIB, Ranobes.net и будущих источников сохранены.
- Универсальный менеджер загрузок и отдельные загрузчики Edge TTS, аудиокниг и манги сохранены.
- Работа Edge TTS и предыдущая сегментация v1.11.158 не переписывались в этом релизе.
- Заметки и закладки хранятся в отдельных метаданных; файлы книг не переписываются для их сохранения.
- Библиотека, настройки, обложки и главы предыдущих версий сохраняют прежние форматы.

## Сборка

Требуются JDK 17, Android SDK с установленной платформой Android API 35, Gradle (версия 8.7 совместима с применявшимся CI окружением), доступ к Maven/Google dependency repositories.

```sh
gradle --no-daemon :app:assembleRelease --stacktrace
```

Исходный проект содержит `app/build.gradle`, `settings.gradle`, Java-исходники, Android-ресурсы и папку `qa/`. Это **не APK**. Если сборка на CI требует иных настроек signing, используйте настройки CI-проекта; не храните ключи подписи в исходниках.

**Ограничения:** Android SDK и полноценная Gradle-сборка в доступном окружении отсутствовали. Сетевое поведение Ranobes.net (включая HTTP 307, 403, 429, 503) невозможно гарантировать без проверки на устройстве и реальном сервере. Код не обходит антибот-защиту. Положение иконок и поведение жестов требуют визуальной проверки при разных DPI, шрифтах, темах и версиях Android.

## Проверка вручную на устройстве

1. Запустите поиск Ranobes.net, введите `all the skills`. При ограничении поиска проверьте прямую ссылку `https://ranobes.net/novels/1205570-all-the-skills-v741610.html`.
2. Откройте произведение, нажмите «Больше глав», перелистните страницы 1—14, сравните общее число записей с данными, которые сайт вернул в данный момент. Проверьте загрузку одной главы и выбранного тома.
3. В читалке долгим нажатием выделите одно слово, добавьте закладку, проверьте целое предложение в «Все закладки»; вручную растяните выделение на два предложения и сравните цитату.
4. Проверьте левый маркер заметки и горизонтальной закладки, включая совпадение обеих отметок на одной строке и переключение темы.
5. Перетащите обе ручки выделения через несколько экранов, при инерционной прокрутке, у границы текстового блока, с изменённым шрифтом; сравните текст после «Копировать».
6. Проверьте, что аудиокниги и Edge TTS по-прежнему открывают менеджер загрузок, а не автоматически плеер.

Полная подробная расшифровка — в `CHANGELOG-v1.11.164-beta.md`.
