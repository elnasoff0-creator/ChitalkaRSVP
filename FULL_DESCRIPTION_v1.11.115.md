# ПРОЧиталка v1.11.115-beta CLEAN

База: v1.11.114-beta CLEAN. Это полный исходный проект Android/Java, не готовый APK.

## Все 16 пунктов согласованного ТЗ

1. **Центрирование TTS** — в `ReaderActivity.centerActiveVisibleLine()` вычисляется середина строки текущего слова относительно свободной зоны между верхними и нижними плавающими панелями. В пределах выделенного предложения активная строка остаётся примерно в центре.
2. **Плавная прокрутка** — близкие цели: `RecyclerView.smoothScrollBy`; удалённые: точное позиционирование внутри чанка через `scrollToPositionWithOffset` с завершением без повторных прыжков к началу чанка.
3. **Зазор toolbar/status bar** — удалены верхние дополнительные отступы 7 dp + 4 dp у toolbar. Защита Android WindowInsets остаётся.
4. **Старое предложение после выбора главы** — сохраняется ручная позиция, если индекс книги/Edge ещё загружается, и применяется именно выбранное предложение после загрузки. После `clearTracksForSelection` сохраняется запрос Play, сделанный до готовности индекса. При подключении сервиса ожидающий ручной выбор не перезаписывается стартовым индексом. Журнал: `USER_SELECT`, `PLAY_TARGET`, `NAVIGATION_IGNORED_STALE`.
5. **Мини-Чтейцо +30%** — обычные смайлы 30→39 sp, смайл сна 20→26 sp. Облако остаётся по тексту. Размер мини-карточки расширен с 140 до 182 dp, чтобы большой текст не обрезался; сам спрайт питомца не масштабируется.
6. **Полный Чтейцо +50%** — обычные смайлы 27→41 sp, смайл сна 19→29 sp. Контейнер и текст для смайлов используют `WRAP_CONTENT`; прежняя ширина для длинных фраз остаётся 235 dp.
7. **TTS overlay в ReaderActivity** — появляется сверху, когда пользователь вручную прокручивает во время работающего TTS. Это обычный View внутри `sceneRoot`, не системный float и не требует разрешений.
8. **Дополнение слов** — overlay отображает префикс текущего предложения до последнего активного слова; позиция обновляется из локального TTS или Edge WordBoundary и периодического UI tick.
9. **Касание overlay** — возвращает к текущему слову/предложению, скрывает overlay, возвращает обычное сопровождение без перезапуска аудио.
10. **Пауза «Курсор»** — если подсвеченная строка целиком ушла за фактическую область чтения при ручной прокрутке, останавливается счётчик курсора. Автоматического возврата и автопродолжения нет; требуется Play.
11. **Нет возврата по таймеру** — исключён прежний ограничитель 900 мс. Вручную прокрученный экран не возвращается при новых словах или предложениях.
12. **Только три события возврата** — касание overlay, возвращение в интерфейс чтения/смена режима, Play после паузы. Ручное листание блокирует сопровождение, пока не произошло одно из этих действий.
13. **Ближний и дальний переход** — близкое расстояние плавно, далёкое позиционируется быстро и точно, без перебора всех промежуточных глав.
14. **Сохранение подсветки в RSVP** — добавлено фоновое выделение активного слова при паузе и обновление выделения, даже если индекс изменился внутри прежнего чанка.
15. **Выход из RSVP** — сохранённый индекс слова переносится в обычное чтение; выделение и центрирование выполняются при явной смене режима.
16. **Реакции Чтейца** — новая `EmotionTapWaves.java` рисует короткие расходящиеся лучи при появлении эмоции в мини-карточке. Полный UI использует существующий `TapWaves` и при эмоциях, а не только при касании спрайта. Один тактильный импульс на появление эмоции: у мини-питомца при свайпе, в полном UI при показе смайла. Вибрация мини-питомца при начале Drag and Drop и короткого/длинного взаимодействия не меняет правила навигации.

## Механика ручного листания

`AUTO_FOLLOW` — идёт сопровождение активной строки, если нет ручного скролла. Когда RecyclerView получает `SCROLL_STATE_DRAGGING`, `followSuspended=true` и дальнейшие события TTS не перемещают список. При TTS поверх списка показывается обновляемая реплика; при Cursor выделение за пределами области ставит чтение на паузу. Пока пользователь листает, простое прекращение движения пальца НЕ восстанавливает следование. Возврат осуществляется только по явно оговорённым действиям. При возвращении в ReaderActivity состояние аудио остаётся источником позиции TTS.

## Навигация Edge при выборе новой главы

- До завершения `EdgeStreamingService.openBook` ручное `setAnchor(word, true)` сохраняется в `deferredSelectedWord`, вместо того чтобы терять флаг пользовательского перехода.
- При завершении индексирования выполняется именно этот переход, а не обычное восстановление старого чанка.
- При сохранённом запросе Play очистка старого Media3-плейлиста больше не должна оставлять новый выбор без воспроизведения; запрос Play перевыставляется.
- Обработчик UI отклоняет устаревший WordBoundary, если он не принадлежит выбранному предложению.
- Сетевые настройки, таймер сна, локальный кэш, фоновые ограничения WebSocket из v1.11.114 не изменялись.
