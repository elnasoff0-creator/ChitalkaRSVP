# ПРОЧиталка v1.11.169-beta CLEAN — исходный проект

База: **v1.11.168-beta CLEAN (Gradle Compile Hotfix)**. Версия в `app/build.gradle`: `versionCode 16900`, `versionName 1.11.169-beta`.

Изменения версии:

1. Кнопка «⋮» в верхней панели чтения вновь имеет обычную тематическую подложку, без акцентной обводки.
2. «Загрузки»: «Проверить загрузки» перенесено из Toolbar в раскрывающийся список «Все загрузки»; панель действий адаптируется к ширине экрана и скрывает лишние действия под «⋮».
3. «Менеджер»: кнопки Play/Pause, «Скачать всё», «Папка» используют обычную залитую подложку и контрастные иконки вместо зелёного контура.
4. Edge TTS: содержимое «Инфо» сохраняется по ID произведения; при повторном входе отображается из кэша, а уточнение выполняется в фоне. Сохранённое оглавление не разбирается повторно при каждом входе.
5. Сохранены функции и защита v1.11.168-beta: событийное обновление загрузок, адресная проверка заданий, ручная сверка файлов, управление очередями и SAF.

Подробности: `CHANGELOG-v1.11.169-beta.md`. Ограничения и результаты проверок: `QA-REPORT-v1.11.169-beta.md`.

## Сборка

В Android Studio открыть корень проекта; целевой SDK 35, Java 17, Android Gradle Plugin из корневого `build.gradle`. Команда CI:

```bash
gradle --no-daemon :app:assembleRelease --stacktrace
```

**APK в этой передаче не собран.** Наличие исходного проекта и прохождение синтаксических проверок не подтверждают успешную Android/Gradle-сборку. Перед публикацией нужен реальный CI build и проверка поведения на устройстве.

В ZIP присутствует документация только текущей версии; исторические README/CHANGELOG не включены.
