ПРОЧиталка v1.11.105-beta CLEAN
Основа: v1.11.104-beta. Дата: 27.10.2026.

ГЛАВНОЕ: строго последовательная сетевая озвучка MS Edge TTS.

1. EdgeStreamingService.java
   - Удалён механизм фоновой подготовки будущего MP3-блока: больше нет
     startLive(ahead) и nearEndOfCurrentAudio с порогом 12 секунд.
   - Во время чтения допускается синтез только выбранного блока текста.
   - Готовые MP3 следующих блоков по-прежнему можно добавлять в плейлист:
     это чтение с диска и не вызывает сетевого запроса.
   - После полного воспроизведения последнего доступного MP3 сервис получает
     onTrackFinished(start,end,key), переносит anchorWord на end и только тогда
     запрашивает следующий отсутствующий блок.
   - На окончании книги или границе таймера сна «Конец главы» воспроизведение
     останавливается вместо запуска новой сетевой генерации.

2. EdgePlaybackService.java
   - Добавлено одноразовое событие окончания последнего доступного MP3
     (Player.STATE_ENDED). Повторные события одного и того же трека
     не вызывают повторного сетевого запроса.
   - При добавлении нового MP3 после состояния ENDED плеер может продолжить
     воспроизведение автоматически, если пользователь не нажал Pause.
   - Проверка границы таймера сна выполняется до запроса следующего блока.

3. EdgeSpeechEngine.java
   - Отмена и завершение WebSocket не освобождают сетевой слот преждевременно.
   - Следующий запрос ожидает onClosed/onFailure предыдущего соединения.
   - При зависшей процедуре закрытия через 4 секунды выполняется
     принудительная отмена соединения и освобождение слота; это аварийная
     защита, а не задержка перед каждым блоком.
   - Сохранено однократное восстановление HTTP 403 по серверной дате,
     прежние правила HTTP 429 и потоковая передача MP3.

4. EdgeSpeechQueue.java
   - Во время активного пользовательского воспроизведения Edge TTS новые
     фоновые задания полной подготовки книги ожидают Pause или завершения.
   - Все WebSocket-задания продолжают обрабатываться одним общим арбитром.

5. ПАРАМЕТРЫ БЕЗ ИЗМЕНЕНИЙ
   - MAX = 900, FIRST_TARGET = 900, SentenceChunks.LIMIT = 900.
   - FIRST_TARGET_PRIORITY = 600 при ручном выборе предложения.
   - Первый текущий блок при входе в режим Edge TTS по-прежнему может
     предварительно загружаться до Play. Отключена именно подготовка
     ПОСЛЕДУЮЩИХ блоков во время воспроизведения предыдущего.
   - MP3-кэш, WordBoundary, Media3, настройки UI и мини-питомец сохранены.

6. QA
   - Добавлена проверка последовательного воспроизведения и отсутствия
     speculative startLive(ahead) в qa/check_edge_serial_playback.sh.
   - В сценариях WebSocket протестирована непараллельность двух реальных
     сетевых запусков и отмена первого перед открытием второго.
   - Протестирована пауза фоновой подготовки при активной озвучке.
   - Актуализирован тест выбора предложения для нового отсутствия look-ahead.

ОГРАНИЧЕНИЯ
   - Возможно короткое ожидание между двумя ещё не сохранёнными блоками:
     новый синтез начинается после воспроизведения предыдущего, а не заранее.
   - Сервер Microsoft всё ещё может вернуть HTTP 429 даже при одной сессии.
   - Android APK и испытания на устройстве здесь не выполнялись; проверки
     исходников и моделируемых сетевых сценариев не заменяют assembleRelease.
