# ПРОЧиталка v1.11.174-beta CLEAN — Full Source

Исходный Android Java проект на базе v1.11.173. `versionCode=17400`, `versionName=1.11.174-beta`.

## Что изменилось

Основное: ленивое восстановление только запрашиваемых MP3-фрагментов Edge TTS из SAF, неблокирующая проверка смены папки, виртуализированный менеджер MangaLib без 2.5-секундного полного обновления, сохранение прогресса манги пакетами, асинхронное открытие комиксов, индексирование текста/поиск/длительности аудиокниг без лишних UI-циклов. Все детали — `CHANGELOG-v1.11.174-beta.md`. ТЗ — `TZ-PROChitalka-v1.11.174-beta.md`.

## Проверка

Выполнить `sh qa/check_v174.sh` для автономных проверок. Для полноценной сборки нужен Android SDK 35, JDK 17 и Gradle 8.7+ с Android Gradle Plugin, соответствующим проекту:

```
gradle --no-daemon :app:assembleRelease --stacktrace --console=plain
```

**Важно:** данный ZIP содержит исходники, не APK; полная Gradle/Android сборка пока не подтверждена. См. `QA-REPORT-v1.11.174-beta.md`.

## Сохранность данных

Смена папки сама по себе не переносит и не удаляет файлы. Ранее выданные SAF разрешения не отзываются, но для чтения книг, оставшихся в старой папке после перехода на новую, может потребоваться повторно выбрать старое расположение. Перед обновлением желательно иметь резервную копию пользовательских данных.
