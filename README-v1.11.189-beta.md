# ПРОЧиталка v1.11.189-beta CLEAN — полные исходники

## Что это

Android-приложение «ПРОЧиталка» (Java, Android minSdk 24 / targetSdk 35): чтение книг, Edge TTS и локальные движки TTS, MP3/WordBoundary, заметки, закладки, цитаты, питомец «Чтейцо» и менеджер загрузок. Архив содержит исходники приложения, ресурсы, GitHub Actions и QA-тесты. APK в архив не включён.

**Версия:** `versionName=1.11.189-beta`, `versionCode=18900`.
**Основа:** `v1.11.188-beta CLEAN`.

## Что нового в 1.11.189

1. **Новый `ReaderTtsScrollController`.** Управляет только перемещением `RecyclerView` за *текущим озвучиваемым словом* (WordBoundary), независимо от аудио, пользовательского выделения и подсветки. Рабочая зона примерно до 69% полезной высоты экрана. Пока слово в ней, экран неподвижен. Когда слово приближается к краю или уходит за экран — плавно догоняет с единственным обновляемым циклом кадров.
2. **Нет конкурентных автопереходов.** Для обычного TTS больше не используется старая логика «любая часть предложения видна», `smoothScrollBy` и старое центрирование строки. Плавное движение выполняется небольшими шагами `scrollBy` в одном `postOnAnimation`-цикле; новое слово меняет цель без запуска второй анимации. Далёкое мгновенное позиционирование допустимо только при явном возврате/переходе.
3. **Преимущество действий пользователя.** Прокрутка рукой, выделение и перетаскивание маркеров останавливают автосопровождение; старые отложенные команды проверяют `viewportNavigationEpoch`. Возврат к речи выполняется только по явному действию пользователя. Во время паузы сопровождение не выполняется.
4. **Уточнена геометрия текущего слова.** Координата рассчитывается в системе координат `RecyclerView`, включая реальный `TextView` и строку по символам книги; так же определяется видимость слова для плавающей подписи.
5. **Расширена диагностика.** В журнал добавлены события `TTS_SCROLL`: `FOLLOW_TARGET`, `FOLLOW_START`, `FOLLOW_FINISHED`, `FOLLOW_SKIPPED`, `FOLLOW_CANCELLED`, `MANUAL_SCROLL`, `RETURN_TO_SPEECH`, `FOLLOW_JUMP_EXPLICIT` — индекс слова, эпоха навигации, смещение в пикселях, длительность. Текст книги не записывается.
6. **Облачко цитат «Чтейца».** Внешняя карточка, окно и контейнер питомца не растягиваются ради цитаты: высота исходного контейнера остаётся 260 dp, размеры самого пузыря подбираются по содержимому с ограничением доступной ширины и высоты. В длинных репликах применяется `TextUtils.TruncateAt.END` (`…`), без внутренней прокрутки облачка. Полная цитата в SQLite сохраняется без изменений. Вероятность категорий реплик 50/50 сохранена.

## Проверка и разработка

В GitHub Actions: установка Java 17, Android SDK 35 и Gradle 8.7, выполнение QA, сборка и подпись APK. Для сборки подписанного релиза нужны четыре прежних GitHub secrets. Код не содержит ключей подписи.

Локальные автономные проверки (требуется JDK):

```bash
bash qa/test_reader_tts_scroll_189.sh
bash qa/check_java_syntax.sh
bash qa/test_edge_startup_188.sh
bash qa/test_reader_selection_navigation_185.sh
bash qa/test_word_boundary_refresh_186.sh
```

`qa/test_reader_tts_scroll_189.sh` проверяет расчёт зоны, пошаговое перемещение, направления поиска ещё не загруженного элемента, ограничения облачка и статические связи с ReaderActivity/ChteicoActivity.

**Ограничение:** синтаксические и автономные QA-тесты не заменяют полноценную Android-сборку и проверку плавности жестов на телефоне. Реальную отзывчивость и отсутствие визуальных скачков нужно подтвердить на устройстве.

## Как записать диагностический лог

Включите режим разработчика (10 быстрых нажатий на логотип в боковом меню приложения), затем откройте пункт **«Показать лог-файл»**. Для точного опыта очистите журнал, включите Edge TTS, прослушайте длинное предложение, затем прокрутите страницу вручную и нажмите возврат к озвучиваемому слову. Экспортируйте `prochitalka_log_export.txt` и передайте файл для анализа этапов `TTS_SCROLL`. Дополнительно полезно проверить фоновую паузу, выделение и переход между MP3/главами.

## Чего не меняли

Путь к книгам/SAF, формат сохранённых MP3, блоки целых предложений, сохранённые заметки/закладки/цитаты, правила выбора двигателя Edge/резервного TTS, распределение 50/50 обычных фраз питомца и цитат. Исходники не очищают и не пересоздают базу данных пользователя при обновлении.
