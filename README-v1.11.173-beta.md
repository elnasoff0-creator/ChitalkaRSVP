# ПРОЧиталка — v1.11.173-beta CLEAN

Полные исходники Android/Java, версия `1.11.173-beta`, `versionCode 17300`, база: **v1.11.172-beta CLEAN Gradle Compile Hotfix**. ZIP содержит весь Gradle-проект и текущие QA-скрипты. APK в комплект не входит.

## Что изменено

1. Edge TTS: обычная загрузка главы публикует **отдельные MP3-фрагменты с WordBoundary**. Автоматическое объединение и его настройка убраны; прежние объединённые главы по-прежнему читаются.
2. Контекстное меню `⋮` карточки Edge TTS: **«Перенести готовые аудиоглавы едиными файлами в аудиотеку»**. По явной команде один MP3 для каждой полностью готовой главы, а не один MP3 на всю книгу. Сохраняются имена из оглавления или номера, общая папка книги и максимум один файл обложки `cover.jpg`/`cover.png`/`cover.webp`. WordBoundary в экспорт не копируется, обложка в MP3 не встраивается. Исходные данные Edge TTS не изменяются.
3. «Диагностика → Показать лог-файл» перенесено из «Аудио» в самый низ вкладки «Общие».
4. Контурная галочка в круге с акцентным цветом: готовые главы в менеджере (16 dp), карточка произведения в «Загрузках» при полной готовности (18 dp).

## Что сохранено

- Исправления v1.11.172: адресная запись через SAF, отказ от обязательных `.pending`/переименования, сохранение готового результата, свайп «В архив» **вправо**, работоспособные кнопки действий.
- Рыбалка v1.11.171: временная усталость рыб, иконка усталости, редкости и бонусы удочек.
- Прочие режимы чтения, Edge/Android TTS, OCR, комиксы, темизация, менеджер и библиотека — без намеренных функциональных изменений вне перечисленных пунктов.

## Состав

- `CHANGELOG-v1.11.173-beta.md` — детальное описание правок.
- `TZ-PROChitalka-v1.11.173-beta.md` — накопительное ТЗ (раздел v173 имеет приоритет над историческими разделами).
- `QA-REPORT-v1.11.173-beta.md` — результаты тестов и ограничения.
- `qa/check_v173.sh` — набор автономных проверок.

## Запуск проверки

```sh
sh qa/check_v173.sh
```

Для полной сборки на ПК/CI с Android SDK и Gradle 8.7:

```sh
gradle --no-daemon :app:assembleRelease --stacktrace --console=plain
```

**Статус:** исходный релиз-кандидат. В среде подготовки доступны Java 17 и автономные тесты, но нет Gradle и Android SDK; `:app:assembleRelease`, реальное воспроизведение на телефоне, UI-свайпы и запись SAF на устройстве не выполнены. См. QA-отчёт.
