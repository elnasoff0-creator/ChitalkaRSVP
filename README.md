# Читалка RSVP 1.8 — рабочая архитектура v1.7

Полный проект Android Java с `MainActivity` (библиотека) и **отдельным проверенным экраном** `ReaderActivity` на основе работающей версии v2.

Изменения:
- Переключатель режимов: «📖 Обычный» / «⚡ Скоростной».
- В скоростном режиме перелистывание по словам свайпами вверх/вниз вместо кнопок ‹ / ›. Пока палец на экране, отображается окно из 11 слов: выделенное чёрным, остальные серым. После отпускания восстанавливается выбранный режим отображения слов.
- Кнопка «Чтение» в нижнем меню теперь открывает отдельную `ReaderActivity` и последнюю книгу.
- В настройках ReaderActivity появился экран «Паузы при скорочтении»: запятая / пунктуация, длинные слова (12+), конец предложения. Настройки сохраняются локально. Длительности: соответственно +60%, +50%, +120% к интервалу слова; эффекты суммируются.
- Обложки в библиотеке извлекаются из EPUB (OPF `cover-image` / `meta name=cover`) и FB2 (`coverpage/image` + `binary`, base64), декодируются в фоне и сохраняются в cache приложения. При отсутствии обложки остаётся текстовая заглушка. Не все нестандартные EPUB/FB2 гарантированно поддерживаются.

**Сборка:** заменить исходники в GitHub и запустить прежний Actions workflow `gradle assembleDebug`. `versionCode=9`, `versionName=1.8`. Никаких внешних библиотек.

**Тестирование:** этот архив не компилировался в среде подготовки (нет Android SDK); сборку и проверку на устройстве нужно выполнить через GitHub Actions. Существующие данные `SharedPreferences` сохраняются, если приложение устанавливается поверх предыдущего APK с той же подписью.
