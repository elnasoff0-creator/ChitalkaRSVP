# ПРОЧиталка v1.11.55-beta

Восстановленная версия на основе приложенного пользователем Android-проекта **v1.11.53-beta**, без отката к старым спрайтам. Сохраняет `ru.reader.rsvp`, название приложения **ПРОЧиталка** и подписанный Release workflow GitHub Actions.

## Версия

- `versionName`: `1.11.55-beta`
- `versionCode`: `11155`
- Пакет: `ru.reader.rsvp`
- Сборка: `.github/workflows/release.yml`, `:app:assembleRelease`, `zipalign`, `apksigner`, SHA-256 и Artifacts.
- Репозиторные secrets: `RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_PASSWORD`, `RELEASE_KEY_ALIAS`.

## Исправление анимации касаний в v1.11.55-beta

В `ChteicoActivity.java` восемь расходящихся линий теперь рисуются примерно с толщиной 5,4dp (по толщине основного контура питомца) и диаметром примерно вдвое больше прежнего. Для лучей используется полный горизонтальный размер карточки, а область касаний остаётся строго на питомце. Время анимации 320мс; AVD-персонажи и их эмоции не изменены. Подробности — в `FULL_CHANGELOG_v1.11.55.txt`.

## Восстановленные возможности Чтейца

- Четыре стадии: яйцо Чтейцо → Чтенчик → Чтенец → большой летающий Чтун.
- Девять векторных образов по трём веткам: обычное чтение, скорочтение/Курсор и аудиокниги.
- 54 реальных AnimatedVectorDrawable (состояния idle, joy, surprise, evolve, sleep, wake) на базе 9 VectorDrawable и 32 animator XML.
- Независимые крылья, голова, тело, брови, глаза, клюв и аксессуары; без смены полноразмерных двухкадровых изображений.
- Сон/пробуждение один раз в день, моргание, дыхание, чтение/аудио в простое, полёт Чтуна, радость и удивление от касаний, эволюция.
- Именование, облачко с цельным контуром и согласованные реплики, кроме молчаливого яйца.
- Читательская статистика даже при выключенном питомце; вместо яйца — кнопка статистики.
- Только earned-награды; 6 контурных значков.
- Скрытый режим разработчика с четырьмя стадиями и тремя ветками.

## Исправления v1.11.54-beta относительно v1.11.53-beta

1. Исправлена пустая иконка кнопки «Статистика» в `MainActivity` при выключенном Чтейце.
2. При первом включении Чтейца начальные показатели предыдущего чтения не определяют ветку нового яйца; последующий прогресс и статистика сохраняются.
3. Все 54 AVD-сцены используются через прямые `R.drawable` ссылки вместо строкового поиска ресурсов во время выполнения.
4. Обновлены версии, signed-release workflow и отдельный журнал изменений. Полное описание v1.11.53 также сохранено.

## Проверка и ограничения

Статически проверены Java-синтаксис, XML-ресурсы, ссылки AVD и логика игрового состояния с тестовым JVM окружением. **Android APK здесь не собирался:** местный Android SDK и Gradle отсутствуют. Финальную компиляцию, подпись, установку и визуальный тест анимаций следует провести в GitHub Actions и на устройстве.
