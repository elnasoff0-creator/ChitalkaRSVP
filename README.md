# Читалка RSVP — версия 1.5, исправление экрана чтения

Главный экран с библиотекой сохранён. Исправлена регрессия, появившаяся после добавления главного меню:

- Контейнер чтения теперь FrameLayout, занимающий доступную высоту; RSVP и обычный режим — две перекрывающиеся области высотой match_parent. Не используется вложенное вертикальное размещение двух элементов с `height=0`.
- Панель кнопок управления остаётся вне контейнера чтения и доступна в обоих режимах.
- Последняя книга при перезапуске сначала загружается в память, после чего открывается экран чтения.
- При пустом тексте выводится предупреждение; пустой экран чтения не открывается.
- При каждом слове больше не пересчитываются глава и фрагмент книги для библиотеки.
- В остальном сохранены предыдущие исправления EPUB XML и библиотека.

Проект собирается через GitHub Actions, как в предыдущих версиях (Android Gradle Plugin 8.6.1, Gradle 8.7, Java 17, SDK 35).

**Важно:** компиляция и запуск на реальном устройстве в данном окружении не выполнялись. Для подтверждения исправления следует пересобрать APK и проверить EPUB в обоих режимах чтения.
