# ПРОЧиталка v1.11.51-beta — реплики «Чтейца»

**Signed Release Android source project** · `versionCode 11151` · `versionName 1.11.51-beta` · `applicationId ru.reader.rsvp`.

The Android launcher name is **«ПРОЧиталка»** (without `-beta`). App ID and release signing secrets are unchanged, allowing updates over existing installs when signed with the original key.

## Новые изменения v1.11.51-beta

- **Вернулись интерактивные реплики Чтенца и Чтуна.** Каждое касание взрослого или вылупившегося питомца запускает прежние визуальные волны, лёгкий прыжок и показывает новое контурное облачко-комикс над персонажем. Реплика видна около 4 секунд; следующее касание меняет текст и перезапускает отсчёт. Всплывающие облачка не изменяют положение питомца и не требуют отдельного toggle.
- **Полный согласованный набор из 35 фраз:** 33 разнообразные фразы (мотивация, мягкие подсказки о росте, обычное чтение, скорочтение/Курсор, аудио, Чтенец, Чтун, возвращение после перерыва, достижения) и 2 однократных представления после эволюции. Все они находятся в `ChteicoPhrases.java`.
- **Контекстный подбор:** учитываются стадия, закреплённая ветка, дни без чтения/аудио (в соответствии с пользовательской настройкой) и достижение результатов. Фразы не повторяются подряд; подходящий набор перебирается без повторений до начала следующего цикла. Состояние подбора сохраняется между запусками и очищается игровыми сбросами.
- **Яйцо НЕ разговаривает:** касания по-прежнему дают 1/8 роста, показывают полупрозрачные волны и запускают вылупление по прежним условиям. Механика яйца в этой версии не изменена.
- **Сохранены представления:** «Привет! Я Чтенец!» и «Я вырос! Теперь я Чтун!» показываются один раз независимо от пользовательского имени. Они остались отдельными событиями, не смешиваются с ежедневными репликами.
- **Подписанный релиз:** обновлены `versionName 1.11.51-beta`, `versionCode 11151` и пути артефактов `.github/workflows/release.yml`. `applicationId`, четыре GitHub Signing Secrets и механизм подписания не изменены.

### Каталог фраз и поведение

В `ChteicoPhrases.java` содержатся все 35 утверждённых реплик. Движение крыльев, персонажи, история эволюции и прочие возможности v1.11.49-beta сохранены. Пользовательские реплики избегают технической терминологии и точных численных требований для эволюции.

### Проверки

Все Java-файлы проверены синтаксическим анализатором JDK, отдельные Java-тесты проверили содержимое набора, смену реплик, отсутствие повторений внутри цикла и отсутствие речи у яйца. Полную Android-сборку и работу на устройстве нужно проверить в GitHub Actions/на телефоне, так как локальный Android SDK недоступен.

## Предыдущие изменения v1.11.49-beta

- Экран питомца: заголовок и направление эволюции скрыты; вместо стадии показывается имя питомца, шкала с нейтральным названием «До следующей эволюции», статистика и награды. Управление напоминаниями и развивающие подсказки из Activity убраны.
- Настройки → Чтейцо: раскрывающаяся **«Справка»** (по умолчанию закрыта) с образным текстом, без технических имён и скрытых порогов. Отдельные настройки ежедневных напоминаний, дней неактивности (ввод целого положительного числа), достижений и времени уведомления; сброс питомца/ветки. Удалены переключатели анимации и реплик: анимация всегда включена.
- Яйцо: каждое нажатие добавляет 1/8 прогресса (12,5%) с круговыми волнами; при 4/8 появляется спрайт с трещиной, после 8/8 яйцо вылупляется. Каждый **зачётный** возврат на главный экран после посещения книги или аудиокниги даёт 2/8 (25%). Обычное открытие главного экрана без нового посещения не начисляет прогресс; события суммируются в одной шкале.
- После первой эволюции однократно показывается облачко «Привет! Я Чтенец!», при взрослении — «Я вырос! Теперь я Чтун!». С v1.11.51-beta обычные касания Чтенца и Чтуна также вызывают новые разнообразные реплики.
- Имя можно дать даже яйцу; имя выбирается один раз за цикл и сохраняется при взрослении. Полный сброс позволяет выбрать новое; сброс ветки оставляет имя и статистику. Игровые сбросы не затрагивают книги, закладки, файлы и позиции чтения.
- При определении ветки **«Курсор» теперь относится к «Скорочтению»**, а не к обычному чтению. После вылупления ветка фиксируется и не меняется до сброса.
- Контурная иконка яйца в настройках и нижней панели получила отдельный векторный ресурс с более толстой линией. Герой-яйцо оставлен со стандартной толщиной и получил второй векторный спрайт с трещиной.
- Анимация: два кадра крыльев, небольшое сжатие туловища с фиксированной опорой, добавлен акцент поднятых бровей; в аудиоветке верх наушников сохраняется из постоянного спрайта при смене позиций крыльев.

## Как работает счётчик

Яйцо имеет 8 условных единиц: 1 за нажатие и 2 за зачётное возвращение. Прогресс виден как процент, но количество действий и ветки эволюции скрыты в пользовательской справке и основном интерфейсе. Выбор оформления основан на реально учтённых активных секундах чтения, курсорного и скоростного чтения и прослушивания. Статистика локальная, начинается после включения «Чтейца». Завершение произведения по-прежнему может привести к взрослению после возвращения в библиотеку. Никакие игровые действия не изменяют прогресс и библиотеку пользователя.

## Подписанная сборка APK

Единственный `.github/workflows/release.yml` собирает `:app:assembleRelease`, выполняет `zipalign` и `apksigner`, проверяет сертификат и публикует signed APK и SHA-256 в GitHub Actions.

Нужны существующие Repository Secrets: `RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_PASSWORD`, `RELEASE_KEY_ALIAS`.

Для обновления исходников сохраните папку `.git`, скопируйте файлы из ZIP в корень репозитория, проверьте удаление старых файлов, затем в GitHub Desktop выполните **Commit to main → Push origin**.

Локально проверяются Java-синтаксис, XML и самостоятельные модульные тесты счётчика яйца. Android SDK в текущей среде недоступен, поэтому финальная компиляция и визуальная проверка на телефоне должны пройти после GitHub Actions.
