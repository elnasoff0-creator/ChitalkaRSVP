# Читалка RSVP — версия 1.4

Обновлено:
- Кнопка «📖 Обычное чтение» переключает в обычный режим, обратная — «⚡ Скорочтение».
- Для настроек, поиска, импорта и панели навигации использованы системные Android-иконки вместо плохо отображающихся Unicode-символов. Закладка обозначена ⭐.
- Исправлено восстановление книги после холодного запуска: приложение не показывает пустой экран чтения, а сначала асинхронно загружает сохранённый файл.
- Исправлена проверка пустого текста; при отсутствии текста показывается сообщение вместо пустого экрана.
- Панель управления чтением и скорость расположены над компактной панелью дополнительных настроек, чтобы не пропадать с экрана.
- Убрана лишняя обработка метаданных на каждом слове RSVP.

## Сборка

Обновите в GitHub содержимое папки `app`, затем запустите Actions → Build Android APK → Run workflow.

Проект не прошёл сборку в локальной среде (отсутствует Android SDK). Проверяйте результат через GitHub Actions и затем на телефоне.
