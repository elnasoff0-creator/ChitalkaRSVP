# Читалка RSVP для Android — версия 1.6

## Исправление пустого экрана чтения

- Панель управления («назад», «плей/пауза», «вперёд»), скорость чтения и кнопки настроек построены **до** области текста. Они больше не могут оказаться ниже неё.
- Раньше приложение при открытии EPUB создавало один TextView на весь роман. Теперь в обычном режиме отображается ограниченный фрагмент текста (~3000 символов), что значительно уменьшает нагрузку на главный поток.
- Переход между фрагментами выполняется кнопками назад/вперёд; кнопка плей плавно прокручивает текст и загружает следующий фрагмент.
- В режиме скорочтения по-прежнему отображается текущее слово; три варианта отображения и регулятор скорости сохранены.
- Сохраняются библиотека, обложки-заглушки, закладки и параметры чтения.

## Обновление GitHub

Распакуйте архив и перенесите **содержимое** проекта в корень вашего GitHub-репозитория, сохраняя пути `app/src/main/java/...`. Существующие файлы надо заменить, а не загрузить отдельной вложенной папкой. Затем Actions → Build Android APK → Run workflow.

## Ограничения и проверка

Этот ZIP содержит Android-исходники, не собранный APK. В этой среде Android SDK недоступен, поэтому компиляция и работа на устройстве не проверены. Для надёжного подтверждения необходима сборка GitHub Actions и испытание EPUB на смартфоне. Постраничная навигация в обычном режиме ориентировочная и не сохраняет исходную HTML-верстку EPUB.
