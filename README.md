## Новая встроенная функция «Чтейцо»

- Новая пятая вкладка **Настройки → Чтейцо** с контурной иконкой яйца.
- Включение функции необязательное и изначально выключено. Включение добавляет кнопку **Чтейцо** в нижнюю панель главной библиотеки.
- Отдельная `ChteicoActivity`: яйцо/Чтенец/Чтун, анимация, закреплённая ветка, шкала роста, статистика, серия дней, достижения, управление напоминаниями.
- **Яйцо**: два состояния с мягким сжатием, без ног. **Чтенец и Чтун**: отдельные векторные изображения вверх/вниз с анимацией крыльев. Лапки в одном экранном положении, рисунки адаптированы из выбранных визуальных референсов.
- **Ветки развития, определяемые один раз при вылуплении:** Чтение/Курсор (очки), Скорочтение (молния и тёмные очки), Аудио (наушники). Следующая стадия наследует ту же ветку.
- Стадия «Яйцо» вылупляется после открытия книги или аудиокниги **при возвращении на главный экран**. Стадия «Чтенец» переходит во взрослую после завершения книги/аудиокниги. Статистика учитывает сессии, открытые и завершённые произведения, фактическое время чтения/воспроизведения, слова, серию дней.
- Учёт аудио привязан к реальному состоянию воспроизведения фонового сервиса. Просмотр одной лишь обложки аудиокниги не начисляет минуты прослушивания. Завершения аудиокниг фиксируются в штатном MP3-плеере при естественном окончании последнего трека. Edge TTS-фрагменты учитываются как прослушивание, но не выдаются за полностью завершённую аудиокнигу.
- Уведомления **выключены по умолчанию**: ежедневное напоминание, напоминание после трёх дней без чтения, оповещения о достижениях. Настраивается час (по умолчанию 19:00); запрашивается Android-разрешение на уведомления. Локальный будильник восстанавливается после перезапуска телефона.
- Можно сбросить ветку и стадию, не затрагивая накопленные минуты и библиотеку; можно полностью сбросить **только игровые данные Чтейца**. Позиции книг, настройки плееров и файлы не удаляются.
- Отдельные переключатели анимации питомца и текстовых реакций.

## Особенности измерения

Деятельность фиксируется локально, на устройстве. Чтение в `ReaderActivity` измеряется во время активной сессии и пока активна прокрутка/воспроизведение, без учёта фоновой паузы. Время штатного MP3 и Edge TTS начисляется, только пока звук действительно воспроизводится. Разные типы учитываются отдельно. Автоматическая ветка выбирается по накопленному активному времени к моменту вылупления; при отсутствии набранных секунд — по последнему открытому типу контента. Многократное завершение одной и той же книги не даёт повторной награды.

## Сборка APK (через GitHub Actions)

Единственный workflow `.github/workflows/release.yml`: `:app:assembleRelease`, `zipalign` и `apksigner`, проверка подписи, артефакт в Actions. Необходимы четыре действующих GitHub Secrets:
`RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_PASSWORD`, `RELEASE_KEY_ALIAS`.

Для загрузки обновления в тот же GitHub-репозиторий распакуйте содержимое ZIP поверх рабочей папки, **сохранив `.git`**, удалите старые посторонние файлы, если они остались; затем GitHub Desktop → Commit to main → Push origin.

**Проверено локально:** Java parsing всех исходников, XML-файлы и ZIP. Полная Android-компиляция и поведение на устройстве должны быть подтверждены GitHub Actions и проверкой установленного APK.
