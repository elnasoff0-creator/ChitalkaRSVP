# Читалка RSVP для Android

Исходный проект Android (Java, без сторонних библиотек). Открывает файлы EPUB, FB2, HTML/HTM через системный выбор документов. Поддерживает RSVP, обычный режим, настройку скорости, цветов и шрифтов, закладки и сохранение позиции локально. EPUB обрабатывается как ZIP, OPF/spine читаются в порядке книги, HTML преобразуется в текст. В этой начальной версии сложная верстка, картинки и CSS электронных книг не сохраняются.

## Сборка APK
1. Откройте папку `ChitalkaRSVP` в Android Studio с Android SDK Platform 35 и JDK 17.
2. Дождитесь загрузки Android Gradle Plugin 8.6.1.
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK будет по пути `app/build/outputs/apk/debug/app-debug.apk`.

Проект не удалось собрать или протестировать в среде подготовки: Android SDK и Gradle недоступны. Для сборки нужен Android Studio с доступом к необходимым зависимостям.
