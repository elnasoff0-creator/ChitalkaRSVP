# ПРОЧиталка

**ПРОЧиталка** — приложение для Android, объединяющее чтение электронных книг, скоростное чтение (RSVP), озвучивание текста, аудиокниги, мангу и загрузку произведений.

**Версия:** `1.11.193-beta` · **Android:** 7.0+ (API 24) · **Язык интерфейса:** русский

## Возможности

- **Электронные книги:** библиотека с обложками, оглавлением и сохранением позиции; обычное чтение, режим «Курсор» и скоростное чтение RSVP. Настройка шрифта (включая собственные), размера, межстрочного интервала, цветов и оформления.
- **Озвучивание текста:** системные голоса Android и Microsoft Edge TTS, выбор голоса и скорости, подсветка произносимого слова, сопровождение текста прокруткой. Подготовленные аудиофрагменты Edge TTS можно слушать без интернета; готовые главы — экспортировать в MP3.
- **Словарь TTS:** замены слов и произношения, ударения, контекстные правила, регулярные выражения, игнорирование фрагментов; импорт и экспорт словаря в CSV.
- **Аудиокниги:** отдельная аудиотека, воспроизведение по главам, регулировка скорости, таймер сна и запоминание позиции.
- **Манга и комиксы:** библиотека и чтение изображений, архивов CBZ/CBR (а также ZIP/RAR), режимы «Лента» и «Страницы», сохранение главы и страницы.
- **Загрузки:** поиск и загрузка материалов через поддерживаемые источники (в том числе MangaLib, RanobeLib, Ranobes и Kvuhe), загрузка по прямой ссылке, единый менеджер загрузок с прогрессом, историей и отменой.
- **Web Transfer:** передача книг, комиксов и аудиофайлов с компьютера через браузер в одной сети Wi-Fi. Локальный адрес, QR-код, временный PIN, пакетная загрузка, прогресс и отмена в общем списке «Загрузки».
- **Работа с текстом:** закладки, выделения, заметки, цитаты и возврат к сохранённому месту чтения.
- **Дополнительно:** настройка тем и интерфейса, встроенная справка, книжный питомец «Чтейцо», награды и мини-игра «Рыбалка».

## Форматы

| Назначение | Форматы |
|---|---|
| Чтение книг | EPUB, FB2, HTML/HTM |
| Комиксы | CBZ, CBR, ZIP, RAR; папки с изображениями и HTML |
| Аудиофайлы для передачи по Wi-Fi | MP3, M4A, M4B, OGG, FLAC |

> **Примечание:** Web Transfer также принимает `.txt`, но прямое открытие TXT через текущий загрузчик книг `BookLoader` не реализовано. PDF-читалка в составе этой версии не заявлена.

## Передача файлов по Wi-Fi

1. На телефоне откройте **Загрузки → Передача по Wi-Fi**.
2. При необходимости выберите папки для книг, комиксов и аудиокниг.
3. Запустите сервер кнопкой в верхней панели.
4. На компьютере в той же сети откройте показанный адрес или QR-код и введите PIN.
5. Выберите файлы в браузере или перетащите их на страницу. Прогресс и результат импорта появятся в **Загрузках → Wi-Fi**.

Сервер запускается только вручную. Передача работает по **локальному HTTP без шифрования** — используйте доверенную сеть Wi-Fi.

## Сборка из исходников

Необходимы **JDK 17**, **Android SDK 35** и **Gradle 8.7**.

```bash
gradle --no-daemon :app:assembleRelease --stacktrace
```

Для подписанного release APK потребуются параметры подписи, настроенные в GitHub Actions. Проект находится в **beta-стадии**; работоспособность конкретной сборки нужно проверять на устройстве.
