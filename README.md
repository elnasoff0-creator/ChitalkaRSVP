# ПРОЧиталка v1.11.53-beta

Полный исходный Android-проект для GitHub Actions. Приложение на телефоне называется **ПРОЧиталка**, `versionName` — `1.11.53-beta`, `versionCode` — `11153`, идентификатор `ru.reader.rsvp`.

## Основные изменения

- Настоящие многослойные `AnimatedVectorDrawable`: 9 персонажей, 54 сценария анимации, 32 animator XML.
- Три стадии птиц: Чтенчик, Чтенец, Чтун; последний всегда летает с большими крыльями-страницами.
- Три закрепляемые ветки: обычное чтение (очки), скорочтение/Курсор (молния и тёмные очки), аудиокниги (наушники).
- Раздельные idle-анимации чтения, аудио и полёта; моргание, дыхание, радость, удивление, эволюция, дневной сон и пробуждение.
- Независимый от включения питомца учёт прочитанных книг, аудиокниг, времени чтения/аудио, посещений и слов.
- Когда Чтейцо выключено, показывается раздел «Статистика» с наградами; игровые сбросы не удаляют общую книжную статистику.
- Награды становятся видимыми только после получения; шесть контурных значков.
- Облачко реплик рисуется одним цельным контуром.

**Полная расшифровка:** `FULL_CHANGELOG_v1.11.53.txt` в корне проекта. Отдельный PNG-предпросмотр девяти векторных образов предоставляется вместе с ZIP.

## Сборка подписанного Release APK

В репозитории оставлен `.github/workflows/release.yml`. Workflow работает с существующими четырьмя Signing Secrets: `RELEASE_KEYSTORE_B64`, `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_PASSWORD`, `RELEASE_KEY_ALIAS`. Пароли и keystore в проект не включены.

Обновите содержимое GitHub Desktop-репозитория файлами этого ZIP, сохранив `.git`, затем выполните Commit to main → Push origin. Скачайте готовый APK из GitHub Actions → Artifacts после успешной компиляции.
