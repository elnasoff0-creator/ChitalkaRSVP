# Читалка RSVP 1.7 — восстановлен рабочий экран чтения

Исправление по сравнению с v1.6:
- `ReaderActivity.java` — отдельный экран чтения на основе работающего кода v2, предоставленного пользователем.
- Главное меню и библиотека остались в `MainActivity.java`, но открытие книг теперь запускает `ReaderActivity`.
- В `AndroidManifest.xml` зарегистрирован новый экран.
- URI книги и позиция передаются через Intent / локальные SharedPreferences; прогресс синхронизируется с библиотекой при сохранении.
- Кнопка возврата возвращает к библиотеке; переключатель режимов: «📖 Обычное чтение» / «⚡ Скорочтение»; закладка «⭐».

Сборка: заменить файлы в GitHub целиком, сохраняя структуру `app/`, затем запустить Actions -> Build Android APK.

Примечание: в данной среде Android SDK отсутствует, поэтому APK не был собран и тестирование на устройстве не выполнено.
