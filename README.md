# Читалка — обновление 1.1

Изменения: иконка книги с молнией; единая кнопка режимов («Скорочтение» / «Обычное чтение»), тёплая карточная тема, более быстрый переход между режимами без пересоздания длинного текста, настройки показа одного/соседних слов, ускоренная работа кнопки паузы, совместимый XML-парсер.

Замените папку `app` в GitHub-репозитории, сохранив вложенность `app/src/main/...`. Файл `BookLoader.java` содержит исправление XML-парсера. После обновления запустите GitHub Actions `Build Android APK`.

Ограничение: обычный режим использует один длинный TextView и на очень больших книгах может требовать дополнительных улучшений; переход оптимизирован, но скорость на конкретном устройстве не проверена. Дизайн приближен к макетам, не является их точной реализацией.
