# ПРОЧиталка v1.11.58-beta — clean two-frame Chteico edition

Исходный Android-проект для подписанной Release-сборки с существующими GitHub Actions Secrets.

## Чтейцо — упрощённая графика

По утверждённым изображениям созданы 18 масштабируемых Android VectorDrawable-кадров: три стадии (Чтенчик, Чтенец и Чтун), три ветки (обычное чтение, скорочтение/Курсор, аудио), два положения крыльев и хохолка (up/down). Это самостоятельные XML-векторы, а не PNG, вставленные в приложение.

- Анимация `AnimatedVectorDrawable` полностью удалена из ресурсов и Java.
- Все 48 старых XML-аниматоров и 54 AVD-ресурса удалены.
- Оставлено попеременное переключение двух векторных кадров с едва заметным пружинящим масштабированием.
- Яйцо и треснувшее яйцо сохранили свои исходные XML-векторы; яйцо слегка сжимается и разжимается.
- При тапе показываются прежние контурные расходящиеся лучи, реплики и сохранённая игровая логика; новые эмоции, сон, пробуждение и отдельные сценки эволюции больше не проигрываются.
- Для Чтуна сохранён утверждённый внешний вид летающей птицы, но сложный 12-фазный полёт заменён на up/down.

Графика получена через векторную трассировку предоставленных изображений, поэтому соответствует референсу по силуэту, но не является исходным редактируемым авторским SVG. Положение крыльев во втором кадре получено небольшим искажением областей крыльев, а не отдельным 3D-скелетом.
