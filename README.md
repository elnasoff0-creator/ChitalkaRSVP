# Читалка RSVP — 1.9.2

Обновление на базе рабочего проекта v1.9.1 с отдельной ReaderActivity и поддержкой GitHub Releases.

## Изменения

- Добавлена **SettingsActivity**, зарегистрированная в `AndroidManifest.xml`. Настройки доступны из главного меню и ReaderActivity, хранятся в прежнем `SharedPreferences("reader")`.
- Темы чтения удалены с главного экрана и перенесены в SettingsActivity.
- Настройки «Открыть книгу» и «Закладки» больше не показываются в настройках.
- В SettingsActivity есть живой предпросмотр шрифта, размера и цвета текста, RGB-регулировка и палитра фона/текста, настройка отображения соседних слов, дополнительные паузы, проверка обновлений.
- Скорость меняется кнопками `−10` / `+10` в диапазоне **100–1000 слов/мин**. Рядом — минималистичный значок спидометра.
- В обычном режиме больше не отображаются кнопка воспроизведения и блок скорости. В скоростном режиме панель остаётся.
- Из скоростного режима удалена отдельная кнопка «Показ слов» (настройка только в SettingsActivity).
- Добавлен набор векторных Android-иконок `app/src/main/res/drawable/ic_*.xml` для навигации, управления, библиотеки, закладок, настроек и других действий.
- В `release.yml` публикация обновлена: если GitHub Release с тегом уже существует, приложение прикрепляет APK через `gh release upload --clobber`, иначе создаёт релиз.

## Сборка

Обновите файлы в ветке `main` своего репозитория GitHub. Сначала соберите Debug APK или ручную подписанную release-сборку через Actions, проверьте её на устройстве, и только затем создайте тег `v1.9.2`.

**Примечание:** Android SDK здесь недоступен, поэтому APK не был локально скомпилирован и не тестировался на телефоне. Полная проверка требует GitHub Actions.

Не меняйте ключ подписи для обновления поверх v1.9.1.


## 1.9.2.4
- Кнопка Play/Pause в ReaderActivity теперь имеет фиксированную ширину 88dp и располагается по центру.
- ic_settings.xml заменена на контурную шестерёнку с прозрачной заливкой, единый стиль в главном меню, настройках и читалке.
- versionCode: 10906, versionName: 1.9.2.4.


## 1.9.2.5: исправлена проверка обновлений

UpdateManager теперь сравнивает GitHub tag (`v1.9.2.5`) с установленным `versionName` (`1.9.2.4`) по числовым компонентам. В прежних сборках сравнение велось с Android `versionCode`, что ошибочно показывало «Обновлений нет». Android `versionCode` увеличен до 10907.

**Важно:** у уже установленной версии со старым UpdateManager ошибка остаётся. Первую исправленную версию требуется установить вручную из GitHub Releases, подписав тем же ключом; далее обновления определяются правильно.
