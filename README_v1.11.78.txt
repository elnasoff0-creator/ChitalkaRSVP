ПРОЧиталка v1.11.78-beta CLEAN — полный исходный проект Android.

Вариант для тестирования: исправление TTS-таймлайна и менеджера UI-блоков.

Проверка сборки после загрузки репозитория в GitHub Actions:
    gradle --no-daemon :app:assembleRelease --stacktrace

Этот ZIP НЕ содержит проверенного APK. В доступной среде Android SDK и Gradle отсутствуют, поэтому результаты javac-парсинга и unit-тестов не доказывают успешную Android-сборку.

Рекомендуемые сценарии тестирования на телефоне:
1. Перейти с начала книги на главу 61: левый счётчик TTS должен немедленно показать оценочное время позиции от начала всей книги, не время прослушивания сессии.
2. Повторить переход при запущенном Edge TTS и замедленной сети: прошлое предложение не должно временно возвращать старое значение.
3. Повторить с системным TTS Samsung/Google.
4. Выбрать дальний блок через менеджер: должны быть крупные UI-блоки (примерно по 560 слов), а не десятки маленьких аудиопредложений; границы символов вычислены из BookChunkIndex.
5. Изменить WPM: примерное время позиции и общий расчёт должны пересчитаться, текущая позиция и локальные MP3 не исчезают.
6. Вручную прокрутить текст без выбора: значение позиции остаётся связанным с текущим воспроизведением, а не просто с областью экрана.
7. Проверить WordBoundary и подсветку при повторном воспроизведении скачанного MP3.
