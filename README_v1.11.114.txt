ПРОЧиталка v1.11.114-beta CLEAN — исходный Android-проект
=======================================================

Основа: v1.11.113-beta CLEAN ColorFill Icons FIX.
Версия: versionName 1.11.114-beta, versionCode 11400.

В этой версии:
- В мини-Чтейце возвращён смайл сна ( ◡‿◡ ) Zzz... с циклом точек.
- Спящий мини-питомец всегда получает локальный ночной фон и белые контуры,
  не переключая общую тему книги, экран настроек или полный UI питомца.
- Обычные эмоции мини-питомца увеличены с 23 до 30 sp; сонная строка
  20 sp целиком, чтобы умещались лицо и Zzz. Полный UI сохраняет 27 sp.
- В полном UI Чтейца добавлен виброотклик тапа и свайпа.
  В мини-версии вибрация по-прежнему только при начале долгого Drag and Drop.
- Размеры облаков по содержимому, 5 dp бокового отступа для коротких эмоций.
- Edge TTS: при активном чтении фоновый синтез использует только уже
  свободный WebSocket. Новое соединение допускается для приоритетного Play.
- Журнал: callback Media3 теперь обозначен как callback, не как звуковая пауза.
- Цветные VectorDrawable XML без фона сохранены без изменений.

Проверка:
  bash qa/check_java_syntax.sh
  python3 qa/test_v11114_completion.py
  bash qa/test_edge_priority.sh
  bash qa/test_edge_reuse_pool.sh
  bash qa/test_edge_timing_and_diagnostics.sh
  Полный список см. QA_RESULTS_v1.11.114.txt.

Сборка на Android SDK 35 + JDK 17:
  gradle --no-daemon :app:assembleDebug --stacktrace

Важно: полноценно собрать APK и испытать на телефоне в данной среде
не удалось. Тесты Java — синтаксические и JVM/мок-сценарии.
Синхронизация аудиосэмплов на выходе AudioTrack не измерялась.
