# ПРОЧиталка v1.11.70-beta CLEAN — исправление Java-компиляции

## Исправлено

- `app/src/main/java/ru/reader/rsvp/EdgeOnlineActivity.java`, метод `refresh()`:
  переменная `end` теперь инициализируется начальной позицией `start`.
- Предыдущий код оставлял `end` неприсвоенной, если в локальном TTS
  воспроизведение стояло на паузе, а `SentenceChunks.forWord(...)`
  не находил соответствующий фрагмент. Java-компилятор корректно сообщал
  `variable end might not have been initialized`.
- Если соответствующее предложение не найдено, вызов `mark(start,end,playing)`
  не выполняется из-за существующей проверки `if(end > start)`.
- Номер версии изменён на `1.11.70-beta`, `versionCode 11170`.

## Сохранено без изменений

- Общий алгоритм предложений с пределом 600 символов;
- подсветка предложений и WordBoundary, режим «Курсор»;
- параметры WPM, таймер сна и переключатели аудио;
- постоянные файлы Microsoft Edge TTS, временный кэш Android TTS;
- 18 векторных спрайтов Чтейца и остальные ресурсы.

## Проверки

- Синтаксический разбор всех Java-файлов (не равнозначен Android-компиляции);
- разбор XML-файлов и целостность ZIP;
- проверка чистоты Git patch и его применимости к v1.11.69.

Полная Gradle-сборка не проводилась: Android SDK и Gradle не установлены в текущем окружении.
Необходимо повторно запустить `gradle --no-daemon :app:assembleRelease --stacktrace` в GitHub Actions.
