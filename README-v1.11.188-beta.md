# ПРОЧиталка v1.11.188-beta CLEAN — Full Source

**Основа:** v1.11.187-beta CLEAN. **Версия:** `1.11.188-beta`, `versionCode=18800`.

## Что включено

- Принудительное возвращение с резервного Android TTS на Microsoft Edge TTS: повторный выбор Edge обрабатывается даже тогда, когда Edge уже выбран в настройках, но фактически звучит резервный движок.
- Остановка старой локальной сессии и проверка поздних callback при завершении сервиса; сохранение выбранного предложения и режима Play/Pause.
- Обновление бейджа по фактическому движку после `ACTION_STATE`; встроенная Edge-иконка по-прежнему не требует браузера Microsoft Edge.
- Ускорение первого звука: `DownloadFolderPicker.granted()` вместо синхронной проверки `DocumentFile` при Play; максимум 160 мс ожидания восстановления foreground MP3 из SAF вместо 9 с. Старое фоновое восстановление не блокирует нажатие Play.
- Изоляция локального восстановления SAF от синтезируемого MP3: проверка права на публикацию перед заменой локального MP3 и sidecar; запоздавшие операции не должны перезаписать синтез.
- Приватный журнал диагностики `EDGE_STARTUP` и `TTS_SWITCH` с этапами запуска; можно экспортировать из приложения.
- Сохранены предыдущие функции: целые предложения Edge TTS, WordBoundary, словарь TTS, собственное выделение с контурными иконками, цитатник, питомец (50/50), анимации загрузок, SAF-папки.

## Как собрать

Проект предназначен для Android SDK 35, Java 17 и Gradle 8.7. Откройте корень проекта в Android Studio или запустите workflow `.github/workflows/release.yml` (для подписанного релиза нужны ранее настроенные GitHub Secrets).

Исходный ZIP **не содержит APK**. Синтаксический анализ и unit/regression тесты выполнены локально; полноценную сборку Android и проверку звука на телефоне необходимо провести отдельно.

## Как получить и прислать диагностический лог

1. Установите собранный APK версии 1.11.188-beta.
2. Откройте боковое меню «ПРОЧиталки» и **10 раз быстро нажмите на логотип** приложения вверху, чтобы включить режим разработчика (если он не включён).
3. В боковом меню появится **«Показать лог-файл»**. Откройте его и нажмите **«Очистить»**, чтобы удалить старые события перед тестом.
4. Тест А: откройте книгу, перейдите в режим TTS, выберите Microsoft Edge, нажмите Play, дождитесь **первого звука**, затем Pause. Запишите для себя, холодный это старт или MP3 уже сохранён.
5. Тест Б: если возник резервный Google/RuVoice TTS, откройте выбор движка и **повторно выберите Microsoft Edge**, дождитесь продолжения либо ошибки. Отмечайте, был ли резервный TTS на паузе или в режиме Play.
6. Снова откройте «Показать лог-файл» → **«Поделиться»** и отправьте экспортированный `prochitalka_log_export.txt` в чат.

Не нужно искусственно вызывать десятки HTTP 429: проверка на реальной ошибке либо при уже активном резервном TTS достаточна. При желании проверьте экспортируемый файл перед отправкой: приложение скрывает сетевые и локальные URI, но старые события, добавленные другим кодом, всё же стоит просмотреть.

### Что искать в логе

`EDGE_STARTUP`: `id=… t=… stage=PLAY`, `SAF_PERMISSION`, `BOOK_OPENED`/`BOOK_REUSED`, `GROUP_INDEXED`, `BOOK_READY`, `SAF_RESTORE_CHECK`/`SAF_RESTORE_BYPASS`/`SAF_RESTORE_TIMEOUT`, `CLIP_PREPARED`, `NETWORK_REQUEST`, `WS_CONNECTED`, `FIRST_MP3_PACKET`, `FIRST_AUDIO`. Отсутствие сетевых этапов допустимо при воспроизведении готового MP3.

`LATENCY`: время handshake, первого пакета и запуска Media3. `TTS_SWITCH`: `TTS_FORCE_SELECTION`, `TTS_BACKUP_STOP_REQUESTED`, `TTS_BACKUP_STOPPED`, `TTS_EDGE_ACTIVATED`, `TTS_BADGE_UPDATED`, `FALLBACK_INIT_MS`, `TTS_FALLBACK_AUDIO_STARTED`.

Точка `FIRST_AUDIO` соответствует событию `Media3.onIsPlayingChanged(true)`, а не физическому измерению звука через микрофон. По логу можно локализовать программную задержку, но для акустической задержки понадобится измерение на устройстве.
