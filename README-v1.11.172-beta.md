# ПРОЧиталка v1.11.172-beta CLEAN — исходный проект

Версия: `1.11.172-beta` (`versionCode 17200`). Основа: `v1.11.171-beta CLEAN`.

Полный исходный проект Android (Java, `app/src/main`). В этом выпуске обновлены два функциональных блока:

1. **Edge TTS:** адресное завершение главы и облегчённое сохранение в пользовательскую SAF-папку Book, без обязательного `.pending`/rename и без повторного чтения итогового MP3 после каждой публикации. Прежняя глава остаётся доступной до фиксации нового индекса. Обновлена совместимость с индексами прошлых версий.
2. **Экран загрузок:** архивирование по частичному свайпу **ВПРАВО**; раскрывающиеся кнопки «В архив» и «Отмена» находятся слева под карточкой и после завершения жеста доступны для настоящих нажатий. Удалён `ItemTouchHelper` swipe-to-dismiss.

Вся механика рыбалки версии v1.11.171, интерфейсы чтения/аудиокниг/комиксов и прочие компоненты сохранены.

## Файлы

- `CHANGELOG-v1.11.172-beta.md` — подробная расшифровка изменений и обратная совместимость.
- `TZ-PROChitalka-v1.11.172-beta.md` — текущее накопительное ТЗ, включая ранее утверждённые механики.
- `QA-REPORT-v1.11.172-beta.md` — проверки и ограничения их достоверности.
- `qa/check_v172.sh` — автономные проверки Java-синтаксиса, XML, регрессионных контрактов, рыбалки и чистой логики свайпа.

## Открытие и сборка

Откройте корень проекта в Android Studio; соберите `:app:assembleDebug` либо `:app:assembleRelease` при наличии Android SDK 35, Gradle и зависимостей. APK не включён. Автономные проверки (Linux/macOS) — `sh qa/check_v172.sh`.

**Ограничение:** доступная при подготовке среда не имела Android SDK/Gradle/устройства, поэтому настоящая компиляция APK и проверка SAF/касания кнопок на телефоне в этом релизном пакете не подтверждены. Подробности — в QA-REPORT.
