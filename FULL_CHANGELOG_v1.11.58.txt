ПРОЧиталка v1.11.58-beta — полная расшифровка CLEAN

БАЗОВАЯ ВЕРСИЯ
Взята v1.11.57-beta из загруженного архива проекта. Не использовалась более старая ветка.

1. ГРАФИКА ЧТЕЙЦА
- Использованы последние приложенные референсы для Чтенчика, Чтенца и Чтуна.
- Чтенчик остаётся в нижней половине скорлупы.
- Чтенец — стоящая полностью вылупившаяся птица.
- Чтун — взрослая птица с большими книжными крыльями.
- Для каждого из трёх образов отдельно подготовлены ветки: обычное чтение (очки), аудио (наушники), скорочтение/Курсор (молния и тёмные очки).
- Получены 18 независимых Android VectorDrawable (9 образов × 2 кадра).
- Все новые XML располагаются в res/drawable под именами ic_chteico_{chick,reader,adult}_{classic,audio,speed}_{up,down}.xml.
- Контуры перенесены из растровых референсов в масштабируемые pathData. Подробное совпадение мелких контуров зависит от точности автоматической трассировки.
- Яйцо (с трещиной и без) оставлено из исходного проекта.

2. НОВАЯ ДВУХКАДРОВАЯ АНИМАЦИЯ
- Полностью исключены AnimatedVectorDrawable и Android XML-аниматоры Чтейца.
- Каждые приблизительно 820 мс птица переключает up/down.
- Между кадрами за 740 мс слегка изменяется масштаб по X и Y, создавая мягкое пружинящее движение.
- Второй кадр отличается небольшим изменением положения крыльев и хохолка; голова, глаза и аксессуары не анимируются отдельно.
- Яйцо использует свой существующий XML с мягким сжатием/разжатием.
- Удалены отдельные AVD-состояния idle/joy/surprise/evolve/sleep/wake.
- Для Чтуна удалён сложный 12-фазный полёт; оставлены те же два кадра движения.
- При тапании осталось контурное расходящееся сияние (лучи), без дополнительной анимации эмоций.

3. ОЧИСТКА РЕСУРСОВ
- Удалены 54 res/drawable/avd_chteico_*.xml.
- Удалены 9 устаревших res/drawable/v_chteico_*.xml.
- Удалены 48 res/animator/ch_*.xml; пустой каталог animator удалён.
- Удалены ненужные устаревшие GIF/PNG демонстрации прежних AVD-сцен и старые журналы изменений из исходного проекта.
- Переписан ChteicoPetView.java: остались только два кадра, пружинящее движение, обновление при смене стадии и корректное освобождение обработчиков.
- Из ChteicoActivity.java исключён вызов анимаций пробуждения и эволюции. Реплики сохраняются.

4. ЧТО СОХРАНЕНО
- Четыре стадии эволюции, игровая статистика и очки активности.
- Закрепление ветки после вылупления, имя и подсказки питомца.
- Реплики и облачко, лучи при касании.
- Награды, настройки, скрытый режим разработчика.
- Основное чтение, Скорочтение/Курсор, аудиокниги и Edge TTS.
- Подписанный Release workflow с теми же Signing Secrets и package ID.
