## 2. Прозрачные поля и нормализация изображений

**Проблема предыдущей версии:** хотя файлы PNG имели размер 64×64 пикселя, сам рисунок занимал небольшую часть холста, а его прозрачная область учитывалась при отрисовке и столкновениях. Это делало питомцев и книги визуально меньше и вызывало ложные столкновения рядом с контуром.

**Исправление:** для всех 14 исходных изображений определены действительные альфа-границы (`alpha > 16`). Прозрачные поля обрезаны. Для игровых питомцев три кадра каждой стадии получили одинаковый нормализованный холст, выравнивание по нижней центральной точке и одинаковую высоту рисунка. Для небольшого технического зазора добавлены две прозрачные пиксельные строки/колонки по краям. При выравнивании высоты пиксельный рисунок пересчитан методом nearest-neighbor, без сглаживания.

### Размеры нормализованных ресурсов

| Ресурс | Размер PNG после обработки |
|---|---|
| Чтенчик — все 3 кадра | 30×30 px |
| Чтенец — все 3 кадра | 35×34 px |
| Чтун — все 3 кадра | 45×43 px |
| Книга 1 | 27×34 px |
| Книга 2 | 46×25 px |
| Книга 3 | 42×37 px |
| Книга 4 | 58×27 px |
| Книга 5 | 51×29 px |

Исходные размеры до нормализации: 64×64 px. Полная таблица исходных альфа-границ находится в `qa/game_assets_bounds_v11124.json`.

## 3. Исправлена отрисовка игровых объектов

Файл: `ChteicoRunnerActivity.java`.

- Персонаж больше не рисуется в произвольном квадратном прямоугольнике: ширина вычисляется по реальному отношению размеров нормализованного PNG.
- У всех трёх кадров одной стадии общий размер холста и нижняя центральная опорная точка — это исключает скачки позиции при переключении фаз бега и прыжка.
- У книг ширина вычисляется из высоты и собственного соотношения сторон конкретного изображения. Книги больше не растягиваются и не сплющиваются до произвольных размеров.
- Визуальная нижняя граница каждого объекта совмещена с линией земли через общий baseline, а в прыжке перемещается вместе с питомцем.
- Фильтрация Bitmap выключена, чтобы сохранять пиксельные грани изображения.

### Физические размеры игры

Сохраняются запланированные размеры отображения игровой стадии: 72 dp (Чтенчик), 88 dp (Чтенец), 108 dp (Чтун). Для препятствий назначены ориентиры высоты по типу: 80, 34, 69, 38 и 43 dp. Это размеры отрисовываемого холста, включая небольшой технический прозрачный край; фактический контур на несколько пикселей меньше.

## 4. Исправлена логика коллизий

Добавлен файл `RunnerHitboxes.java`; обновлён `ChteicoRunnerActivity.java`.

### Границы на основе реальной графики

При загрузке кадра движок сканирует непрозрачные пиксели Bitmap (`alpha > 16`) и запоминает их реальные границы. Из этих границ рассчитываются мировые координаты видимого рисунка. Полные размеры исходного квадратного PNG больше не являются основой для столкновений.

### Отдельные хитбоксы

**Питомец:** используется внутренняя область видимого рисунка, охватывающая центральное тело и лапы. Сильно выступающие крылья, хвост и прозрачные участки исключаются. Рабочие относительные границы: 22%–78% ширины и 12%–92% высоты видимого рисунка.

**Книги:** прямоугольник столкновения строится по непрозрачной области, с небольшим отступом внутрь: 7% ширины с каждой стороны, 6% сверху и 3,5% снизу. Это предотвращает несправедливые столкновения при лёгком касании контура.

Столкновение определяется пересечением этих независимых прямоугольников. Пустое пространство PNG не считается физическим препятствием. Сохраняются размеры различных эволюций, максимальная высота прыжка 90 dp и гравитация 1365 dp/с².
