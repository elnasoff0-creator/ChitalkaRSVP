# Перенос книг из памяти приложения — v1.11.158-beta

## Как перенести одну книгу

1. Откройте **Библиотеку**, **Аудиотеку** или **Комиксотеку**.
2. Откройте меню `⋮` у нужной книги и выберите **«Перенести в папку»**.
3. Выберите папку накопителя или SD-карты в стандартном окне Android.
4. Подтвердите разрешение на чтение и запись. Дождитесь результата проверки файлов.
5. Проверьте книгу, обложку и прогресс в Библиотеке.

Те же действия доступны в меню `⋮` конкретной записи **Загрузок** и **Архива загрузок**.

## Как перенести много книг

Откройте **Загрузки** → нажмите фильтр над списком → **«Перенести всё из внутреннего хранилища»** → выберите папку. Программа обработает завершённые, неактивные задания и свои локальные книги. Уже перенесённые RanobeLIB/MangaLib пропускаются; пользовательские исходные документы не удаляются.

## Что переносится

| Источник | Что происходит |
| --- | --- |
| RanobeLIB | Перенос всех сохранённых глав, HTML, иллюстраций, обложки и метаданных; докачивание в новую папку |
| MangaLib | Перенос CBZ с обновлением индекса; новые главы пишутся в выбранную папку |
| Обычные текстовые книги | Копирование файла и известных папок ресурсов; библиотечный адрес обновляется |
| «Книга в ухе» | Перенос завершённых MP3 и обновление путей в Аудиотеке |
| Аудиокниги из Библиотеки | Копирование треков, обновление аудио-URI; оригиналы удаляются только из папок приложения |
| Загрузки по ссылке | Проверенная копия завершённых файлов, обновление URI; пользовательские SAF-оригиналы сохраняются |
| Edge TTS | Экспорт/копирование, но рабочие MP3, WordBoundary и служебный кэш остаются в исходном расположении |

## Безопасность и ограничения

- Нельзя переносить активную загрузку: остановите или приостановите её. Для «Книга в ухе» и загрузок по ссылке дождитесь окончания всей загрузки.
- Совпадающий файл проверяется по SHA-256. Если в целевой папке существует файл с тем же именем, но другим содержимым, перенос останавливается, а оригинал сохраняется.
- При отзыве разрешения на выбранную папку книга станет временно недоступна до повторного предоставления доступа.
- Приложение не удаляет импортированные файлы пользователя из его собственных папок; это сознательная защита от потери данных.
- Временный кэш открытия архивов комиксов и рабочие файлы Edge TTS могут оставаться во внутренней памяти.
- Рекомендуется проверить перенесённую книгу перед ручной очисткой каких-либо исходных папок.

## Сборка из исходников

Java 17, Android SDK (платформа для `targetSdk 35`) и Android Gradle Plugin из `app/build.gradle`. Выполните `gradle --no-daemon :app:assembleRelease --stacktrace` в подготовленной среде. Этот архив содержит исходный проект, не APK.

Локальная проверка: `sh qa/check_java_syntax.sh`, `python qa/test_v11158_transfer.py`. Полноценная компиляция Android и запуск не были выполнены в данной среде.
