## 1. Ranobes.net — исправление поиска и HTTP 307

**Файл:** `RanobesApi.java`

- Вместо GET с параметрами `do`, `subaction`, `story`, `page` используется реальная форма сайта: POST к `https://ranobes.net/index.php`, `catlist[]=1`, `story=...`, `do=search`, `subaction=search`.
- Добавлена ограниченная обработка ответов 301/302/303/307/308. Для 307/308 сохраняется метод POST и тело формы; для 303 выполняется GET. Перенаправления ограничены HTTPS-адресами `ranobes.net`, с защитой от циклов и бесконечных переходов.
- В рамках сессии HTTP-клиента сохраняются обычные cookies сайта. Никакие CAPTCHA/защиты/авторизации не обходятся.
- На 401, 403, 429 и 503 показывается понятное сообщение; HTML ошибки не принимается за главу.
- Возможность открыть книгу по прямой ссылке сохранена независимо от поиска.
- Обработка названия и автора произведения уточнена по реальной разметке карточки.

**Важно:** HTTP 307 из пользовательского скриншота подтверждён, но его фактический заголовок `Location` не предоставлен. Поэтому работоспособность поиска на живом сайте требует контрольного прогона — не следует трактовать изменение как гарантированное снятие ограничений сайта.

## 2. Ranobes.net — «Больше глав» и полное оглавление

**Файлы:** `RanobesApi.java`, `RanobesBookActivity.java`.

- Для карточки из предоставленного HTML `All The Skills` на странице произведения есть последние 25 глав и ссылка `More chapters` на `/chapters/1205570/`.
- Добавлено обращение к `/chapters/{bookId}/`, `/chapters/{bookId}/page/2/` и последующим страницам.
- `window.__DATA__` используется как структурированное оглавление: `book_id`, `chapters`, `pages_count`, `count_all`; резервно анализируются HTML-ссылки `.cat_block.cat_line a`.
- Для предоставленного образца HTML указано **340 глав, 14 страниц, по 25 на странице** (последняя неполная). Эти цифры не жёстко заданы: они читаются со страницы.
- Сбор полного оглавления идёт последовательно с отображением номера полученной страницы. Если отдельная страница недоступна, собранные ранее записи остаются и список помечается как неполный.
- Дубли глав исключаются по стабильному ID, порядок приведён к чтению от старых глав к новым.
- В карточку книги добавлено раскрытие **«Больше глав · полное оглавление»** с переключателями страниц и выбором номера страницы. Можно выбрать главы текущей страницы либо скачать отдельную главу. Группировка по томам, выбор глав тома и всей доступной книги сохранены.

## 3. Выбор поискового источника — верхнее окно

**Файл:** `DownloadSourcePicker.java`.

- Для существующей кнопки поиска ранобэ открывается верхнее окно с двумя закруглёнными карточками **RanobeLIB** и **Ranobes.net**.
- Для манги аналогичный диалог показывает MangaLib, для аудиокниг — «Книга в ухе»; структура предусматривает добавление новых поставщиков без новых кнопок.
- Окно располагается под панелью управления, использует выбранные цвета темы, имеет раздельные зоны нажатия с подписями.
- Внутренние API загрузчиков и общие пути категорий не изменены.

## 4. Закладки — предложение вместо отдельного слова

**Файлы:** `ReaderBookmarkSentences.java` (новый), `ReaderBookmarks.java`, `ReaderActivity.java`.

- Когда пользователь выделяет одно слово и выбирает «Закладка», сохраняется **полное предложение**, к которому относится слово (используется существующий `SentenceIndex`).
- Когда пользователь расширил выделение ручками на несколько слов или предложений, сохраняется именно выбранный диапазон, без автоматической обрезки.
- Сохраняются начало и конец диапазона слов, полная цитата и глава. Цитата хранится без искусственного ограничения 500 символов, а список визуально остаётся компактным.
- Старые закладки со словесным индексом не удаляются. Их пропущенная цитата восстанавливается из уже загруженной книги при открытии менеджера, без обращения к HTML.
- В менеджере «Все закладки» основной блок остаётся текстом; название главы и номер слова — внизу.

## 5. Маркеры заметок и закладок слева от текста

**Файлы:** `ReaderNoteIndicatorSpan.java`, `ic_reader_bookmark_side.xml` (новый), `ReaderActivity.java`.

- Значок заметки **оставлен прежнего размера — 18 dp**. Вместо правого края текста он рисуется в фиксированном левом поле.
- Цвет заливки заметки — `UiColorScheme.accent()` от текущей темы.
- Новый маркер закладки — горизонтальный заполненный флажок с заострённым язычком вправо, к тексту, также в акцентном цвете.
- Если заметок на строке несколько, маркер остаётся единым со счётчиком и контекстным горизонтальным выбором.
- Нажатие на левую область открывает заметку или карточку закладки, а при совпадении обоих типов предлагает выбрать действие.
- Постоянные отступы TextView изменены с 14/35 dp на 24/25 dp. Общая сумма боковых отступов сохранена (49 dp), поэтому переносы строк при наличии/отсутствии маркеров не должны меняться. Текст постоянно смещён относительно прежнего релиза на 10 dp вправо; это одноразовая настройка страницы, не прыжок при создании отметки.
- Для обеих иконок сохранена векторная отрисовка без размывания.

## 6. Выделение текста — скроллинг и ручки

**Файлы:** `ReaderSelectionController.java`, `ReaderActivity.java`.

- Маркеры обновляются при `RecyclerView.onScrolled`; если край выделения вне экрана, соответствующий маркер временно скрывается, но индексы слов остаются.
- При перетаскивании к верхнему или нижнему краю текст автоматически прокручивается в направлении движения. Перемещение ограничено текущим RecyclerView и прекращается при отпускании пальца.
- При пересечении начальной и конечной границ меняются роли ручек; диапазон остаётся корректным.
- Добавлено сохранение ID активного указателя, корректное завершение на `ACTION_CANCEL` или отпускание активного пальца.
- Системному родителю запрещено перехватывать жест, пока пользователь удерживает ручку; меню выделения скрывается на время движения и возвращается на новую видимую позицию после остановки.
- Не менялись TTS-индексы слов и воспроизведение; действие «Копировать» продолжает работать с общим индексом книги.

## 8. Проверка и известные ограничения

В проект добавлены `qa/test_v164.py` и `qa/TestBookmarkSentences164.java` для проверки ключевых контрактов. Для чистого JVM-теста не нужен Android SDK.

**Без Android SDK нельзя проверить полноценную Gradle-сборку или поведение экранов на устройстве.** Особое внимание уделить POST-поиску Ranobes.net, обработке 307, корректности распознавания динамического HTML, позициям маркеров при больших шрифтах и автопрокрутке ручек выделения. Поскольку Ranobes.net может ограничивать внешние запросы, загрузка глав не гарантируется при HTTP 403/429/503.
