# ПРОЧиталка 1.11.168-beta CLEAN — полный Android Java проект

Исходная база: `v1.11.167-beta CLEAN + ThemeFix`. Версия проекта в `app/build.gradle`: `16800` / `1.11.168-beta`.

## Что изменилось

Обновление разгружает экраны «Загрузки» и «Менеджер»: вместо периодического пересканирования задания отправляют адресные уведомления, а списки и оглавления отображаются из кэша. Меню «⋮» не ждёт проверки всех загрузок. Кнопки и всплывающие панели используют цветовую палитру настроек. Путь к файлам во вкладке «Инфо» показывается до двух строк с приоритетом последней папки.

Подробный перечень файлов и изменений — в `CHANGELOG-v1.11.168-beta.md`. План проверок — в `QA-REPORT-v1.11.168-beta.md`.

## Проект

- Java 17, Gradle Android application plugin, compileSdk 35, targetSdk 35, minSdk 24.
- Запуск теста синтаксиса: `sh qa/check_java_syntax.sh`.
- Контрактные тесты: `python qa/test_v168_contracts.py`.
- Проверка шины событий на JVM: `sh qa/test_change_bus.sh`.

## Статус

**Исходники подготовлены, APK в комплекте отсутствует.** Эта среда не содержит Android SDK и Gradle, поэтому полную Android-сборку и runtime/UI-проверку провести невозможно. Не считать этот архив готовым релизом для автоматического обновления устройств до подтверждения сборки в Android Studio и проверки на телефоне.

Некоторые старые QA-скрипты, привязанные к номерам версий 1.11.166 или 1.11.167, закономерно не проходят проверки точного номера релиза. Их следует использовать как исторические контракты, а для 168-й версии — новый тест `test_v168_contracts.py`.
