ПРОЧиталка v1.11.81-beta CLEAN
Дата: 26.10.2026
База: v1.11.80-beta

1. ЕДИНЫЙ ЭКРАН ТЕКСТОВОЙ КНИГИ
- Обычное чтение, «Курсор», «Скорочтение» и «Озвучка» переключаются внутри одного ReaderActivity.
- Переключение через иконку в верхнем Toolbar, без перехода в EdgeOnlineActivity и без повторного создания RecyclerView/BookChunkIndex.
- «Назад», закладка и настройки остаются в Toolbar для всех режимов. В режиме «Озвучка» дополнительно доступны движок, голос, таймер и WPM.
- Нижняя панель: «Оглавление» + позиция/прогресс, Play/Pause только у «Курсора», «Скорочтения» и «Озвучки». В обычном чтении Play/Pause отсутствует, селектор режима снизу убран.
- Оглавление и переходы по структурным главам либо крупным подготовленным текстовым блокам одинаковы для всех четырёх режимов.

2. ОДНА ЗАГРУЗКА И ОДНИ ИНДЕКСЫ
- Новый UnifiedBookSession хранит один снимок открытой книги: текст, главы EPUB/FB2, позиции слов, виртуализированные UI-блоки (цель ~560 слов) и аудиофрагменты SentenceChunks (<=600 символов).
- EdgeStreamingService и AudioPlaybackService получают общий сеанс вместо повторного разбора исходной книги при переключении режима.
- ReaderBookCache обновлён до RBI3: текст, позиции слов и структурное оглавление сохраняются на диск. После перезапуска приложение использует готовый индекс; старый RBI2 автоматически перестраивается при первом открытии.
- Отображение текста по-прежнему виртуализировано через RecyclerView и не создаёт огромный TextView на всю книгу.

3. СКОРОЧТЕНИЕ
- Панель основного слова и линий появляется только во время Play, при остановке возвращается обычный текст.
- По умолчанию начало чтения выбирается касанием слова, как в «Курсоре».
- Новая настройка «Выбирать слово прокруткой вместо касания» (по умолчанию отключена). Свайп по слову/странице во время активного скорочтения не заменяет обычное воспроизведение.

4. ОЗВУЧКА В ОБЩЕМ ЭКРАНЕ
- TTS теперь использует тот же индекс позиции и оглавления без открытия второго экрана.
- Подключение Android TTS и MS Edge TTS через существующие сервисы из ReaderActivity.
- Для онлайн Edge сохранён Streaming-first PCM/AudioTrack, один следующий фрагмент и независимый офлайн-кэш из v1.11.80; протокол Edge здесь не переписывался.
- Подсветка текущего предложения и слова по WordBoundary; для сохранённых MP3 метки кэшируются в памяти на время воспроизведения.
- Ранняя команда Play локального TTS не теряется до окончания подготовки текста. Позиция из Intent используется при открытии TTS из внешней кнопки/уведомления.
- Ошибки Edge TTS снова видимы пользователю (Toast), а не скрываются молча.

5. СОХРАННОСТЬ
- Интерфейс аудиокниг MP3/M4A не перерабатывался.
- Векторные спрайты «Чтейца» и остальное оформление сохранены.
- Версия: versionName 1.11.81-beta; versionCode 11181.

ПРОВЕРКИ
- Java: синтаксический разбор 81 файла.
- SentenceChunks: предел 600 символов и корректные глобальные границы.
- Индекс UI-текста и оценка времени позиции: модульные тесты.
- Книги с главами: модульный тест границ.
- UnifiedBookSession: JVM-тест однократного парсинга и восстановления RBI3 из файла после имитации перезапуска.
- XML и ZIP: контроль синтаксиса/структуры.
- Android :app:assembleRelease и живой тест Edge TTS на устройстве НЕ выполнялись — нужна проверка GitHub Actions/телефона.
