# ПРОЧиталка v1.11.160-beta — инструкция

## Быстрое чтение HTML

Откройте **Библиотека → книга → Читать**. При возвращении из Библиотеки, настроек и других экранов книга повторно не проверяет все HTML-главы, не пересчитывает контрольные суммы содержимого и не переносит закладки.

**Импорт папки** по-прежнему доступен: **Главная → + → Книгу → Импортировать папку с HTML**. Программа один раз создаёт собранную книгу с обложкой и оглавлением. Если выбрать ту же папку ещё раз, будет открыта ранее импортированная копия; изменения исходных глав не сканируются и не вносятся автоматически. Для другого перевода удобнее импортировать отдельную папку.

Книга, которая уже находится в Библиотеке, и её пользовательское название не удаляются при обновлении приложения. Ранее сохранённый прогресс не пересчитывается.

## Edge TTS

При обычной озвучке блоки стараются не превышать примерно 800 символов, но заканчиваются на **конце законченного предложения**. При ручном выборе слова озвучка начинается с выбранного слова и продолжается до конца группы без 500-символьного разрезания. Из-за изменения границ ранее созданные MP3-файлы могут не совпадать с новыми ключами кэша; такие фрагменты будут синтезироваться заново.

Если единственное предложение содержит более 4096 байт UTF-8, Edge может вернуть ошибку превышения лимита — программа не обрезает его посередине, чтобы не создавать паузы.

## Загрузки

Слева верхнего toolbar остаётся кнопка бокового меню. Остальные иконки находятся справа в прокручиваемом ряду. Кнопка **«Архив загрузок»** теперь справа от заголовка **«Загрузки»**, под toolbar.

## Запуск проекта

Откройте этот Android Gradle-проект в Android Studio с Android SDK. Версия приложения — `1.11.160-beta`. Для сборки из консоли при наличии Android SDK и Gradle используйте `gradle :app:assembleRelease`. Полная Gradle-сборка в этой среде не проверена.
