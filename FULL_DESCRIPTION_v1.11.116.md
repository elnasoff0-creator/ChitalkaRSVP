# ПРОЧиталка v1.11.116-beta CLEAN — полная расшифровка

Основа: `v1.11.115-beta CLEAN`. Версия приложения: `versionName 1.11.116-beta`, `versionCode 11600`.

## Изменения 17–34

17. **Мини-питомец на весь контейнер.** `ChteicoPetView` занимает квадратную область `182×182 dp`, эмоция и её лучи поверх питомца, без принудительного смещения изображения вниз. Размер иллюстрации задаётся независимо от облака эмоций.
18. **Эволюционный масштаб.** Яйцо 70%, Чтенчик 80%, Чтенец 90%, Чтун 100%. Динамические внутренние поля относительно контейнера, одинаковый центр.
19. **Пробуждение тапом.** Нажатие на спящего мини-питомца устанавливает состояние бодрствования и передаёт `wake_pet` в `ChteicoActivity`. Полный UI показывает эмоцию пробуждения, расходящиеся линии и виброотклик.
20. **Полный текст Edge-overlay.** Убран `ellipsize`, добавлен ограничитель высоты 188 dp и прокрутка содержимого к нижним строкам. Слова после длинных предложений не обрываются искусственным многоточием.
21. **Положение Edge-overlay.** Отступ от верхней кромки 44 dp вместо 79 dp: надпись книги может быть перекрыта, кнопки верхнего toolbar не перекрываются.
22. **Оглавление.** Если обнаружено менее трёх осмысленных глав (0–2), ReaderActivity считает его недоступным, навигация использует ранее существующий индекс текстовых блоков. При 3+ главах сохраняется оглавление.
23. **Награды.** Отображаются только полученные награды (или dev-preview) компактными квадратными карточками со значком и подписью, максимум три в одной строке. Следующие строки добавляются динамически.
24. **Ударения.** В `EdgeDictionaryActivity` пользователь выбирает конкретную гласную; при выборе к букве добавляется знак Unicode U+0301. Исходное слово и произносимый вариант хранятся отдельно.
25. **Кнопка прослушивания.** Синтезирует отдельное слово выбранным Edge-голосом и скоростью. Создаёт временный MP3 в cache, воспроизводит `MediaPlayer`, удаляет временный файл при завершении/закрытии. Предпрослушивание работает отдельным запросом `PREFETCH` и не меняет состояние основной книги.
26. **Контекстные правила.** В словаре возможно несколько записей одного слова с дополнительным контекстом: `слово|фраза-контекста=произношение`. Контекст сопоставляется в окне до 90 символов вокруг вхождения. Более специфичные правила выполняются раньше общих. Если точного контекста нет, правило не срабатывает.
27. **WordBoundary.** Сохранена исходная UTF-16 карта соответствий `from/to` в `EdgeSpeechTextTransform.Result`: подсветка оригинального текста не должна зависеть от длины варианта произношения. Дополнены проверки на регрессии.
28. **Самостоятельный словарь.** Новый `EdgeDictionaryActivity`, прописан в Manifest, доступен из SettingsActivity и ReaderActivity; компактный список строк с поиском, редактированием, удалением и озвучиванием.
29. **Выбор слова при Edge TTS.** Тап выбирает конкретное слово, выделение хранится отдельно в `dictionarySelectedWord`, а позиция воспроизведения по-прежнему ставится на начало содержащего его предложения.
30. **Быстрое добавление.** `ReaderActivity` → `⋮` → «Словарь MS Edge»: Intent передаёт выбранное слово; новый экран открывает его в редакторе (либо открывает существующую запись). Без выбора слова — обычный список.
31. **Поиск по книге.** `ReaderActivity` → `⋮` → «Поиск по книге»: текстовый поиск по всему нормализованному тексту, общее число совпадений, до 100 видимых фрагментов, переход с подсветкой. Переход по результату не запускает TTS.
32. **Универсальное боковое меню.** `UniversalDrawer` — собственный левый диалоговый overlay приложения без разрешения `SYSTEM_ALERT_WINDOW`. Подключено к верхним кнопкам Reader, AudioPlayer, Settings, Chteico, Downloads, Dictionary, Voice, Help и вспомогательным экранам. Переходы используют Intent, навигация не требует запуска нового системного overlay.
33. **«Главный экран» вместо «Библиотека» в меню.** Кнопка с векторной контурной иконкой дома; отдельные «Библиотека» и «Аудиотека» в боковом меню отсутствуют.
34. **Главный экран MainActivity.** Сохранены существующие блоки «Продолжить книгу», «Библиотека», «Продолжить аудиокнигу», «Аудиотека» (если соответствующий контент доступен). Два раскрывающихся списка снабжены иконками: библиотека — существующая `ic_audio_chapters`, аудиотека — новая `ic_audiotheque` (книга внутри наушников), контурный VectorDrawable; пустая аудиотека также отображается.

## Ограничения и незавершённая проверка

- **APK и Android Gradle-сборка не выполнены:** в доступной среде отсутствуют Android SDK и Gradle. Тесты анализируют Java-синтаксис и программные контракты; они не доказывают безошибочную компиляцию Android-приложения и правильную отрисовку на телефоне.
- **Распознавание омографов не семантическое.** Контекст задаётся вручную и ищется как текстовая подстрока; автоматического языкового анализа/определения значения слова нет.
- **Знак ударения U+0301 Edge TTS может игнорировать.** Поэтому добавлено прослушивание; гарантии произношения для каждого голоса нет.
- **Предпрослушивание** выполняется самостоятельным Edge-запросом с очередью PREFETCH. При активном озвучивании книги запрос может быть отложен до освобождения сетевого ресурса; одновременная работа ещё требует тестирования на устройстве.
- **Длинные предложения overlay:** текст сохраняется полностью и внутренне прокручивается; проверить визуальное поведение и доступность на разных размерах экранов.
- **Поиск по книге:** синхронная фильтрация текстовой строки и первые 100 показанных совпадений; на очень больших книгах проверить скорость и отзывчивость UI.
- **Sidebar:** навигация реализована как activity-owned dialog поверх каждого экрана, а не как одна сохраняемая глобальная View. На Android необходимо проверить отсутствие потери состояния при переходах между Activity и повторных открытиях Reader.
