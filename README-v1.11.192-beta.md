# ПРОЧиталка v1.11.192-beta CLEAN — полный исходный код

База: **v1.11.191-beta CLEAN QA Hotfix**. Android Java; namespace `ru.reader.rsvp`; `versionCode 19200`, `versionName 1.11.192-beta`. Исходный код, ресурсы, HTML/JS Web Transfer, QA и настройки CI включены. APK в архиве нет.

## Главное

1. **Web Transfer** — управляемый пользователем локальный HTTP-сервер для передачи файлов в ПРОЧиталку через браузер другого устройства в той же сети Wi-Fi. Автоматический запуск запрещён. Доступ из «Загрузки» → новая кнопка **«Передача по Wi-Fi»** на месте старого экрана «Подготовить аудиокнигу». Добавлена новая контурная векторная иконка `res/drawable/ic_wifi_transfer.xml`.
2. **Старый отдельный экран подготовки аудиокниги удалён**, но сервис `EdgeFullBookService` и очередь для менеджера загрузок сохранены: их используют другие экраны TTS/аудиозагрузки.
3. **Активные вкладки** показываются верхней и боковыми гранями цветного контура со скруглёнными верхними углами; нижнее подчёркивание удалено в общем `BrowserTabs`.
4. **Подсветка текущего слова TTS** отдельно от фоновой подсветки предложения: выключатель, цвет, непрозрачность 5–100% и образец в «Настройки» → «Чтение». Значения по умолчанию сохраняют прежнюю жёлтую подсветку.
5. **Настройки Web Transfer** находятся исключительно в «Настройки» → «Онлайн»: порт (авто или 1024–65535), остановка при простое (5/15/30 минут или вручную), дубликаты (спросить/пропускать/новое имя), уведомление о завершении. Ограничение двух одновременных загрузок и PIN обязательны.

## Как пользоваться Web Transfer

1. На телефоне настройте разрешённые для записи SAF-папки **Книги**, **Комиксы** и/или **Аудиокниги** в «Настройки» → «Общие» → «Папки загрузок».
2. Подключите телефон и устройство с браузером к **одной сети Wi-Fi**; локальный сервер не открывается через мобильную сеть и не использует облако.
3. В «Загрузках» нажмите «Передача по Wi-Fi» → «Запустить сервер».
4. Откройте показанный HTTP-адрес в браузере (либо отсканируйте QR-код); введите 6-значный PIN с экрана телефона. PIN генерируется заново при каждом запуске сервера.
5. Выберите файлы или перетащите их на страницу. Смотрите прогресс и отменяйте операции в браузере. Допустимы два параллельных файла, максимум **1 ГиБ на файл**.
6. Файлы сохраняются через Android SAF в соответствующую папку и регистрируются в библиотеке. Дубликаты никогда не перезаписываются без явного нового имени. Готовые файлы сохраняются при остановке, незавершённые временные файлы удаляются. Остановите сервер кнопкой или через системное уведомление.

## Поддерживаемые расширения Web Transfer

- Текст: `.epub`, `.fb2`, `.txt`, `.html`, `.htm` → SAF «Книги» / `ImportedBooks`.
- Манга: `.cbz`, `.cbr` → SAF «Комиксы» / `WebTransfer` и запись в библиотеку комиксов.
- Аудио: `.mp3`, `.m4a`, `.m4b`, `.ogg`, `.flac` → SAF «Аудиокниги» / `WebTransfer` и запись в аудиобиблиотеку.

Другие форматы отвергаются вместо неподтверждённой поддержки. Нельзя читать, просматривать, скачивать или удалять файлы библиотеки через веб-интерфейс. На текущем этапе Web Transfer **только импортирует файлы на Android-устройство**.

## Архитектура

- `WebTransferActivity`: экран с адресом, PIN, QR-кодом, статусом, кнопкой запуска/остановки, активными передачами.
- `WebTransferService`: foreground-service (`dataSync`), уведомление, защита от автоперезапуска, остановка по простоям/потере сети.
- `WebTransferServer`: IPv4 Wi-Fi binding, сервер на `ServerSocket`, одноразовая секретная cookie-сессия после PIN, одноисточниковые POST, ограниченные HTTP-заголовки, файловые запросы без доступа к ФС.
- `WebTransferPolicy`: валидация расширения, имён и размеров и проверка Origin/Host (можно тестировать обычным `javac`).
- `WebTransferUploadManager`: потоковая загрузка во временный файл → проверка → SAF → индексация библиотеки.
- `WebTransferPrefs`: сохранённые настройки вкладки «Онлайн».
- `assets/webtransfer/index.html`: адаптивный интерфейс браузера (HTML/CSS/JS).
- `BrowserTabs`, `ReaderWordHighlightSpan`, `SettingsActivity`, `ReaderActivity`: изменение выбора вкладок и TTS-подсветки.

## Безопасность

Сервер слушает *только активный IPv4 Wi-Fi-интерфейс*, не `0.0.0.0`; доступ к загрузке требует PIN, затем cookie `HttpOnly; SameSite=Strict`. Нет CORS и маршрутов скачивания/списка библиотеки. Проверяются Host и Origin, запрет `Transfer-Encoding`, максимальный `Content-Length`, размер HTTP-заголовков и допустимые имена. Все записи идут в ранее подтверждённые SAF-папки, а не по внешним путям. При смене сети соединения закрываются. 

Передача выполняется по HTTP **без TLS**, поэтому рекомендуется только доверенная домашняя Wi-Fi-сеть; PIN защищает от случайного подключения, но **не шифрует** передаваемые книги. Не используйте на публичных сетях.

## Сборка

CI: `.github/workflows/release.yml` включает новые проверки Web Transfer и старые регрессии. Для полноценной сборки нужен Android SDK 35, JDK 17, Gradle 8.7 и зависимости Maven Central (добавлен `com.google.zxing:core:3.5.3` для локального QR-кода). Запуск проекта: `gradle :app:assembleRelease` (требуется окружение Android). Текущие локальные QA не заменяют Android-компиляцию или испытание на реальном устройстве.

В корне архива должны быть только четыре документа версии 1.11.192: README, CHANGELOG, QA-REPORT и TZ.
