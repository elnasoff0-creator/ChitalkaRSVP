Полные исходники Android-приложения «ПРОЧиталка» на основе версии 1.11.185-beta.

- `versionName`: `1.11.186-beta`
- `versionCode`: `18600`

- `minSdk`: 24; `targetSdk`: 35
- Java / Android Gradle Plugin; исходники: `app/src/main/`

## Изменения версии

1. Отказ от стандартного `TextView`-выделения с `ActionMode`. Собственный жест долгого нажатия, собственная панель с шестью векторными кнопками, межблочное выделение RecyclerView и единый символьный диапазон книги.
2. Новые акцентные маркеры выделения в виде каплевидных ручек Android: два зеркальных элемента, большая область касания, без жёстко заданного цвета.
3. Иконки словаря `ic_reader_selection_dictionary.xml` и `ic_edge_dictionary.xml` перерисованы контуром без заливки, толщина штриха 1,5.
4. Более частые, привязанные к реальным WordBoundary обновления подсветки; короткая 70-мс анимация цветовой насыщенности без смены шрифта и переноса строк. Постоянные аннотации отделены от обновляемой подсветки слова.
5. Общий прогресс-бар загрузки и прогресс глав Edge TTS показывают движущийся световой блик при активной работе; процент остаётся реальным. Кнопки «Пауза/Продолжить», «Скачать всё» и «Подготовить все» получают акцентную обводку при нажатии и активной задаче.
6. Сохранены цитатник, заметки, закладки, словарь TTS, совместимость с прежними данными, реплики питомца 50/50 и прежние механизмы Edge TTS.

## Проверка

Запустить в корне проекта:

```bash
bash qa/check_java_syntax.sh
bash qa/test_reader_selection_navigation_185.sh
bash qa/test_reader_touch_policy_186.sh
bash qa/test_word_boundary_refresh_186.sh
python3 qa/check_v186_contracts.py
```

Дополнительные тесты Edge, питомца и базы цитат перечислены в `QA-REPORT-v1.11.186-beta.md`. Workflow `.github/workflows/release.yml` проверяет контракты перед Android-сборкой.

**Внимание:** проверки исходников и тестов Java не равны Android Gradle-компиляции и тестированию UI на устройстве. APK в архив не входит. Для подтверждения выпускной сборки необходимо запустить GitHub Actions с Android SDK и настроенными ключами подписи.
