# ПРОЧиталка v1.11.160-beta CLEAN — изменения

База: **v1.11.159-beta CLEAN Full Source**. Полный исходный Android-проект.

## 1. Возвращено быстрое открытие HTML-книг

- Полностью удалена автоматическая синхронизация HTML-глав при возвращении в чтение: из `UnifiedBookSession.open()` больше не вызываются `HtmlFolderLibrary.syncIfChanged()` и `RanobeLibStorage.syncManualEdits()`.
- Удалены сами механизмы автоматической и ручной проверки изменённых HTML, класс сопоставления старого и нового положения `HtmlReadingAnchor`, а также пункт меню «Проверить изменения HTML».
- `ReaderBookCache.revision()` больше **не читает целиком HTML** для SHA-256 при открытии. Проверка состояния кэша использует дешёвые метаданные (для обычных файлов — размер и время изменения; для SAF — доступный размер файла).
- Старые RBI4-кэши с SHA-256 поддерживаются без принудительной повторной обработки книги, если метаданные исходного файла совпадают.
- При возвращении к уже открытой книге в том же процессе возвращается текущий `UnifiedBookSession` без повторного запроса состояния файлов.
- Индекс предложений `SentenceIndex` хранится в `UnifiedBookSession` и повторно используется `ReaderActivity`, Android TTS и Edge TTS.
- Фоновая докачка новых глав RanobeLIB инвалидирует индекс на диске, но **не уничтожает текущую сессию чтения**, чтобы возврат к экрану оставался быстрым.
- Ранее добавленный импорт папки HTML сохранён. Повторный выбор уже импортированной папки возвращает книгу без повторного сканирования и пересборки. Самопроизвольное обновление при изменении исходных файлов отключено.

**Изменение поведения:** заменённые вручную HTML-главы больше не подхватываются автоматически. Это сознательное возвращение к быстрому статическому кэшу по запросу пользователя. Для получения нового текста создайте отдельный импорт или используйте штатную загрузку новой версии книги. Точное сопоставление позиции по фрагментам HTML удалено.

## 2. Edge TTS — только законченные предложения

- Новый чистый Java-класс `EdgeSentenceBoundary` определяет естественные границы реплик по `.`, `!`, `?`, `…` и закрывающим кавычкам.
- Десятичные дроби и распространённые сокращения не создают лишние разрывы.
- `EdgeSpeechSegments.split()` собирает фрагменты только из **целых предложений**. 800 символов теперь мягкая целевая длина, а не жёсткая граница.
- В `priorityPieces()` удалено разделение текста на 500-символьные части при ручном переходе. Фрагмент начинается с выбранного слова и заканчивается на конце полной группы предложений.
- Оффлайн-подготовка Edge TTS использует те же границы и ключи сегментов, что и интерактивная озвучка.
- **Технический предел:** `EdgeSpeechEngine` по-прежнему отклоняет одиночный текстовый запрос более 4096 байт UTF-8. Искусственно разрезать такое предложение посередине программа теперь не будет, поэтому чрезмерно длинные предложения без финальной пунктуации могут потребовать исправления исходного текста.

## 3. Экран «Загрузки»

- Кнопка «Архив загрузок» перенесена из верхнего toolbar в строку заголовка «Загрузки», справа, вплотную к правому краю контейнера.
- Боковое меню закреплено слева. Остальные иконки верхней панели выровнены по правому краю.
- При нехватке ширины панель поисковых действий прокручивается горизонтально, боковое меню остаётся неподвижным.
