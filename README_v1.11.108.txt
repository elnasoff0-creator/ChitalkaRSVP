ПРОЧиталка 1.11.108-beta CLEAN — исходный проект Android

НОВОЕ: потоковый Edge TTS с подготовкой одного следующего MP3 после полного сохранения текущего; только один активный WebSocket через EdgeSpeechQueue. Пунктуация V1/V2/V3, пользовательский словарь, сохранение WordBoundary в координатах оригинального текста.

Настройка: «Настройки» -> «Аудио» -> «TTS» -> «Замена точки · Edge TTS» / «Словарь произношения · Edge TTS».
V1 — все обычные точки; V2 — кроме конца строки; V3 — только перед пробелом или табуляцией. Для словаря вводить по строке "оригинал=произношение". Набор RU.lexx не встроен.

Размеры: MAX/FIRST_TARGET/LIMIT=800, FIRST_TARGET_PRIORITY=500.
Старт первого блока остаётся потоковым; следующий запрашивается после сохранения текущего MP3, пока Media3 может продолжать его воспроизведение. До Play лишние следующие блоки не запрашиваются.

Проверка: bash qa/test_edge_text_transform.sh; bash qa/check_edge_serial_playback.sh; bash qa/check_java_syntax.sh и остальные qa/*.sh.
Системные зависимости: Android Gradle Plugin (см. build.gradle), Gradle, Android SDK. SDK недоступен в окружении подготовки, APK не собирался.

См. CHANGELOG_v1.11.108.txt и COMMIT_MESSAGE_v1.11.108.txt.
