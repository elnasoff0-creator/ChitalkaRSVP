# Утверждённое ТЗ: ПРОЧиталка v1.11.183-beta CLEAN

## 1. TTS-бейджи

Убрать дополнительные белые/цветные подложки; основная XML-иконка способа озвучивания и встроенная иконка Edge сохраняются. Бейдж остаётся справа внизу без изменения размера кнопки.

## 2. Меню ReaderActivity

Убрать устаревший пункт «Путь к файлам Edge TTS» для TTS и остальных режимов. Пункт «Загрузка озвучки» и его переход в единый менеджер текущей книги сохранить. Настройки папок находятся во вкладке «Общие», работу SAF не затрагивать.

## 3. Непрерывность Edge TTS

Устранить периодические зависания между предложениями и блоками: готовые следующие MP3 подключать к Media3 заранее, включая ситуацию, когда текущий MP3 ещё воспроизводится потоково. Если следующий MP3 ещё создаётся — показывать кольцо ожидания **вокруг** Pause, не перекрывая иконку; продолжать автоматически после получения данных. Не стартовать кольцо при готовом MP3. Обрабатывать `STATE_ENDED`, устаревшие и дублирующие callbacks, отмену live-источников, сетевые ошибки, пропуски по словарю, восстановление из SAF. Не повторять и не пропускать предложения; не нарушать паузу пользователя, таймер сна и приоритеты очередей.

## 4. Справочные значки

Во всех вкладках настроек располагать `?` в контейнере напротив заголовка или поясняемого параметра, без отдельных пустых строк, с областью касания минимум 48×48dp. Не ломать темы, отступы, переключатели, прокрутку и большие системные шрифты.

## 5. Регрессия и поставка

Сохранить функции v182, в том числе неделимые предложения Edge TTS и кеш, ссылки Ranobes, папки SAF, словарь и резервную озвучку. Прогнать автоматические проверки; сборку APK выполнить в GitHub Actions. CLEAN ZIP содержит только документы версии `1.11.183-beta`, без устаревших `.md`.
