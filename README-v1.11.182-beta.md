# ПРОЧиталка v1.11.182-beta CLEAN — исходный проект

Версия: `versionName 1.11.182-beta`, `versionCode 18200`. Полный Android Java-проект, Android Gradle Plugin 8.x / Java 17 / compileSdk 35; выпуск производится GitHub Actions из `.github/workflows/release.yml`.

Основа: **v1.11.181-beta CLEAN Ranobes URL Hotfix**. Все функции предыдущей версии сохранены, включая единый менеджер загрузок, словарь TTS и резервный голос.

## Новое

- Встроенная цветная `app/src/main/res/drawable-nodpi/ic_edge_official.webp` без необходимости устанавливать Microsoft Edge. Показывается в диалоге выбора способа озвучивания и на бейдже ReaderActivity.
- Длинные адреса Ranobes.net обрабатываются как URL, а не как поисковый запрос до 70 символов. Сохранены изменения URL Hotfix из v1.11.181.
- Пять настроек папок SAF перенесены из «Онлайн» в самый низ «Общие», под разделитель. Книги / Комиксы / Аудиокниги — русские названия. Выбранные URI и разрешения не изменяются.
- Удалён только пункт «Папка Book · Edge TTS» из настроек аудио; хранение книг и MP3 не изменено.
- Значок справки для «Редактирование меню» находится в строке заголовка справа, без пустой отдельной строки.
- Единые неделимые предложения в Edge TTS: основной и ускоренный синтез, переход к выбранному слову, скачивание книги. Лимиты 300–500 / 600–800 символов — **мягкие**, всегда округляются вниз по целым предложениям. Одно длинное предложение не разрезается.
- Учёт длины UTF-8 после применения словаря и XML-экранирования; недопустимо длинное одиночное предложение приводит к явному сообщению об ошибке, а не к обрезке или пропуску.
- Адаптивные размеры новых Edge-блоков на основании времени до первого MP3 и полного синтеза; структура готовой книги фиксируется в `edge-block-layout-v182.txt` в приватном кеше и не меняется вслед за колебаниями сети.
- Единая группа фрагментов для интерактивного чтения и массового скачивания через `UnifiedBookSession`.

## Проверки

Из корня проекта на компьютере с JDK 17+:

```bash
bash qa/test_edge_sentence_blocks_182.sh
python3 qa/check_v182_contracts.py
```

Полная сборка и подпись APK запускаются CI (для подписи требуются четыре `RELEASE_*` GitHub Secrets). В этой поставке полная сборка и проверка интерфейса на реальном Android **не выполнялись** — см. `QA-REPORT-v1.11.182-beta.md`.
