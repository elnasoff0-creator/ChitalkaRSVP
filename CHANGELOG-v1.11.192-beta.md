# Изменения в ПРОЧиталка v1.11.192-beta CLEAN

## Новое: Web Transfer
- Добавлен локальный HTTP Web Transfer (ручной запуск) с динамическим/заданным портом, привязкой к IP Wi-Fi и автоматической остановкой при потере сети или истечении времени простоя.
- Добавлена кнопка «Передача по Wi-Fi» с индивидуальной контурной иконкой в верхнем ряду «Загрузки» **на месте** «Подготовить книгу Edge».
- Удалён отдельный `EdgeFullBookActivity` и его регистрация в манифесте; **не удалён** `EdgeFullBookService`, используемый «Менеджером загрузок», существующими очередями и MP3/TTS.
- Добавлен экран WebTransferActivity: статус, IP:порт, временный PIN, QR-код, копирование адреса, число активных передач, запуск/остановка.
- Добавлена браузерная адаптивная страница для пакетной загрузки, Drag & Drop, индивидуального прогресса, отмены, ошибок и режима дубликатов.
- Вся загрузка потоковая, через временный файл с контролем размера, с атомарным по стадиям переносом в SAF-папку; после сохранения индексируются текстовые книги, комиксы и аудиокниги.
- Файлы не предоставляются для чтения/скачивания/удаления через HTTP.

## Настройки → Онлайн
- Web Transfer: порт (0=авто), таймер простоя (5/15/30/отключён), стратегия дубликатов (спрашивать/пропускать/новое имя), уведомления об окончании, ссылка на запуск.
- Базовые ограничения: локальный Wi-Fi, временный PIN, не более двух параллельных передач, никакого автозапуска.

## Настройки → Чтение: TTS
- Отдельный выключатель «Выделять произносимое слово», собственная цветовая палитра + RGB, прозрачность/интенсивность 5–100%, образец и сброс.
- Рендер слова использует `ReaderWordHighlightSpan(ttsWordHighlightColor,ttsWordHighlightOpacity)`; сохранён 70-мс fade без изменения геометрии текста. Ранее согласованные WordBoundary/Edge/MP3/автопрокрутка не переустраивались.
- Стандартный вид сохранён: цвет `0xffffda00`, включено, 100%.

## Общие вкладки
- `BrowserTabs` выделяет активную вкладку верхним и боковыми контурными штрихами с верхним скруглением, без нижнего индикатора. Накладывается на все экраны, использующие этот компонент.

## QA Hotfix — Java compileReleaseJavaWithJavac
- Исправлено повторное объявление `error` в `WebTransferServer.handle()`: байтовый массив HTTP-ответа переименован в `errorPayload`. Алгоритм обработки ошибок, заголовки и HTTP-статусы не изменены.
- Добавлен `qa/typecheck_web_transfer_server_192.sh`: автономная компиляция **всего `WebTransferServer.java`** с минимальными Android-заглушками. QA GitHub Actions запускает её перед `assembleRelease`, чтобы ловить ошибки типов и конфликтов локальных имён, не обнаруживаемые синтаксическим парсером.
- Версия Android-приложения остаётся `1.11.192-beta` (`versionCode 19200`); это исправление исходников без изменения версии.
