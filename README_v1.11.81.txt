ПРОЧиталка v1.11.81-beta CLEAN — исходный Android-проект

Обновление поверх v1.11.80-beta. В ZIP нет документации старых версий.

Ключевые классы:
- ReaderActivity: четыре режима в одном окне, единый RecyclerView, единое оглавление.
- UnifiedBookSession: общий immutable-снимок книги для UI и TTS-сервисов.
- ReaderBookCache: RBI3, восстановление текста, глав и смещений слов.
- EdgeStreamingService / AudioPlaybackService: используют общий сеанс книги.
- UiNavigationSheet: общие главы и текстовые блоки.
- SettingsActivity: новая настройка способа выбора слова в «Скорочтении».

Проверки без Android SDK:
  sh qa/check_java_syntax.sh
  sh qa/check_sentence_chunks.sh
  sh qa/test_shared_book_session.sh

Полная Android-сборка (через Android SDK/Gradle или GitHub Actions):
  gradle --no-daemon :app:assembleRelease --stacktrace

Что проверить на телефоне:
1. Открыть EPUB/FB2, сменить Чтение -> Курсор -> Скорочтение -> Озвучка -> Чтение. Позиция, оглавление и текст должны сохраниться без повторной загрузки окна.
2. Открыть оглавление во всех четырёх режимах. Для книг без глав используются крупные подготовленные UI-блоки.
3. В Скорочтении до Play виден обычный текст; после Play — слово с линиями. Тап выбирает слово, а свайп меняет выбранное слово только с включённой новой настройкой.
4. Для Edge TTS проверить первый потоковый Play, точную WordBoundary-подсветку, остановку и переключение предложений. Реальную работу WebSocket на Samsung статические тесты не подтверждают.
5. Проверить локальный TTS, включая нажатие Play до подготовки движка и сохранение позиции при переходах.
6. Проверить возврат из настроек, кнопку Назад, фон системных полос и отсутствие ненужной кнопки Play в обычном чтении.

ОГРАНИЧЕНИЕ: не поставляется APK; полноценная компиляция и тест на Samsung в этом окружении не проводились.
